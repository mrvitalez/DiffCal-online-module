1.4The Tangent and Velocity Problems

Before calculus, math was great at dealing with averages: average speed, the slope of a line, and so on. But then questions like "What is the speed exactly at this instant?" or "What is the slope of the curve at this exact point?" come up. Both questions seem impossible to answer, yet answering them is exactly what led to the derivative. Stewart §1.4 shows that both questions lead to the same new idea: the limit.

The tangent problem. For a circle, we define the tangent as the line that touches the circle exactly once. However, this definition does not cover what a tangent really is for other curves. A line can cross a curve exactly once and still not look like a tangent at all (for example, a vertical line through a parabola). And a line can be a true tangent at one point and still cut the curve again somewhere else.

So if we want the slope of the tangent line to a curve \(y = f(x)\) at a point \(P(a, f(a))\), how do we do that? A line's slope is easy: rise over run. But a curve doesn't have a single slope; its steepness is constantly changing. So, how do we define the slope at one exact point?

Let's try it with the parabola \(y = x^2\) at \(P(1, 1)\). We need two points, so let's take another point \(Q(x, x^2)\) on the parabola. The line \(PQ\) is a secant line, a line that intersects a curve more than once. Its slope is \[m_{PQ} = \frac{y_2 - y_1}{x_2 - x_1} = \frac{x^2 - 1}{x - 1}.\] For \(Q(1.5, 2.25)\): \(m_{PQ} = \dfrac{2.25 - 1}{1.5 - 1} = \dfrac{1.25}{0.5} = 2.5\). If we try more values:

The closer \(Q\) is to \(P\), the closer \(x\) is to 1, and the closer \(m_{PQ}\) is to 2. We say that the slope of the tangent line is the limit of the slopes of the secant lines, and we write \(\displaystyle\lim_{x \to 1} \frac{x^2 - 1}{x - 1} = 2\). Using the point-slope form \(y - y_1 = m(x - x_1)\), the tangent line is \(y - 1 = 2(x - 1)\), that is, \(y = 2x - 1\) (Figure 2.1). Figure 2.2 shows the same idea on another parabola.

In general, the slope of the secant line through \(P(a, f(a))\) and \(Q(x, f(x))\) is equation (1) below. As \(x \to a\), the secant line approaches the tangent line, so the tangent slope is the limit (2). This limit, if it exists, is called the derivative of \(f\) at \(a\), which we study in Module 3.

The velocity problem. In our physics class, we define the average velocity as the change in position over the change in time. Over the time interval from \(t\) to \(t + h\), that is equation (3). This tells us how fast the object moves on average, not at a precise moment. To find the instantaneous velocity, we shrink the interval to zero. That's basically the limit, equation (4). If this limit exists, it is the instantaneous velocity.

For example, suppose a ball is dropped from a building 450 m above the ground. The distance it has fallen after \(t\) seconds is \(s(t) = \tfrac12 gt^2 = 4.9t^2\) metres (with \(g = 9.8\) m/s²). How fast is it falling after 5 s? From \(t = 5\) to \(t = 5.1\): \[v_{\text{ave}} = \frac{4.9(5.1)^2 - 4.9(5)^2}{0.1} = \frac{127.449 - 122.5}{0.1} = 49.49 \text{ m/s}.\] Over 0.01 s we get 49.049 m/s, and over 0.001 s we get 49.0049 m/s. As we shrink the interval, the averages approach 49 m/s.

Notice that both problems are the same calculation. The slope of a secant line is an average rate of change; the slope of the tangent line is an instantaneous rate of change.

Take note If we substitute \(h = 0\) (or \(x = a\)) right away, the expression collapses to \(\tfrac00\). That does not mean there is no answer; it means we must simplify first. Also, do not cancel \(h\) before expanding: in \(\dfrac{(3 + h)^2 - 9}{h}\), the \(h\) is a factor only after expanding, \((3 + h)^2 - 9 = 6h + h^2 = h(6 + h)\). So for \(s(t) = t^2\), the velocity at \(t = 3\) is \(\lim_{h \to 0}(6 + h) = 6\).
Key equations
\[ (1)\quad m_{\text{sec}} = \frac{f(x) - f(a)}{x - a} \]
\[ (2)\quad m = \lim_{x \to a} \frac{f(x) - f(a)}{x - a} \]
\[ (3)\quad v_{\text{ave}} = \frac{\Delta s}{\Delta t} = \frac{s(t + h) - s(t)}{h} \]
\[ (4)\quad v(t) = \lim_{h \to 0} \frac{s(t + h) - s(t)}{h} \]

1.5The Limit of a Function

From the tangent and velocity problems, we can now give an intuitive definition of a limit. This topic answers the question "What value does a function approach as \(x\) gets close to a number?"

Definition 1 We write \(\displaystyle\lim_{x \to a} f(x) = L\) and say "the limit of \(f(x)\), as \(x\) approaches \(a\), equals \(L\)" if we can make the values of \(f(x)\) as close to \(L\) as we like by taking \(x\) sufficiently close to \(a\) (on either side of \(a\)) but not equal to \(a\).

An alternative notation is \(f(x) \to L\) as \(x \to a\). Notice that we did not define it with \(x = a\) but with \(x \to a\). That's because what we need is how \(f\) is defined near \(a\). The value \(f(a)\) plays no role; \(f(a)\) does not even have to exist.

Let's guess \(\displaystyle\lim_{x \to 1} \frac{x - 1}{x^2 - 1}\). From the left, \(x = 0.5, 0.9, 0.99, 0.999\) give \(0.666667, 0.526316, 0.502513, 0.500250\); from the right, \(x = 1.5, 1.1, 1.01, 1.001\) give \(0.400000, 0.476190, 0.497512, 0.499750\). As \(x\) gets closer to 1, the values reach toward 0.5. We can confirm it by factoring and then substituting: \[\lim_{x \to 1} \frac{x - 1}{(x - 1)(x + 1)} = \lim_{x \to 1} \frac{1}{x + 1} = \frac{1}{1 + 1} = \frac12.\]

Can a table fool us? Let's estimate \(\displaystyle\lim_{t \to 0} \frac{\sqrt{t^2 + 9} - 3}{t^2}\). For \(t = 1, 0.5, 0.1, 0.01\) a calculator gives \(0.162277, 0.165525, 0.166620, 0.166666\), so the limit looks like \(\tfrac16\). Multiplying by the conjugate confirms it: \(\dfrac{\sqrt{t^2 + 9} - 3}{t^2} \cdot \dfrac{\sqrt{t^2 + 9} + 3}{\sqrt{t^2 + 9} + 3} = \dfrac{1}{\sqrt{t^2 + 9} + 3} \to \dfrac16\). But for \(t = 0.000001\) the calculator shows \(0.166533\ldots\), and for \(t = 0.00000001\) it shows 0! Does that mean we got the wrong answer? No. Do you know why? For such tiny \(t\), \(\sqrt{t^2 + 9}\) is so close to 3 that the calculator rounds it to exactly 3 and the numerator becomes 0. The calculator is wrong, not the limit.

One-sided limits. We write \(\lim_{x \to a^-} f(x) = L\) (the left-hand limit) when we only let \(x\) approach \(a\) with \(x < a\). Similarly, the right-hand limit \(\lim_{x \to a^+} f(x) = L\) requires \(x > a\). In Figure 2.3, the left-hand limit of \(g\) at 2 is 3 and the right-hand limit is 1, so \(\lim_{x \to 2} g(x)\) does not exist. At 5 both one-sided limits are 2, so \(\lim_{x \to 5} g(x) = 2\), even though \(g(5) = 1\). Meaning: \[\lim_{x \to a} f(x) = L \iff \lim_{x \to a^-} f(x) = L \text{ and } \lim_{x \to a^+} f(x) = L.\]

Infinite limits. As \(x\) gets closer to 0, \(1/x^2\) becomes very large: \(x = 0.1\) gives 100, \(x = 0.01\) gives 10,000, \(x = 0.001\) gives 1,000,000. We write \(\lim_{x \to 0} \frac{1}{x^2} = \infty\). Likewise \(-1/x^2\) becomes very large negative, so \(\lim_{x \to 0} \left(-\frac{1}{x^2}\right) = -\infty\). Take note that the symbol \(\infty\) is not a number. Saying the limit is \(\infty\) is a precise way of saying it does not exist because the values blow up. The same notation works for one-sided limits.

The line \(x = a\) is a vertical asymptote if at least one one-sided limit at \(a\) is \(\infty\) or \(-\infty\). To find the sign, check the signs of the numerator and denominator on each side of \(a\) (Figure 2.4). If both are 0 at \(a\), simplify first: it may be a hole instead of an asymptote.

Key equations
\[ \lim_{x \to a} f(x) = L \iff \lim_{x \to a^-} f(x) = L = \lim_{x \to a^+} f(x) \]
\[ \lim_{x \to 0} \frac{1}{x^2} = \infty, \qquad \lim_{x \to 0} \left(-\frac{1}{x^2}\right) = -\infty \]
\[ \lim_{x \to a^+} f(x) = \pm\infty \text{ or } \lim_{x \to a^-} f(x) = \pm\infty \;\Rightarrow\; x = a \text{ is a vertical asymptote} \]

1.6Calculating Limits Using the Limit Laws

Tables and graphs only suggest a limit; we saw that a calculator can even give us 0 when the answer is \(\tfrac16\). So how do we compute limits exactly? Stewart §1.6 gives us the Limit Laws. If \(\lim_{x \to a} f(x)\) and \(\lim_{x \to a} g(x)\) both exist, then the limit of a sum, difference, constant multiple, product or quotient is the sum, difference, constant multiple, product or quotient of the limits. For a quotient, the limit of the denominator must not be 0. Powers and roots behave the same way.

Direct Substitution Property If \(f\) is a polynomial or a rational function and \(a\) is in the domain of \(f\), then \(\lim_{x \to a} f(x) = f(a)\).

So \(\lim_{x \to 2} (x^3 - 4x + 7) = 8 - 8 + 7 = 7\). Easy. The interesting cases are those where substitution gives \(\tfrac00\). Take note that \(\tfrac00\) is not an answer. It is a signal that we have to simplify first.

Our algebra tools.

  • Factor and cancel: \(\displaystyle\lim_{x \to 4} \frac{x^2 - 16}{x - 4} = \lim_{x \to 4} \frac{(x - 4)(x + 4)}{x - 4} = \lim_{x \to 4} (x + 4) = 8\).
  • Multiply by the conjugate (when there is a square root): \(\displaystyle\lim_{x \to 0} \frac{\sqrt{x + 4} - 2}{x} = \lim_{x \to 0} \frac{(x + 4) - 4}{x(\sqrt{x + 4} + 2)} = \lim_{x \to 0} \frac{1}{\sqrt{x + 4} + 2} = \frac14\).
  • Combine fractions: put a compound fraction over a common denominator, then cancel.
  • Absolute values and piecewise functions: compute the left- and right-hand limits separately, then compare.

But wait. Why are we allowed to cancel? The function \(\frac{x^2 - 16}{x - 4}\) is undefined at 4, while \(x + 4\) is not, so they are different functions. However, they agree at every \(x \ne 4\). Recall that a limit as \(x \to 4\) never looks at \(x = 4\) itself. So their limits are the same. If after simplifying we get a nonzero number over 0, the limit is infinite or does not exist, and we check the one-sided limits as in §1.5.

The Squeeze Theorem. Some limits cannot be done by algebra. If \(g(x) \le f(x) \le h(x)\) near \(a\) (except possibly at \(a\)) and \(\lim_{x \to a} g(x) = \lim_{x \to a} h(x) = L\), then \(\lim_{x \to a} f(x) = L\) too. Think of \(f\) as trapped between two functions that meet at \(L\). For example, \(\cos(1/x)\) wobbles between \(-1\) and \(1\), so \(-x^2 \le x^2\cos(1/x) \le x^2\). Both outer functions approach 0, so \(\lim_{x \to 0} x^2\cos(1/x) = 0\) (Figure 2.6).

Common mistake We cannot use the Product Law on \(x^2\cos(1/x)\), because \(\lim_{x \to 0}\cos(1/x)\) does not exist. That is exactly when we need the Squeeze Theorem.
Key equations
\[ \lim_{x \to a} [f(x) \pm g(x)] = \lim_{x \to a} f(x) \pm \lim_{x \to a} g(x), \qquad \lim_{x \to a} [f(x)g(x)] = \lim_{x \to a} f(x) \cdot \lim_{x \to a} g(x) \]
\[ \lim_{x \to a} \frac{f(x)}{g(x)} = \frac{\lim_{x \to a} f(x)}{\lim_{x \to a} g(x)} \quad \text{if } \lim_{x \to a} g(x) \ne 0 \]
\[ g(x) \le f(x) \le h(x),\; \lim_{x \to a} g(x) = \lim_{x \to a} h(x) = L \;\Rightarrow\; \lim_{x \to a} f(x) = L \]

1.7The Precise Definition of a Limit

In §1.5 we said "as close to \(L\) as we like" and "sufficiently close to \(a\)". But how close is close? These words are vague. Stewart §1.7 makes them precise using two small positive numbers, \(\varepsilon\) (epsilon) and \(\delta\) (delta).

Definition \(\displaystyle\lim_{x \to a} f(x) = L\) means: for every number \(\varepsilon > 0\) there is a number \(\delta > 0\) such that \[\text{if } 0 < |x - a| < \delta \text{ then } |f(x) - L| < \varepsilon.\]

What does this actually mean? The epsilon \(\varepsilon\) represents how "close" we want \(f(x)\) to be to \(L\). Think of it as how close the output will be. On the other hand, the delta \(\delta\) represents how "close" \(x\) must be to \(a\), that is, how close the input must be. The part \(0 < |x - a|\) says, once again, that \(x = a\) itself does not count.

Let's read it as a challenge. Someone gives us a tolerance \(\varepsilon\) for the output. We must answer with a distance \(\delta\) for the input, so that every \(x\) within \(\delta\) of \(a\) gives an output within \(\varepsilon\) of \(L\). On a graph: over the interval \((a - \delta, a + \delta)\), the curve must stay inside the horizontal band between \(L - \varepsilon\) and \(L + \varepsilon\) (Figure 2.7).

A smaller \(\varepsilon\) usually forces a smaller \(\delta\). And the definition demands a \(\delta\) for every \(\varepsilon\), however tiny. So checking a few values is not enough; we must give a formula for \(\delta\) in terms of \(\varepsilon\). That is why every proof has two stages. First, the scratch work: start from \(|f(x) - L| < \varepsilon\) and work backwards until we get \(|x - a| < \text{something}\). Second, the proof itself, written forwards: given \(\varepsilon\), state \(\delta\), assume \(0 < |x - a| < \delta\), and show that \(|f(x) - L| < \varepsilon\).

A linear example. Let's prove \(\lim_{x \to -1} (5x + 2) = -3\). Scratch work: \(|f(x) - L| = |5x + 2 + 3| = |5x + 5| = 5|x + 1|\). We want \(5|x + 1| < \varepsilon\), that is, \(|x + 1| < \varepsilon/5\). So we choose \(\delta = \varepsilon/5\). Proof: given \(\varepsilon > 0\), let \(\delta = \varepsilon/5\). If \(0 < |x + 1| < \delta\), then \(|(5x + 2) - (-3)| = 5|x + 1| < 5\delta = \varepsilon\).

A quadratic example. Now let's prove \(\lim_{x \to 2} x^2 = 4\). This time \(|x^2 - 4| = |x - 2|\,|x + 2|\), and the factor \(|x + 2|\) is not constant. So how do we control it? We first agree that \(\delta \le 1\). Then \(|x - 2| < 1\) gives \(1 < x < 3\), so \(|x + 2| < 5\). Now \(|x^2 - 4| < 5|x - 2|\), which is less than \(\varepsilon\) when \(|x - 2| < \varepsilon/5\). We choose \(\delta = \min\{1, \varepsilon/5\}\). Why the min? Because \(\delta\) has two jobs: keep \(|x + 2| < 5\), and make \(5|x - 2| < \varepsilon\). The smaller of the two numbers does both jobs. With \(\varepsilon = 0.5\), for example, \(\delta = 0.1\).

Common mistake \(\delta\) may depend on \(\varepsilon\) and \(a\), but never on \(x\). An answer like "\(\delta = \varepsilon/|x + 2|\)" is not allowed; that is why we bound \(|x + 2|\) by a constant.
Key equations
\[ \lim_{x \to a} f(x) = L \iff \forall \varepsilon \gt 0\ \exists \delta \gt 0:\ 0 \lt |x - a| \lt \delta \Rightarrow |f(x) - L| \lt \varepsilon \]

1.8Continuity

Recall that for polynomials, finding a limit was as easy as substituting. Wouldn't it be nice if every function were like that? Stewart §1.8 gives a name to the functions with this property.

Definition A function \(f\) is continuous at \(a\) if \(\displaystyle\lim_{x \to a} f(x) = f(a)\).

Notice that this one equation asks for three things: \(f(a)\) is defined, \(\lim_{x \to a} f(x)\) exists, and the two are equal. Informally, we can draw the graph near \(a\) without lifting our pen. If \(f\) is not continuous at \(a\), we say \(f\) has a discontinuity there. There are three common types:

  • Removable: the limit exists, but \(f(a)\) is missing or has the wrong value, for example \(\dfrac{x^2 - 9}{x - 3}\) at 3. Redefining one value fixes it. The function \(g\) of Figure 2.3 has a removable discontinuity at 5.
  • Jump: the one-sided limits exist but are different, as for \(\dfrac{|x|}{x}\) at 0, or \(g\) at 2.
  • Infinite: a one-sided limit is \(\pm\infty\), as for \(\dfrac{1}{x - 2}\) at 2.

We also say \(f\) is continuous from the right at \(a\) if \(\lim_{x \to a^+} f(x) = f(a)\) (similarly from the left), and continuous on an interval if it is continuous at every number in it. The good news: polynomials, rational functions, root functions and trigonometric functions are continuous at every number in their domains. Sums, products, quotients and compositions of continuous functions are continuous too. So \(\sqrt{x^2 + 1}\,\sin x\), for instance, is continuous everywhere.

The Intermediate Value Theorem Suppose \(f\) is continuous on the closed interval \([a, b]\), \(f(a) \ne f(b)\), and \(N\) is any number between \(f(a)\) and \(f(b)\). Then there is a number \(c\) in \((a, b)\) with \(f(c) = N\).

What is this good for? Finding roots. Let \(f(x) = x^3 + 2x - 5\). Then \(f(1) = 1 + 2 - 5 = -2 < 0\) and \(f(2) = 8 + 4 - 5 = 7 > 0\). Since \(f\) is a polynomial, it is continuous, so with \(N = 0\) the IVT tells us the equation \(x^3 + 2x - 5 = 0\) has a root between 1 and 2 (Figure 2.8; it is about 1.33). Take note that the IVT tells us a root exists; it does not tell us exactly where.

Common mistake Do not forget to check continuity. For \(1/x\) on \([-1, 1]\), the endpoint values have opposite signs, yet there is no root, because the function is not continuous at 0.
Key equations
\[ f \text{ continuous at } a \iff \lim_{x \to a} f(x) = f(a) \]
\[ f \text{ continuous on } [a, b],\ N \text{ between } f(a), f(b) \;\Rightarrow\; f(c) = N \text{ for some } c \in (a, b) \]

★Key takeaways

  • The slope of a tangent line and an instantaneous velocity are both limits: m = lim (f(x) − f(a))/(x − a) as x → a, and v(t) = lim (s(t + h) − s(t))/h as h → 0.
  • lim f(x) = L as x → a depends only on the values of f near a, never on f(a); the two-sided limit exists exactly when the left- and right-hand limits agree.
  • ∞ is not a number: a limit of ±∞ means the values blow up, and the line x = a is then a vertical asymptote; check the signs on each side.
  • A result of 0/0 is not an answer. Simplify first: factor, multiply by the conjugate or combine fractions; use the Squeeze Theorem when algebra cannot help.
  • In the ε–δ definition, ε says how close the output must be to L and δ says how close the input must be to a; δ may depend on ε but never on x.
  • f is continuous at a when lim f(x) = f(a); the Intermediate Value Theorem guarantees a root of a continuous function between two points where its sign changes.

Example 2.1 Tangent line to y = √x

Find an equation of the tangent line to the curve \(y = \sqrt{x}\) at the point \(P(4, 2)\).

(Stewart §1.4 (the tangent problem))
Show solution (try it first)
Given
  • \(f(x) = \sqrt{x}\), \(a = 4\), \(f(a) = \sqrt{4} = 2\).
  • Asked: the slope \(m\) of the tangent at \(P(4, 2)\) and the equation of the tangent line.
Step 1: Set up the limit for the slope

We use the tangent-slope formula with \(a = 4\).

\[m = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}\]

\[m = \lim_{x \to 4} \frac{\sqrt{x} - 2}{x - 4}\]

Step 2: Multiply by the conjugate

If we substitute \(x = 4\) right away, the expression collapses to \(\tfrac00\). So let's multiply the top and bottom by the conjugate \(\sqrt{x} + 2\) first.

\[m = \lim_{x \to 4} \frac{\sqrt{x} - 2}{x - 4} \cdot \frac{\sqrt{x} + 2}{\sqrt{x} + 2}\]

\[= \lim_{x \to 4} \frac{(\sqrt{x})^2 - 2^2}{(x - 4)(\sqrt{x} + 2)}\]

\[= \lim_{x \to 4} \frac{x - 4}{(x - 4)(\sqrt{x} + 2)}\]

Step 3: Cancel and substitute

Now \(x - 4\) is a common factor, so we can cancel it (\(x \ne 4\)), and then substitute.

\[m = \lim_{x \to 4} \frac{1}{\sqrt{x} + 2}\]

\[= \frac{1}{\sqrt{4} + 2} = \frac{1}{2 + 2} = \frac14\]

Step 4: Write the tangent line

Use the point-slope form \(y - y_1 = m(x - x_1)\) with \(P(4, 2)\) and \(m = \tfrac14\).

\[y - 2 = \tfrac14(x - 4)\]

\[y - 2 = \tfrac14 x - 1\]

\[y = \tfrac14 x + 1\]

Answer

The slope is \(m = \tfrac14\), so the tangent line is \(y = \tfrac14 x + 1\).

Check

At \(x = 4\): \(\tfrac14(4) + 1 = 2\), so the line passes through \(P\). A secant check: from \(x = 4\) to \(x = 4.01\), \(\dfrac{\sqrt{4.01} - 2}{0.01} \approx 0.2498\), close to \(0.25\).

Example 2.2 Tangent line to y = x³

Find the equation of the tangent line to the curve \(y = x^3\) at the point \(P(2, 8)\).

(Stewart §1.4 (the tangent problem))
Show solution (try it first)
Given
  • \(f(x) = x^3\), \(a = 2\), \(f(a) = 2^3 = 8\).
  • Asked: the tangent slope \(m\) at \(P(2, 8)\) and the tangent line.
Step 1: Set up the limit for the slope

Substitute \(f(x) = x^3\) and \(f(2) = 8\) into the tangent-slope formula.

\[m = \lim_{x \to 2} \frac{f(x) - f(a)}{x - a}\]

\[= \lim_{x \to 2} \frac{x^3 - 8}{x - 2}\]

Step 2: Factor the difference of cubes

Direct substitution gives \(\tfrac00\). Recall \(a^3 - b^3 = (a - b)(a^2 + ab + b^2)\), so the numerator has the factor \(x - 2\).

\[x^3 - 8 = x^3 - 2^3 = (x - 2)(x^2 + 2x + 4)\]

\[m = \lim_{x \to 2} \frac{(x - 2)(x^2 + 2x + 4)}{x - 2}\]

Step 3: Cancel and substitute

Cancel \(x - 2\) (allowed because \(x \ne 2\)), then substitute \(x = 2\).

\[m = \lim_{x \to 2} (x^2 + 2x + 4)\]

\[= 2^2 + 2(2) + 4\]

\[= 4 + 4 + 4 = 12\]

Step 4: Write the tangent line

Point-slope form with \(P(2, 8)\) and \(m = 12\):

\[y - 8 = 12(x - 2)\]

\[y - 8 = 12x - 24\]

\[y = 12x - 16\]

Answer

So the equation of the tangent line is \(y = 12x - 16\).

Check

At \(x = 2\): \(12(2) - 16 = 8\). Good. The secant slope from \(x = 2\) to \(x = 2.01\) is \(\dfrac{2.01^3 - 8}{0.01} = 12.0601\), close to 12.

Example 2.3 Estimating an instantaneous velocity

If a ball is thrown into the air with a velocity of 40 ft/s, its height in feet \(t\) seconds later is given by \(y = 40t - 16t^2\). Estimate the instantaneous velocity when \(t = 2\) by using the time intervals \([2, 2.1]\) and \([1.9, 2]\).

(Stewart §1.4 (the velocity problem))
Show solution (try it first)
Given
  • Height: \(y(t) = 40t - 16t^2\) (feet), time \(t\) in seconds.
  • Time step: \(h = 0.1\) s, on each side of \(t = 2\).
  • Asked: an estimate of the instantaneous velocity at \(t = 2\).
Step 1: Compute the heights we need

Let's find \(y(1.9)\), \(y(2)\) and \(y(2.1)\) first.

\[y(2) = 40(2) - 16(2)^2 = 80 - 64 = 16\]

\[y(2.1) = 40(2.1) - 16(2.1)^2 = 84 - 16(4.41) = 84 - 70.56 = 13.44\]

\[y(1.9) = 40(1.9) - 16(1.9)^2 = 76 - 16(3.61) = 76 - 57.76 = 18.24\]

Step 2: Average velocity just after t = 2

Use \(v_{\text{ave}} = \dfrac{\Delta y}{\Delta t}\) on \([2, 2.1]\).

\[v_{\text{ave}} = \frac{y(2.1) - y(2)}{0.1} = \frac{13.44 - 16}{0.1} = \frac{-2.56}{0.1} = -25.6 \text{ ft/s}\]

Step 3: Average velocity just before t = 2

Now on \([1.9, 2]\).

\[v_{\text{ave}} = \frac{y(2) - y(1.9)}{0.1} = \frac{16 - 18.24}{0.1} = \frac{-2.24}{0.1} = -22.4 \text{ ft/s}\]

Step 4: Average the two estimates

The true value lies between the two, so let's take their average.

\[v(2) \approx \frac{-25.6 + (-22.4)}{2} = \frac{-48}{2} = -24 \text{ ft/s}\]

Answer

The instantaneous velocity at \(t = 2\) is about \(-24\) ft/s. The minus sign tells us the ball is already on its way down, moving at about 24 ft/s.

Check

Exactly: \(\dfrac{y(2 + h) - y(2)}{h} = \dfrac{-24h - 16h^2}{h} = -24 - 16h \to -24\) as \(h \to 0\). Take note of the sign: a negative velocity means the height is decreasing.

Example 2.4 One-sided infinite limits

Find \(\displaystyle\lim_{x \to 3^+} \frac{2x}{x - 3}\) and \(\displaystyle\lim_{x \to 3^-} \frac{2x}{x - 3}\). What does this say about the graph of \(y = \dfrac{2x}{x - 3}\)?

(Stewart §1.5 (infinite limits))
Show solution (try it first)
Given
  • \(f(x) = \dfrac{2x}{x - 3}\), with \(x \to 3\) from the right and from the left.
  • Asked: both one-sided limits and what they tell us about the graph.
Step 1: Try substitution

At \(x = 3\) the numerator is \(2(3) = 6\) and the denominator is \(3 - 3 = 0\). A nonzero number over 0 means the values blow up, so the answer is \(\infty\) or \(-\infty\). We only need the sign.

Step 2: Signs when x is a little more than 3

If \(x > 3\) and close to 3, the numerator is close to 6 (positive) and \(x - 3\) is a small positive number.

\[\frac{\text{about } 6}{\text{small positive}} = \text{large positive}\]

For example, \(x = 3.01\) gives \(\dfrac{6.02}{0.01} = 602\). So \(\displaystyle\lim_{x \to 3^+} \frac{2x}{x - 3} = \infty\).

Step 3: Signs when x is a little less than 3

If \(x < 3\) and close to 3, the numerator is still close to 6, but \(x - 3\) is a small negative number.

\[\frac{\text{about } 6}{\text{small negative}} = \text{large negative}\]

For example, \(x = 2.99\) gives \(\dfrac{5.98}{-0.01} = -598\). So \(\displaystyle\lim_{x \to 3^-} \frac{2x}{x - 3} = -\infty\).

Answer

\(\displaystyle\lim_{x \to 3^+} \frac{2x}{x - 3} = \infty\) and \(\displaystyle\lim_{x \to 3^-} \frac{2x}{x - 3} = -\infty\). So the line \(x = 3\) is a vertical asymptote: the graph shoots up on the right of it and down on the left.

Example 2.5 Limits of the form 0/0

Evaluate (a) \(\displaystyle\lim_{x \to -2} \frac{x^2 + 5x + 6}{x^2 - 4}\) and (b) \(\displaystyle\lim_{x \to 3} \frac{\frac{1}{x} - \frac13}{x - 3}\).

(Stewart §1.6 (factoring and common denominators))
Show solution (try it first)
Given
  • (a) a rational function at \(x = -2\); (b) a compound fraction at \(x = 3\).
  • Substitution gives \(\tfrac{4 - 10 + 6}{4 - 4} = \tfrac00\) in (a) and \(\tfrac{1/3 - 1/3}{0} = \tfrac00\) in (b), so we must simplify first.
Step 1: (a) Factor the top and bottom

Factor both so the common factor \(x + 2\) shows.

\[x^2 + 5x + 6 = (x + 2)(x + 3)\]

\[x^2 - 4 = (x + 2)(x - 2)\]

Step 2: (a) Cancel and substitute

Cancel \(x + 2\) (since \(x \ne -2\)), then substitute.

\[\lim_{x \to -2} \frac{(x + 2)(x + 3)}{(x + 2)(x - 2)} = \lim_{x \to -2} \frac{x + 3}{x - 2}\]

\[= \frac{-2 + 3}{-2 - 2} = \frac{1}{-4} = -\frac14\]

Step 3: (b) Combine the fractions in the numerator

Use the common denominator \(3x\).

\[\frac1x - \frac13 = \frac{3}{3x} - \frac{x}{3x} = \frac{3 - x}{3x} = \frac{-(x - 3)}{3x}\]

Step 4: (b) Divide by x − 3 and cancel

Dividing by \(x - 3\) is the same as multiplying by \(\frac{1}{x - 3}\).

\[\frac{\frac1x - \frac13}{x - 3} = \frac{-(x - 3)}{3x} \cdot \frac{1}{x - 3} = -\frac{1}{3x} \quad (x \ne 3)\]

\[\lim_{x \to 3} \left(-\frac{1}{3x}\right) = -\frac{1}{3(3)} = -\frac19\]

Answer

(a) \(-\tfrac14\); (b) \(-\tfrac19\).

Check

(a) At \(x = -2.01\) the original fraction is \(\dfrac{-0.0099}{0.0401} \approx -0.247\), close to \(-0.25\). (b) At \(x = 3.1\): \(\dfrac{1/3.1 - 1/3}{0.1} \approx -0.1075\), close to \(-0.111\). A common error in (b) is to write \(3 - x = x - 3\) and lose the minus sign.

Example 2.6 An ε–δ proof for a quadratic

Use the \(\varepsilon\)–\(\delta\) definition to prove that \(\displaystyle\lim_{x \to 3} (x^2 - 2x) = 3\).

(Stewart §1.7 (the precise definition))
Show solution (try it first)
Given
  • \(f(x) = x^2 - 2x\), \(a = 3\), \(L = 3\).
  • Asked: for every \(\varepsilon > 0\), a \(\delta > 0\) such that \(0 < |x - 3| < \delta\) implies \(|f(x) - 3| < \varepsilon\).
Step 1: Scratch work, factor |f(x) − L|

We want the factor \(|x - 3|\) to appear, because that is what \(\delta\) controls.

\[|(x^2 - 2x) - 3| = |x^2 - 2x - 3|\]

\[= |(x - 3)(x + 1)| = |x - 3|\,|x + 1|\]

Step 2: Scratch work, bound the extra factor

The factor \(|x + 1|\) is not constant, so let's agree that \(\delta \le 1\). Then \(|x - 3| < 1\) means:

\[2 < x < 4\]

\[3 < x + 1 < 5, \quad\text{so } |x + 1| < 5\]

\[|x - 3|\,|x + 1| < 5|x - 3|\]

This is less than \(\varepsilon\) if \(|x - 3| < \varepsilon/5\). So we choose \(\delta = \min\{1, \varepsilon/5\}\).

Step 3: Write the proof forwards

Let \(\varepsilon > 0\) be given and let \(\delta = \min\{1, \varepsilon/5\}\). Suppose \(0 < |x - 3| < \delta\).

Since \(\delta \le 1\): \(|x - 3| < 1\), so \(|x + 1| < 5\).

Since \(\delta \le \varepsilon/5\): \(|x - 3| < \varepsilon/5\).

\[|(x^2 - 2x) - 3| = |x - 3|\,|x + 1| < \frac{\varepsilon}{5} \cdot 5 = \varepsilon\]

Answer

With \(\delta = \min\{1, \varepsilon/5\}\), the definition is satisfied, so \(\displaystyle\lim_{x \to 3} (x^2 - 2x) = 3\).

Check

Try \(\varepsilon = 0.5\): \(\delta = \min\{1, 0.1\} = 0.1\). At \(x = 3.1\) (the edge): \(3.1^2 - 2(3.1) = 9.61 - 6.2 = 3.41\), and \(|3.41 - 3| = 0.41 < 0.5\). Good. Remember: \(\delta\) depends on \(\varepsilon\) only, never on \(x\).
