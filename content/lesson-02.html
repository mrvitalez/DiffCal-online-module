1.4The Tangent and Velocity Problems

Calculus grew out of two questions: how steep is a curve at a single point, and how fast is an object moving at a single instant? Stewart §1.4 shows that both questions lead to the same new idea, the limit.

The tangent problem. A tangent line to a curve at a point \(P\) is the line that "just touches" the curve there and has the same direction as the curve. To find its slope you need two points, but you only know one. The trick is to pick a second point \(Q\) on the curve, compute the slope of the secant line \(PQ\), and then let \(Q\) slide toward \(P\).

Take \(y = \tfrac12 x^2 + 1\) and \(P(2, 3)\). If \(Q\) has \(x\)-coordinate \(2 + h\), the secant slope is \[m_{PQ} = \frac{\tfrac12(2 + h)^2 + 1 - 3}{h} = \frac{2h + \tfrac12 h^2}{h} = 2 + \tfrac12 h.\] With \(h = 1, 0.1, 0.01\) the slopes are \(2.5, 2.05, 2.005\). As \(h\) approaches 0 the slopes approach 2, so the tangent line at \(P\) has slope \(m = 2\) and equation \(y - 3 = 2(x - 2)\).

The velocity problem. If \(s(t)\) is the position of an object at time \(t\), its average velocity over the time interval \([a, a + h]\) is \[\text{average velocity} = \frac{\text{change in position}}{\text{time elapsed}} = \frac{s(a + h) - s(a)}{h}.\] The instantaneous velocity at time \(a\) is the number that these averages approach as \(h\) shrinks to 0. For a stone dropped from a bridge with \(s(t) = 5t^2\) metres (using \(g \approx 10\) m/s²), the average velocity on \([1, 1 + h]\) is \(\dfrac{5(1 + h)^2 - 5}{h} = 10 + 5h\), which approaches 10 m/s.

Notice that the two problems are the same calculation: the slope of a secant line is an average rate of change, and the slope of the tangent line is an instantaneous rate of change. In both cases you cannot just put \(h = 0\), because that gives the meaningless \(\tfrac00\). You must first simplify, then see what happens as \(h\) gets close to 0.

Common mistake Do not cancel \(h\) before expanding. In \(\dfrac{(2 + h)^2 - 4}{h}\) the \(h\) is not a factor of the numerator until you expand: \((2 + h)^2 - 4 = 4h + h^2 = h(4 + h)\).
Key equations
\[ m_{PQ} = \frac{f(a + h) - f(a)}{h}, \qquad m = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h} \]
\[ v_{\text{avg}} = \frac{s(a + h) - s(a)}{h}, \qquad v(a) = \lim_{h \to 0} \frac{s(a + h) - s(a)}{h} \]

1.5The Limit of a Function

Stewart §1.5 gives the informal meaning of a limit. We write \[\lim_{x \to a} f(x) = L\] and say "the limit of \(f(x)\), as \(x\) approaches \(a\), equals \(L\)" if we can make \(f(x)\) as close to \(L\) as we like by taking \(x\) close enough to \(a\) (on either side), but not equal to \(a\).

That last phrase matters: the value \(f(a)\) plays no role. The function \(f(x) = \dfrac{x^2 - 4}{x - 2}\) is undefined at 2, yet a table with \(x = 1.9, 1.99, 2.01, 2.1\) gives \(3.9, 3.99, 4.01, 4.1\), so \(\lim_{x \to 2} f(x) = 4\). A table only suggests a limit; guessing from a few values can mislead you, which is why we need the limit laws of §1.6.

One-sided limits. We write \(\lim_{x \to a^-} f(x) = L\) when \(f(x)\) approaches \(L\) as \(x\) approaches \(a\) from the left (\(x < a\)), and \(\lim_{x \to a^+} f(x) = L\) for the right (\(x > a\)). The two-sided limit exists exactly when both one-sided limits exist and are equal: \[\lim_{x \to a} f(x) = L \iff \lim_{x \to a^-} f(x) = L \text{ and } \lim_{x \to a^+} f(x) = L.\] For \(f(x) = \dfrac{|x|}{x}\), the left limit at 0 is \(-1\) and the right limit is \(1\), so \(\lim_{x \to 0} f(x)\) does not exist.

Infinite limits. Sometimes \(f(x)\) grows without bound. We write \(\lim_{x \to a} f(x) = \infty\) if \(f(x)\) can be made as large as we like by taking \(x\) close enough to \(a\), and similarly \(-\infty\). For example, \(\lim_{x \to 1} \dfrac{1}{(x - 1)^2} = \infty\) because the denominator is a tiny positive number near 1. The symbol \(\infty\) is not a number; saying the limit is \(\infty\) is a precise way of saying it does not exist because the values blow up.

The line \(x = a\) is a vertical asymptote of \(y = f(x)\) if at least one one-sided limit at \(a\) is \(\infty\) or \(-\infty\). To decide the sign, look at the signs of numerator and denominator just to the left and right of \(a\). For \(\dfrac{x + 1}{x - 3}\): near 3 the numerator is about 4; the denominator is a small negative number for \(x < 3\) and a small positive number for \(x > 3\). So the left limit is \(-\infty\) and the right limit is \(\infty\). Vertical asymptotes appear where a denominator is zero but the numerator is not; if both are zero, simplify first, because the result may be a hole instead of an asymptote.

Key equations
\[ \lim_{x \to a} f(x) = L \iff \lim_{x \to a^-} f(x) = L = \lim_{x \to a^+} f(x) \]
\[ \lim_{x \to a^+} f(x) = \pm\infty \text{ or } \lim_{x \to a^-} f(x) = \pm\infty \;\Rightarrow\; x = a \text{ is a vertical asymptote} \]

1.6Calculating Limits Using the Limit Laws

Tables and graphs only suggest limits. Stewart §1.6 gives rules that compute them exactly. If \(\lim_{x \to a} f(x)\) and \(\lim_{x \to a} g(x)\) both exist, the Limit Laws say that the limit of a sum, difference, constant multiple, product or quotient is the sum, difference, constant multiple, product or quotient of the limits (for a quotient, provided the limit of the denominator is not 0). Powers and roots behave the same way.

Direct Substitution Property If \(f\) is a polynomial or a rational function and \(a\) is in the domain of \(f\), then \(\lim_{x \to a} f(x) = f(a)\).

So \(\lim_{x \to 2} (x^3 - 4x + 7) = 8 - 8 + 7 = 7\). The interesting cases are those where substitution gives \(\tfrac00\). This is not an answer; it is a signal to simplify first, using the fact that if \(f(x) = g(x)\) for all \(x \ne a\) near \(a\), then the two functions have the same limit at \(a\).

Algebraic tricks.

  • Factor and cancel: \(\displaystyle\lim_{x \to 4} \frac{x^2 - 16}{x - 4} = \lim_{x \to 4} (x + 4) = 8\).
  • Multiply by the conjugate: \(\displaystyle\lim_{x \to 0} \frac{\sqrt{x + 4} - 2}{x} = \lim_{x \to 0} \frac{(x + 4) - 4}{x(\sqrt{x + 4} + 2)} = \lim_{x \to 0} \frac{1}{\sqrt{x + 4} + 2} = \frac14\).
  • Combine fractions: put a compound fraction over a common denominator, then cancel.
  • Absolute values and piecewise functions: compute the left and right limits separately.

Why is cancelling allowed? The function \(\frac{x^2 - 16}{x - 4}\) is undefined at 4, while \(x + 4\) is not, so they are different functions. But they agree at every \(x \ne 4\), and a limit as \(x \to 4\) never looks at \(x = 4\) itself. So their limits are the same. If after simplifying you get a nonzero number over 0, the limit is infinite or does not exist; check the one-sided limits as in §1.5.

The Squeeze Theorem. Some limits cannot be found by algebra. If \(g(x) \le f(x) \le h(x)\) near \(a\) (except possibly at \(a\)) and \(\lim_{x \to a} g(x) = \lim_{x \to a} h(x) = L\), then \(\lim_{x \to a} f(x) = L\) as well: \(f\) is trapped between two functions that meet at \(L\). For example, \(\cos(1/x)\) wobbles between \(-1\) and \(1\), so \(-x^2 \le x^2\cos(1/x) \le x^2\). Both outer functions approach 0, so \(\lim_{x \to 0} x^2\cos(1/x) = 0\).

Common mistake You cannot use the Product Law on \(x^2\cos(1/x)\), because \(\lim_{x \to 0}\cos(1/x)\) does not exist. That is exactly when the Squeeze Theorem is needed.
Key equations
\[ \lim_{x \to a} [f(x) \pm g(x)] = \lim_{x \to a} f(x) \pm \lim_{x \to a} g(x), \qquad \lim_{x \to a} [f(x)g(x)] = \lim_{x \to a} f(x) \cdot \lim_{x \to a} g(x) \]
\[ \lim_{x \to a} \frac{f(x)}{g(x)} = \frac{\lim_{x \to a} f(x)}{\lim_{x \to a} g(x)} \quad \text{if } \lim_{x \to a} g(x) \ne 0 \]
\[ g(x) \le f(x) \le h(x),\; \lim_{x \to a} g(x) = \lim_{x \to a} h(x) = L \;\Rightarrow\; \lim_{x \to a} f(x) = L \]

1.7The Precise Definition of a Limit

"As close as we like" and "close enough" in §1.5 are vague. Stewart §1.7 makes them precise using two small positive numbers, \(\varepsilon\) (epsilon) and \(\delta\) (delta).

Definition \(\displaystyle\lim_{x \to a} f(x) = L\) means: for every number \(\varepsilon > 0\) there is a number \(\delta > 0\) such that \[\text{if } 0 < |x - a| < \delta \text{ then } |f(x) - L| < \varepsilon.\]

Read it as a challenge and response. Someone names a tolerance \(\varepsilon\) for the output. You must answer with a distance \(\delta\) for the input so that every \(x\) within \(\delta\) of \(a\) (except \(a\) itself) gives an output within \(\varepsilon\) of \(L\). Graphically, the curve over \((a - \delta, a + \delta)\) must stay inside the horizontal band between \(L - \varepsilon\) and \(L + \varepsilon\).

A smaller \(\varepsilon\) usually forces a smaller \(\delta\), and the definition demands a working \(\delta\) for every \(\varepsilon\), however tiny. That is why a proof cannot just check a few values: it must produce a formula for \(\delta\) in terms of \(\varepsilon\). Every proof has two stages. First comes the scratch work, where you start from \(|f(x) - L| < \varepsilon\) and work backwards to a condition of the form \(|x - a| < \text{something}\). Then comes the proof itself, written forwards: given \(\varepsilon\), state your \(\delta\), assume \(0 < |x - a| < \delta\), and show that \(|f(x) - L| < \varepsilon\) follows. Only the second stage is the proof, but you cannot write it without the first.

A linear example. Prove \(\lim_{x \to -1} (5x + 2) = -3\). Find \(\delta\) (scratch work): \(|f(x) - L| = |5x + 2 + 3| = |5x + 5| = 5|x + 1|\). We want \(5|x + 1| < \varepsilon\), that is \(|x + 1| < \varepsilon/5\). So choose \(\delta = \varepsilon/5\). Proof: given \(\varepsilon > 0\), let \(\delta = \varepsilon/5\). If \(0 < |x + 1| < \delta\), then \(|(5x + 2) - (-3)| = 5|x + 1| < 5\delta = \varepsilon\).

A quadratic example. Prove \(\lim_{x \to 2} x^2 = 4\). Now \(|x^2 - 4| = |x - 2|\,|x + 2|\), and the factor \(|x + 2|\) is not constant. Control it by first agreeing that \(\delta \le 1\): then \(|x - 2| < 1\) gives \(1 < x < 3\), so \(|x + 2| < 5\). Then \(|x^2 - 4| < 5|x - 2|\), which is less than \(\varepsilon\) when \(|x - 2| < \varepsilon/5\). Choose \(\delta = \min\{1, \varepsilon/5\}\). If \(0 < |x - 2| < \delta\), both conditions hold and \(|x^2 - 4| < 5 \cdot \tfrac{\varepsilon}{5} = \varepsilon\).

Why the \(\min\)? The number \(\delta\) has two jobs: keep \(x\) close enough to 2 that the bound \(|x + 2| < 5\) holds, and make \(5|x - 2|\) smaller than \(\varepsilon\). Taking the smaller of 1 and \(\varepsilon/5\) does both jobs at once. With \(\varepsilon = 0.5\), for example, you would use \(\delta = 0.1\).

Common mistake \(\delta\) may depend on \(\varepsilon\) and \(a\), but never on \(x\). An answer like "\(\delta = \varepsilon/|x + 2|\)" is not allowed; that is why we bound \(|x + 2|\) by a constant.
Key equations
\[ \lim_{x \to a} f(x) = L \iff \forall \varepsilon \gt 0\ \exists \delta \gt 0:\ 0 \lt |x - a| \lt \delta \Rightarrow |f(x) - L| \lt \varepsilon \]

1.8Continuity

For polynomials, finding a limit was as easy as substituting. Stewart §1.8 names the functions with this convenient property.

Definition A function \(f\) is continuous at \(a\) if \(\displaystyle\lim_{x \to a} f(x) = f(a)\).

This one equation contains three requirements: \(f(a)\) is defined, \(\lim_{x \to a} f(x)\) exists, and the two are equal. Informally, you can draw the graph near \(a\) without lifting your pen. If \(f\) fails to be continuous at \(a\), we say \(f\) has a discontinuity there. There are three common types:

  • Removable: the limit exists but \(f(a)\) is missing or has the wrong value, for example \(\dfrac{x^2 - 9}{x - 3}\) at 3. Redefining one value fixes it.
  • Jump: the one-sided limits exist but differ, as for \(\dfrac{|x|}{x}\) at 0.
  • Infinite: a one-sided limit is \(\pm\infty\), as for \(\dfrac{1}{x - 2}\) at 2.

We also say \(f\) is continuous from the right at \(a\) if \(\lim_{x \to a^+} f(x) = f(a)\) (and similarly from the left), and continuous on an interval if it is continuous at every point of it. Polynomials, rational functions, root functions and trigonometric functions are continuous at every number in their domains, and sums, products, quotients and compositions of continuous functions are continuous. So, for instance, \(\sqrt{x^2 + 1}\,\sin x\) is continuous everywhere.

The Intermediate Value Theorem Suppose \(f\) is continuous on the closed interval \([a, b]\), \(f(a) \ne f(b)\), and \(N\) is any number between \(f(a)\) and \(f(b)\). Then there is a number \(c\) in \((a, b)\) with \(f(c) = N\).

The most common use is locating roots. Let \(f(x) = x^3 + 2x - 5\). Then \(f(1) = -2 < 0\) and \(f(2) = 7 > 0\), and \(f\) is a continuous polynomial, so with \(N = 0\) the IVT says the equation \(x^3 + 2x - 5 = 0\) has a root between 1 and 2 (it is about 1.33). The IVT tells you a root exists; it does not tell you where exactly.

Common mistake Do not forget to check continuity. For \(1/x\) on \([-1, 1]\), the endpoint values have opposite signs, yet there is no root: the function is not continuous at 0.
Key equations
\[ f \text{ continuous at } a \iff \lim_{x \to a} f(x) = f(a) \]
\[ f \text{ continuous on } [a, b],\ N \text{ between } f(a), f(b) \;\Rightarrow\; f(c) = N \text{ for some } c \in (a, b) \]

★Key takeaways

  • The slope of a tangent line and an instantaneous velocity are both limits of the form lim (f(a + h) − f(a))/h as h → 0.
  • lim f(x) = L as x → a depends only on values near a, never on f(a); the two-sided limit exists exactly when both one-sided limits agree.
  • If a one-sided limit is ±∞, the line x = a is a vertical asymptote; check signs on each side to get the direction.
  • A result of 0/0 means simplify first: factor, multiply by a conjugate or combine fractions; use the Squeeze Theorem when algebra cannot help.
  • The ε–δ definition says every output tolerance ε can be met by some input distance δ; for a quadratic, first bound the extra factor by taking δ ≤ 1.
  • f is continuous at a when lim f(x) = f(a); the Intermediate Value Theorem guarantees roots of continuous functions between points where the sign changes.

Example 2.1 A tangent line as a limit of secant slopes

Find the slope of the tangent line to the curve \(y = x^2 - 2x\) at the point \(P(3, 3)\) by computing the limit of secant slopes, and write the equation of the tangent line.

(Similar to Stewart §1.4, Example 1)
Show solution (try it first)

Strategy:

Let \(Q\) be the point with \(x\)-coordinate \(3 + h\). Write the secant slope \(m_{PQ}\) in terms of \(h\), simplify until the \(h\) in the denominator cancels, then let \(h \to 0\).

Solution:

Let \(f(x) = x^2 - 2x\), so \(f(3) = 9 - 6 = 3\). Then \[f(3 + h) = (3 + h)^2 - 2(3 + h) = 9 + 6h + h^2 - 6 - 2h = 3 + 4h + h^2.\] The secant slope is \[m_{PQ} = \frac{f(3 + h) - f(3)}{h} = \frac{3 + 4h + h^2 - 3}{h} = \frac{4h + h^2}{h} = \frac{h(4 + h)}{h} = 4 + h \quad (h \ne 0).\] For \(h = 0.1\) the slope is 4.1; for \(h = -0.01\) it is 3.99. As \(h \to 0\), \(m_{PQ} \to 4\). So the tangent slope is \(m = 4\), and the tangent line is \(y - 3 = 4(x - 3)\), that is, \(y = 4x - 9\).

Check:

The line \(y = 4x - 9\) passes through \(P\): \(4(3) - 9 = 3\). Also, the curve and the line meet only at \(x = 3\): \(x^2 - 2x = 4x - 9\) gives \(x^2 - 6x + 9 = (x - 3)^2 = 0\), a double root, which is exactly what "just touching" looks like for a parabola.

Example 2.2 Limits of the form 0/0

Evaluate (a) \(\displaystyle\lim_{x \to -2} \frac{x^2 + 5x + 6}{x^2 - 4}\) and (b) \(\displaystyle\lim_{x \to 3} \frac{\frac{1}{x} - \frac13}{x - 3}\).

(Similar to Stewart §1.6, Examples 5 and 7)
Show solution (try it first)

Strategy:

Try direct substitution first. Both give \(\tfrac00\), so simplify: in (a) factor and cancel; in (b) combine the fractions in the numerator over a common denominator.

Solution:

(a) Factor: \(x^2 + 5x + 6 = (x + 2)(x + 3)\) and \(x^2 - 4 = (x + 2)(x - 2)\). For \(x \ne -2\), \[\frac{x^2 + 5x + 6}{x^2 - 4} = \frac{(x + 2)(x + 3)}{(x + 2)(x - 2)} = \frac{x + 3}{x - 2}.\] Now substitution works: \(\displaystyle\lim_{x \to -2} \frac{x + 3}{x - 2} = \frac{1}{-4} = -\frac14\).

(b) Numerator: \(\dfrac1x - \dfrac13 = \dfrac{3 - x}{3x} = \dfrac{-(x - 3)}{3x}\). So for \(x \ne 3\), \[\frac{\frac1x - \frac13}{x - 3} = \frac{-(x - 3)}{3x(x - 3)} = -\frac{1}{3x}.\] Therefore the limit is \(-\dfrac{1}{3 \cdot 3} = -\dfrac19\).

Check:

(a) At \(x = -2.01\) the original fraction is \(\dfrac{-0.0099}{0.0401} \approx -0.247\), close to \(-0.25\). (b) At \(x = 3.1\): \(\dfrac{1/3.1 - 1/3}{0.1} \approx -0.1075\), close to \(-\tfrac19 \approx -0.111\). A common error in (b) is to write \(3 - x = x - 3\) and lose the minus sign.

Example 2.3 An ε–δ proof for a quadratic

Use the ε–δ definition to prove that \(\displaystyle\lim_{x \to 3} (x^2 - 2x) = 3\).

(Similar to Stewart §1.7, Example 4)
Show solution (try it first)

Strategy:

Scratch work first: rewrite \(|f(x) - L|\) so that the factor \(|x - 3|\) appears. Bound the remaining factor by a constant by agreeing that \(\delta \le 1\). Then write the proof in the forward direction.

Solution:

Scratch work. \(|(x^2 - 2x) - 3| = |x^2 - 2x - 3| = |x - 3|\,|x + 1|\). If \(|x - 3| < 1\), then \(2 < x < 4\), so \(3 < x + 1 < 5\) and \(|x + 1| < 5\). Then \(|x - 3|\,|x + 1| < 5|x - 3|\), which is less than \(\varepsilon\) if \(|x - 3| < \varepsilon/5\).

Proof. Let \(\varepsilon > 0\) be given and choose \(\delta = \min\{1, \varepsilon/5\}\). Suppose \(0 < |x - 3| < \delta\). Since \(\delta \le 1\), we have \(|x - 3| < 1\), so \(|x + 1| < 5\). Since \(\delta \le \varepsilon/5\), we have \(|x - 3| < \varepsilon/5\). Therefore \[|(x^2 - 2x) - 3| = |x - 3|\,|x + 1| < \frac{\varepsilon}{5} \cdot 5 = \varepsilon.\] By the definition, \(\lim_{x \to 3} (x^2 - 2x) = 3\).

Check:

Test with \(\varepsilon = 0.5\): \(\delta = \min\{1, 0.1\} = 0.1\). The worst case is \(x = 3.1\) (just inside): \(3.1^2 - 6.2 = 3.41\), and \(|3.41 - 3| = 0.41 < 0.5\). Good. Remember: \(\delta\) depends on \(\varepsilon\) only, not on \(x\).
