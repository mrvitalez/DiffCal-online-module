2.1Derivatives and Rates of Change

Let's recall our discussion on tangents from Module 2. There we could only estimate a slope or a velocity using averages. Now we want the exact value. So, how do we define the slope of a curve at one exact point? Stewart §2.1 answers this with one special limit.

Tangents. Consider a curve \(C\) given by \(y = f(x)\), and let \(P(a, f(a))\) be a point on \(C\). Then let's take another point \(Q(x, f(x))\) on the curve, where \(x \ne a\) (see Figure 3.1). We can compute the slope of the secant line \(PQ\): \[m_{PQ} = \frac{f(x) - f(a)}{x - a}.\] Then we let \(Q\) approach \(P\) along the curve \(C\) by letting \(x\) approach \(a\). If \(m_{PQ}\) approaches a number \(m\), then we define the tangent line \(t\) to be the line through \(P\) with slope \(m\).

Definition 1 The tangent line to the curve \(y = f(x)\) at the point \(P(a, f(a))\) is the line through \(P\) with slope \[m = \lim_{x \to a} \frac{f(x) - f(a)}{x - a},\] provided that this limit exists.

There is another expression for the slope of the tangent line that is sometimes easier to use. If \(h = x - a\), then \(x = a + h\), and so the slope of the secant line \(PQ\) is \[m_{PQ} = \frac{f(a + h) - f(a)}{h}.\] Notice that as \(x\) approaches \(a\), \(h\) approaches 0. So the slope of the tangent line becomes \[m = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h}. \qquad (2)\]

Take note: if we substitute \(h = 0\) right away, the quotient collapses to \(0/0\). So we always expand and simplify first, cancel the \(h\), and only then let \(h \to 0\). Example 1 does this for the hyperbola \(y = 3/x\).

Velocities. In general, suppose an object moves along a straight line according to an equation of motion \(s = f(t)\), where \(s\) is the displacement of the object from the origin at time \(t\). The function \(f\) that describes the motion is called the position function of the object. In the time interval from \(t = a\) to \(t = a + h\), the change in position is \(f(a + h) - f(a)\), so the average velocity is \(\dfrac{f(a + h) - f(a)}{h}\).

Now, suppose that we compute the average velocities over shorter and shorter time intervals \([a, a + h]\). In other words, we let \(h\) approach 0. Then we define the velocity (or instantaneous velocity) \(v(a)\) at time \(t = a\) to be the limit of these average velocities: \[v(a) = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h}.\] This means that the velocity at \(t = a\) is equal to the slope of the tangent line at \(P\) on the graph of the position function (Figure 3.3).

Derivatives. As we have seen, the limit \(\lim_{h \to 0} \frac{f(a + h) - f(a)}{h}\) arises whenever we calculate a rate of change in any of the sciences or engineering, such as a rate of reaction in chemistry or marginal cost in economics. Since this type of limit occurs so widely, it is given a special name and notation.

Definition 4 The derivative of a function \(f\) at a number \(a\), denoted by \(f'(a)\), is \[f'(a) = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h}\] if this limit exists.

If we write \(x = a + h\), then \(h = x - a\), and \(h\) approaches 0 if and only if \(x\) approaches \(a\). Therefore an equivalent way of stating the definition of the derivative, as we saw in finding tangent lines, is

Definition 5 \[f'(a) = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}.\]

So \(f'(a)\) is the slope of the tangent line to \(y = f(x)\) at \((a, f(a))\), and that tangent line is \(y - f(a) = f'(a)(x - a)\). Examples 3 and 4 find the same derivative both ways.

Rates of change. For any quantity \(y = f(x)\), the difference quotient \(\Delta y/\Delta x\) is the average rate of change over an interval, and \(f'(a)\) is the instantaneous rate of change of \(y\) with respect to \(x\) at \(x = a\). Its units are (units of \(y\)) per (unit of \(x\)): metres per second, pesos per item, degrees per hour. A large \(|f'(a)|\) means \(y\) is changing quickly near \(a\).

Common mistake \(f(a + h)\) is not \(f(a) + h\). Replace every \(x\) in the formula by \((a + h)\), with brackets, and expand carefully. Also watch the minus sign in front of \(f(a)\): it changes the sign of every term of \(f(a)\).
Key equations
\[ m = \lim_{x \to a} \frac{f(x) - f(a)}{x - a} = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h} \]
\[ v(a) = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h} \]
\[ f'(a) = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h} = \lim_{x \to a} \frac{f(x) - f(a)}{x - a} \]
\[ y - f(a) = f'(a)(x - a) \]

2.2The Derivative as a Function

In §2.1 we found \(f'(a)\) one number at a time. But do we really need to repeat the whole limit for every point? No. Let's keep the point as a variable. If we replace \(a\) by \(x\), we get a whole new function. This is Stewart §2.2.

Definition The derivative of \(f\) is the function \[f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}.\] Its domain is the set of all \(x\) where this limit exists.

Let's try \(f(x) = x^2 + 5x\): \[\frac{(x + h)^2 + 5(x + h) - x^2 - 5x}{h} = \frac{2xh + h^2 + 5h}{h} = 2x + h + 5.\] As \(h \to 0\), this becomes \(f'(x) = 2x + 5\). Notice that this one formula gives the slope at every point: \(f'(1) = 7\), and \(f'(-2.5) = 0\), so the parabola has a horizontal tangent at \(x = -2.5\). Take note that the domain of \(f'\) can be smaller than the domain of \(f\). Example 5 shows a square root whose derivative does not exist at an endpoint.

Notation. If \(y = f(x)\), all of these mean the same thing: \[f'(x) = y' = \frac{dy}{dx} = \frac{df}{dx} = \frac{d}{dx}f(x) = Df(x).\] The Leibniz form \(dy/dx\) reminds us of \(\Delta y/\Delta x\). To show the value at a point, we write \(\dfrac{dy}{dx}\Big|_{x = a}\), which means \(f'(a)\).

Differentiability. We say \(f\) is differentiable at \(a\) if \(f'(a)\) exists, and differentiable on an open interval if it is differentiable at every number in that interval.

Theorem If \(f\) is differentiable at \(a\), then \(f\) is continuous at \(a\).

Why? Because \(f(a + h) - f(a) = \frac{f(a + h) - f(a)}{h}\cdot h\), which approaches \(f'(a)\cdot 0 = 0\). Does it work the other way around? No. Do you know why? Recall \(f(x) = |x|\). It is continuous at 0, but its secant slopes are \(+1\) from the right and \(-1\) from the left, so \(f'(0)\) does not exist.

So, how can a function fail to be differentiable at \(a\)? (See Figure 3.5.)

  • a corner (or kink), where the left and right slopes are different, like \(|x|\) at 0;
  • a discontinuity (a hole, a jump or an infinite break), by the theorem above;
  • a vertical tangent, where the curve is continuous but the slopes grow without bound, like \(y = \sqrt[3]{x}\) at 0.

Higher derivatives. Since \(f'\) is a function, we can differentiate it again. The second derivative is \(f'' = (f')'\), also written \(\dfrac{d^2y}{dx^2}\); after that come \(f'''\), \(f^{(4)}\), and so on. If \(s(t)\) is the position function, then \(v = s'\) is the velocity and \(a = v' = s''\) is the acceleration, the rate at which the velocity changes. Example 6 finds both.

Graphing \(f'\) from \(f\). The height of \(f'\) at \(x\) is the slope of \(f\) at \(x\). So \(f' \gt 0\) where \(f\) rises, \(f' \lt 0\) where \(f\) falls, and \(f' = 0\) at the horizontal tangents (the peaks and valleys of \(f\)). We can see this in Figure 3.4.

Common mistake The zeros of \(f'\) are at the peaks and valleys of \(f\), not where \(f\) crosses the \(x\)-axis. Read the slopes of \(f\), not its heights.
Key equations
\[ f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h} \]
\[ f'(x) = y' = \frac{dy}{dx} = \frac{d}{dx}f(x) = Df(x) \]
\[ a(t) = v'(t) = s''(t) \]

★Key takeaways

  • The slope of the tangent line at P(a, f(a)) is the limit of the secant slopes: m = lim_{h→0} [f(a + h) − f(a)]/h.
  • The derivative f′(a) is that same limit; Definition 5 writes it as lim_{x→a} [f(x) − f(a)]/(x − a), and both give the same answer.
  • The tangent line at x = a is y − f(a) = f′(a)(x − a); the velocity at t = a is the derivative of the position function, in units of distance per time.
  • Letting a vary gives the derivative function f′(x); differentiating again gives f″, such as acceleration.
  • Differentiable implies continuous, but not the reverse: corners, breaks and vertical tangents all stop f′ from existing.
  • Never substitute h = 0 first: expand, simplify and cancel the h, and only then take the limit.

Example 3.1 Tangent line to the hyperbola y = 3/x

Find an equation of the tangent line to the hyperbola \(y = \dfrac{3}{x}\) at the point \(P(3, 1)\).

(Instr. Vitalez, Module 2, Example 1 (compare Stewart §2.1))
Show solution (try it first)
Given
  • \(f(x) = \dfrac{3}{x}\), point \(P(3, 1)\), so \(a = 3\) and \(f(3) = 1\).
  • Find: the slope \(m\) of the tangent at \(P\), then the equation of the tangent line.
Step 1: Write the slope using Equation (2)

Let \(f(x) = 3/x\). By Equation (2), the slope of the tangent at \((3, 1)\) is

\[m = \lim_{h \to 0} \frac{f(3 + h) - f(3)}{h} = \lim_{h \to 0} \frac{\dfrac{3}{3 + h} - 1}{h}.\]

Step 2: Combine the fractions in the numerator

If we substitute \(h = 0\) right away, we get \(0/0\). So let's first write the numerator over the common denominator \(3 + h\).

\[\frac{3}{3 + h} - 1 = \frac{3}{3 + h} - \frac{3 + h}{3 + h} = \frac{3 - (3 + h)}{3 + h} = \frac{-h}{3 + h}\]

Step 3: Divide by h and cancel

Dividing by \(h\) is the same as multiplying the denominator by \(h\). Since \(h \ne 0\), the \(h\) cancels.

\[m = \lim_{h \to 0} \frac{-h}{h(3 + h)} = \lim_{h \to 0} \frac{-1}{3 + h}\]

Step 4: Take the limit

Now we can substitute \(h = 0\).

\[m = \frac{-1}{3 + 0} = -\frac{1}{3}\]

Step 5: Use the point-slope form

The tangent line passes through \((x_1, y_1) = (3, 1)\) with slope \(m = -\tfrac13\).

\[y - y_1 = m(x - x_1)\]

\[y - 1 = -\frac{1}{3}(x - 3)\]

Multiply both sides by 3:

\[3y - 3 = -x + 3\]

\[x + 3y - 6 = 0\]

Answer

The tangent line to \(y = 3/x\) at \(P(3, 1)\) is \(x + 3y - 6 = 0\), that is, \(y = -\tfrac13 x + 2\). (See Figure 3.2.)

Check

Substitute \(P\): \(3 + 3(1) - 6 = 0\). The point is on the line. The slope is negative, which makes sense because \(y = 3/x\) is falling for \(x \gt 0\).

Example 3.2 Velocity of a dropped ball

Suppose that a ball is dropped from the upper floor of a building, 450 m above the ground. Its distance fallen after \(t\) seconds is \(s(t) = 4.9t^2\) metres (using \(g = 9.8\) m/s²). (a) Find the velocity of the ball after 5 seconds. (b) How fast is the ball moving when it hits the ground?

(Instr. Vitalez, Module 2, Example 2 (compare Stewart §2.1))
Show solution (try it first)
Given
  • Position function \(s(t) = 4.9t^2\) m (from \(s = s_0 + v_0 t + \tfrac12 g t^2\) with \(s_0 = 0\), \(v_0 = 0\), \(g = 9.8\) m/s²).
  • Height of the building: 450 m.
  • Find: \(v(5)\), and the velocity when \(s = 450\).
Step 1: Write the velocity as a limit

The velocity is the limit of the average velocities. Let's keep the time as \(t\) so we can use the result twice.

\[v(t) = \lim_{h \to 0} \frac{s(t + h) - s(t)}{h} = \lim_{h \to 0} \frac{4.9(t + h)^2 - 4.9t^2}{h}\]

Step 2: Expand the square

Expand \((t + h)^2 = t^2 + 2th + h^2\) and multiply by 4.9.

\[= \lim_{h \to 0} \frac{4.9t^2 + 9.8th + 4.9h^2 - 4.9t^2}{h}\]

\[= \lim_{h \to 0} \frac{9.8th + 4.9h^2}{h}\]

Step 3: Cancel h and take the limit

Factor out \(h\) and cancel it, then let \(h \to 0\).

\[= \lim_{h \to 0} (9.8t + 4.9h) = 9.8t\]

So \(v(t) = 9.8t\) m/s.

Step 4: Evaluate at t = 5

\[v(5) = 9.8(5) = 49 \text{ m/s}\]

Step 5: Find when the ball hits the ground

The ball hits the ground when it has fallen 450 m.

\[4.9t^2 = 450\]

\[t^2 = \frac{450}{4.9} \approx 91.84\]

\[t = \sqrt{91.84} \approx 9.58 \text{ s}\]

Step 6: Find the velocity at that time

\[v(9.58) = 9.8\sqrt{\frac{450}{4.9}} \approx 9.8(9.583) \approx 93.9 \text{ m/s}\]

Answer

(a) After 5 seconds the ball is falling at \(49\) m/s. (b) It hits the ground after about 9.58 s, at about \(93.9\) m/s.

Check

Units: \(s\) is in metres and \(t\) in seconds, so \(v\) is in m/s. And \(v = 9.8t\) grows by 9.8 m/s every second, which is exactly what \(g = 9.8\) m/s² means.

Example 3.3 f′(a) for a parabola using Definition 4

Find the derivative of the function \(f(x) = x^2 - 8x + 9\) at the number \(a\).

(Instr. Vitalez, Module 2, Example 3 (compare Stewart §2.1))
Show solution (try it first)
Given
  • \(f(x) = x^2 - 8x + 9\).
  • Find: \(f'(a)\) using Definition 4, \(f'(a) = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h}\).
Step 1: Substitute a + h and a into f

Replace every \(x\) by \((a + h)\), and put \(f(a)\) in brackets because of the minus sign.

\[f'(a) = \lim_{h \to 0} \frac{\left[(a + h)^2 - 8(a + h) + 9\right] - \left[a^2 - 8a + 9\right]}{h}\]

Step 2: Expand and remove the brackets

\[= \lim_{h \to 0} \frac{a^2 + 2ah + h^2 - 8a - 8h + 9 - a^2 + 8a - 9}{h}\]

Step 3: Collect like terms

The \(a^2\), \(8a\) and \(9\) terms cancel.

\[= \lim_{h \to 0} \frac{2ah + h^2 - 8h}{h}\]

Step 4: Cancel h and take the limit

\[= \lim_{h \to 0} (2a + h - 8)\]

\[f'(a) = 2a - 8\]

Answer

The derivative of \(f(x) = x^2 - 8x + 9\) at the number \(a\) is \(f'(a) = 2a - 8\).

Check

At \(a = 4\), \(f'(4) = 0\). That is the vertex of the parabola, \(x = -b/(2a) = 8/2 = 4\), where the tangent is horizontal.

Example 3.4 The same derivative with Definition 5, and a tangent line

Find the derivative of \(f(x) = x^2 - 8x + 9\) at the number \(a\) using Definition 5, \(f'(a) = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}\). Then find the tangent line to the parabola at the point \((3, -6)\).

(Instr. Vitalez, Module 2, Activity 1 (compare Stewart §2.1))
Show solution (try it first)
Given
  • \(f(x) = x^2 - 8x + 9\); point \((3, -6)\).
  • Find: \(f'(a)\) by Definition 5, then the tangent line at \(x = 3\).
Step 1: Set up Definition 5

\[f'(a) = \lim_{x \to a} \frac{(x^2 - 8x + 9) - (a^2 - 8a + 9)}{x - a}\]

\[= \lim_{x \to a} \frac{x^2 - 8x - a^2 + 8a}{x - a}\]

Step 2: Group the terms so (x − a) shows

If we substitute \(x = a\) now, we get \(0/0\). So let's group the squares and the linear terms.

\[= \lim_{x \to a} \frac{(x^2 - a^2) - 8(x - a)}{x - a}\]

\[= \lim_{x \to a} \frac{(x - a)(x + a) - 8(x - a)}{x - a}\]

Step 3: Cancel (x − a) and take the limit

Since \(x \ne a\), we can cancel the common factor.

\[= \lim_{x \to a} (x + a - 8) = a + a - 8\]

\[f'(a) = 2a - 8\]

This is the same answer we got with Definition 4 in Example 3.

Step 4: Find the slope at a = 3

First check that the point is on the curve: \(f(3) = 9 - 24 + 9 = -6\). Then

\[m = f'(3) = 2(3) - 8 = -2\]

Step 5: Use the point-slope form

\[y - (-6) = -2(x - 3)\]

\[y + 6 = -2x + 6\]

\[y = -2x\]

Answer

\(f'(a) = 2a - 8\), and the tangent line at \((3, -6)\) is \(y = -2x\).

Check

The line \(y = -2x\) passes through \((3, -6)\) since \(-2(3) = -6\). Also, the line and parabola meet where \(x^2 - 8x + 9 = -2x\), that is, \((x - 3)^2 = 0\): a double root, so the line just touches the curve.

Example 3.5 A derivative function with a square root

Let \(f(x) = \sqrt{4x + 1}\). Use the definition to find \(f'(x)\). State the domains of \(f\) and \(f'\).

(Similar to Stewart §2.2, derivative from the definition)
Show solution (try it first)
Given
  • \(f(x) = \sqrt{4x + 1}\).
  • Find: \(f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}\), and the domains of \(f\) and \(f'\).
Step 1: Write the difference quotient

\[\frac{f(x + h) - f(x)}{h} = \frac{\sqrt{4x + 4h + 1} - \sqrt{4x + 1}}{h}\]

If we let \(h \to 0\) right away, we get \(0/0\). So let's multiply by the conjugate first.

Step 2: Multiply by the conjugate

Multiply the top and bottom by \(\sqrt{4x + 4h + 1} + \sqrt{4x + 1}\). Recall \((A - B)(A + B) = A^2 - B^2\).

\[= \frac{(4x + 4h + 1) - (4x + 1)}{h\left(\sqrt{4x + 4h + 1} + \sqrt{4x + 1}\right)}\]

\[= \frac{4h}{h\left(\sqrt{4x + 4h + 1} + \sqrt{4x + 1}\right)}\]

Step 3: Cancel h

\[= \frac{4}{\sqrt{4x + 4h + 1} + \sqrt{4x + 1}}\]

Step 4: Take the limit

Now let \(h \to 0\).

\[f'(x) = \frac{4}{\sqrt{4x + 1} + \sqrt{4x + 1}} = \frac{4}{2\sqrt{4x + 1}} = \frac{2}{\sqrt{4x + 1}}\]

Step 5: Find the domains

\(f\) needs \(4x + 1 \ge 0\), so \(x \ge -\tfrac14\). \(f'\) also needs a nonzero denominator, so \(4x + 1 \gt 0\), that is, \(x \gt -\tfrac14\).

Answer

\(f'(x) = \dfrac{2}{\sqrt{4x + 1}}\). The domain of \(f\) is \(\left[-\tfrac14, \infty\right)\) and the domain of \(f'\) is \(\left(-\tfrac14, \infty\right)\). At \(x = -\tfrac14\) the graph has a vertical tangent.

Check

At \(x = 2\): \(f'(2) = 2/\sqrt9 = 2/3\). With \(h = 0.01\): \(\frac{\sqrt{9.04} - 3}{0.01} \approx 0.666\). It agrees.

Example 3.6 Velocity and acceleration of a particle

A particle moves along a line with position \(s(t) = t^3 - 6t^2\) metres after \(t\) seconds (\(t \ge 0\)). (a) Use the definition to find the velocity \(v(t)\). (b) Find the acceleration \(a(t)\). (c) When is the particle at rest for \(t \gt 0\), and what are its position and acceleration then?

(Similar to Stewart §2.2, higher derivatives)
Show solution (try it first)
Given
  • \(s(t) = t^3 - 6t^2\) m, \(t \ge 0\).
  • Find: \(v(t) = s'(t)\), \(a(t) = v'(t)\), and the time \(t \gt 0\) when \(v(t) = 0\).
Step 1: Expand s(t + h)

Recall \((t + h)^3 = t^3 + 3t^2h + 3th^2 + h^3\) and \((t + h)^2 = t^2 + 2th + h^2\).

\[s(t + h) - s(t) = (t^3 + 3t^2h + 3th^2 + h^3) - 6(t^2 + 2th + h^2) - t^3 + 6t^2\]

\[= 3t^2h + 3th^2 + h^3 - 12th - 6h^2\]

Step 2: Divide by h and take the limit

\[\frac{s(t + h) - s(t)}{h} = 3t^2 + 3th + h^2 - 12t - 6h\]

\[v(t) = \lim_{h \to 0}\left(3t^2 + 3th + h^2 - 12t - 6h\right) = 3t^2 - 12t \text{ m/s}\]

Step 3: Differentiate v to get the acceleration

Use the definition again, now on \(v(t) = 3t^2 - 12t\).

\[v(t + h) - v(t) = 3(t^2 + 2th + h^2) - 12(t + h) - 3t^2 + 12t = 6th + 3h^2 - 12h\]

\[a(t) = \lim_{h \to 0} \frac{6th + 3h^2 - 12h}{h} = \lim_{h \to 0}(6t + 3h - 12) = 6t - 12 \text{ m/s}^2\]

Step 4: Find when the particle is at rest

At rest means \(v(t) = 0\).

\[3t^2 - 12t = 0\]

\[3t(t - 4) = 0\]

So \(t = 0\) or \(t = 4\). For \(t \gt 0\), we take \(t = 4\) s.

Step 5: Evaluate position and acceleration at t = 4

\[s(4) = 4^3 - 6(4^2) = 64 - 96 = -32 \text{ m}\]

\[a(4) = 6(4) - 12 = 12 \text{ m/s}^2\]

Answer

(a) \(v(t) = 3t^2 - 12t\) m/s. (b) \(a(t) = 6t - 12\) m/s². (c) The particle is at rest at \(t = 4\) s, at position \(s = -32\) m, with acceleration \(12\) m/s².

Check

For \(0 \lt t \lt 4\), \(v \lt 0\) (moving backward); for \(t \gt 4\), \(v \gt 0\). The positive acceleration at \(t = 4\) is what turns the particle around. Take note: velocity zero does not mean acceleration zero.
