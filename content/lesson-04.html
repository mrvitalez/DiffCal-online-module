2.3Differentiation Formulas

In Module 3 we found every derivative from the definition: write the difference quotient, expand, cancel the \(h\), take the limit. That works, but imagine doing it for \(f(x) = x^{10} - 3x^7 + 5\). It will take forever! Fortunately, there is a pattern in the answers, and once we see it we can write derivatives almost immediately. In this section we build those shortcuts, the differentiation formulas. Each one can be proved with the limit definition, so they are not magic; they are the definition done once and for all.

Constants and powers. The graph of a constant function \(f(x) = c\) is a horizontal line, so its slope is 0 everywhere. For powers, recall that we found \(\frac{d}{dx}(x^2) = 2x\) and \(\frac{d}{dx}\sqrt{x} = \frac{1}{2\sqrt{x}}\). Notice the pattern: the exponent comes down in front and the new exponent is one less. This is the Power Rule, and it works for every real exponent \(n\), including negative and fractional ones.

Here is the summary table of the rules, with a sample for each. Take note of how each sample uses only the rule in its row.

Differentiation ruleGeneral formSample
Derivative of a constant\(\dfrac{d}{dx}(c) = 0\)\(\dfrac{d}{dx}(2) = 0\)
Power Rule\(\dfrac{d}{dx}(x^n) = nx^{n-1}\)\(\dfrac{d}{dx}(x^3) = 3x^2\); \(\;\dfrac{d}{dx}(x^{-3}) = -3x^{-4}\)
Constant Multiple Rule\(\dfrac{d}{dx}[cf(x)] = c\dfrac{d}{dx}f(x)\)\(\dfrac{d}{dx}(3x^3) = 3(3x^2) = 9x^2\)
Sum Rule\(\dfrac{d}{dx}[f + g] = f' + g'\)\(\dfrac{d}{dx}(x^5 + 3x^4) = 5x^4 + 12x^3\)
Difference Rule\(\dfrac{d}{dx}[f - g] = f' - g'\)\(\dfrac{d}{dx}(x^4 - 2x^3) = 4x^3 - 6x^2\)
Product Rule\(\dfrac{d}{dx}[f g] = g\dfrac{df}{dx} + f\dfrac{dg}{dx}\)\(\dfrac{d}{dx}[(6x^3)(2x^2)] = 2x^2(18x^2) + 6x^3(4x) = 60x^4\)
Quotient Rule\(\dfrac{d}{dx}\left[\dfrac{f}{g}\right] = \dfrac{g\frac{df}{dx} - f\frac{dg}{dx}}{g^2}\)\(\dfrac{d}{dx}\left[\dfrac{x^2}{2x^3}\right] = \dfrac{2x^3(2x) - x^2(6x^2)}{(2x^3)^2} = \dfrac{-2x^4}{4x^6} = -\dfrac{1}{2x^2}\)

You can check the last two samples by simplifying first: \((6x^3)(2x^2) = 12x^5\), whose derivative is \(60x^4\) ✓; and \(\frac{x^2}{2x^3} = \frac12 x^{-1}\), whose derivative is \(-\frac12 x^{-2} = -\frac{1}{2x^2}\) ✓. This is a good habit: if a product or quotient simplifies easily, simplify first and use the Power Rule.

The Product Rule in words "The second times the derivative of the first, plus the first times the derivative of the second." Take note that the derivative of a product is not the product of the derivatives: \(\frac{d}{dx}(x \cdot x) = 2x\), but \(\frac{d}{dx}(x)\cdot\frac{d}{dx}(x) = 1\).
The Quotient Rule in words "Low d-high minus high d-low, over the square of what's below." The order in the numerator matters, because of the minus sign: always start with the denominator times the derivative of the numerator.

Tangent and normal lines. Now that derivatives are quick, so are tangent lines. The tangent line at \((a, f(a))\) has slope \(f'(a)\). The normal line is the line through the same point perpendicular to the tangent, so its slope is the negative reciprocal, \(-\dfrac{1}{f'(a)}\) (when \(f'(a) \ne 0\)).

Common mistake Using the Power Rule on a constant base or forgetting to rewrite roots and reciprocals first. Before differentiating, rewrite: \(\sqrt{x} = x^{1/2}\), \(\frac{3}{x^2} = 3x^{-2}\), \(\frac{1}{\sqrt[3]{x}} = x^{-1/3}\). Then the Power Rule applies directly.
Key equations
\[ \frac{d}{dx}(x^n) = nx^{n-1} \]
\[ (fg)' = f'g + fg', \qquad \left(\frac{f}{g}\right)' = \frac{gf' - fg'}{g^2} \]

2.4Derivatives of Trigonometric Functions

So far, our formulas cover polynomials, roots and rational functions. But in astronomy and physics, many things repeat: the phases of the Moon, a pendulum, a mass on a spring, the height of a point on a rotating wheel. These are described by trigonometric functions, so we need their derivatives too. Take note that in calculus, angles are always measured in radians; the formulas in this section are false in degrees.

Before we can differentiate \(\sin x\), we need two special limits.

Two special limits \[ \lim_{\theta \to 0} \frac{\sin\theta}{\theta} = 1, \qquad \lim_{\theta \to 0} \frac{\cos\theta - 1}{\theta} = 0. \]

Why is the first one true? On the unit circle, an angle \(\theta\) cuts off an arc of length \(\theta\) and a vertical segment of height \(\sin\theta\). For small angles the arc and the segment are almost the same length, so their ratio approaches 1. Stewart proves it with the Squeeze Theorem, and Figure 4.2 shows the graph of \(\sin\theta/\theta\) heading to 1. The second limit follows from the first by multiplying by \(\frac{\cos\theta + 1}{\cos\theta + 1}\).

These limits also handle variations. If we look intently at \(\lim_{x \to 0}\frac{\sin 2x}{7x}\), the angle is \(2x\) but the denominator is \(7x\). So we make the denominator match the angle:

\[ \lim_{x \to 0} \frac{\sin 2x}{7x} = \frac{2}{7}\lim_{x \to 0}\frac{\sin 2x}{2x} = \frac{2}{7}\cdot 1 = \frac{2}{7}. \]

The derivative of sine. Using the addition formula \(\sin(x + h) = \sin x\cos h + \cos x\sin h\) in the definition,

\[ \frac{\sin(x + h) - \sin x}{h} = \sin x\cdot\frac{\cos h - 1}{h} + \cos x\cdot\frac{\sin h}{h} \;\longrightarrow\; \sin x\cdot 0 + \cos x\cdot 1 = \cos x. \]

A similar argument gives \(\frac{d}{dx}(\cos x) = -\sin x\). The other four follow from the Quotient Rule; for example, \(\frac{d}{dx}(\tan x) = \frac{d}{dx}\left(\frac{\sin x}{\cos x}\right) = \frac{\cos x\cos x - \sin x(-\sin x)}{\cos^2 x} = \frac{1}{\cos^2 x} = \sec^2 x\).

Here is the table of the six derivatives with a sample for each, so you can see them working together with the rules of Section 2.3:

FormulaSample
\(\dfrac{d}{dx}(\sin x) = \cos x\)\(\dfrac{d}{dx}(x^2\sin x) = x^2\cos x + 2x\sin x\) (Product Rule)
\(\dfrac{d}{dx}(\cos x) = -\sin x\)\(\dfrac{d}{d\theta}\left(\dfrac{\cos\theta}{1 - \sin\theta}\right) = \dfrac{1}{1 - \sin\theta}\) (Quotient Rule, see Example 4.4)
\(\dfrac{d}{dx}(\tan x) = \sec^2 x\)\(\dfrac{d}{dx}(2\tan x) = 2\sec^2 x\)
\(\dfrac{d}{dx}(\csc x) = -\csc x\cot x\)\(\dfrac{d}{dx}(2\sec x - \csc x) = 2\sec x\tan x + \csc x\cot x\)
\(\dfrac{d}{dx}(\sec x) = \sec x\tan x\)\(\dfrac{d}{dx}(\sec x\tan x) = \sec^3 x + \sec x\tan^2 x\)
\(\dfrac{d}{dx}(\cot x) = -\csc^2 x\)\(\dfrac{d}{dx}(x^2\cot x) = 2x\cot x - x^2\csc^2 x\)

A pattern helps us remember the signs: the derivatives of the "co" functions (cosine, cosecant, cotangent) all carry a minus sign.

A repeating pattern. Differentiating \(\sin x\) again and again gives \(\cos x,\ -\sin x,\ -\cos x,\ \sin x\), and then the cycle repeats every four steps. This is very useful for motion that goes back and forth. If a mass on a spring has position \(s(t) = 4\sin t\) cm, its velocity is \(v = 4\cos t\) and its acceleration is \(a = -4\sin t = -s\). The acceleration always points back toward the rest position, which is exactly why the mass keeps oscillating. Figure 4.3 shows how the graph of \(\cos x\) records the slopes of \(\sin x\).

Common mistake \(\dfrac{\sin 2x}{x}\) does not tend to 1, and we cannot "cancel" the \(x\) inside \(\sin 2x\). The limit \(\sin\theta/\theta \to 1\) needs the same quantity in the sine and in the denominator. Another common slip is the sign: \(\frac{d}{dx}(\cos x) = -\sin x\), not \(+\sin x\).
Key equations
\[ \lim_{\theta \to 0} \frac{\sin\theta}{\theta} = 1, \qquad \lim_{\theta \to 0} \frac{\cos\theta - 1}{\theta} = 0 \]
\[ (\sin x)' = \cos x, \quad (\cos x)' = -\sin x, \quad (\tan x)' = \sec^2 x \]
\[ (\csc x)' = -\csc x\cot x, \quad (\sec x)' = \sec x\tan x, \quad (\cot x)' = -\csc^2 x \]

★Key takeaways

  • The differentiation formulas are the limit definition done once and for all; use them instead of the definition unless a problem says otherwise.
  • Power Rule: \(\frac{d}{dx}x^n = nx^{n-1}\) for every real \(n\). Rewrite roots and reciprocals as powers first.
  • The derivative of a product is not the product of the derivatives: \((fg)' = f'g + fg'\).
  • Quotient Rule: low d-high minus high d-low, over the square of what's below. The order matters.
  • The normal line has slope \(-1/f'(a)\), the negative reciprocal of the tangent slope.
  • In radians, \(\lim_{\theta\to 0}\frac{\sin\theta}{\theta} = 1\); match the angle and the denominator before using it.
  • The "co" functions have negative derivatives: \((\cos x)' = -\sin x\), \((\csc x)' = -\csc x\cot x\), \((\cot x)' = -\csc^2 x\).

Example 4.1 Product Rule, and a check by expanding

Find the derivative of \(y = (6x^3)(2x^2)\) using the Product Rule, then check by simplifying first.

(From the instructor's module)
Show solution (try it first)

Given: \(f(x) = 6x^3\), \(g(x) = 2x^2\), \(y = f(x)g(x)\).   Find: \(dy/dx\).

Plan: Use the Product Rule: the second times the derivative of the first, plus the first times the derivative of the second.

Step 1. Differentiate each factor with the Constant Multiple and Power Rules:

\[ \frac{d}{dx}(6x^3) = 18x^2, \qquad \frac{d}{dx}(2x^2) = 4x \]

Step 2. Apply the Product Rule \(\frac{d}{dx}[fg] = g\frac{df}{dx} + f\frac{dg}{dx}\):

\[ \frac{dy}{dx} = 2x^2(18x^2) + 6x^3(4x) \]

Step 3. Multiply and combine like terms:

\[ \frac{dy}{dx} = 36x^4 + 24x^4 = 60x^4 \]

Answer: \(\boxed{\dfrac{dy}{dx} = 60x^4}\). That is our answer.

Check: Simplify first: \(y = 12x^5\), so \(y' = 5 \cdot 12x^4 = 60x^4\). ✓ Same answer.

Example 4.2 Quotient Rule

Differentiate \(y = \dfrac{x^2}{2x^3}\) using the Quotient Rule, and check by simplifying first.

(From the instructor's module)
Show solution (try it first)

Given: numerator \(f = x^2\), denominator \(g = 2x^3\).   Find: \(dy/dx\).

Plan: "Low d-high minus high d-low, over the square of what's below." Then simplify.

Step 1. Find the two derivatives:

\[ \frac{d}{dx}(x^2) = 2x, \qquad \frac{d}{dx}(2x^3) = 6x^2 \]

Step 2. Apply the Quotient Rule, starting with the denominator times the derivative of the numerator:

\[ \frac{dy}{dx} = \frac{2x^3(2x) - x^2(6x^2)}{(2x^3)^2} \]

Step 3. Multiply out the numerator and square the denominator:

\[ = \frac{4x^4 - 6x^4}{4x^6} = \frac{-2x^4}{4x^6} \]

Step 4. Cancel \(2x^4\):

\[ \frac{dy}{dx} = -\frac{1}{2x^2} \]

Answer: \(\boxed{\dfrac{dy}{dx} = -\dfrac{1}{2x^2}}\). That is our answer.

Check: Simplify first: \(y = \frac{1}{2}x^{-1}\), so \(y' = -\frac12 x^{-2} = -\frac{1}{2x^2}\). ✓

Example 4.3 Tangent and normal lines

Find the equations of the tangent line and the normal line to \(y = \dfrac{\sqrt{x}}{1 + x^2}\) at the point \((1, \tfrac12)\).

Similar to Stewart §2.3, Example 7
Show solution (try it first)

Given: \(y = \dfrac{x^{1/2}}{1 + x^2}\), the point \((1, \frac12)\).   Find: the tangent and normal lines at \(x = 1\).

Plan: Get the slope from the Quotient Rule, evaluate at \(x = 1\), then use the point-slope form twice (slope \(m\) for the tangent, \(-1/m\) for the normal).

Step 1. Derivatives of the numerator and denominator:

\[ \frac{d}{dx}(x^{1/2}) = \frac{1}{2\sqrt{x}}, \qquad \frac{d}{dx}(1 + x^2) = 2x \]

Step 2. Quotient Rule:

\[ y' = \frac{(1 + x^2)\frac{1}{2\sqrt{x}} - \sqrt{x}(2x)}{(1 + x^2)^2} \]

Step 3. Substitute \(x = 1\) right away (we only need the slope at one point):

\[ y'(1) = \frac{(2)\frac12 - (1)(2)}{(2)^2} = \frac{1 - 2}{4} = -\frac14 \]

Step 4. Tangent line, slope \(-\frac14\) through \((1, \frac12)\):

\[ y - \tfrac12 = -\tfrac14(x - 1) \;\Rightarrow\; y = -\tfrac14 x + \tfrac34 \]

Step 5. Normal line, slope \(-\frac{1}{-1/4} = 4\):

\[ y - \tfrac12 = 4(x - 1) \;\Rightarrow\; y = 4x - \tfrac72 \]

Answer: Tangent: \(\boxed{y = -\tfrac14 x + \tfrac34}\); normal: \(\boxed{y = 4x - \tfrac72}\). That is our answer.

Check: Both lines pass through \((1, \frac12)\): \(-\frac14 + \frac34 = \frac12\) ✓ and \(4 - \frac72 = \frac12\) ✓. The slopes multiply to \(-\frac14 \cdot 4 = -1\), so the lines are perpendicular ✓.

Example 4.4 A trigonometric quotient

Find \(\dfrac{d}{d\theta}\left(\dfrac{\cos\theta}{1 - \sin\theta}\right)\).

(From the instructor's module)
Show solution (try it first)

Given: numerator \(\cos\theta\), denominator \(1 - \sin\theta\).   Find: the derivative, simplified.

Plan: Quotient Rule, then the Pythagorean identity \(\sin^2\theta + \cos^2\theta = 1\) to simplify.

Step 1. Derivatives of the parts:

\[ \frac{d}{d\theta}(\cos\theta) = -\sin\theta, \qquad \frac{d}{d\theta}(1 - \sin\theta) = -\cos\theta \]

Step 2. Quotient Rule:

\[ \frac{(1 - \sin\theta)(-\sin\theta) - (\cos\theta)(-\cos\theta)}{(1 - \sin\theta)^2} \]

Step 3. Expand the numerator:

\[ = \frac{-\sin\theta + \sin^2\theta + \cos^2\theta}{(1 - \sin\theta)^2} \]

Step 4. Use \(\sin^2\theta + \cos^2\theta = 1\):

\[ = \frac{1 - \sin\theta}{(1 - \sin\theta)^2} \]

Step 5. Cancel one factor of \(1 - \sin\theta\):

\[ = \frac{1}{1 - \sin\theta} \]

Answer: \(\boxed{\dfrac{1}{1 - \sin\theta}}\). That is our answer.

Check: At \(\theta = 0\) the formula gives 1. Numerically, \(\frac{\cos(0.001)/(1 - \sin 0.001) - 1}{0.001} \approx 1.0005\). ✓

Example 4.5 Sum and product of trigonometric functions

Differentiate (a) \(y = 2\sec x - \csc x\) and (b) \(y = \sec x\tan x\).

(From the instructor's module)
Show solution (try it first)

Given: the six trigonometric derivative formulas.   Find: both derivatives.

Plan: (a) uses the Difference and Constant Multiple Rules; (b) uses the Product Rule.

Step 1. (a) Differentiate term by term:

\[ y' = 2\frac{d}{dx}(\sec x) - \frac{d}{dx}(\csc x) = 2\sec x\tan x - (-\csc x\cot x) \]

Step 2. Simplify the double negative:

\[ y' = 2\sec x\tan x + \csc x\cot x \]

Step 3. (b) Product Rule with \(f = \sec x\), \(g = \tan x\):

\[ y' = \sec x\,\frac{d}{dx}(\tan x) + \tan x\,\frac{d}{dx}(\sec x) = \sec x\sec^2 x + \tan x\sec x\tan x \]

Step 4. Simplify:

\[ y' = \sec^3 x + \sec x\tan^2 x \]

Answer: (a) \(\boxed{2\sec x\tan x + \csc x\cot x}\); (b) \(\boxed{\sec^3 x + \sec x\tan^2 x}\). That is our answer.

Check: In (a), a quick check at \(x = \pi/4\): \(2\sqrt2(1) + \sqrt2(1) = 3\sqrt2 \approx 4.243\); a difference quotient with \(h = 0.0001\) gives about 4.243 ✓. In (b), using \(\tan^2 x = \sec^2 x - 1\), the answer can also be written \(2\sec^3 x - \sec x\).

Example 4.6 A trigonometric limit

Evaluate \(\displaystyle\lim_{x \to 0} \frac{\tan 3x}{x}\).

Similar to Stewart §2.4, Example 5
Show solution (try it first)

Given: the limit has the form \(\frac00\).   Find: the value of the limit.

Plan: Write \(\tan 3x = \frac{\sin 3x}{\cos 3x}\) and make the denominator match the angle \(3x\).

Step 1. Rewrite the tangent:

\[ \frac{\tan 3x}{x} = \frac{\sin 3x}{x\cos 3x} \]

Step 2. Multiply and divide by 3 so that \(\sin 3x\) is over \(3x\):

\[ = 3\cdot\frac{\sin 3x}{3x}\cdot\frac{1}{\cos 3x} \]

Step 3. As \(x \to 0\), \(3x \to 0\), so \(\frac{\sin 3x}{3x} \to 1\), and \(\cos 3x \to 1\):

\[ \lim_{x \to 0}\frac{\tan 3x}{x} = 3 \cdot 1 \cdot \frac11 = 3 \]

Answer: \(\boxed{3}\). That is our answer.

Check: With \(x = 0.001\): \(\tan(0.003)/0.001 \approx 3.000009\). ✓
