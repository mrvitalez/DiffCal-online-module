2.5The Chain Rule

Suppose we are asked to differentiate \(F(x) = \sqrt{x^2 + 1}\). The differentiation formulas from Module 4 do not cover it directly: it is not a sum, a product or a quotient of functions we know. So, how do we do it? If we look intently at \(F\), we can see that it is a function inside another function: first we compute \(x^2 + 1\), then we take the square root. In other words, \(F\) is a composite function, \(F = f \circ g\), with an outer function \(f(u) = \sqrt{u}\) and an inner function \(u = g(x) = x^2 + 1\).

The rule for differentiating composites is the Chain Rule, and it is one of the most important rules in this course. Here is the idea. If \(u\) changes twice as fast as \(x\), and \(y\) changes three times as fast as \(u\), then \(y\) changes \(2 \times 3 = 6\) times as fast as \(x\). Rates of change multiply along the chain.

The Chain Rule If \(g\) is differentiable at \(x\) and \(f\) is differentiable at \(g(x)\), then the composite \(F = f \circ g\), \(F(x) = f(g(x))\), is differentiable at \(x\) and \[ F'(x) = f'(g(x))\cdot g'(x). \] In Leibniz notation, if \(y = f(u)\) and \(u = g(x)\), then \[ \frac{dy}{dx} = \frac{dy}{du}\,\frac{du}{dx}. \]

In words: the derivative of the outer function, evaluated at the inner function, times the derivative of the inner function. We will use the same three moves every time: (1) let \(u\) be the inner function, (2) differentiate the outer function with respect to \(u\), (3) multiply by \(du/dx\), and then put \(u\) back in terms of \(x\).

Let's apply it to our three warm-up functions.

  • \(y = \sqrt{x^2 + 1}\): let \(u = x^2 + 1\), so \(y = u^{1/2}\). Then \(\frac{dy}{dx} = \frac12 u^{-1/2}\cdot 2x = \dfrac{x}{\sqrt{x^2 + 1}}\).
  • \(y = (5x - 2)^4\): let \(u = 5x - 2\), so \(y = u^4\). Then \(\frac{dy}{dx} = 4u^3\cdot 5 = 20(5x - 2)^3\).
  • \(y = \sin(4x^3)\): let \(u = 4x^3\), so \(y = \sin u\). Then \(\frac{dy}{dx} = \cos u\cdot 12x^2 = 12x^2\cos(4x^3)\).

The Power Rule combined with the Chain Rule. The first two bullets follow one pattern that appears so often that it deserves its own formula. If \(n\) is any real number and \(u = g(x)\) is differentiable, then

\[ \frac{d}{dx}\left(u^n\right) = nu^{n-1}\frac{du}{dx}, \qquad\text{that is,}\qquad \frac{d}{dx}[g(x)]^n = n[g(x)]^{n-1}g'(x). \]

For example, \(y = \dfrac{1}{\sqrt[3]{x^2 + x + 1}} = (x^2 + x + 1)^{-1/3}\) gives \(y' = -\frac13(x^2 + x + 1)^{-4/3}(2x + 1) = -\dfrac{2x + 1}{3(x^2 + x + 1)^{4/3}}\).

Combining the rules. In real problems the Chain Rule rarely works alone. A product of two composites needs the Product Rule and the Chain Rule twice; a power of a quotient needs the Chain Rule and the Quotient Rule. The worked examples show three of these. The safest habit is to name each piece (\(u\), \(v\), \(a\), \(b\), ...), find each derivative separately, and only then assemble the answer.

Longer chains. The rule extends to more links. If \(y = f(u)\), \(u = g(v)\) and \(v = h(x)\), then \(\frac{dy}{dx} = \frac{dy}{du}\frac{du}{dv}\frac{dv}{dx}\). For example, \(y = \sin^2(3x) = [\sin(3x)]^2\) has three layers (square, sine, \(3x\)), so \(y' = 2\sin(3x)\cdot\cos(3x)\cdot 3 = 6\sin 3x\cos 3x\).

Common mistake Forgetting to multiply by the derivative of the inner function. \(\frac{d}{dx}\sin(x^3)\) is \(3x^2\cos(x^3)\), not \(\cos(x^3)\). A second mistake is changing the inside: the inner function stays the same inside the outer derivative, so it is \(\cos(x^3)\), not \(\cos(3x^2)\).
Key equations
\[ \frac{d}{dx}f(g(x)) = f'(g(x))\,g'(x), \qquad \frac{dy}{dx} = \frac{dy}{du}\frac{du}{dx} \]
\[ \frac{d}{dx}[g(x)]^n = n[g(x)]^{n-1}g'(x) \]
\[ \frac{d}{dx}\sin u = \cos u\,\frac{du}{dx}, \qquad \frac{d}{dx}\cos u = -\sin u\,\frac{du}{dx} \]

2.6Implicit Differentiation

All the functions we have differentiated so far were written as \(y = f(x)\): \(y\) alone on one side, a formula in \(x\) on the other. We call this an explicit function. But many curves we care about are not like this. Recall the circle \(x^2 + y^2 = 25\), or the orbit of a planet, which is an ellipse. These are relations between \(x\) and \(y\), and a circle fails the Vertical Line Test, so it is not one function of \(x\). We say the equation defines \(y\) implicitly as one or more functions of \(x\).

So, how do we get the slope \(dy/dx\) of such a curve? We could solve for \(y\), as in \(y = \pm\sqrt{25 - x^2}\), but for many curves that is very hard or impossible. Fortunately, we do not need to. The method of implicit differentiation is:

  1. Differentiate both sides of the equation with respect to \(x\), treating \(y\) as a function of \(x\).
  2. Every time we differentiate an expression in \(y\), use the Chain Rule: multiply by \(\frac{dy}{dx}\). For example, \(\frac{d}{dx}(y^2) = 2y\frac{dy}{dx}\) and \(\frac{d}{dx}(\sin y) = \cos y\frac{dy}{dx}\).
  3. Collect all the \(\frac{dy}{dx}\) terms on one side, factor out \(\frac{dy}{dx}\), and solve for it.

Take note that a product such as \(xy\) needs the Product Rule: \(\frac{d}{dx}(xy) = 1\cdot y + x\frac{dy}{dx}\). The answer for \(dy/dx\) will usually contain both \(x\) and \(y\); that is fine, because we will evaluate it at a point \((x, y)\) on the curve.

For the circle, differentiating \(x^2 + y^2 = 25\) gives \(2x + 2y\frac{dy}{dx} = 0\), so \(\frac{dy}{dx} = -\frac{x}{y}\). At the point \((3, 4)\), the slope is \(-\frac34\), and the tangent line is \(y - 4 = -\frac34(x - 3)\). Notice that this agrees with geometry: the radius to \((3, 4)\) has slope \(\frac43\), and the tangent to a circle is perpendicular to the radius.

Second derivatives implicitly. To find \(\frac{d^2y}{dx^2}\), differentiate the expression for \(\frac{dy}{dx}\) again with respect to \(x\) (using the Quotient Rule, and remembering that \(y\) is a function of \(x\)), then substitute the expression for \(\frac{dy}{dx}\) you already found. Often the original equation of the curve can then be used to simplify.

Common mistake Writing \(\frac{d}{dx}(y^2) = 2y\). Because \(y\) depends on \(x\), the Chain Rule gives \(2y\frac{dy}{dx}\). Also, do not forget that the derivative of the constant on the right side is 0.
Key equations
\[ \frac{d}{dx}\left(y^n\right) = ny^{n-1}\frac{dy}{dx}, \qquad \frac{d}{dx}(xy) = y + x\frac{dy}{dx} \]
\[ x^2 + y^2 = r^2 \;\Rightarrow\; \frac{dy}{dx} = -\frac{x}{y} \]

★Key takeaways

  • A composite function is a function inside another; name the inner function \(u\) before you differentiate.
  • Chain Rule: \(\frac{dy}{dx} = \frac{dy}{du}\frac{du}{dx}\), the derivative of the outside (inside left alone) times the derivative of the inside.
  • Power + Chain: \(\frac{d}{dx}[g(x)]^n = n[g(x)]^{n-1}g'(x)\).
  • In longer problems, name each piece, find each derivative separately, then assemble and factor.
  • Implicit differentiation: differentiate both sides, attach \(\frac{dy}{dx}\) to every \(y\)-derivative, then solve for \(\frac{dy}{dx}\).
  • An implicit \(dy/dx\) usually contains both \(x\) and \(y\); evaluate it at a point on the curve.
  • For \(y''\), differentiate \(y'\) again, substitute \(y'\), and simplify with the equation of the curve.

Example 5.1 Power, Chain and Quotient Rules together

Find the derivative of the function \(y = \left(\dfrac{t - 2}{2t + 1}\right)^9\).

(From the instructor's module)
Show solution (try it first)

Given: \(y = u^9\) with inner function \(u = \dfrac{t - 2}{2t + 1}\).   Find: \(dy/dt\), simplified.

Plan: For this problem, we are going to combine the Power Rule, the Chain Rule and the Quotient Rule: the outer function is the 9th power, and the inner function is a quotient.

Step 1. Let \(u = \dfrac{t - 2}{2t + 1}\), so \(y = u^9\). By the Chain Rule:

\[ \frac{dy}{dt} = \frac{dy}{du}\cdot\frac{du}{dt} = 9u^8\cdot\frac{du}{dt} \]

Step 2. Find \(\frac{du}{dt}\) with the Quotient Rule (low d-high minus high d-low):

\[ \frac{du}{dt} = \frac{(2t + 1)(1) - (t - 2)(2)}{(2t + 1)^2} = \frac{2t + 1 - 2t + 4}{(2t + 1)^2} = \frac{5}{(2t + 1)^2} \]

Step 3. Substitute back \(u\) and \(\frac{du}{dt}\):

\[ \frac{dy}{dt} = 9\left(\frac{t - 2}{2t + 1}\right)^8\cdot\frac{5}{(2t + 1)^2} \]

Step 4. Combine the powers of \(2t + 1\) in the denominator (\(8 + 2 = 10\)):

\[ \frac{dy}{dt} = \frac{45(t - 2)^8}{(2t + 1)^{10}} \]

Answer: \(\boxed{\dfrac{dy}{dt} = \dfrac{45(t - 2)^8}{(2t + 1)^{10}}}\). That is our answer.

Check: At \(t = 3\): the formula gives \(\frac{45(1)^8}{7^{10}} \approx 1.593\times 10^{-7}\), and a difference quotient \(\frac{y(3.0001) - y(3)}{0.0001}\) gives the same value. ✓

Example 5.2 Product Rule with two chains

Find the derivative of the function \(y = (2x + 1)^5(x^3 - x + 1)^4\).

(From the instructor's module)
Show solution (try it first)

Given: a product of two composite functions.   Find: \(dy/dx\) in factored form.

Plan: As you can observe, we will use the Product Rule, and the Chain Rule for each factor. Let \(u = (2x + 1)^5\) and \(v = (x^3 - x + 1)^4\). Find \(u'\) and \(v'\) first, then assemble.

Step 1. For \(u\): let \(a = 2x + 1\), so \(u = a^5\):

\[ u' = 5a^4\cdot\frac{da}{dx} = 5(2x + 1)^4\cdot 2 = 10(2x + 1)^4 \]

Step 2. For \(v\): let \(b = x^3 - x + 1\), so \(v = b^4\):

\[ v' = 4b^3\cdot\frac{db}{dx} = 4(x^3 - x + 1)^3(3x^2 - 1) \]

Step 3. Recall the Product Rule \((uv)' = u'v + uv'\):

\[ y' = 10(2x + 1)^4(x^3 - x + 1)^4 + (2x + 1)^5\cdot 4(x^3 - x + 1)^3(3x^2 - 1) \]

Step 4. Factor out the common factor \(2(2x + 1)^4(x^3 - x + 1)^3\):

\[ y' = 2(2x + 1)^4(x^3 - x + 1)^3\left[5(x^3 - x + 1) + 2(2x + 1)(3x^2 - 1)\right] \]

Step 5. Expand inside the brackets: \(5x^3 - 5x + 5\) and \(2(6x^3 + 3x^2 - 2x - 1) = 12x^3 + 6x^2 - 4x - 2\). Add them:

\[ y' = 2(2x + 1)^4(x^3 - x + 1)^3(17x^3 + 6x^2 - 9x + 3) \]

Answer: \(\boxed{y' = 2(2x + 1)^4(x^3 - x + 1)^3(17x^3 + 6x^2 - 9x + 3)}\). That is our answer.

Check: At \(x = 0\): the original form gives \(10(1)(1) + (1)(4)(1)(-1) = 6\), and the factored form gives \(2(1)(1)(3) = 6\). ✓

Example 5.3 A product with a trigonometric chain

Find the derivative of the function \(y = (3x - 1)^4\cos(x^2)\).

(From the instructor's module)
Show solution (try it first)

Given: \(u = (3x - 1)^4\), \(v = \cos(x^2)\), \(y = uv\).   Find: \(dy/dx\).

Plan: Product Rule, with the Chain Rule inside each factor.

Step 1. Let \(a = 3x - 1\), so \(u = a^4\):

\[ u' = 4a^3\cdot 3 = 12(3x - 1)^3 \]

Step 2. Let \(b = x^2\), so \(v = \cos b\):

\[ v' = -\sin b\cdot\frac{db}{dx} = -2x\sin(x^2) \]

Step 3. Product Rule \(y' = u'v + uv'\):

\[ y' = 12(3x - 1)^3\cos(x^2) + (3x - 1)^4\left(-2x\sin(x^2)\right) \]

Step 4. Tidy up the signs:

\[ y' = 12(3x - 1)^3\cos(x^2) - 2x(3x - 1)^4\sin(x^2) \]

Answer: \(\boxed{y' = 12(3x - 1)^3\cos(x^2) - 2x(3x - 1)^4\sin(x^2)}\). That is our answer.

Check: At \(x = 0\): \(y'(0) = 12(-1)^3(1) - 0 = -12\). A difference quotient at 0 with \(h = 0.0001\) gives about \(-12.0\). ✓

Example 5.4 Implicit differentiation and a tangent line

Find \(\dfrac{dy}{dx}\) for the curve \(x^3 + y^3 = 6xy\), and find the tangent line at the point \((3, 3)\).

Similar to Stewart §2.6, Example 2
Show solution (try it first)

Given: the folium of Descartes \(x^3 + y^3 = 6xy\) and the point \((3, 3)\).   Find: \(dy/dx\) and the tangent line.

Plan: Differentiate both sides with respect to \(x\), treating \(y\) as a function of \(x\) (Chain Rule for \(y^3\), Product Rule for \(6xy\)). Then solve for \(dy/dx\).

Step 1. Differentiate both sides:

\[ 3x^2 + 3y^2\frac{dy}{dx} = 6\left(1\cdot y + x\frac{dy}{dx}\right) = 6y + 6x\frac{dy}{dx} \]

Step 2. Divide by 3 and move the \(dy/dx\) terms to the left:

\[ y^2\frac{dy}{dx} - 2x\frac{dy}{dx} = 2y - x^2 \]

Step 3. Factor out \(\frac{dy}{dx}\) and solve:

\[ \frac{dy}{dx} = \frac{2y - x^2}{y^2 - 2x} \]

Step 4. Check that \((3, 3)\) is on the curve (\(27 + 27 = 54 = 6\cdot 9\) ✓) and substitute:

\[ \left.\frac{dy}{dx}\right|_{(3, 3)} = \frac{6 - 9}{9 - 6} = -1 \]

Step 5. Tangent line through \((3, 3)\) with slope \(-1\):

\[ y - 3 = -(x - 3) \;\Rightarrow\; x + y = 6 \]

Answer: \(\boxed{\dfrac{dy}{dx} = \dfrac{2y - x^2}{y^2 - 2x}}\), and the tangent line is \(\boxed{x + y = 6}\). That is our answer.

Check: The curve is symmetric in \(x\) and \(y\) (swapping them gives the same equation), so at the symmetric point \((3, 3)\) the tangent must be perpendicular to the line \(y = x\); slope \(-1\) ✓.

Example 5.5 A second derivative, implicitly

Find \(y''\) if \(x^4 + y^4 = 16\).

Similar to Stewart §2.6, Example 4
Show solution (try it first)

Given: \(x^4 + y^4 = 16\).   Find: \(y''\) in terms of \(x\) and \(y\), simplified.

Plan: Find \(y'\) implicitly, differentiate it again with the Quotient Rule, substitute \(y'\), and use the original equation to simplify.

Step 1. Differentiate implicitly:

\[ 4x^3 + 4y^3y' = 0 \;\Rightarrow\; y' = -\frac{x^3}{y^3} \]

Step 2. Differentiate \(y'\) with the Quotient Rule (remember \(y\) depends on \(x\)):

\[ y'' = -\frac{y^3(3x^2) - x^3(3y^2y')}{y^6} \]

Step 3. Substitute \(y' = -x^3/y^3\):

\[ y'' = -\frac{3x^2y^3 - 3x^3y^2\left(-\frac{x^3}{y^3}\right)}{y^6} = -\frac{3x^2y^3 + \frac{3x^6}{y}}{y^6} \]

Step 4. Multiply the numerator and denominator by \(y\):

\[ y'' = -\frac{3x^2y^4 + 3x^6}{y^7} = -\frac{3x^2(y^4 + x^4)}{y^7} \]

Step 5. Use the curve itself: \(x^4 + y^4 = 16\):

\[ y'' = -\frac{3x^2(16)}{y^7} = -\frac{48x^2}{y^7} \]

Answer: \(\boxed{y'' = -\dfrac{48x^2}{y^7}}\). That is our answer.

Check: At the top of the curve, \((0, 2)\): \(y'' = 0\), and the curve \(y = (16 - x^4)^{1/4}\) is indeed very flat there (its first nonzero term is of order \(x^4\)). ✓
