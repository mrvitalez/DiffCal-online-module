2.5The Chain Rule

So far you can differentiate polynomials, rational functions and the six trigonometric functions, and you can combine them with the Product and Quotient Rules. But what about \(F(x) = \sqrt{x^2 + 5}\) or \(G(x) = \sin(x^2)\)? Neither is a sum, product or quotient of functions you already know. Each is a composition: one function is fed into another. Stewart §2.5 gives the rule for this case, and it is the rule you will use more than any other.

Outer and inner. Write \(F(x) = f(g(x))\). The inner function \(g\) acts first; the outer function \(f\) acts on the result. For \(F(x) = \sqrt{x^2 + 5}\), the inner function is \(u = x^2 + 5\) and the outer function is \(f(u) = \sqrt{u}\).

The Chain Rule If \(g\) is differentiable at \(x\) and \(f\) is differentiable at \(g(x)\), then \(F = f \circ g\) is differentiable at \(x\) and \[F'(x) = f'\big(g(x)\big)\cdot g'(x).\] In words: the derivative of the outer function, evaluated at the inner function, times the derivative of the inner function.

Leibniz form. If \(y = f(u)\) and \(u = g(x)\), then \[\frac{dy}{dx} = \frac{dy}{du}\,\frac{du}{dx}.\] This form shows why the rule is true: rates multiply. If \(u\) changes 3 times as fast as \(x\), and \(y\) changes 2 times as fast as \(u\), then \(y\) changes \(2 \times 3 = 6\) times as fast as \(x\). (The \(du\)'s look like they cancel; they are not really fractions, but the notation is a good memory aid.)

For \(F(x) = \sqrt{x^2 + 5}\): \(\dfrac{dy}{du} = \dfrac{1}{2\sqrt{u}}\) and \(\dfrac{du}{dx} = 2x\), so \(F'(x) = \dfrac{1}{2\sqrt{x^2+5}}\cdot 2x = \dfrac{x}{\sqrt{x^2+5}}\).

Power Rule combined with the Chain Rule. When the outer function is a power, \[\frac{d}{dx}\big[g(x)\big]^n = n\big[g(x)\big]^{n-1} g'(x).\] So \(\dfrac{d}{dx}(2x^3 - x)^5 = 5(2x^3 - x)^4(6x^2 - 1)\). There is no need to expand the fifth power!

Trigonometric functions. \(\dfrac{d}{dx}\sin(x^2) = \cos(x^2)\cdot 2x\): the outer function is sine, the inner is \(x^2\). Compare \(\sin^2 x = (\sin x)^2\), where the outer function is squaring: \(\dfrac{d}{dx}\sin^2 x = 2\sin x\cos x\).

Nested chains. With three layers, \(y = f(g(h(x)))\), keep peeling from the outside in: \(y' = f'(g(h(x)))\cdot g'(h(x))\cdot h'(x)\). For example, \[\frac{d}{dx}\cos\!\big(\sqrt{1 + x^2}\big) = -\sin\!\big(\sqrt{1 + x^2}\big)\cdot\frac{1}{2\sqrt{1+x^2}}\cdot 2x = -\frac{x\sin\sqrt{1+x^2}}{\sqrt{1+x^2}}.\]

Common mistake Forgetting the inner derivative. \(\dfrac{d}{dx}\sin(5x)\) is \(5\cos(5x)\), not \(\cos(5x)\). After you differentiate the outer function, always ask: "what was inside, and what is its derivative?" Also leave the inside unchanged in the outer derivative: \(\dfrac{d}{dx}(x^2+1)^3 = 3(x^2+1)^2\cdot 2x\), never \(3(2x)^2\).
Key equations
\[ \big(f(g(x))\big)' = f'\big(g(x)\big)\,g'(x) \]
\[ \frac{dy}{dx} = \frac{dy}{du}\,\frac{du}{dx} \]
\[ \frac{d}{dx}\big[g(x)\big]^n = n\big[g(x)\big]^{n-1}g'(x) \]

2.6Implicit Differentiation

Most curves you have met are given explicitly, as \(y = f(x)\). Some curves are given implicitly by an equation that relates \(x\) and \(y\), such as the circle \(x^2 + y^2 = 25\) or the curve \(x^3 + y^3 = 9xy\) (a folium of Descartes). You could solve the circle for \(y = \pm\sqrt{25 - x^2}\), but solving the folium for \(y\) is very messy. Stewart §2.6 shows how to find \(dy/dx\) without solving for \(y\) at all.

The method of implicit differentiation.

  1. Think of \(y\) as an unknown function of \(x\).
  2. Differentiate both sides of the equation with respect to \(x\). Every time you differentiate an expression in \(y\), the Chain Rule adds a factor \(\dfrac{dy}{dx}\): for example \(\dfrac{d}{dx}(y^3) = 3y^2\dfrac{dy}{dx}\).
  3. Collect all terms containing \(\dfrac{dy}{dx}\) on one side, factor it out, and solve.

Circle. From \(x^2 + y^2 = 25\): \(2x + 2y\dfrac{dy}{dx} = 0\), so \(\dfrac{dy}{dx} = -\dfrac{x}{y}\). At the point \((3, 4)\) the slope is \(-\tfrac34\), and the tangent line is \(y - 4 = -\tfrac34(x - 3)\). Notice the answer contains both \(x\) and \(y\); that is normal. It works for the top half and the bottom half of the circle at once.

Folium. From \(x^3 + y^3 = 9xy\), differentiate the right side with the Product Rule: \[3x^2 + 3y^2 y' = 9y + 9x y'.\] Collect: \(3y^2 y' - 9xy' = 9y - 3x^2\), so \(y'(3y^2 - 9x) = 9y - 3x^2\) and \[y' = \frac{3y - x^2}{y^2 - 3x}.\] The point \((2,4)\) is on the curve (\(8 + 64 = 72 = 9\cdot 2\cdot 4\)), and there \(y' = \dfrac{12 - 4}{16 - 6} = \dfrac45\).

Second derivatives implicitly. Differentiate the formula for \(y'\) again with respect to \(x\), remembering that \(y\) is still a function of \(x\), then substitute the formula for \(y'\). For the circle \(x^2 + y^2 = r^2\), the Quotient Rule gives \[y'' = -\frac{y - x y'}{y^2} = -\frac{y + x^2/y}{y^2} = -\frac{x^2 + y^2}{y^3} = -\frac{r^2}{y^3}.\] The last step used the original equation, \(x^2 + y^2 = r^2\). Using the curve's equation to simplify is a very common final step.

Why it works. Near most points, a piece of the curve is the graph of some differentiable function \(y = f(x)\), even if you cannot write a formula for it. The equation is true for every \(x\) on that piece, so both sides have equal derivatives. You never need the formula for \(f\); you only need the fact that it exists, so that the Chain Rule applies to terms like \(y^3 = [f(x)]^3\).

Implicit differentiation also works with trigonometric functions: from \(\sin y = x\), you get \(\cos y \cdot y' = 1\), so \(y' = 1/\cos y\).

Common mistake Writing \(\dfrac{d}{dx}(y^2) = 2y\). The variable is \(x\), so the Chain Rule is needed: \(\dfrac{d}{dx}(y^2) = 2y\,y'\). Similarly \(\dfrac{d}{dx}(xy) = y + x y'\) by the Product Rule, not just \(y'\). And remember to differentiate the constant on the right: \(\dfrac{d}{dx}(25) = 0\).
Key equations
\[ \frac{d}{dx}\big(y^n\big) = n y^{n-1}\,\frac{dy}{dx} \]
\[ x^2 + y^2 = 25 \;\Rightarrow\; \frac{dy}{dx} = -\frac{x}{y} \]
\[ x^3 + y^3 = 9xy \;\Rightarrow\; \frac{dy}{dx} = \frac{3y - x^2}{y^2 - 3x} \]

★Key takeaways

  • The Chain Rule: the derivative of f(g(x)) is f'(g(x)) times g'(x), the outer derivative at the inner function times the inner derivative.
  • In Leibniz notation, dy/dx = (dy/du)(du/dx): rates of change multiply along a chain.
  • For powers of a function, d/dx [g(x)]^n = n[g(x)]^(n-1) g'(x); you never need to expand the power first.
  • With several layers, peel from the outside in and multiply one derivative per layer.
  • In implicit differentiation, every derivative of an expression in y picks up a factor dy/dx; then solve for dy/dx.
  • Implicit answers usually contain both x and y; substitute the point's coordinates to get a slope, and use the curve's equation to simplify second derivatives.

Example 5.1 Powers of a function

Differentiate: (a) \(y = (3x^2 - 5x + 1)^6\)   (b) \(y = \dfrac{1}{(x^3 + 2)^4}\).

(Similar to Stewart §2.5, Examples 3 and 4)
Show solution (try it first)

Strategy:

Both are a power of an inner function. Use \(\dfrac{d}{dx}[g(x)]^n = n[g(x)]^{n-1}g'(x)\). For (b), first rewrite the fraction as a negative power so that you do not need the Quotient Rule.

Solution:

(a) The inner function is \(u = 3x^2 - 5x + 1\), with \(u' = 6x - 5\). The outer function is \(u^6\), with derivative \(6u^5\). So \[y' = 6(3x^2 - 5x + 1)^5\,(6x - 5).\]

(b) Rewrite \(y = (x^3 + 2)^{-4}\). The inner function is \(u = x^3 + 2\), with \(u' = 3x^2\). Then \[y' = -4(x^3 + 2)^{-5}\cdot 3x^2 = -\frac{12x^2}{(x^3 + 2)^5}.\]

Check:

In (b) the exponent goes from \(-4\) to \(-5\) (one less), not to \(-3\). A quick check of the sign: for \(x > 0\), \(x^3 + 2\) grows, so \(1/(x^3+2)^4\) shrinks, and indeed \(y' < 0\).

Example 5.2 A nested chain and a product

Differentiate: (a) \(F(x) = \cos^4(3x^2 + 1)\)   (b) \(G(x) = x^2\sqrt{1 - x^2}\).

(Similar to Stewart §2.5, Examples 5 and 8)
Show solution (try it first)

Strategy:

(a) has three layers: the fourth power (outside), then cosine, then \(3x^2 + 1\) (inside). Write one factor per layer. (b) is a product, and one factor needs the Chain Rule.

Solution:

(a) Write \(F(x) = \big[\cos(3x^2+1)\big]^4\). Peel the layers:

  • outer power: \(4\cos^3(3x^2+1)\)
  • cosine: \(-\sin(3x^2+1)\)
  • inside: \(6x\)

Multiply: \(F'(x) = 4\cos^3(3x^2+1)\cdot\big(-\sin(3x^2+1)\big)\cdot 6x = -24x\cos^3(3x^2+1)\sin(3x^2+1)\).

(b) Product Rule, with \(\dfrac{d}{dx}\sqrt{1-x^2} = \dfrac{1}{2\sqrt{1-x^2}}\cdot(-2x) = \dfrac{-x}{\sqrt{1-x^2}}\): \[G'(x) = 2x\sqrt{1-x^2} + x^2\cdot\frac{-x}{\sqrt{1-x^2}}.\] Put everything over \(\sqrt{1-x^2}\): \(2x\sqrt{1-x^2} = \dfrac{2x(1-x^2)}{\sqrt{1-x^2}}\), so \[G'(x) = \frac{2x - 2x^3 - x^3}{\sqrt{1-x^2}} = \frac{2x - 3x^3}{\sqrt{1-x^2}}.\]

Check:

In (a), a common slip is to stop after two layers and forget the \(6x\). Count: three layers, three factors. In (b), at \(x = 0\) the formula gives \(G'(0) = 0\), which makes sense: \(G(x) \approx x^2\) near 0, and \(x^2\) has a horizontal tangent there.

Example 5.3 Tangent lines to the folium

For the curve \(x^3 + y^3 = 9xy\): (a) find \(dy/dx\); (b) find the tangent line at \((2, 4)\); (c) find the point in the first quadrant (other than the origin) where the tangent line is horizontal.

(Similar to Stewart §2.6, Example 2)
Show solution (try it first)

Strategy:

Differentiate both sides with respect to \(x\), treating \(y\) as a function of \(x\). The term \(9xy\) needs the Product Rule. A tangent line is horizontal where the numerator of \(dy/dx\) is zero (and the denominator is not); combine that condition with the curve's equation.

Solution:

(a) \(3x^2 + 3y^2 y' = 9y + 9xy'\). Move the \(y'\) terms to the left: \(3y^2 y' - 9x y' = 9y - 3x^2\). Factor and divide by 3: \[y'(y^2 - 3x) = 3y - x^2 \quad\Rightarrow\quad y' = \frac{3y - x^2}{y^2 - 3x}.\]

(b) At \((2,4)\): \(y' = \dfrac{12 - 4}{16 - 6} = \dfrac{4}{5}\). The tangent line is \(y - 4 = \tfrac45(x - 2)\), that is \(y = \tfrac45 x + \tfrac{12}{5}\).

(c) Horizontal tangent: \(3y - x^2 = 0\), so \(y = x^2/3\). Substitute into the curve: \[x^3 + \frac{x^6}{27} = 9x\cdot\frac{x^2}{3} = 3x^3 \quad\Rightarrow\quad \frac{x^6}{27} = 2x^3 \quad\Rightarrow\quad x^3 = 54\] (for \(x \ne 0\)). So \(x = \sqrt[3]{54} = 3\sqrt[3]{2} \approx 3.78\) and \(y = x^2/3 = 3\sqrt[3]{4} \approx 4.76\). The denominator \(y^2 - 3x \approx 22.7 - 11.3 \ne 0\), so the tangent really is horizontal at \(\big(3\sqrt[3]{2},\, 3\sqrt[3]{4}\big)\).

Check:

Look at Figure 5.4: the top of the loop is a little to the right of \(x = 3.5\) and a little below \(y = 5\), matching \((3.78, 4.76)\). The slope \(4/5\) at \((2,4)\) is positive, and the loop is still rising there. Good.
