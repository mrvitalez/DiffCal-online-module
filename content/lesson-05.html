2.5The Chain Rule

So far we can differentiate polynomials, rational functions and the six trigonometric functions, and we can combine them with the Product and Quotient Rules. But what about \(y = \sqrt{x^2 + 1}\) or \(y = \sin(4x^3)\)? Neither one is a sum, product or quotient of functions we already know. So, how do we differentiate them?

Notice that each one is a composition: one function is fed into another. The inner function acts first, and the outer function acts on the result. In \(y = \sqrt{x^2 + 1}\), the inner function is \(u = x^2 + 1\) and the outer function is \(y = \sqrt{u}\). Stewart §2.5 gives the rule for this case, and it is the rule we will use more than any other.

The Chain Rule If \(g\) is differentiable at \(x\) and \(f\) is differentiable at \(g(x)\), then \(F(x) = f(g(x))\) is differentiable at \(x\) and \[F'(x) = f'\big(g(x)\big)\cdot g'(x).\] In Leibniz notation, if \(y = f(u)\) and \(u = g(x)\), then \[\frac{dy}{dx} = \frac{dy}{du}\,\frac{du}{dx}.\]

Why is the rule true? The Leibniz form shows us: rates multiply. If \(u\) changes 3 times as fast as \(x\), and \(y\) changes 2 times as fast as \(u\), then \(y\) changes \(2 \times 3 = 6\) times as fast as \(x\). Take note that the \(du\)'s look like they cancel. They are not really fractions, but the notation is a good memory aid.

How we use it. In every problem we do the same thing: we let \(u\) be the inner function, write \(y\) in terms of \(u\), and then use \(\dfrac{dy}{dx} = \dfrac{dy}{du}\,\dfrac{du}{dx}\). Let's see it in three short examples.

  • \(y = \sqrt{x^2 + 1}\). Let \(u = x^2 + 1\); therefore \(y = u^{1/2}\). Then \(\dfrac{dy}{dx} = \tfrac12 u^{-1/2}\cdot 2x = \dfrac{x}{\sqrt{x^2 + 1}}\).
  • \(y = (5x - 2)^4\). Let \(u = 5x - 2\); therefore \(y = u^4\). Then \(\dfrac{dy}{dx} = 4u^3\cdot 5 = 20(5x - 2)^3\).
  • \(y = \sin(4x^3)\). Let \(u = 4x^3\); therefore \(y = \sin u\). Then \(\dfrac{dy}{dx} = \cos u\cdot 12x^2 = 12x^2\cos(4x^3)\).

The same steps give the tangent line in Figure 5.2: for \(F(x) = \sqrt{x^2 + 5}\), \(F'(x) = \dfrac{x}{\sqrt{x^2 + 5}}\), so \(F'(2) = \tfrac23\). And Figure 5.1 shows what the inner derivative does: \(y = \sin 2x\) climbs twice as steeply at the origin as \(y = \sin x\).

Power Rule combined with the Chain Rule. When the outer function is a power, we get \[\frac{d}{dx}\big[g(x)\big]^n = n\big[g(x)\big]^{n-1} g'(x).\] Do we need to expand \((5x - 2)^4\) first? No. That is the beauty of the Chain Rule.

Watch the layers. Compare \(\sin(x^2)\) with \(\sin^2 x = (\sin x)^2\). In the first, the outer function is sine: \(\dfrac{d}{dx}\sin(x^2) = 2x\cos(x^2)\). In the second, the outer function is squaring: \(\dfrac{d}{dx}\sin^2 x = 2\sin x\cos x\). With three layers, we just keep peeling from the outside in, one factor per layer: \[\frac{d}{dx}\cos\!\big(\sqrt{1 + x^2}\big) = -\sin\!\big(\sqrt{1 + x^2}\big)\cdot\frac{1}{2\sqrt{1+x^2}}\cdot 2x = -\frac{x\sin\sqrt{1+x^2}}{\sqrt{1+x^2}}.\] In the worked examples we will also combine the Chain Rule with the Quotient and Product Rules.

Common mistake Forgetting the inner derivative. \(\dfrac{d}{dx}\sin(5x)\) is \(5\cos(5x)\), not \(\cos(5x)\). After we differentiate the outer function, we always ask: "what was inside, and what is its derivative?" Also, leave the inside unchanged in the outer derivative: \(\dfrac{d}{dx}(x^2+1)^3 = 3(x^2+1)^2\cdot 2x\), never \(3(2x)^2\).
Key equations
\[ \big(f(g(x))\big)' = f'\big(g(x)\big)\,g'(x) \]
\[ \frac{dy}{dx} = \frac{dy}{du}\,\frac{du}{dx} \]
\[ \frac{d}{dx}\big[g(x)\big]^n = n\big[g(x)\big]^{n-1}g'(x) \]

2.6Implicit Differentiation

Most curves we have met are given explicitly, as \(y = f(x)\). Some curves are given implicitly by an equation that relates \(x\) and \(y\), such as the circle \(x^2 + y^2 = 25\) or the curve \(x^3 + y^3 = 9xy\) (a folium of Descartes). We could solve the circle for \(y = \pm\sqrt{25 - x^2}\), but solving the folium for \(y\) is very messy. So, how do we find the slope of such a curve? Stewart §2.6 shows us how to find \(dy/dx\) without solving for \(y\) at all.

The method of implicit differentiation.

  1. Think of \(y\) as an unknown function of \(x\).
  2. Differentiate both sides of the equation with respect to \(x\). Every time we differentiate an expression in \(y\), the Chain Rule adds a factor \(\dfrac{dy}{dx}\): for example \(\dfrac{d}{dx}(y^3) = 3y^2\dfrac{dy}{dx}\).
  3. Collect all terms containing \(\dfrac{dy}{dx}\) on one side, factor it out, and solve.

Circle. Let's start with \(x^2 + y^2 = 25\). Differentiating gives \(2x + 2y\dfrac{dy}{dx} = 0\), so \(\dfrac{dy}{dx} = -\dfrac{x}{y}\). At the point \((3, 4)\) the slope is \(-\tfrac34\), and the tangent line is \(y - 4 = -\tfrac34(x - 3)\). Notice that the answer contains both \(x\) and \(y\). Is that a problem? No, that is normal. It works for the top half and the bottom half of the circle at once.

Folium. From \(x^3 + y^3 = 9xy\), we differentiate the right side with the Product Rule: \[3x^2 + 3y^2 y' = 9y + 9x y'.\] Collect: \(3y^2 y' - 9xy' = 9y - 3x^2\), so \(y'(3y^2 - 9x) = 9y - 3x^2\) and \[y' = \frac{3y - x^2}{y^2 - 3x}.\] The point \((2,4)\) is on the curve (\(8 + 64 = 72 = 9\cdot 2\cdot 4\)), and there \(y' = \dfrac{12 - 4}{16 - 6} = \dfrac45\).

Second derivatives implicitly. We differentiate the formula for \(y'\) again with respect to \(x\), remembering that \(y\) is still a function of \(x\), then substitute the formula for \(y'\). For the circle \(x^2 + y^2 = r^2\), the Quotient Rule gives \[y'' = -\frac{y - x y'}{y^2} = -\frac{y + x^2/y}{y^2} = -\frac{x^2 + y^2}{y^3} = -\frac{r^2}{y^3}.\] Take note that the last step used the original equation, \(x^2 + y^2 = r^2\). Using the curve's equation to simplify is a very common final step.

Why does it work? Near most points, a piece of the curve is the graph of some differentiable function \(y = f(x)\), even if we cannot write a formula for it. The equation is true for every \(x\) on that piece, so both sides have equal derivatives. We never need the formula for \(f\); we only need the fact that it exists, so that the Chain Rule applies to terms like \(y^3 = [f(x)]^3\).

Implicit differentiation also works with trigonometric functions: from \(\sin y = x\), we get \(\cos y \cdot y' = 1\), so \(y' = 1/\cos y\).

Common mistake Writing \(\dfrac{d}{dx}(y^2) = 2y\). The variable is \(x\), so the Chain Rule is needed: \(\dfrac{d}{dx}(y^2) = 2y\,y'\). Similarly \(\dfrac{d}{dx}(xy) = y + x y'\) by the Product Rule, not just \(y'\). And remember to differentiate the constant on the right: \(\dfrac{d}{dx}(25) = 0\).
Key equations
\[ \frac{d}{dx}\big(y^n\big) = n y^{n-1}\,\frac{dy}{dx} \]
\[ x^2 + y^2 = 25 \;\Rightarrow\; \frac{dy}{dx} = -\frac{x}{y} \]
\[ x^3 + y^3 = 9xy \;\Rightarrow\; \frac{dy}{dx} = \frac{3y - x^2}{y^2 - 3x} \]

★Key takeaways

  • The Chain Rule: the derivative of f(g(x)) is f'(g(x)) times g'(x), that is, the outer derivative at the inner function times the inner derivative.
  • In Leibniz notation, dy/dx = (dy/du)(du/dx): we can think of it as rates of change multiplying along a chain.
  • For powers of a function, d/dx [g(x)]^n = n[g(x)]^(n-1) g'(x); take note that we never need to expand the power first.
  • With several layers, we peel from the outside in and multiply one derivative per layer.
  • In implicit differentiation, every derivative of an expression in y picks up a factor dy/dx; then we solve for dy/dx.
  • Implicit answers usually contain both x and y; we substitute the point's coordinates to get a slope, and use the curve's equation to simplify second derivatives.

Example 5.1 A root in the denominator

Find the derivative of \(y = \dfrac{1}{\sqrt[3]{x^2 + x + 1}}\).

(Instr. Vitalez's notes, Example 8 (Stewart §2.5))
Show solution (try it first)
Given
  • \(y = \dfrac{1}{\sqrt[3]{x^2 + x + 1}}\).
  • Find: \(\dfrac{dy}{dx}\).
Step 1: Rewrite y as a power

A cube root is a \(\tfrac13\) power, and one over a power is a negative power. Writing it this way lets us use the Power Rule instead of the Quotient Rule.

\[y = \frac{1}{(x^2 + x + 1)^{1/3}} = (x^2 + x + 1)^{-1/3}\]

Step 2: Let u be the inner function

Let \(u = x^2 + x + 1\); therefore \(y = u^{-1/3}\).

\[\frac{dy}{du} = -\tfrac13 u^{-4/3}\]

\[\frac{du}{dx} = 2x + 1\]

Step 3: Multiply the two derivatives

By the Chain Rule, \(\dfrac{dy}{dx} = \dfrac{dy}{du}\,\dfrac{du}{dx}\).

\[\frac{dy}{dx} = -\tfrac13 u^{-4/3}\,(2x + 1)\]

Step 4: Substitute u back and simplify

We put \(u = x^2 + x + 1\) back, then move the negative power to the denominator.

\[\frac{dy}{dx} = -\tfrac13 (x^2 + x + 1)^{-4/3}(2x + 1)\]

\[\frac{dy}{dx} = -\frac{2x + 1}{3(x^2 + x + 1)^{4/3}}\]

\[\frac{dy}{dx} = -\frac{2x + 1}{3\sqrt[3]{(x^2 + x + 1)^4}}\]

Answer

\(\dfrac{dy}{dx} = -\dfrac{2x + 1}{3\sqrt[3]{(x^2 + x + 1)^4}}\).

Check

Take note that the exponent went from \(-\tfrac13\) to \(-\tfrac43\) (one less), not to \(\tfrac23\). Also, at \(x = -\tfrac12\) the inner function \(x^2 + x + 1\) has its smallest value, so \(y\) is largest there, and indeed our derivative is 0 at \(x = -\tfrac12\).

Example 5.2 Power of a quotient

Find the derivative of \(y = \left(\dfrac{t - 2}{2t + 1}\right)^9\).

(Instr. Vitalez's notes, Example 9 (Stewart §2.5))
Show solution (try it first)
Given
  • \(y = \left(\dfrac{t - 2}{2t + 1}\right)^9\), a power of a quotient.
  • Find: \(\dfrac{dy}{dt}\). For this problem, we are going to combine the Power Rule, the Chain Rule and the Quotient Rule.
Step 1: Let u be the quotient

Let \(u = \dfrac{t - 2}{2t + 1}\); therefore \(y = u^9\).

\[\frac{dy}{du} = 9u^8\]

Step 2: Differentiate u with the Quotient Rule

Recall \(\left(\dfrac{f}{g}\right)' = \dfrac{g f' - f g'}{g^2}\), with \(f = t - 2\) and \(g = 2t + 1\).

\[\frac{du}{dt} = \frac{(2t + 1)\frac{d}{dt}(t - 2) - (t - 2)\frac{d}{dt}(2t + 1)}{(2t + 1)^2}\]

\[\frac{du}{dt} = \frac{(2t + 1)(1) - (t - 2)(2)}{(2t + 1)^2}\]

\[\frac{du}{dt} = \frac{2t + 1 - 2t + 4}{(2t + 1)^2}\]

\[\frac{du}{dt} = \frac{5}{(2t + 1)^2}\]

Step 3: Multiply the two derivatives

By the Chain Rule, \(\dfrac{dy}{dt} = \dfrac{dy}{du}\,\dfrac{du}{dt}\), and we put \(u\) back.

\[\frac{dy}{dt} = 9\left(\frac{t - 2}{2t + 1}\right)^8\cdot\frac{5}{(2t + 1)^2}\]

Step 4: Simplify

The eighth power of the quotient is \(\dfrac{(t-2)^8}{(2t+1)^8}\). Then we multiply the denominators: \((2t+1)^8(2t+1)^2 = (2t+1)^{10}\).

\[\frac{dy}{dt} = \frac{9(t - 2)^8}{(2t + 1)^8}\cdot\frac{5}{(2t + 1)^2}\]

\[\frac{dy}{dt} = \frac{45(t - 2)^8}{(2t + 1)^{10}}\]

Answer

\(\dfrac{dy}{dt} = \dfrac{45(t - 2)^8}{(2t + 1)^{10}}\).

Check

At \(t = 2\) the quotient is 0 and \(y = u^9\) is very flat near \(u = 0\), so we expect \(y'(2) = 0\). Our answer gives \(45(0)^8/5^{10} = 0\). Good.

Example 5.3 Product of two powers

Find the derivative of \(y = (2x + 1)^5(x^3 - x + 1)^4\) and write it in factored form.

(Instr. Vitalez's notes, Example 10 (Stewart §2.5))
Show solution (try it first)
Given
  • \(y = (2x + 1)^5(x^3 - x + 1)^4\), a product of two powers.
  • Find: \(y'\), factored. As we can observe, we will use the Product Rule and the Chain Rule.
Step 1: Differentiate the first factor with the Chain Rule

Let \(u = (2x + 1)^5\). With \(a = 2x + 1\), we have \(u = a^5\).

\[u' = 5a^4\cdot\frac{d}{dx}(2x + 1)\]

\[u' = 5(2x + 1)^4\cdot 2\]

\[u' = 10(2x + 1)^4\]

Step 2: Differentiate the second factor with the Chain Rule

Let \(v = (x^3 - x + 1)^4\). With \(b = x^3 - x + 1\), we have \(v = b^4\).

\[v' = 4b^3\cdot\frac{d}{dx}(x^3 - x + 1)\]

\[v' = 4(x^3 - x + 1)^3(3x^2 - 1)\]

Step 3: Apply the Product Rule

Recall \((uv)' = u'v + uv'\).

\[y' = 10(2x + 1)^4(x^3 - x + 1)^4 + (2x + 1)^5\cdot 4(x^3 - x + 1)^3(3x^2 - 1)\]

Step 4: Factor out the common factors

Both terms contain \(2\), \((2x + 1)^4\) and \((x^3 - x + 1)^3\). Let's take them out.

\[y' = 2(2x + 1)^4(x^3 - x + 1)^3\big[5(x^3 - x + 1) + 2(2x + 1)(3x^2 - 1)\big]\]

Step 5: Simplify the bracket

We expand each part of the bracket and combine like terms.

\[5(x^3 - x + 1) = 5x^3 - 5x + 5\]

\[2(2x + 1)(3x^2 - 1) = 2(6x^3 + 3x^2 - 2x - 1) = 12x^3 + 6x^2 - 4x - 2\]

\[(5x^3 - 5x + 5) + (12x^3 + 6x^2 - 4x - 2) = 17x^3 + 6x^2 - 9x + 3\]

Answer

\(y' = 2(2x + 1)^4(x^3 - x + 1)^3(17x^3 + 6x^2 - 9x + 3)\).

Check

At \(x = 0\): from Step 3, \(y'(0) = 10(1)(1) + (1)(4)(1)(-1) = 6\). From the factored answer, \(y'(0) = 2(1)(1)(3) = 6\). The two forms agree.

Example 5.4 The Chain Rule inside a product and a quotient

Find the derivatives of (a) \(y = (3x - 1)^4\cos(x^2)\) and (b) \(y = \dfrac{(x^2 + 1)^3}{\sin x}\).

(Instr. Vitalez's notes, Examples 11 and 12 (Stewart §2.5))
Show solution (try it first)
Given
  • (a) \(y = (3x - 1)^4\cos(x^2)\), a product; both factors need the Chain Rule.
  • (b) \(y = \dfrac{(x^2 + 1)^3}{\sin x}\), a quotient; the numerator needs the Chain Rule.
  • Find: \(y'\) for each.
Step 1: Differentiate the factors of (a)

Let \(u = (3x - 1)^4\) (with \(a = 3x - 1\), \(u = a^4\)) and \(v = \cos(x^2)\) (with \(b = x^2\), \(v = \cos b\)).

\[u' = 4(3x - 1)^3\cdot 3 = 12(3x - 1)^3\]

\[v' = -\sin(x^2)\cdot 2x = -2x\sin(x^2)\]

Step 2: Apply the Product Rule in (a)

Again, using \((uv)' = u'v + uv'\):

\[y' = 12(3x - 1)^3\cos(x^2) + (3x - 1)^4\big(-2x\sin(x^2)\big)\]

\[y' = 12(3x - 1)^3\cos(x^2) - 2x(3x - 1)^4\sin(x^2)\]

Step 3: Differentiate the numerator and denominator of (b)

Let \(u = (x^2 + 1)^3\) (with \(a = x^2 + 1\), \(u = a^3\)) and \(v = \sin x\).

\[u' = 3(x^2 + 1)^2\cdot 2x = 6x(x^2 + 1)^2\]

\[v' = \cos x\]

Step 4: Apply the Quotient Rule in (b)

Recall \(\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}\).

\[y' = \frac{6x(x^2 + 1)^2\sin x - (x^2 + 1)^3\cos x}{\sin^2 x}\]

Step 5: Factor the numerator of (b)

Both terms of the numerator contain \((x^2 + 1)^2\), so we can take it out.

\[y' = \frac{(x^2 + 1)^2\big[6x\sin x - (x^2 + 1)\cos x\big]}{\sin^2 x}\]

Answer

(a) \(y' = 12(3x - 1)^3\cos(x^2) - 2x(3x - 1)^4\sin(x^2)\). (b) \(y' = \dfrac{6x(x^2 + 1)^2\sin x - (x^2 + 1)^3\cos x}{\sin^2 x} = \dfrac{(x^2 + 1)^2\big[6x\sin x - (x^2 + 1)\cos x\big]}{\sin^2 x}\).

Check

In (a), take note that the inner derivative of \(\cos(x^2)\) gives the factor \(2x\); without it the answer is wrong. In (b), the order in the numerator matters: it is \(u'v - uv'\), not \(uv' - u'v\).

Example 5.5 Tangent lines to the folium

For the curve \(x^3 + y^3 = 9xy\): (a) find \(dy/dx\); (b) find the tangent line at \((2, 4)\); (c) find the point in the first quadrant (other than the origin) where the tangent line is horizontal.

(Similar to Stewart §2.6, Example 2)
Show solution (try it first)
Given
  • The curve \(x^3 + y^3 = 9xy\) (a folium of Descartes), with \(y\) a function of \(x\).
  • The point \((2, 4)\) on the curve.
  • Find: \(dy/dx\), the tangent line at \((2,4)\), and the first-quadrant point (not the origin) with a horizontal tangent.
Step 1: Differentiate both sides with respect to x

Every term in \(y\) picks up a factor \(y'\), and \(9xy\) needs the Product Rule.

\[\frac{d}{dx}\left(x^3 + y^3\right) = \frac{d}{dx}(9xy)\]

\[3x^2 + 3y^2 y' = 9y + 9x y'\]

Step 2: Solve for y'

Let's move every \(y'\) term to the left, factor out \(y'\), and divide.

\[3y^2 y' - 9x y' = 9y - 3x^2\]

\[y'(3y^2 - 9x) = 9y - 3x^2\]

\[y' = \frac{9y - 3x^2}{3y^2 - 9x}\]

\[y' = \frac{3y - x^2}{y^2 - 3x} \quad\text{(dividing top and bottom by 3)}\]

Step 3: Find the slope at (2, 4)

We substitute \(x = 2\) and \(y = 4\) into the formula for \(y'\).

\[y' = \frac{3(4) - 2^2}{4^2 - 3(2)} = \frac{12 - 4}{16 - 6} = \frac{8}{10} = \frac45\]

Step 4: Write the tangent line at (2, 4)

Recall the point-slope form \(y - y_1 = m(x - x_1)\).

\[y - 4 = \tfrac45(x - 2)\]

\[y = \tfrac45 x - \tfrac85 + 4\]

\[y = \tfrac45 x + \tfrac{12}{5}\]

Step 5: Set the numerator of y' equal to 0

A tangent line is horizontal when \(y' = 0\), which happens when the numerator is 0 (and the denominator is not).

\[3y - x^2 = 0 \quad\Rightarrow\quad y = \frac{x^2}{3}\]

Step 6: Substitute into the curve's equation

The point must also be on the curve, so we put \(y = x^2/3\) into \(x^3 + y^3 = 9xy\) and solve for \(x\).

\[x^3 + \left(\frac{x^2}{3}\right)^3 = 9x\cdot\frac{x^2}{3}\]

\[x^3 + \frac{x^6}{27} = 3x^3\]

\[\frac{x^6}{27} = 2x^3\]

\[x^6 = 54x^3\]

\[x^3 = 54 \quad (x \ne 0)\]

\[x = \sqrt[3]{54} = \sqrt[3]{27\cdot 2} = 3\sqrt[3]{2} \approx 3.78\]

Step 7: Find y and check the denominator

We use \(y = x^2/3\), then make sure the denominator \(y^2 - 3x\) is not 0 there.

\[y = \frac{(3\sqrt[3]{2})^2}{3} = \frac{9\sqrt[3]{4}}{3} = 3\sqrt[3]{4} \approx 4.76\]

\[y^2 - 3x \approx 22.68 - 11.34 = 11.34 \ne 0\]

Answer

(a) \(\dfrac{dy}{dx} = \dfrac{3y - x^2}{y^2 - 3x}\). (b) The tangent line at \((2,4)\) is \(y = \tfrac45 x + \tfrac{12}{5}\). (c) The tangent is horizontal at \(\big(3\sqrt[3]{2},\, 3\sqrt[3]{4}\big) \approx (3.78, 4.76)\).

Check

Look at Figure 5.4: the top of the loop is a little to the right of \(x = 3.5\) and a little below \(y = 5\), matching \((3.78, 4.76)\). The slope \(4/5\) at \((2,4)\) is positive, and the loop is still rising there. Good.

Example 5.6 A second derivative found implicitly

For the ellipse \(2x^2 + y^2 = 9\): (a) find \(y'\); (b) find \(y''\) and simplify it using the equation of the ellipse; (c) evaluate \(y'\) and \(y''\) at the point \((2, 1)\).

(Similar to Stewart §2.6, Example 4)
Show solution (try it first)
Given
  • The ellipse \(2x^2 + y^2 = 9\), with \(y\) a function of \(x\).
  • The point \((2, 1)\) (check: \(2(4) + 1 = 9\)).
  • Find: \(y'\), \(y''\), and their values at \((2,1)\).
Step 1: Differentiate both sides with respect to x

The term \(y^2\) picks up a factor \(y'\), and the constant 9 has derivative 0.

\[4x + 2y\,y' = 0\]

Step 2: Solve for y'

We isolate \(y'\) and divide by \(2y\).

\[2y\,y' = -4x\]

\[y' = -\frac{4x}{2y} = -\frac{2x}{y}\]

Step 3: Differentiate y' with the Quotient Rule

Recall that \(y\) is still a function of \(x\), so the derivative of \(y\) on the bottom is \(y'\).

\[y'' = -\frac{(2)(y) - (2x)(y')}{y^2}\]

\[y'' = -\frac{2y - 2x\,y'}{y^2}\]

Step 4: Substitute the formula for y'

Let's replace \(y'\) by \(-2x/y\) so that \(y''\) contains only \(x\) and \(y\).

\[y'' = -\frac{2y - 2x\left(-\frac{2x}{y}\right)}{y^2}\]

\[y'' = -\frac{2y + \frac{4x^2}{y}}{y^2}\]

\[y'' = -\frac{2y^2 + 4x^2}{y^3} \quad\text{(multiplying top and bottom by } y\text{)}\]

Step 5: Simplify with the equation of the ellipse

Notice that \(2y^2 + 4x^2 = 2(2x^2 + y^2)\), and the curve tells us \(2x^2 + y^2 = 9\).

\[y'' = -\frac{2(2x^2 + y^2)}{y^3}\]

\[y'' = -\frac{2(9)}{y^3} = -\frac{18}{y^3}\]

Step 6: Evaluate at (2, 1)

We substitute \(x = 2\) and \(y = 1\).

\[y' = -\frac{2(2)}{1} = -4\]

\[y'' = -\frac{18}{1^3} = -18\]

Answer

(a) \(y' = -\dfrac{2x}{y}\). (b) \(y'' = -\dfrac{18}{y^3}\). (c) At \((2,1)\), \(y' = -4\) and \(y'' = -18\).

Check

The point \((2,1)\) is on the top half of the ellipse, which is shaped like a cap, so we expect \(y'' < 0\). Indeed \(-18/y^3 < 0\) whenever \(y > 0\). Take note of the same pattern as the circle: \(y''\) depends only on \(y\) once we use the curve's equation.
