3.1Maximum and Minimum Values

Many practical questions ask for the best value of something: the largest area, the lowest cost, the highest point of a path. In calculus language these are maximum and minimum values, together called extreme values or extrema. Stewart §3.1 shows how the derivative finds them.

Definition Let \(c\) be a number in the domain \(D\) of \(f\). Then \(f(c)\) is the absolute maximum value of \(f\) if \(f(c) \ge f(x)\) for all \(x\) in \(D\), and the absolute minimum value if \(f(c) \le f(x)\) for all \(x\) in \(D\). It is a local maximum value if \(f(c) \ge f(x)\) when \(x\) is near \(c\) (on some open interval containing \(c\)), and a local minimum value if \(f(c) \le f(x)\) when \(x\) is near \(c\).

Think of a mountain trail: each peak is a local maximum, but only the highest point of the whole trail is the absolute maximum. Figure 7.1 shows both kinds.

When are extrema guaranteed? The function \(f(x) = 1/x\) on \((0, 1]\) has no maximum: it grows without bound near 0. The next theorem says this cannot happen for a continuous function on a closed interval.

Extreme Value Theorem If \(f\) is continuous on a closed interval \([a, b]\), then \(f\) attains an absolute maximum value \(f(c)\) and an absolute minimum value \(f(d)\) at some numbers \(c\) and \(d\) in \([a, b]\).

Where can they be? At a smooth peak or valley the tangent line is horizontal.

Fermat's Theorem If \(f\) has a local maximum or minimum at \(c\), and \(f'(c)\) exists, then \(f'(c) = 0\).

This leads to a short list of candidates. A critical number of \(f\) is a number \(c\) in the domain of \(f\) such that either \(f'(c) = 0\) or \(f'(c)\) does not exist. For example, \(g(x) = x^{2/3}(x - 5)\) has \(g'(x) = \frac{5(x - 2)}{3x^{1/3}}\), so its critical numbers are \(2\) (where \(g' = 0\)) and \(0\) (where \(g'\) does not exist). Fermat's Theorem can now be restated: if \(f\) has a local extremum at \(c\), then \(c\) is a critical number.

Common mistake The converse is false. For \(f(x) = x^3\), \(f'(0) = 0\), yet \(x^3\) has no maximum or minimum at 0. A critical number is only a candidate. Also, a number where \(f\) itself is undefined is never a critical number.

The Closed Interval Method. To find the absolute extrema of a continuous \(f\) on \([a, b]\):

  1. Find the values of \(f\) at the critical numbers of \(f\) in \((a, b)\).
  2. Find the values \(f(a)\) and \(f(b)\) at the endpoints.
  3. The largest of these values is the absolute maximum; the smallest is the absolute minimum.

Try \(f(x) = 2x^3 - 9x^2 + 12x\) on \([0, 3]\). Here \(f'(x) = 6x^2 - 18x + 12 = 6(x - 1)(x - 2)\), so the critical numbers are 1 and 2. The table of values is \(f(0) = 0\), \(f(1) = 5\), \(f(2) = 4\), \(f(3) = 9\). The absolute maximum is \(9\) (at the endpoint \(x = 3\)) and the absolute minimum is \(0\) (at \(x = 0\)). Notice that the local maximum \(f(1) = 5\) is not the absolute maximum: never skip the endpoints.

Key equations
\[ f(c) \text{ abs. max} \iff f(c) \ge f(x) \text{ for all } x \in D \]
\[ \text{local extremum at } c \text{ and } f'(c) \text{ exists} \implies f'(c) = 0 \]
\[ c \text{ critical} \iff f'(c) = 0 \text{ or } f'(c) \text{ does not exist} \]

3.2The Mean Value Theorem

The Mean Value Theorem (MVT) is one of the quiet workhorses of calculus. It turns information about the derivative into information about the function itself. Stewart §3.2 starts with a special case.

Rolle's Theorem Let \(f\) satisfy three hypotheses: (1) \(f\) is continuous on \([a, b]\); (2) \(f\) is differentiable on \((a, b)\); (3) \(f(a) = f(b)\). Then there is a number \(c\) in \((a, b)\) such that \(f'(c) = 0\).

Why is it true? If \(f\) is constant, \(f' = 0\) everywhere. Otherwise \(f\) goes above or below its common end value, so by the Extreme Value Theorem it has an absolute maximum or minimum inside \((a, b)\), and by Fermat's Theorem the derivative is 0 there. For \(f(x) = x^2(3 - x)\) on \([0, 3]\), \(f(0) = f(3) = 0\) and \(f'(x) = 6x - 3x^2 = 3x(2 - x)\), so \(c = 2\) works (Figure 7.3).

Counting roots. Rolle's Theorem helps show an equation has exactly one root. Take \(x^3 + 4x - 3 = 0\). Let \(f(x) = x^3 + 4x - 3\). Since \(f(0) = -3 \lt 0\) and \(f(1) = 2 \gt 0\), the Intermediate Value Theorem gives a root between 0 and 1. If there were two roots \(a \lt b\), then \(f(a) = f(b) = 0\) and Rolle would give \(f'(c) = 0\). But \(f'(x) = 3x^2 + 4 \ge 4\) is never 0. So there is exactly one root.

Now tilt the picture so the end values need not match.

The Mean Value Theorem If \(f\) is continuous on \([a, b]\) and differentiable on \((a, b)\), then there is a number \(c\) in \((a, b)\) such that \[f'(c) = \frac{f(b) - f(a)}{b - a}, \quad\text{equivalently}\quad f(b) - f(a) = f'(c)(b - a).\]

Geometrically: somewhere between \(a\) and \(b\), the tangent line is parallel to the secant line through the end points. In terms of motion: if your average velocity over a trip is 60 km/h, then at some instant your speedometer read exactly 60 km/h.

For \(f(x) = x^3 - x\) on \([0, 2]\), the secant slope is \(\frac{6 - 0}{2 - 0} = 3\). Solve \(f'(c) = 3c^2 - 1 = 3\): \(c^2 = \tfrac43\), so \(c = \tfrac{2}{\sqrt3} \approx 1.155\), which does lie in \((0, 2)\) (Figure 7.4). The negative root is rejected because it is outside the interval.

Consequences. The MVT proves facts you may have taken for granted.

Theorem If \(f'(x) = 0\) for all \(x\) in an interval \((a, b)\), then \(f\) is constant on \((a, b)\).
Corollary: If \(f'(x) = g'(x)\) for all \(x\) in \((a, b)\), then \(f - g\) is constant there: \(f(x) = g(x) + C\).

Reason: for any \(x_1 \lt x_2\) in the interval, \(f(x_2) - f(x_1) = f'(c)(x_2 - x_1) = 0\). So if \(f'(x) = 2x\) everywhere, then \(f(x) = x^2 + C\), and one known value such as \(f(1) = 5\) fixes \(C = 4\).

Common mistake Check the hypotheses before using Rolle or the MVT. The interval must make \(f\) continuous on \([a, b]\) and differentiable on \((a, b)\). For instance \(f(x) = |x|\) has \(f(-1) = f(1)\) but no horizontal tangent, because \(f'(0)\) does not exist.
Key equations
\[ f(a) = f(b) \implies f'(c) = 0 \text{ for some } c \in (a, b) \]
\[ f'(c) = \frac{f(b) - f(a)}{b - a} \]
\[ f' = g' \text{ on } (a, b) \implies f(x) = g(x) + C \]

★Key takeaways

  • An absolute extremum is the highest or lowest value over the whole domain; a local extremum only beats its nearby values.
  • A continuous function on a closed interval always has an absolute maximum and an absolute minimum (Extreme Value Theorem).
  • Local extrema can occur only at critical numbers, where f′ is 0 or does not exist, but not every critical number gives an extremum.
  • Closed Interval Method: evaluate f at the critical numbers inside the interval and at both endpoints, then pick the largest and smallest values.
  • The Mean Value Theorem says some tangent line is parallel to the secant line: f(b) − f(a) = f′(c)(b − a).
  • If f′ = 0 on an interval, f is constant there; if f′ = g′, then f and g differ by a constant.

Example 7.1 Finding critical numbers

Find all critical numbers of (a) \(f(x) = x^3 + 3x^2 - 24x\) and (b) \(g(x) = x^{1/3}(x - 4)\).

(Similar to Stewart §3.1, Example 7)
Show solution (try it first)

Strategy:

Differentiate, then look for two kinds of numbers in the domain: where the derivative is 0, and where it does not exist. For (b), write \(g'\) as a single fraction so both kinds are easy to see.

Solution:

(a) \(f'(x) = 3x^2 + 6x - 24 = 3(x^2 + 2x - 8) = 3(x + 4)(x - 2)\). This is a polynomial, so it exists everywhere. Setting it to 0 gives the critical numbers \(x = -4\) and \(x = 2\).

(b) Expand first: \(g(x) = x^{4/3} - 4x^{1/3}\). Then \[g'(x) = \tfrac43 x^{1/3} - \tfrac43 x^{-2/3} = \frac{4}{3}\cdot\frac{x - 1}{x^{2/3}} = \frac{4x - 4}{3x^{2/3}}.\] (To combine, multiply the first term by \(x^{2/3}/x^{2/3}\): \(x^{1/3}\cdot x^{2/3} = x\).) The numerator is 0 when \(x = 1\). The denominator is 0 when \(x = 0\), so \(g'(0)\) does not exist; but \(g(0) = 0\) is defined, so 0 is in the domain. The critical numbers are \(x = 0\) and \(x = 1\).

Check:

In (b) it is tempting to stop at \(x = 1\). Look at the graph of \(g\) near 0: it has a vertical tangent there, which is exactly where \(g'\) fails to exist. Always check where the derivative is undefined, not only where it equals 0.

Example 7.2 Closed Interval Method with a trigonometric function

Find the absolute maximum and absolute minimum values of \(f(x) = x + 2\cos x\) on \([0, \pi]\).

(Similar to Stewart §3.1, Example 8)
Show solution (try it first)

Strategy:

\(f\) is continuous on the closed interval, so the Extreme Value Theorem promises both extrema. Use the Closed Interval Method: critical numbers inside \((0, \pi)\), then the endpoints, then compare.

Solution:

\(f'(x) = 1 - 2\sin x\), which exists everywhere. Setting \(f'(x) = 0\) gives \(\sin x = \tfrac12\). In \((0, \pi)\) this happens at \(x = \tfrac{\pi}{6}\) and \(x = \tfrac{5\pi}{6}\).

\(x\)\(f(x)\)decimal
\(0\)\(0 + 2(1) = 2\)2
\(\pi/6\)\(\tfrac{\pi}{6} + 2\cdot\tfrac{\sqrt3}{2} = \tfrac{\pi}{6} + \sqrt3\)2.256
\(5\pi/6\)\(\tfrac{5\pi}{6} + 2\left(-\tfrac{\sqrt3}{2}\right) = \tfrac{5\pi}{6} - \sqrt3\)0.886
\(\pi\)\(\pi + 2(-1) = \pi - 2\)1.142

The absolute maximum is \(\tfrac{\pi}{6} + \sqrt3 \approx 2.256\) at \(x = \pi/6\), and the absolute minimum is \(\tfrac{5\pi}{6} - \sqrt3 \approx 0.886\) at \(x = 5\pi/6\).

Check:

The endpoint values 2 and 1.142 lie between the two answers, as they must. Remember to use \(\cos(5\pi/6) = -\sqrt3/2\) (cosine is negative in the second quadrant); a sign slip here would change which value is smallest.

Example 7.3 What the Mean Value Theorem says about f(6)

Suppose \(f\) is differentiable for all \(x\), \(f(2) = -1\), and \(2 \le f'(x) \le 5\) for every \(x\). What are the smallest and largest possible values of \(f(6)\)?

(Similar to Stewart §3.2, Example 5)
Show solution (try it first)

Strategy:

We do not know a formula for \(f\), but the MVT links \(f(6) - f(2)\) to a value of \(f'\). A differentiable function is also continuous, so the hypotheses hold on \([2, 6]\).

Solution:

By the MVT there is a number \(c\) in \((2, 6)\) with \[f(6) - f(2) = f'(c)(6 - 2) = 4f'(c).\] So \(f(6) = -1 + 4f'(c)\). Since \(2 \le f'(c) \le 5\), multiply by 4: \(8 \le 4f'(c) \le 20\). Add \(-1\): \(7 \le f(6) \le 19\).

Check:

Both bounds can actually happen: \(f(x) = 2x - 5\) has \(f(2) = -1\), \(f' = 2\) and \(f(6) = 7\); \(f(x) = 5x - 11\) has \(f(6) = 19\). So the smallest possible value is 7 and the largest is 19. We never needed to know where \(c\) is, only that it exists.
