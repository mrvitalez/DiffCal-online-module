3.1Maximum and Minimum Values

Many practical questions ask for the best value of something: the largest area, the lowest cost, the highest point of a path. In calculus language these are maximum and minimum values, together called extreme values or extrema. So, how can the derivative help us find them? That is what Stewart §3.1 shows us.

Definition Let \(c\) be a number in the domain \(D\) of \(f\). Then \(f(c)\) is the absolute maximum value of \(f\) if \(f(c) \ge f(x)\) for all \(x\) in \(D\), and the absolute minimum value if \(f(c) \le f(x)\) for all \(x\) in \(D\). It is a local maximum value if \(f(c) \ge f(x)\) when \(x\) is near \(c\) (on some open interval containing \(c\)), and a local minimum value if \(f(c) \le f(x)\) when \(x\) is near \(c\).

Let's think of a mountain trail: each peak is a local maximum, but only the highest point of the whole trail is the absolute maximum. Figure 7.1 shows both kinds.

When are extrema guaranteed? Does every function have a maximum? No. The function \(f(x) = 1/x\) on \((0, 1]\) has no maximum: it grows without bound near 0. The next theorem says this cannot happen for a continuous function on a closed interval.

Extreme Value Theorem If \(f\) is continuous on a closed interval \([a, b]\), then \(f\) attains an absolute maximum value \(f(c)\) and an absolute minimum value \(f(d)\) at some numbers \(c\) and \(d\) in \([a, b]\).

Where can they be? Notice that at a smooth peak or valley the tangent line is horizontal.

Fermat's Theorem If \(f\) has a local maximum or minimum at \(c\), and \(f'(c)\) exists, then \(f'(c) = 0\).

This gives us a short list of candidates. A critical number of \(f\) is a number \(c\) in the domain of \(f\) such that either \(f'(c) = 0\) or \(f'(c)\) does not exist. For example, \(g(x) = x^{2/3}(x - 5)\) has \(g'(x) = \frac{5(x - 2)}{3x^{1/3}}\), so its critical numbers are \(2\) (where \(g' = 0\)) and \(0\) (where \(g'\) does not exist). We can now restate Fermat's Theorem: if \(f\) has a local extremum at \(c\), then \(c\) is a critical number.

Common mistake The converse is false. For \(f(x) = x^3\), \(f'(0) = 0\), yet \(x^3\) has no maximum or minimum at 0. A critical number is only a candidate. Also, take note that a number where \(f\) itself is undefined is never a critical number.

The Closed Interval Method. To find the absolute extrema of a continuous \(f\) on \([a, b]\):

  1. Find the values of \(f\) at the critical numbers of \(f\) in \((a, b)\).
  2. Find the values \(f(a)\) and \(f(b)\) at the endpoints.
  3. The largest of these values is the absolute maximum; the smallest is the absolute minimum.

Let's try \(f(x) = 2x^3 - 9x^2 + 12x\) on \([0, 3]\). Here \(f'(x) = 6x^2 - 18x + 12 = 6(x - 1)(x - 2)\), so the critical numbers are 1 and 2. The table of values is \(f(0) = 0\), \(f(1) = 5\), \(f(2) = 4\), \(f(3) = 9\) (Figure 7.2). The absolute maximum is \(9\) (at the endpoint \(x = 3\)) and the absolute minimum is \(0\) (at \(x = 0\)). Is the local maximum \(f(1) = 5\) the absolute maximum? No. That is why we never skip the endpoints.

Key equations
\[ f(c) \text{ abs. max} \iff f(c) \ge f(x) \text{ for all } x \in D \]
\[ \text{local extremum at } c \text{ and } f'(c) \text{ exists} \implies f'(c) = 0 \]
\[ c \text{ critical} \iff f'(c) = 0 \text{ or } f'(c) \text{ does not exist} \]

3.2The Mean Value Theorem

The Mean Value Theorem (MVT) is one of the quiet workhorses of calculus. It lets us turn information about the derivative into information about the function itself. Stewart §3.2 starts with a special case.

Rolle's Theorem Let \(f\) satisfy three hypotheses: (1) \(f\) is continuous on \([a, b]\); (2) \(f\) is differentiable on \((a, b)\); (3) \(f(a) = f(b)\). Then there is a number \(c\) in \((a, b)\) such that \(f'(c) = 0\).

Why is it true? If \(f\) is constant, \(f' = 0\) everywhere. Otherwise \(f\) goes above or below its common end value, so by the Extreme Value Theorem it has an absolute maximum or minimum inside \((a, b)\), and by Fermat's Theorem the derivative is 0 there. For \(f(x) = x^2(3 - x)\) on \([0, 3]\), \(f(0) = f(3) = 0\) and \(f'(x) = 6x - 3x^2 = 3x(2 - x)\), so \(c = 2\) works (Figure 7.3).

Counting roots. How can we be sure that an equation has exactly one root? Rolle's Theorem helps. Let's take \(x^3 + 4x - 3 = 0\) and let \(f(x) = x^3 + 4x - 3\). Since \(f(0) = -3 \lt 0\) and \(f(1) = 2 \gt 0\), the Intermediate Value Theorem gives a root between 0 and 1. If there were two roots \(a \lt b\), then \(f(a) = f(b) = 0\) and Rolle would give \(f'(c) = 0\). But \(f'(x) = 3x^2 + 4 \ge 4\) is never 0. So there is exactly one root.

Now let's tilt the picture so the end values need not match.

The Mean Value Theorem If \(f\) is continuous on \([a, b]\) and differentiable on \((a, b)\), then there is a number \(c\) in \((a, b)\) such that \[f'(c) = \frac{f(b) - f(a)}{b - a}, \quad\text{equivalently}\quad f(b) - f(a) = f'(c)(b - a).\]

Geometrically: somewhere between \(a\) and \(b\), the tangent line is parallel to the secant line through the end points. In terms of motion: if our average velocity over a trip is 60 km/h, then at some instant the speedometer read exactly 60 km/h.

For \(f(x) = x^3 - x\) on \([0, 2]\), the secant slope is \(\frac{6 - 0}{2 - 0} = 3\). We solve \(f'(c) = 3c^2 - 1 = 3\): \(c^2 = \tfrac43\), so \(c = \tfrac{2}{\sqrt3} \approx 1.155\), which does lie in \((0, 2)\) (Figure 7.4). Take note that the negative root is rejected because it is outside the interval.

Consequences. The MVT proves facts we may have taken for granted.

Theorem If \(f'(x) = 0\) for all \(x\) in an interval \((a, b)\), then \(f\) is constant on \((a, b)\).
Corollary: If \(f'(x) = g'(x)\) for all \(x\) in \((a, b)\), then \(f - g\) is constant there: \(f(x) = g(x) + C\).

Why? For any \(x_1 \lt x_2\) in the interval, \(f(x_2) - f(x_1) = f'(c)(x_2 - x_1) = 0\). So if \(f'(x) = 2x\) everywhere, then \(f(x) = x^2 + C\), and one known value such as \(f(1) = 5\) fixes \(C = 4\).

Common mistake Check the hypotheses before using Rolle or the MVT. The interval must make \(f\) continuous on \([a, b]\) and differentiable on \((a, b)\). For instance \(f(x) = |x|\) has \(f(-1) = f(1)\) but no horizontal tangent, because \(f'(0)\) does not exist.
Key equations
\[ f(a) = f(b) \implies f'(c) = 0 \text{ for some } c \in (a, b) \]
\[ f'(c) = \frac{f(b) - f(a)}{b - a} \]
\[ f' = g' \text{ on } (a, b) \implies f(x) = g(x) + C \]

★Key takeaways

  • An absolute extremum is the highest or lowest value over the whole domain; a local extremum only beats its nearby values.
  • A continuous function on a closed interval always has an absolute maximum and an absolute minimum (Extreme Value Theorem).
  • Local extrema can occur only at critical numbers, where f′ is 0 or does not exist; take note that not every critical number gives an extremum.
  • Closed Interval Method: we evaluate f at the critical numbers inside the interval and at both endpoints, then pick the largest and smallest values.
  • The Mean Value Theorem says some tangent line is parallel to the secant line: f(b) − f(a) = f′(c)(b − a).
  • If f′ = 0 on an interval, f is constant there; if f′ = g′, then f and g differ by a constant.

Example 7.1 Finding critical numbers

Find all critical numbers of (a) \(f(x) = x^3 + 3x^2 - 24x\) and (b) \(g(x) = x^{1/3}(x - 4)\).

(Similar to Stewart §3.1, Example 7)
Show solution (try it first)
Given
  • (a) \(f(x) = x^3 + 3x^2 - 24x\), a polynomial.
  • (b) \(g(x) = x^{1/3}(x - 4)\), defined for every real \(x\).
  • Find: every number in the domain where the derivative is 0 or does not exist.
Step 1: Differentiate and factor f'

We need the zeros of \(f'\), so let's factor it completely.

\[f'(x) = 3x^2 + 6x - 24\]

\[f'(x) = 3(x^2 + 2x - 8)\]

\[f'(x) = 3(x + 4)(x - 2)\]

Step 2: Find the critical numbers of f

\(f'\) is a polynomial, so it exists everywhere. We only need where it equals 0.

\[3(x + 4)(x - 2) = 0 \quad\Rightarrow\quad x = -4 \text{ or } x = 2\]

Step 3: Expand g and differentiate

Expanding first lets us use the Power Rule on each term.

\[g(x) = x^{1/3}\cdot x - 4x^{1/3} = x^{4/3} - 4x^{1/3}\]

\[g'(x) = \tfrac43 x^{1/3} - \tfrac43 x^{-2/3}\]

Step 4: Write g' as a single fraction

Let's factor out \(\tfrac43 x^{-2/3}\), using \(x^{1/3} = x^{-2/3}\cdot x\), so both kinds of critical numbers are easy to see.

\[g'(x) = \tfrac43 x^{-2/3}(x - 1)\]

\[g'(x) = \frac{4(x - 1)}{3x^{2/3}}\]

Step 5: Find where g' is 0 or undefined

The numerator is 0 at \(x = 1\). The denominator is 0 at \(x = 0\), so \(g'(0)\) does not exist; but \(g(0) = 0\) is defined, so 0 is in the domain.

\[4(x - 1) = 0 \quad\Rightarrow\quad x = 1\]

\[3x^{2/3} = 0 \quad\Rightarrow\quad x = 0\]

Answer

(a) The critical numbers of \(f\) are \(x = -4\) and \(x = 2\). (b) The critical numbers of \(g\) are \(x = 0\) and \(x = 1\).

Check

In (b) it is tempting to stop at \(x = 1\). Let's look at the graph of \(g\) near 0: it has a vertical tangent there, which is exactly where \(g'\) fails to exist. So we always check where the derivative is undefined, not only where it equals 0.

Example 7.2 Closed Interval Method with a trigonometric function

Find the absolute maximum and absolute minimum values of \(f(x) = x + 2\cos x\) on \([0, \pi]\).

(Similar to Stewart §3.1, Example 8)
Show solution (try it first)
Given
  • \(f(x) = x + 2\cos x\), continuous on the closed interval \([0, \pi]\).
  • Find: the absolute maximum and minimum values. (The Extreme Value Theorem promises both exist.)
Step 1: Differentiate

The Closed Interval Method starts with the critical numbers, so we need \(f'\).

\[f'(x) = 1 - 2\sin x\]

Step 2: Find the critical numbers in (0, π)

\(f'\) exists everywhere, so we only solve \(f'(x) = 0\).

\[1 - 2\sin x = 0\]

\[\sin x = \tfrac12\]

\[x = \tfrac{\pi}{6} \text{ or } x = \tfrac{5\pi}{6}\]

Step 3: Evaluate f at the critical numbers and the endpoints

Let's substitute each candidate, using \(\cos 0 = 1\), \(\cos\frac{\pi}{6} = \frac{\sqrt3}{2}\), \(\cos\frac{5\pi}{6} = -\frac{\sqrt3}{2}\) and \(\cos\pi = -1\).

\(x\)\(f(x)\)decimal
\(0\)\(0 + 2(1) = 2\)2
\(\pi/6\)\(\tfrac{\pi}{6} + 2\cdot\tfrac{\sqrt3}{2} = \tfrac{\pi}{6} + \sqrt3\)2.256
\(5\pi/6\)\(\tfrac{5\pi}{6} + 2\left(-\tfrac{\sqrt3}{2}\right) = \tfrac{5\pi}{6} - \sqrt3\)0.886
\(\pi\)\(\pi + 2(-1) = \pi - 2\)1.142
Step 4: Pick the largest and smallest values

We compare the four values in the table.

\[\text{largest: } \tfrac{\pi}{6} + \sqrt3 \approx 2.256 \quad (x = \tfrac{\pi}{6})\]

\[\text{smallest: } \tfrac{5\pi}{6} - \sqrt3 \approx 0.886 \quad (x = \tfrac{5\pi}{6})\]

Answer

The absolute maximum is \(\tfrac{\pi}{6} + \sqrt3 \approx 2.256\) at \(x = \pi/6\), and the absolute minimum is \(\tfrac{5\pi}{6} - \sqrt3 \approx 0.886\) at \(x = 5\pi/6\).

Check

The endpoint values 2 and 1.142 lie between the two answers, as they must. Take note that \(\cos(5\pi/6) = -\sqrt3/2\) (cosine is negative in the second quadrant); a sign slip here would change which value is smallest.

Example 7.3 Finding the number c in the Mean Value Theorem

Verify that \(f(x) = \sqrt{x}\) satisfies the hypotheses of the Mean Value Theorem on \([1, 9]\), and find every number \(c\) that satisfies the conclusion.

(Similar to Stewart §3.2, Example 3)
Show solution (try it first)
Given
  • \(f(x) = \sqrt{x}\) on \([1, 9]\).
  • Find: all \(c\) in \((1, 9)\) with \(f'(c) = \dfrac{f(9) - f(1)}{9 - 1}\).
Step 1: Check the hypotheses

The MVT needs continuity on \([1, 9]\) and differentiability on \((1, 9)\).

\[f'(x) = \frac{1}{2\sqrt{x}}\]

\[\sqrt{x} \text{ is continuous for } x \ge 0, \text{ and } f'(x) \text{ exists for } x \gt 0\]

Step 2: Compute the slope of the secant line

We use the end values \(f(1) = 1\) and \(f(9) = 3\).

\[\frac{f(9) - f(1)}{9 - 1} = \frac{3 - 1}{8} = \frac{2}{8} = \frac14\]

Step 3: Set f'(c) equal to the secant slope

The MVT says some tangent slope equals the secant slope.

\[\frac{1}{2\sqrt{c}} = \frac14\]

Step 4: Solve for c

Let's cross-multiply, then square both sides.

\[2\sqrt{c} = 4\]

\[\sqrt{c} = 2\]

\[c = 4\]

Answer

\(f\) satisfies the hypotheses, and the only number is \(c = 4\), which lies in \((1, 9)\).

Check

At \(c = 4\), \(f'(4) = \dfrac{1}{2(2)} = \dfrac14\), the same as the secant slope. Notice that \(c = 4\) is not the midpoint 5 of the interval; the MVT only promises that some \(c\) exists, not where it is.

Example 7.4 What the Mean Value Theorem says about f(6)

Suppose \(f\) is differentiable for all \(x\), \(f(2) = -1\), and \(2 \le f'(x) \le 5\) for every \(x\). What are the smallest and largest possible values of \(f(6)\)?

(Similar to Stewart §3.2, Example 5)
Show solution (try it first)
Given
  • \(f\) is differentiable for all \(x\) (so it is also continuous).
  • \(f(2) = -1\) and \(2 \le f'(x) \le 5\) for every \(x\).
  • Find: the smallest and largest possible values of \(f(6)\).
Step 1: Apply the MVT on [2, 6]

We do not know a formula for \(f\), but the MVT links \(f(6) - f(2)\) to a value of \(f'\). The hypotheses hold because \(f\) is differentiable everywhere.

\[f(6) - f(2) = f'(c)(6 - 2) \quad\text{for some } c \text{ in } (2, 6)\]

\[f(6) - f(2) = 4f'(c)\]

Step 2: Solve for f(6)

We substitute \(f(2) = -1\) and add it to the other side.

\[f(6) - (-1) = 4f'(c)\]

\[f(6) = -1 + 4f'(c)\]

Step 3: Use the bounds on f'

We know \(2 \le f'(c) \le 5\). Let's multiply by 4, then add \(-1\).

\[2 \le f'(c) \le 5\]

\[8 \le 4f'(c) \le 20\]

\[7 \le -1 + 4f'(c) \le 19\]

\[7 \le f(6) \le 19\]

Answer

The smallest possible value of \(f(6)\) is 7 and the largest is 19.

Check

Can both bounds actually happen? Yes: \(f(x) = 2x - 5\) has \(f(2) = -1\), \(f' = 2\) and \(f(6) = 7\); \(f(x) = 5x - 11\) has \(f(2) = -1\), \(f' = 5\) and \(f(6) = 19\). Notice that we never needed to know where \(c\) is, only that it exists.
