3.1Maximum and Minimum Values

So far, we used the derivative to find slopes and velocities. Now, let's ask a more practical question: "What is the largest or the smallest value that a quantity can have?" What is the highest point of a projectile? When is a satellite farthest from Earth? What dimensions make a box hold the most? All of these are questions about maximum and minimum values, which we call extreme values or extrema. And as we will see, the derivative is the tool that finds them.

Definition Let \(c\) be a number in the domain \(D\) of \(f\). Then \(f(c)\) is the
  • absolute maximum value of \(f\) if \(f(c) \ge f(x)\) for all \(x\) in \(D\);
  • absolute minimum value of \(f\) if \(f(c) \le f(x)\) for all \(x\) in \(D\);
  • local maximum value of \(f\) if \(f(c) \ge f(x)\) when \(x\) is near \(c\) (on some open interval containing \(c\));
  • local minimum value of \(f\) if \(f(c) \le f(x)\) when \(x\) is near \(c\).

Think of a mountain trail. Every peak along the trail is a local maximum, because it is higher than the points right beside it. But only the highest point of the whole trail is the absolute maximum. Let's check Figure 7.1: the function has a local maximum and a local minimum inside the interval, but its absolute maximum and absolute minimum are both at the endpoints.

When are we sure that extrema exist? Take note that not every function has a maximum. For example, \(f(x) = 1/x\) on \((0, 1]\) has no maximum, since it grows without bound as \(x \to 0^+\). The next theorem tells us when this cannot happen.

Extreme Value Theorem If \(f\) is continuous on a closed interval \([a, b]\), then \(f\) attains an absolute maximum value \(f(c)\) and an absolute minimum value \(f(d)\) at some numbers \(c\) and \(d\) in \([a, b]\).

Notice the two requirements: continuous and closed interval. If either one is missing, the theorem makes no promise.

Where can the extrema be? If we look intently at a smooth peak or a smooth valley, we can see that the tangent line there is horizontal. That is exactly what the next theorem says.

Fermat's Theorem If \(f\) has a local maximum or minimum at \(c\), and if \(f'(c)\) exists, then \(f'(c) = 0\).

But a graph can also have a sharp corner or a cusp at a peak, where the derivative does not exist. So we collect both kinds of numbers into one list of candidates.

Definition A critical number of \(f\) is a number \(c\) in the domain of \(f\) such that either \(f'(c) = 0\) or \(f'(c)\) does not exist.

For example, \(g(x) = x^{2/3}(x - 5)\) has \(g'(x) = \dfrac{5(x - 2)}{3x^{1/3}}\). The numerator is zero at \(x = 2\), and the denominator is zero at \(x = 0\). So the critical numbers are \(2\) and \(0\). With this definition, Fermat's Theorem becomes: if \(f\) has a local extremum at \(c\), then \(c\) is a critical number.

Common mistake The converse is false. For \(f(x) = x^3\), we have \(f'(0) = 0\), yet \(x^3\) has no maximum or minimum at 0; the graph just flattens and keeps rising. A critical number is only a candidate. Also, take note that a number where \(f\) itself is undefined is never a critical number.

The Closed Interval Method. Now we can answer the question for a continuous function on a closed interval \([a, b]\):

  1. Find the values of \(f\) at the critical numbers of \(f\) in \((a, b)\).
  2. Find the values of \(f\) at the endpoints, \(f(a)\) and \(f(b)\).
  3. The largest of these values is the absolute maximum; the smallest is the absolute minimum.

Let's try it with \(f(x) = 2x^3 - 9x^2 + 12x\) on \([0, 3]\). First, \(f'(x) = 6x^2 - 18x + 12 = 6(x - 1)(x - 2)\), so the critical numbers are 1 and 2. Then we make a table of values: \(f(0) = 0\), \(f(1) = 5\), \(f(2) = 4\), \(f(3) = 9\). So the absolute maximum is \(9\) at the endpoint \(x = 3\), and the absolute minimum is \(0\) at \(x = 0\) (Figure 7.2). Notice that the local maximum \(f(1) = 5\) is not the absolute maximum. That is why we never skip the endpoints.

Key equations
\[ f(c) \text{ abs. max} \iff f(c) \ge f(x) \text{ for all } x \in D \]
\[ \text{local extremum at } c \text{ and } f'(c) \text{ exists} \implies f'(c) = 0 \]
\[ c \text{ critical} \iff f'(c) = 0 \text{ or } f'(c) \text{ does not exist} \]

3.2The Mean Value Theorem

Recall from physics that the average velocity is \(\dfrac{\Delta s}{\Delta t}\), while the instantaneous velocity is the derivative. Here is a natural question: "If my average velocity on a trip was 60 km/h, was my speedometer ever reading exactly 60 km/h?" Our intuition says yes, and the Mean Value Theorem (MVT) proves it. This theorem turns information about the derivative into information about the function itself. Let's start with a special case.

Rolle's Theorem Let \(f\) satisfy the following three hypotheses:
  1. \(f\) is continuous on the closed interval \([a, b]\);
  2. \(f\) is differentiable on the open interval \((a, b)\);
  3. \(f(a) = f(b)\).
Then there is a number \(c\) in \((a, b)\) such that \(f'(c) = 0\).

Why is this true? If \(f\) is constant, then \(f' = 0\) everywhere and we are done. If not, then \(f\) goes above or below its common end value. By the Extreme Value Theorem, it has an absolute maximum or minimum inside \((a, b)\), and by Fermat's Theorem, the derivative is 0 there. Think of a ball thrown straight up that comes back to the same height: at the top, its velocity is exactly 0.

For \(f(x) = x^2(3 - x)\) on \([0, 3]\), we have \(f(0) = f(3) = 0\) and \(f'(x) = 6x - 3x^2 = 3x(2 - x)\). Setting it to zero gives \(c = 2\), which is inside \((0, 3)\) (Figure 7.3).

Counting roots. Rolle's Theorem is also how we show an equation has exactly one root. Take \(x^3 + 4x - 3 = 0\) and let \(f(x) = x^3 + 4x - 3\). Since \(f(0) = -3 \lt 0\) and \(f(1) = 2 \gt 0\), the Intermediate Value Theorem gives at least one root between 0 and 1. Now suppose there were two roots \(a \lt b\). Then \(f(a) = f(b) = 0\), and Rolle's Theorem would give \(f'(c) = 0\). But \(f'(x) = 3x^2 + 4 \ge 4\) is never 0. So there is exactly one root.

Now, what if the end values are not equal? Let's tilt the picture.

The Mean Value Theorem If \(f\) is continuous on \([a, b]\) and differentiable on \((a, b)\), then there is a number \(c\) in \((a, b)\) such that \[f'(c) = \frac{f(b) - f(a)}{b - a}, \quad\text{or equivalently}\quad f(b) - f(a) = f'(c)(b - a).\]

In words: somewhere between \(a\) and \(b\), the tangent line is parallel to the secant line through the endpoints. In terms of motion: the instantaneous velocity equals the average velocity at least once.

For \(f(x) = x^3 - x\) on \([0, 2]\), the secant slope is \(\frac{6 - 0}{2 - 0} = 3\). Then we solve \(f'(c) = 3c^2 - 1 = 3\), so \(c^2 = \tfrac43\) and \(c = \tfrac{2}{\sqrt3} \approx 1.155\), which is inside \((0, 2)\) (Figure 7.4). The negative root is rejected because it is outside the interval.

Consequences. The MVT proves facts that we have been taking for granted.

Theorem If \(f'(x) = 0\) for all \(x\) in an interval \((a, b)\), then \(f\) is constant on \((a, b)\).
Corollary: If \(f'(x) = g'(x)\) for all \(x\) in \((a, b)\), then \(f - g\) is constant there; that is, \(f(x) = g(x) + C\).

Why? For any \(x_1 \lt x_2\) in the interval, \(f(x_2) - f(x_1) = f'(c)(x_2 - x_1) = 0\). So if \(f'(x) = 2x\) everywhere, then \(f(x) = x^2 + C\), and one known value such as \(f(1) = 5\) fixes \(C = 4\). We will use this idea again for antiderivatives in Module 10.

Common mistake Always check the hypotheses before using Rolle's Theorem or the MVT. The function must be continuous on \([a, b]\) and differentiable on \((a, b)\). For instance, \(f(x) = |x|\) has \(f(-1) = f(1)\), but there is no horizontal tangent, because \(f'(0)\) does not exist.
Key equations
\[ f(a) = f(b) \implies f'(c) = 0 \text{ for some } c \in (a, b) \]
\[ f'(c) = \frac{f(b) - f(a)}{b - a} \]
\[ f' = g' \text{ on } (a, b) \implies f(x) = g(x) + C \]

★Key takeaways

  • An absolute extremum is the highest or lowest value over the whole domain; a local extremum only beats the values near it.
  • A continuous function on a closed interval always has an absolute maximum and an absolute minimum (Extreme Value Theorem).
  • Local extrema can occur only at critical numbers, where f′ is 0 or does not exist. But not every critical number gives an extremum.
  • Closed Interval Method: evaluate f at the critical numbers inside the interval and at both endpoints, then pick the largest and the smallest.
  • The Mean Value Theorem says some tangent line is parallel to the secant line: f(b) − f(a) = f′(c)(b − a).
  • If f′ = 0 on an interval, f is constant there; if f′ = g′, then f and g differ by a constant.

Example 7.1 Finding critical numbers

Find all critical numbers of (a) \(f(x) = x^3 + 3x^2 - 24x\) and (b) \(g(x) = x^{1/3}(x - 4)\).

(Similar to Stewart §3.1, Example 7)
Show solution (try it first)

Given: two functions. Find: every number in the domain where the derivative is 0 or does not exist.

Plan: Differentiate. Then look for both kinds of critical numbers. For (b), it helps to write \(g'\) as a single fraction.

Step 1. (a) Differentiate using the Power Rule, then factor.

\[f'(x) = 3x^2 + 6x - 24 = 3(x^2 + 2x - 8) = 3(x + 4)(x - 2)\]

Step 2. This is a polynomial, so \(f'\) exists everywhere. Set it equal to zero.

\[3(x + 4)(x - 2) = 0 \;\Rightarrow\; x = -4 \;\text{ or }\; x = 2\]

Step 3. (b) Expand first so we can use the Power Rule on each term.

\[g(x) = x^{4/3} - 4x^{1/3}\]

Step 4. Differentiate.

\[g'(x) = \tfrac43 x^{1/3} - \tfrac43 x^{-2/3}\]

Step 5. Combine into one fraction. Multiply the first term by \(\frac{x^{2/3}}{x^{2/3}}\); take note that \(x^{1/3}\cdot x^{2/3} = x\).

\[g'(x) = \frac{4x}{3x^{2/3}} - \frac{4}{3x^{2/3}} = \frac{4(x - 1)}{3x^{2/3}}\]

Step 6. The numerator is 0 when \(x = 1\). The denominator is 0 when \(x = 0\), so \(g'(0)\) does not exist. But \(g(0) = 0\) is defined, so 0 is in the domain and it counts.

Answer: (a) \(\boxed{x = -4,\; x = 2}\); (b) \(\boxed{x = 0,\; x = 1}\). That is our answer.

Check: In (b), it is tempting to stop at \(x = 1\). But at \(x = 0\), the graph of \(g\) has a vertical tangent, which is exactly where \(g'\) fails to exist. Always look for both kinds.

Example 7.2 The Closed Interval Method

Find the absolute maximum and absolute minimum values of \(f(x) = x^3 - 3x^2 + 1\) on \(\left[-\tfrac12, 4\right]\).

(Similar to Stewart §3.1, Example 8)
Show solution (try it first)

Given: \(f(x) = x^3 - 3x^2 + 1\) on \([-\tfrac12, 4]\). Find: the absolute maximum and minimum values.

Plan: \(f\) is a polynomial, so it is continuous on the closed interval, and the Extreme Value Theorem promises both extrema. We use the Closed Interval Method.

Step 1. Find the critical numbers.

\[f'(x) = 3x^2 - 6x = 3x(x - 2) = 0 \;\Rightarrow\; x = 0,\; x = 2\]

Step 2. Both are inside \((-\tfrac12, 4)\). Evaluate \(f\) at the critical numbers.

\[f(0) = 1, \qquad f(2) = 8 - 12 + 1 = -3\]

Step 3. Evaluate \(f\) at the endpoints.

\[f\!\left(-\tfrac12\right) = -\tfrac18 - \tfrac34 + 1 = \tfrac18, \qquad f(4) = 64 - 48 + 1 = 17\]

Step 4. Compare the four values: \(\tfrac18,\; 1,\; -3,\; 17\).

Answer: Absolute maximum \(\boxed{f(4) = 17}\); absolute minimum \(\boxed{f(2) = -3}\).

Check: The local maximum \(f(0) = 1\) is not the absolute maximum; the endpoint value 17 beats it. This is why we always include the endpoints in the table.

Example 7.3 A trigonometric function on a closed interval

Find the absolute maximum and absolute minimum values of \(f(x) = x + 2\cos x\) on \([0, \pi]\).

(Similar to Stewart §3.1, Example 9)
Show solution (try it first)

Given: \(f(x) = x + 2\cos x\) on \([0, \pi]\). Find: the absolute extrema.

Plan: Again, \(f\) is continuous on a closed interval, so we use the Closed Interval Method.

Step 1. Differentiate. Recall that \(\frac{d}{dx}\cos x = -\sin x\).

\[f'(x) = 1 - 2\sin x\]

Step 2. Set \(f'(x) = 0\).

\[\sin x = \tfrac12 \;\Rightarrow\; x = \tfrac{\pi}{6} \;\text{ or }\; x = \tfrac{5\pi}{6} \quad(\text{both in } (0,\pi))\]

Step 3. Evaluate \(f\) at the critical numbers. Take note that \(\cos\frac{5\pi}{6} = -\frac{\sqrt3}{2}\) (cosine is negative in Quadrant II).

\[f\!\left(\tfrac{\pi}{6}\right) = \tfrac{\pi}{6} + \sqrt3 \approx 2.256, \qquad f\!\left(\tfrac{5\pi}{6}\right) = \tfrac{5\pi}{6} - \sqrt3 \approx 0.886\]

Step 4. Evaluate \(f\) at the endpoints.

\[f(0) = 2, \qquad f(\pi) = \pi - 2 \approx 1.142\]

Answer: Absolute maximum \(\boxed{\tfrac{\pi}{6} + \sqrt3 \approx 2.256}\) at \(x = \pi/6\); absolute minimum \(\boxed{\tfrac{5\pi}{6} - \sqrt3 \approx 0.886}\) at \(x = 5\pi/6\).

Check: The endpoint values 2 and 1.142 lie between our two answers, as they must.

Example 7.4 Finding the number c in the Mean Value Theorem

Verify that \(f(x) = x^2 - 2x + 3\) satisfies the hypotheses of the Mean Value Theorem on \([0, 4]\), then find every number \(c\) that satisfies its conclusion.

(Similar to Stewart §3.2, Example 3)
Show solution (try it first)

Given: \(f(x) = x^2 - 2x + 3\) on \([0, 4]\). Find: \(c\) with \(f'(c) = \frac{f(4) - f(0)}{4 - 0}\).

Plan: Check the two hypotheses, compute the slope of the secant line, then solve \(f'(c) = \) that slope.

Step 1. Hypotheses: \(f\) is a polynomial, so it is continuous on \([0, 4]\) and differentiable on \((0, 4)\).

Step 2. Slope of the secant line.

\[\frac{f(4) - f(0)}{4 - 0} = \frac{11 - 3}{4} = 2\]

Step 3. Set the derivative equal to the secant slope and solve.

\[f'(c) = 2c - 2 = 2 \;\Rightarrow\; c = 2\]

Step 4. Check that \(c\) is inside the open interval: \(0 \lt 2 \lt 4\). ✓

Answer: \(\boxed{c = 2}\). That is our answer.

Check: The tangent line at \(x = 2\) has slope \(f'(2) = 2\), the same as the secant line through \((0, 3)\) and \((4, 11)\), so they are parallel.

Example 7.5 What the Mean Value Theorem says about f(6)

Suppose \(f\) is differentiable for all \(x\), \(f(2) = -1\), and \(2 \le f'(x) \le 5\) for every \(x\). What are the smallest and the largest possible values of \(f(6)\)?

(Similar to Stewart §3.2, Example 5)
Show solution (try it first)

Given: \(f(2) = -1\) and \(2 \le f'(x) \le 5\). Find: the range of possible values of \(f(6)\).

Plan: We do not know a formula for \(f\), but the MVT connects \(f(6) - f(2)\) to a value of \(f'\). A differentiable function is also continuous, so the hypotheses hold on \([2, 6]\).

Step 1. Apply the MVT on \([2, 6]\): there is a number \(c\) in \((2, 6)\) with

\[f(6) - f(2) = f'(c)(6 - 2) = 4f'(c)\]

Step 2. Solve for \(f(6)\).

\[f(6) = -1 + 4f'(c)\]

Step 3. Use the bounds on the derivative: multiply \(2 \le f'(c) \le 5\) by 4, then add \(-1\).

\[8 \le 4f'(c) \le 20 \;\Rightarrow\; 7 \le f(6) \le 19\]

Answer: \(\boxed{7 \le f(6) \le 19}\): the smallest possible value is 7 and the largest is 19.

Check: Both bounds can really happen: \(f(x) = 2x - 5\) has \(f(2) = -1\), \(f' = 2\) and \(f(6) = 7\); \(f(x) = 5x - 11\) has \(f(6) = 19\). Notice that we never needed to know where \(c\) is, only that it exists.
