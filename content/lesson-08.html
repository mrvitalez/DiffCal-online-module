3.3How Derivatives Affect the Shape of a Graph

In Module 7, we found the candidates for maximum and minimum values. But if we have a critical number, how do we know if it is a peak, a valley, or neither? And more generally, "What does the derivative tell us about the shape of the graph?" Let's recall that \(f'(x)\) is the slope of the tangent line. A positive slope means the graph goes up as we move to the right; a negative slope means it goes down. That simple idea gives us our first test.

Increasing/Decreasing Test (a) If \(f'(x) \gt 0\) on an interval, then \(f\) is increasing on that interval. (b) If \(f'(x) \lt 0\) on an interval, then \(f\) is decreasing on that interval.

To use it, we find the critical numbers, cut the number line at those numbers, and test the sign of \(f'\) on each piece. For \(f(x) = x^3 - 6x^2 + 9x + 1\), we have \(f'(x) = 3x^2 - 12x + 9 = 3(x - 1)(x - 3)\). Testing one number in each piece: \(f'(0) = 9 \gt 0\), \(f'(2) = -3 \lt 0\), \(f'(4) = 9 \gt 0\). So \(f\) increases on \((-\infty, 1)\), decreases on \((1, 3)\), and increases again on \((3, \infty)\) (Figure 8.1).

Classifying critical numbers. Notice what happens at \(x = 1\): the graph goes up, then down. That is a peak. At \(x = 3\) it goes down, then up: a valley.

The First Derivative Test Suppose \(c\) is a critical number of a continuous function \(f\).
  1. If \(f'\) changes from positive to negative at \(c\), then \(f\) has a local maximum at \(c\).
  2. If \(f'\) changes from negative to positive at \(c\), then \(f\) has a local minimum at \(c\).
  3. If \(f'\) does not change sign at \(c\), then \(f\) has no local maximum or minimum at \(c\).

So our function has a local maximum \(f(1) = 5\) and a local minimum \(f(3) = 1\).

Concavity. Two graphs can both be increasing but bend in different ways. If we look at Figure 8.2, the left part of the curve bends downward like a cap, while the right part bends upward like a cup. The second derivative measures this bending, because \(f''\) tells us whether the slope itself is increasing or decreasing.

Definition and Concavity Test If the graph of \(f\) lies above all of its tangents on an interval, it is concave upward there; if it lies below all of its tangents, it is concave downward. (a) If \(f''(x) \gt 0\) on an interval, the graph is concave upward there. (b) If \(f''(x) \lt 0\), it is concave downward. A point where the graph changes concavity is an inflection point.

For our cubic, \(f''(x) = 6x - 12\). It is negative for \(x \lt 2\) and positive for \(x \gt 2\), so the graph is concave downward on \((-\infty, 2)\), concave upward on \((2, \infty)\), and \((2, f(2)) = (2, 3)\) is the inflection point. In physics terms: if \(s(t)\) is a position, then \(s''\) is the acceleration, and concave upward means the velocity is increasing.

The Second Derivative Test Suppose \(f''\) is continuous near \(c\). (a) If \(f'(c) = 0\) and \(f''(c) \gt 0\), then \(f\) has a local minimum at \(c\). (b) If \(f'(c) = 0\) and \(f''(c) \lt 0\), then \(f\) has a local maximum at \(c\).

Check it with our example: \(f''(1) = -6 \lt 0\) (a cap, so a maximum) and \(f''(3) = 6 \gt 0\) (a cup, so a minimum). Same result as the First Derivative Test.

Common mistake The Second Derivative Test says nothing when \(f''(c) = 0\). For example, \(x^4\), \(-x^4\) and \(x^3\) all have \(f'(0) = f''(0) = 0\), but the first has a minimum, the second a maximum, and the third neither. In that case, go back to the First Derivative Test. Also, \(f''(c) = 0\) alone does not make an inflection point: the concavity must actually change.
Key equations
\[ f' \gt 0 \Rightarrow f \text{ increasing}, \qquad f' \lt 0 \Rightarrow f \text{ decreasing} \]
\[ f'' \gt 0 \Rightarrow \text{concave upward}, \qquad f'' \lt 0 \Rightarrow \text{concave downward} \]
\[ f'(c) = 0,\; f''(c) \gt 0 \Rightarrow \text{local min}; \qquad f'(c) = 0,\; f''(c) \lt 0 \Rightarrow \text{local max} \]

3.4Limits at Infinity; Horizontal Asymptotes

In Module 2, we let \(x\) approach a number \(a\). Now let's ask a different question: "What happens to \(f(x)\) when \(x\) becomes very large, positive or negative?" This tells us the long-run behavior of a graph, like the speed that a falling object approaches when air resistance balances gravity (its terminal velocity).

Definition \(\displaystyle\lim_{x\to\infty} f(x) = L\) means that the values of \(f(x)\) can be made as close to \(L\) as we like by taking \(x\) sufficiently large. Similarly for \(x \to -\infty\). The line \(y = L\) is then a horizontal asymptote of the graph.

The basic fact we will use again and again is this: if \(r \gt 0\) is a rational number, then

\[ \lim_{x\to\infty} \frac{1}{x^r} = 0, \]

and the same is true as \(x \to -\infty\) whenever \(x^r\) is defined. As \(x\) grows, \(1/x\), \(1/x^2\), \(1/\sqrt x\) all shrink to 0.

Rational functions. The trick is to divide the numerator and the denominator by the highest power of \(x\) in the denominator. Let's check:

\[ \lim_{x\to\infty} \frac{3x^2 - x}{x^2 + 2} = \lim_{x\to\infty} \frac{3 - \frac1x}{1 + \frac{2}{x^2}} = \frac{3 - 0}{1 + 0} = 3. \]

So \(y = 3\) is a horizontal asymptote. Take note that a graph can cross its horizontal asymptote; this one crosses it at \(x = -6\) (Figure 8.4). An asymptote describes the behavior far away, not near the middle.

A quick rule for rational functions. Compare the degrees of the numerator and the denominator: if the top has the smaller degree, the limit is 0; if the degrees are equal, the limit is the ratio of the leading coefficients; if the top has the larger degree, the limit is \(\pm\infty\) (no horizontal asymptote).

Square roots. Be careful with \(\sqrt{x^2} = |x|\). For \(x \gt 0\), \(\sqrt{x^2} = x\); but for \(x \lt 0\), \(\sqrt{x^2} = -x\). So for \(y = \dfrac{2x}{\sqrt{x^2 + 1}}\), we get \(2\) as \(x \to \infty\) and \(-2\) as \(x \to -\infty\): two different horizontal asymptotes (Figure 8.3).

The form \(\infty - \infty\). When we see something like \(\sqrt{x^2 + x} - x\), both pieces go to infinity, and we cannot conclude anything yet. Just like in Module 2, we multiply by the conjugate:

\[ \sqrt{x^2 + x} - x = \frac{(x^2 + x) - x^2}{\sqrt{x^2 + x} + x} = \frac{x}{\sqrt{x^2 + x} + x} = \frac{1}{\sqrt{1 + \frac1x} + 1} \to \frac12. \]
Common mistake \(\infty\) is not a number, so "\(\infty - \infty = 0\)" and "\(\infty/\infty = 1\)" are both wrong. These are indeterminate forms: rewrite the expression first (divide by a power of \(x\), or use the conjugate), then take the limit.
Key equations
\[ \lim_{x\to\pm\infty} \frac{1}{x^r} = 0 \quad (r \gt 0) \]
\[ \sqrt{x^2} = |x| = \begin{cases} x & x \ge 0 \\ -x & x \lt 0 \end{cases} \]

★Key takeaways

  • The sign of f′ tells where f increases (f′ > 0) or decreases (f′ < 0); cut the number line at the critical numbers and test each piece.
  • First Derivative Test: f′ changing from + to − gives a local maximum, from − to + a local minimum, and no change gives neither.
  • The sign of f″ gives the concavity; an inflection point is where the concavity actually changes.
  • Second Derivative Test: f′(c) = 0 with f″(c) > 0 is a minimum, with f″(c) < 0 a maximum; with f″(c) = 0 the test is silent.
  • For limits at infinity, divide by the highest power of x in the denominator and use 1/xʳ → 0.
  • Remember √(x²) = |x|, and rewrite ∞ − ∞ forms with the conjugate before taking the limit.

Example 8.1 Increasing, decreasing and local extrema

Find where \(f(x) = 3x^4 - 4x^3 - 12x^2 + 5\) is increasing and decreasing, and find its local maximum and minimum values.

(Similar to Stewart §3.3, Example 1)
Show solution (try it first)

Given: \(f(x) = 3x^4 - 4x^3 - 12x^2 + 5\). Find: the intervals of increase/decrease and the local extrema.

Plan: Find the critical numbers, make a sign chart for \(f'\), then use the First Derivative Test.

Step 1. Differentiate and factor completely.

\[f'(x) = 12x^3 - 12x^2 - 24x = 12x(x^2 - x - 2) = 12x(x - 2)(x + 1)\]

Step 2. The critical numbers are \(x = -1, 0, 2\). Test one number in each interval.

\[f'(-2) = 12(-2)(-4)(-1) = -96 \lt 0,\quad f'(-\tfrac12) = 12(-\tfrac12)(-\tfrac52)(\tfrac12) = 7.5 \gt 0\]

Step 3. Continue the sign chart.

\[f'(1) = 12(1)(-1)(2) = -24 \lt 0,\quad f'(3) = 12(3)(1)(4) = 144 \gt 0\]

Step 4. So \(f\) is decreasing on \((-\infty, -1)\) and \((0, 2)\), increasing on \((-1, 0)\) and \((2, \infty)\). Apply the First Derivative Test and evaluate.

\[f(-1) = 3 + 4 - 12 + 5 = 0,\qquad f(0) = 5,\qquad f(2) = 48 - 32 - 48 + 5 = -27\]

Answer: Local minima \(\boxed{f(-1) = 0}\) and \(\boxed{f(2) = -27}\); local maximum \(\boxed{f(0) = 5}\). That is our answer.

Check: A quartic with a positive leading coefficient rises on both far ends, so "down, up, down, up" with two valleys and one peak in between makes sense.

Example 8.2 Concavity and inflection points

For \(f(x) = x^4 - 4x^3\), find the intervals of concavity and the inflection points.

(Similar to Stewart §3.3, Example 6)
Show solution (try it first)

Given: \(f(x) = x^4 - 4x^3\). Find: where the graph is concave up/down, and the inflection points.

Plan: Compute \(f''\), find where it is 0, and check that its sign really changes there.

Step 1. Differentiate twice.

\[f'(x) = 4x^3 - 12x^2, \qquad f''(x) = 12x^2 - 24x = 12x(x - 2)\]

Step 2. Set \(f''(x) = 0\): \(x = 0\) or \(x = 2\). Test the sign of \(f''\) in each interval.

\[f''(-1) = 36 \gt 0,\qquad f''(1) = -12 \lt 0,\qquad f''(3) = 36 \gt 0\]

Step 3. The sign changes at both numbers, so both give inflection points. Find their \(y\)-values.

\[f(0) = 0,\qquad f(2) = 16 - 32 = -16\]

Answer: Concave upward on \((-\infty, 0)\) and \((2, \infty)\), concave downward on \((0, 2)\); inflection points \(\boxed{(0, 0)}\) and \(\boxed{(2, -16)}\).

Check: This is the graph in Figure 9.2 of the next module: it flattens at the origin and bends from cup to cap there.

Example 8.3 Second Derivative Test with a trigonometric function

Use the Second Derivative Test to find the local extreme values of \(f(x) = x + 2\sin x\) on \((0, 2\pi)\).

(Similar to Stewart §3.3, Example 7)
Show solution (try it first)

Given: \(f(x) = x + 2\sin x\) on \((0, 2\pi)\). Find: the local maximum and minimum values.

Plan: Find where \(f' = 0\), then check the sign of \(f''\) at each of those numbers.

Step 1. Differentiate and set the result to zero.

\[f'(x) = 1 + 2\cos x = 0 \;\Rightarrow\; \cos x = -\tfrac12 \;\Rightarrow\; x = \tfrac{2\pi}{3},\; \tfrac{4\pi}{3}\]

Step 2. Second derivative.

\[f''(x) = -2\sin x\]

Step 3. Evaluate \(f''\) at each critical number.

\[f''\!\left(\tfrac{2\pi}{3}\right) = -2\cdot\tfrac{\sqrt3}{2} = -\sqrt3 \lt 0, \qquad f''\!\left(\tfrac{4\pi}{3}\right) = -2\left(-\tfrac{\sqrt3}{2}\right) = \sqrt3 \gt 0\]

Step 4. So \(2\pi/3\) gives a local maximum and \(4\pi/3\) a local minimum. Evaluate \(f\).

\[f\!\left(\tfrac{2\pi}{3}\right) = \tfrac{2\pi}{3} + \sqrt3 \approx 3.826, \qquad f\!\left(\tfrac{4\pi}{3}\right) = \tfrac{4\pi}{3} - \sqrt3 \approx 2.457\]

Answer: Local maximum \(\boxed{\tfrac{2\pi}{3} + \sqrt3}\); local minimum \(\boxed{\tfrac{4\pi}{3} - \sqrt3}\).

Check: The local minimum (2.457) is smaller than the local maximum (3.826), as it should be on this rising, wavy graph.

Example 8.4 Three limits at infinity

Evaluate (a) \(\displaystyle\lim_{x\to\infty}\frac{2x^2 - x + 5}{4x^2 + 3}\), (b) \(\displaystyle\lim_{x\to-\infty}\frac{\sqrt{9x^2 + 1}}{2x - 5}\), (c) \(\displaystyle\lim_{x\to\infty}\left(\sqrt{x^2 + 6x} - x\right)\).

(Similar to Stewart §3.4, Examples 3, 4 and 5)
Show solution (try it first)

Given: three limits at infinity. Find: their values.

Plan: Divide by the highest power of \(x\) in the denominator; for (b), use \(\sqrt{x^2} = -x\) because \(x \lt 0\); for (c), use the conjugate.

Step 1. (a) Divide the top and the bottom by \(x^2\).

\[\frac{2 - \frac1x + \frac5{x^2}}{4 + \frac3{x^2}} \;\to\; \frac{2}{4} = \frac12\]

Step 2. (b) For \(x \lt 0\), \(x = -\sqrt{x^2}\). Divide the top and the bottom by \(x\).

\[\frac{\sqrt{9x^2 + 1}}{x} = \frac{\sqrt{9x^2 + 1}}{-\sqrt{x^2}} = -\sqrt{9 + \tfrac{1}{x^2}}, \qquad \frac{2x - 5}{x} = 2 - \frac5x\]

Step 3. Take the limit.

\[\lim_{x\to-\infty} \frac{-\sqrt{9 + 1/x^2}}{2 - 5/x} = \frac{-3}{2}\]

Step 4. (c) Multiply by the conjugate, then divide by \(x\).

\[\frac{(x^2 + 6x) - x^2}{\sqrt{x^2 + 6x} + x} = \frac{6x}{\sqrt{x^2 + 6x} + x} = \frac{6}{\sqrt{1 + \frac6x} + 1} \;\to\; \frac{6}{2} = 3\]

Answer: (a) \(\boxed{\tfrac12}\) (b) \(\boxed{-\tfrac32}\) (c) \(\boxed{3}\)

Check: (b) must be negative: the numerator is positive and the denominator \(2x - 5\) is negative for large negative \(x\). For (c), try \(x = 1000\): \(\sqrt{1{,}006{,}000} - 1000 \approx 2.996\).

Example 8.5 Horizontal and vertical asymptotes

Find the horizontal and vertical asymptotes of \(f(x) = \dfrac{3x^2 + 2}{x^2 - 4}\).

(Similar to Stewart §3.4, Example 3)
Show solution (try it first)

Given: \(f(x) = \dfrac{3x^2 + 2}{x^2 - 4}\). Find: all asymptotes.

Plan: Horizontal asymptotes come from limits at \(\pm\infty\); vertical asymptotes come from the zeros of the denominator that do not cancel.

Step 1. Limits at infinity: divide by \(x^2\).

\[\lim_{x\to\pm\infty} \frac{3 + \frac{2}{x^2}}{1 - \frac{4}{x^2}} = \frac31 = 3\]

Step 2. Zeros of the denominator: \(x^2 - 4 = (x - 2)(x + 2) = 0\), so \(x = \pm 2\). The numerator \(3x^2 + 2 \ge 2\) is never 0, so nothing cancels.

Step 3. Check one side to see the behavior, for example as \(x \to 2^+\): the top is near 14 and the bottom is a small positive number.

\[\lim_{x\to2^+} \frac{3x^2 + 2}{x^2 - 4} = \infty\]

Answer: Horizontal asymptote \(\boxed{y = 3}\); vertical asymptotes \(\boxed{x = 2 \text{ and } x = -2}\).

Check: The degrees are equal, so the quick rule also gives the ratio of leading coefficients \(3/1 = 3\). ✓
