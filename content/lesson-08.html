3.3How Derivatives Affect the Shape of a Graph

The sign of \(f'\) and the sign of \(f''\) tell you the shape of the graph of \(f\) without plotting a single point. Stewart §3.3 turns this idea into a set of tests.

Increasing or decreasing? The derivative is the slope of the tangent line. Where the slopes are positive, the graph climbs.

Increasing/Decreasing Test (a) If \(f'(x) \gt 0\) on an interval, then \(f\) is increasing on that interval. (b) If \(f'(x) \lt 0\) on an interval, then \(f\) is decreasing on that interval.

(The proof uses the Mean Value Theorem from Module 7: \(f(x_2) - f(x_1) = f'(c)(x_2 - x_1)\) has the same sign as \(f'(c)\).) To use it, find the critical numbers, which split the line into intervals, and check the sign of \(f'\) on each one. For \(f(x) = x^3 - 6x^2 + 9x + 1\), \(f'(x) = 3x^2 - 12x + 9 = 3(x - 1)(x - 3)\). Testing one number in each piece, \(f' \gt 0\) on \((-\infty, 1)\), \(f' \lt 0\) on \((1, 3)\) and \(f' \gt 0\) on \((3, \infty)\). So \(f\) increases, then decreases, then increases (Figure 8.1).

First Derivative Test Suppose \(c\) is a critical number of a continuous \(f\). If \(f'\) changes from positive to negative at \(c\), then \(f\) has a local maximum at \(c\). If \(f'\) changes from negative to positive, \(f\) has a local minimum at \(c\). If \(f'\) does not change sign, there is no local extremum at \(c\).

In our example, \(f(1) = 5\) is a local maximum and \(f(3) = 1\) is a local minimum.

Concavity. If the graph of \(f\) lies above all of its tangent lines on an interval, \(f\) is concave upward there (it bends like a cup); if it lies below them, \(f\) is concave downward (like a cap). Concave upward means the slopes \(f'\) are increasing, which happens when \(f'' \gt 0\).

Concavity Test If \(f''(x) \gt 0\) for all \(x\) in an interval \(I\), the graph of \(f\) is concave upward on \(I\). If \(f''(x) \lt 0\) for all \(x\) in \(I\), it is concave downward on \(I\).

A point on a continuous curve where the concavity changes is called an inflection point. Here \(f''(x) = 6x - 12\), which is negative for \(x \lt 2\) and positive for \(x \gt 2\), so \((2, f(2)) = (2, 3)\) is an inflection point (Figure 8.2).

Second Derivative Test Suppose \(f''\) is continuous near \(c\). If \(f'(c) = 0\) and \(f''(c) \gt 0\), then \(f\) has a local minimum at \(c\). If \(f'(c) = 0\) and \(f''(c) \lt 0\), then \(f\) has a local maximum at \(c\).

Check: \(f''(1) = -6 \lt 0\) (local max) and \(f''(3) = 6 \gt 0\) (local min), matching the First Derivative Test. The picture to remember: a cup holds a minimum, a cap holds a maximum.

Common mistakes (1) If \(f''(c) = 0\), the Second Derivative Test says nothing: \(x^4\), \(-x^4\) and \(x^3\) all have \(f'(0) = f''(0) = 0\), but give a minimum, a maximum and neither. Use the First Derivative Test instead. (2) \(f''(c) = 0\) does not automatically give an inflection point; the sign of \(f''\) must actually change (\(x^4\) has no inflection point at 0).
Key equations
\[ f' \gt 0 \text{ on } I \implies f \text{ increasing on } I, \qquad f' \lt 0 \implies f \text{ decreasing} \]
\[ f'' \gt 0 \implies \text{concave upward}, \qquad f'' \lt 0 \implies \text{concave downward} \]
\[ f'(c) = 0,\ f''(c) \gt 0 \implies \text{local min}; \qquad f'(c) = 0,\ f''(c) \lt 0 \implies \text{local max} \]

3.4Limits at Infinity; Horizontal Asymptotes

Now we ask what happens to \(f(x)\) when \(x\) itself becomes very large, positive or negative. This describes the long-run behaviour of a graph, and Stewart §3.4 uses it to find horizontal asymptotes.

Definition \(\displaystyle\lim_{x\to\infty} f(x) = L\) means that \(f(x)\) can be made as close to \(L\) as we like by taking \(x\) large enough. Similarly for \(x \to -\infty\). The line \(y = L\) is a horizontal asymptote of \(y = f(x)\) if \(\lim_{x\to\infty} f(x) = L\) or \(\lim_{x\to-\infty} f(x) = L\).

The basic fact is that \(\dfrac{1}{x^r} \to 0\) as \(x \to \infty\) for any \(r \gt 0\) (and also as \(x \to -\infty\) when \(x^r\) is defined). The usual limit laws still hold.

Rational functions. Divide the numerator and denominator by the highest power of \(x\) in the denominator: \[\lim_{x\to\infty}\frac{3x^2 - x}{5x^2 + 2} = \lim_{x\to\infty}\frac{3 - \frac{1}{x}}{5 + \frac{2}{x^2}} = \frac{3 - 0}{5 + 0} = \frac35.\] In general, if the degrees are equal the limit is the ratio of leading coefficients; if the denominator has the higher degree the limit is 0. Why does this work? For huge \(x\), the term \(3x^2\) is far bigger than \(x\), and \(5x^2\) is far bigger than 2, so the fraction behaves like \(\frac{3x^2}{5x^2}\). Dividing by \(x^2\) is just a careful way of saying this. The same steps work as \(x \to -\infty\), so \(y = \tfrac35\) is a horizontal asymptote on both sides.

Square roots. Inside a root, \(\sqrt{x^2} = |x|\). For \(x \gt 0\) this is \(x\), but for \(x \lt 0\) it is \(-x\). For example, \(f(x) = \dfrac{2x}{\sqrt{x^2 + 1}}\): divide top and bottom by \(|x| = \sqrt{x^2}\). As \(x \to \infty\), \(f(x) = \dfrac{2}{\sqrt{1 + 1/x^2}} \to 2\). As \(x \to -\infty\), \(\dfrac{2x}{|x|} = -2\), so \(f(x) \to -2\). The graph has two horizontal asymptotes, \(y = 2\) and \(y = -2\) (Figure 8.3).

Difference of large terms. For \(\sqrt{x^2 + x} - x\), both pieces grow without bound, so \(\infty - \infty\) tells you nothing. Multiply by the conjugate: \[\sqrt{x^2 + x} - x = \frac{(x^2 + x) - x^2}{\sqrt{x^2 + x} + x} = \frac{x}{\sqrt{x^2 + x} + x} = \frac{1}{\sqrt{1 + 1/x} + 1} \to \frac12.\]

Infinite limits at infinity. Some functions just keep growing: \(\lim_{x\to\infty} x^3 = \infty\) and \(\lim_{x\to-\infty} x^3 = -\infty\). For a polynomial, the leading term wins: \(x^3 - 5x^2 = x^3(1 - 5/x) \to \infty\). If the numerator of a rational function has higher degree, such as \(\frac{x^2 + 1}{x + 1}\), the limit is infinite and there is no horizontal asymptote. Trigonometric functions such as \(\sin x\) oscillate forever, so \(\lim_{x\to\infty}\sin x\) does not exist, though \(\frac{\sin x}{x} \to 0\) by the Squeeze Theorem since \(-\frac1x \le \frac{\sin x}{x} \le \frac1x\).

Common mistakes (1) Writing \(\infty - \infty = 0\) or \(\frac{\infty}{\infty} = 1\); these are not numbers, so rewrite the expression first. (2) Forgetting that \(\sqrt{x^2} = -x\) when \(x \lt 0\). (3) Believing a graph can never cross its horizontal asymptote. It can: \(\frac{3x^2 - x}{x^2 + 2}\) crosses \(y = 3\) at \(x = -6\) (Figure 8.4). An asymptote describes behaviour far out, not a forbidden line.
Key equations
\[ \lim_{x\to\infty}\frac{1}{x^r} = 0 \quad (r \gt 0) \]
\[ y = L \text{ is a horizontal asymptote if } \lim_{x\to\infty} f(x) = L \text{ or } \lim_{x\to-\infty} f(x) = L \]
\[ \sqrt{x^2} = |x| = -x \quad \text{for } x \lt 0 \]

★Key takeaways

  • Where f′ > 0 the graph rises, and where f′ < 0 it falls; a sign change of f′ at a critical number gives a local extremum.
  • Where f″ > 0 the graph is concave upward (a cup), and where f″ < 0 it is concave downward (a cap); an inflection point is where the concavity actually changes.
  • Second Derivative Test: f′(c) = 0 with f″(c) > 0 gives a local minimum, with f″(c) < 0 a local maximum, and with f″(c) = 0 no conclusion.
  • For limits at infinity of rational functions, divide by the highest power of x in the denominator.
  • With square roots, use √(x²) = |x|, which equals −x when x → −∞; use the conjugate for ∞ − ∞ forms.
  • A horizontal asymptote describes long-run behaviour, and the graph may cross it.

Example 8.1 Full shape analysis of a quartic

For \(f(x) = x^4 - 8x^2 + 3\), find (a) the intervals where \(f\) is increasing or decreasing, (b) the local maximum and minimum values, and (c) the intervals of concavity and the inflection points.

(Similar to Stewart §3.3, Examples 1, 2 and 6)
Show solution (try it first)

Strategy:

Factor \(f'\) to get the critical numbers, make a sign chart for \(f'\) (parts a and b), then do the same for \(f''\) (part c).

Solution:

(a) \(f'(x) = 4x^3 - 16x = 4x(x^2 - 4) = 4x(x - 2)(x + 2)\). Critical numbers: \(-2, 0, 2\). Test one number in each interval:

Interval\(4x\)\(x - 2\)\(x + 2\)\(f'(x)\)\(f\)
\(x \lt -2\)−−−−decreasing
\(-2 \lt x \lt 0\)−−++increasing
\(0 \lt x \lt 2\)+−+−decreasing
\(x \gt 2\)++++increasing

So \(f\) is increasing on \((-2, 0)\) and \((2, \infty)\), decreasing on \((-\infty, -2)\) and \((0, 2)\).

(b) By the First Derivative Test: local minimum \(f(-2) = 16 - 32 + 3 = -13\), local maximum \(f(0) = 3\), local minimum \(f(2) = -13\).

(c) \(f''(x) = 12x^2 - 16 = 4(3x^2 - 4)\), which is 0 when \(x^2 = \tfrac43\), that is \(x = \pm\tfrac{2}{\sqrt3} \approx \pm 1.155\). \(f'' \gt 0\) when \(|x| \gt \tfrac{2}{\sqrt3}\) and \(f'' \lt 0\) between. So \(f\) is concave upward on \(\left(-\infty, -\tfrac{2}{\sqrt3}\right)\) and \(\left(\tfrac{2}{\sqrt3}, \infty\right)\), concave downward on \(\left(-\tfrac{2}{\sqrt3}, \tfrac{2}{\sqrt3}\right)\). At \(x = \pm\tfrac{2}{\sqrt3}\): \(x^2 = \tfrac43\), \(x^4 = \tfrac{16}{9}\), so \(f = \tfrac{16}{9} - \tfrac{32}{3} + 3 = \tfrac{16 - 96 + 27}{9} = -\tfrac{53}{9}\). Inflection points: \(\left(\pm\tfrac{2}{\sqrt3}, -\tfrac{53}{9}\right)\).

Check:

The Second Derivative Test agrees: \(f''(0) = -16 \lt 0\) (max) and \(f''(\pm 2) = 32 \gt 0\) (min). Also \(f\) is even, so the picture is symmetric about the \(y\)-axis, as our answers are.

Example 8.2 Second Derivative Test with a trigonometric function

Let \(f(x) = x - 2\sin x\) for \(0 \lt x \lt 2\pi\). Use the Second Derivative Test to classify the critical numbers, and find the inflection point.

(Similar to Stewart §3.3, Example 4)
Show solution (try it first)

Strategy:

Solve \(f'(x) = 0\) in the given interval, then look at the sign of \(f''\) at each solution. For inflection points, find where \(f''\) changes sign.

Solution:

\(f'(x) = 1 - 2\cos x\). Setting it to 0: \(\cos x = \tfrac12\), so \(x = \tfrac{\pi}{3}\) or \(x = \tfrac{5\pi}{3}\).

\(f''(x) = 2\sin x\).

  • \(f''\left(\tfrac{\pi}{3}\right) = 2\cdot\tfrac{\sqrt3}{2} = \sqrt3 \gt 0\): local minimum \(f\left(\tfrac{\pi}{3}\right) = \tfrac{\pi}{3} - \sqrt3 \approx -0.685\).
  • \(f''\left(\tfrac{5\pi}{3}\right) = 2\left(-\tfrac{\sqrt3}{2}\right) = -\sqrt3 \lt 0\): local maximum \(f\left(\tfrac{5\pi}{3}\right) = \tfrac{5\pi}{3} + \sqrt3 \approx 6.968\).

\(f''(x) = 2\sin x\) is positive on \((0, \pi)\) and negative on \((\pi, 2\pi)\). So \(f\) is concave upward then concave downward, and the inflection point is \((\pi, f(\pi)) = (\pi, \pi - 0) = (\pi, \pi)\).

Check:

It makes sense that the local minimum sits in the concave-up part \((0, \pi)\) and the local maximum in the concave-down part \((\pi, 2\pi)\): a cup holds a minimum, a cap holds a maximum. Watch the sign in \(f(5\pi/3)\): \(\sin(5\pi/3) = -\sqrt3/2\), so subtracting \(2\sin x\) adds \(\sqrt3\).

Example 8.3 Three limits at infinity

Evaluate (a) \(\displaystyle\lim_{x\to\infty}\frac{2x^3 - 5x + 1}{4x^3 + x^2}\), (b) \(\displaystyle\lim_{x\to-\infty}\frac{\sqrt{9x^2 + x}}{2x - 1}\), (c) \(\displaystyle\lim_{x\to\infty}\left(\sqrt{x^2 + 6x} - x\right)\).

(Similar to Stewart §3.4, Examples 3, 4 and 5)
Show solution (try it first)

Strategy:

(a) Divide by the highest power in the denominator, \(x^3\). (b) Divide by \(x\), remembering that \(x \lt 0\) so \(x = -\sqrt{x^2}\). (c) This is \(\infty - \infty\); multiply by the conjugate.

Solution:

(a) \(\displaystyle\frac{2x^3 - 5x + 1}{4x^3 + x^2} = \frac{2 - \frac{5}{x^2} + \frac{1}{x^3}}{4 + \frac{1}{x}} \to \frac{2}{4} = \frac12.\)

(b) For \(x \lt 0\), \(\sqrt{9x^2 + x} = \sqrt{x^2}\sqrt{9 + \tfrac1x} = |x|\sqrt{9 + \tfrac1x} = -x\sqrt{9 + \tfrac1x}\). So \[\frac{\sqrt{9x^2 + x}}{2x - 1} = \frac{-x\sqrt{9 + \frac1x}}{x\left(2 - \frac1x\right)} = \frac{-\sqrt{9 + \frac1x}}{2 - \frac1x} \to \frac{-\sqrt9}{2} = -\frac32.\]

(c) \(\displaystyle\sqrt{x^2 + 6x} - x = \frac{(x^2 + 6x) - x^2}{\sqrt{x^2 + 6x} + x} = \frac{6x}{\sqrt{x^2 + 6x} + x} = \frac{6}{\sqrt{1 + \frac{6}{x}} + 1} \to \frac{6}{2} = 3.\) (In the last step we divided top and bottom by \(x = \sqrt{x^2}\), which is fine because \(x \gt 0\).)

Check:

(b) A quick sign check: when \(x\) is a large negative number, the numerator is positive and the denominator negative, so the limit must be negative. Students who write \(\sqrt{x^2} = x\) get \(+\tfrac32\), which fails this check. (c) Try \(x = 1000\): \(\sqrt{1006000} - 1000 \approx 2.996\), close to 3.
