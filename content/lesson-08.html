3.3How Derivatives Affect the Shape of a Graph

Can we know the shape of a graph without plotting a single point? Yes. The sign of \(f'\) and the sign of \(f''\) tell us the shape of the graph of \(f\). Stewart §3.3 turns this idea into a set of tests.

Increasing or decreasing? Recall that the derivative is the slope of the tangent line. Where the slopes are positive, the graph climbs.

Increasing/Decreasing Test (a) If \(f'(x) \gt 0\) on an interval, then \(f\) is increasing on that interval. (b) If \(f'(x) \lt 0\) on an interval, then \(f\) is decreasing on that interval.

(The proof uses the Mean Value Theorem from Module 7: \(f(x_2) - f(x_1) = f'(c)(x_2 - x_1)\) has the same sign as \(f'(c)\).) To use it, we find the critical numbers, which split the line into intervals, and check the sign of \(f'\) on each one. Let's take \(f(x) = x^3 - 6x^2 + 9x + 1\). Then \(f'(x) = 3x^2 - 12x + 9 = 3(x - 1)(x - 3)\). Testing one number in each piece, \(f' \gt 0\) on \((-\infty, 1)\), \(f' \lt 0\) on \((1, 3)\) and \(f' \gt 0\) on \((3, \infty)\). So \(f\) increases, then decreases, then increases (Figure 8.1).

First Derivative Test Suppose \(c\) is a critical number of a continuous \(f\). If \(f'\) changes from positive to negative at \(c\), then \(f\) has a local maximum at \(c\). If \(f'\) changes from negative to positive, \(f\) has a local minimum at \(c\). If \(f'\) does not change sign, there is no local extremum at \(c\).

In our example, \(f(1) = 5\) is a local maximum and \(f(3) = 1\) is a local minimum.

Concavity. If the graph of \(f\) lies above all of its tangent lines on an interval, \(f\) is concave upward there (it bends like a cup); if it lies below them, \(f\) is concave downward (like a cap). Notice that concave upward means the slopes \(f'\) are increasing, which happens when \(f'' \gt 0\).

Concavity Test If \(f''(x) \gt 0\) for all \(x\) in an interval \(I\), the graph of \(f\) is concave upward on \(I\). If \(f''(x) \lt 0\) for all \(x\) in \(I\), it is concave downward on \(I\).

A point on a continuous curve where the concavity changes is called an inflection point. Here \(f''(x) = 6x - 12\), which is negative for \(x \lt 2\) and positive for \(x \gt 2\), so \((2, f(2)) = (2, 3)\) is an inflection point (Figure 8.2).

Second Derivative Test Suppose \(f''\) is continuous near \(c\). If \(f'(c) = 0\) and \(f''(c) \gt 0\), then \(f\) has a local minimum at \(c\). If \(f'(c) = 0\) and \(f''(c) \lt 0\), then \(f\) has a local maximum at \(c\).

Let's check: \(f''(1) = -6 \lt 0\) (local max) and \(f''(3) = 6 \gt 0\) (local min), matching the First Derivative Test. The picture to remember: a cup holds a minimum, a cap holds a maximum.

Common mistakes (1) If \(f''(c) = 0\), the Second Derivative Test says nothing: \(x^4\), \(-x^4\) and \(x^3\) all have \(f'(0) = f''(0) = 0\), but give a minimum, a maximum and neither. Use the First Derivative Test instead. (2) \(f''(c) = 0\) does not automatically give an inflection point; take note that the sign of \(f''\) must actually change (\(x^4\) has no inflection point at 0).
Key equations
\[ f' \gt 0 \text{ on } I \implies f \text{ increasing on } I, \qquad f' \lt 0 \implies f \text{ decreasing} \]
\[ f'' \gt 0 \implies \text{concave upward}, \qquad f'' \lt 0 \implies \text{concave downward} \]
\[ f'(c) = 0,\ f''(c) \gt 0 \implies \text{local min}; \qquad f'(c) = 0,\ f''(c) \lt 0 \implies \text{local max} \]

3.4Limits at Infinity; Horizontal Asymptotes

Now let's ask: what happens to \(f(x)\) when \(x\) itself becomes very large, positive or negative? This describes the long-run behaviour of a graph, and Stewart §3.4 uses it to find horizontal asymptotes.

Definition \(\displaystyle\lim_{x\to\infty} f(x) = L\) means that \(f(x)\) can be made as close to \(L\) as we like by taking \(x\) large enough. Similarly for \(x \to -\infty\). The line \(y = L\) is a horizontal asymptote of \(y = f(x)\) if \(\lim_{x\to\infty} f(x) = L\) or \(\lim_{x\to-\infty} f(x) = L\).

The basic fact is that \(\dfrac{1}{x^r} \to 0\) as \(x \to \infty\) for any \(r \gt 0\) (and also as \(x \to -\infty\) when \(x^r\) is defined). The usual limit laws still hold.

Rational functions. We divide the numerator and denominator by the highest power of \(x\) in the denominator: \[\lim_{x\to\infty}\frac{3x^2 - x}{5x^2 + 2} = \lim_{x\to\infty}\frac{3 - \frac{1}{x}}{5 + \frac{2}{x^2}} = \frac{3 - 0}{5 + 0} = \frac35.\] In general, if the degrees are equal the limit is the ratio of leading coefficients; if the denominator has the higher degree the limit is 0. Why does this work? For huge \(x\), the term \(3x^2\) is far bigger than \(x\), and \(5x^2\) is far bigger than 2, so the fraction behaves like \(\frac{3x^2}{5x^2}\). Dividing by \(x^2\) is just a careful way of saying this. The same steps work as \(x \to -\infty\), so \(y = \tfrac35\) is a horizontal asymptote on both sides.

Square roots. Take note that inside a root, \(\sqrt{x^2} = |x|\). For \(x \gt 0\) this is \(x\), but for \(x \lt 0\) it is \(-x\). For example, let's take \(f(x) = \dfrac{2x}{\sqrt{x^2 + 1}}\) and divide top and bottom by \(|x| = \sqrt{x^2}\). As \(x \to \infty\), \(f(x) = \dfrac{2}{\sqrt{1 + 1/x^2}} \to 2\). As \(x \to -\infty\), \(\dfrac{2x}{|x|} = -2\), so \(f(x) \to -2\). The graph has two horizontal asymptotes, \(y = 2\) and \(y = -2\) (Figure 8.3).

Difference of large terms. For \(\sqrt{x^2 + x} - x\), both pieces grow without bound, so \(\infty - \infty\) tells us nothing. What do we do? Just like with limits at a number, we multiply by the conjugate: \[\sqrt{x^2 + x} - x = \frac{(x^2 + x) - x^2}{\sqrt{x^2 + x} + x} = \frac{x}{\sqrt{x^2 + x} + x} = \frac{1}{\sqrt{1 + 1/x} + 1} \to \frac12.\]

Infinite limits at infinity. Some functions just keep growing: \(\lim_{x\to\infty} x^3 = \infty\) and \(\lim_{x\to-\infty} x^3 = -\infty\). For a polynomial, the leading term wins: \(x^3 - 5x^2 = x^3(1 - 5/x) \to \infty\). If the numerator of a rational function has higher degree, such as \(\frac{x^2 + 1}{x + 1}\), the limit is infinite and there is no horizontal asymptote. Trigonometric functions such as \(\sin x\) oscillate forever, so \(\lim_{x\to\infty}\sin x\) does not exist, though \(\frac{\sin x}{x} \to 0\) by the Squeeze Theorem since \(-\frac1x \le \frac{\sin x}{x} \le \frac1x\).

Common mistakes (1) Writing \(\infty - \infty = 0\) or \(\frac{\infty}{\infty} = 1\); these are not numbers, so rewrite the expression first. (2) Forgetting that \(\sqrt{x^2} = -x\) when \(x \lt 0\). (3) Believing a graph can never cross its horizontal asymptote. Can it? Yes: \(\frac{3x^2 - x}{x^2 + 2}\) crosses \(y = 3\) at \(x = -6\) (Figure 8.4). An asymptote describes behaviour far out, not a forbidden line.
Key equations
\[ \lim_{x\to\infty}\frac{1}{x^r} = 0 \quad (r \gt 0) \]
\[ y = L \text{ is a horizontal asymptote if } \lim_{x\to\infty} f(x) = L \text{ or } \lim_{x\to-\infty} f(x) = L \]
\[ \sqrt{x^2} = |x| = -x \quad \text{for } x \lt 0 \]

★Key takeaways

  • Where f′ > 0 the graph rises, and where f′ < 0 it falls; a sign change of f′ at a critical number gives a local extremum.
  • Where f″ > 0 the graph is concave upward (a cup), and where f″ < 0 it is concave downward (a cap); take note that an inflection point is where the concavity actually changes.
  • Second Derivative Test: f′(c) = 0 with f″(c) > 0 gives a local minimum, with f″(c) < 0 a local maximum, and with f″(c) = 0 no conclusion.
  • For limits at infinity of rational functions, we divide by the highest power of x in the denominator.
  • With square roots, we use √(x²) = |x|, which equals −x when x → −∞; we use the conjugate for ∞ − ∞ forms.
  • A horizontal asymptote describes long-run behaviour, and the graph may cross it.

Example 8.1 Full shape analysis of a quartic

For \(f(x) = x^4 - 8x^2 + 3\), find (a) the intervals where \(f\) is increasing or decreasing, (b) the local maximum and minimum values, and (c) the intervals of concavity and the inflection points.

(Similar to Stewart §3.3, Examples 1, 2 and 6)
Show solution (try it first)
Given
  • \(f(x) = x^4 - 8x^2 + 3\), a polynomial (defined and differentiable everywhere).
  • Find: where \(f\) increases/decreases, its local extreme values, its concavity and its inflection points.
Step 1: Differentiate and factor f'

The critical numbers come from the zeros of \(f'\), so let's factor completely.

\[f'(x) = 4x^3 - 16x\]

\[f'(x) = 4x(x^2 - 4)\]

\[f'(x) = 4x(x - 2)(x + 2)\]

Step 2: Find the critical numbers

We set each factor equal to 0.

\[4x = 0,\quad x - 2 = 0,\quad x + 2 = 0 \quad\Rightarrow\quad x = 0,\ 2,\ -2\]

Step 3: Make a sign chart for f'

The critical numbers split the line into four intervals. We test the sign of each factor in each one.

Interval\(4x\)\(x - 2\)\(x + 2\)\(f'(x)\)\(f\)
\(x \lt -2\)−−−−decreasing
\(-2 \lt x \lt 0\)−−++increasing
\(0 \lt x \lt 2\)+−+−decreasing
\(x \gt 2\)++++increasing
Step 4: Find the local extreme values

By the First Derivative Test, \(f'\) goes − to + at \(\pm 2\) (minimum) and + to − at 0 (maximum). Let's substitute.

\[f(-2) = (-2)^4 - 8(-2)^2 + 3 = 16 - 32 + 3 = -13\]

\[f(0) = 0 - 0 + 3 = 3\]

\[f(2) = 2^4 - 8(2)^2 + 3 = 16 - 32 + 3 = -13\]

Step 5: Find where f'' is 0

Concavity depends on the sign of \(f''\), so we differentiate again and solve \(f''(x) = 0\).

\[f''(x) = 12x^2 - 16 = 4(3x^2 - 4)\]

\[3x^2 - 4 = 0 \quad\Rightarrow\quad x^2 = \tfrac43\]

\[x = \pm\frac{2}{\sqrt3} \approx \pm 1.155\]

Step 6: Determine the concavity

\(f''\) is an upward parabola with zeros at \(\pm\tfrac{2}{\sqrt3}\), so it is positive outside them and negative between them. For example, \(f''(0) = -16\) and \(f''(2) = 32\).

\[f'' \gt 0 \text{ on } \left(-\infty, -\tfrac{2}{\sqrt3}\right) \text{ and } \left(\tfrac{2}{\sqrt3}, \infty\right) \;\Rightarrow\; \text{concave upward}\]

\[f'' \lt 0 \text{ on } \left(-\tfrac{2}{\sqrt3}, \tfrac{2}{\sqrt3}\right) \;\Rightarrow\; \text{concave downward}\]

Step 7: Find the inflection points

The concavity changes at \(x = \pm\tfrac{2}{\sqrt3}\). There \(x^2 = \tfrac43\) and \(x^4 = \tfrac{16}{9}\), so

\[f = \frac{16}{9} - 8\cdot\frac43 + 3\]

\[f = \frac{16}{9} - \frac{32}{3} + 3\]

\[f = \frac{16}{9} - \frac{96}{9} + \frac{27}{9}\]

\[f = -\frac{53}{9}\]

Answer

(a) \(f\) is increasing on \((-2, 0)\) and \((2, \infty)\), decreasing on \((-\infty, -2)\) and \((0, 2)\). (b) Local maximum \(f(0) = 3\); local minimum \(f(\pm 2) = -13\). (c) Concave upward on \(\left(-\infty, -\tfrac{2}{\sqrt3}\right)\) and \(\left(\tfrac{2}{\sqrt3}, \infty\right)\), concave downward on \(\left(-\tfrac{2}{\sqrt3}, \tfrac{2}{\sqrt3}\right)\); inflection points \(\left(\pm\tfrac{2}{\sqrt3}, -\tfrac{53}{9}\right)\).

Check

The Second Derivative Test agrees: \(f''(0) = -16 \lt 0\) (max) and \(f''(\pm 2) = 32 \gt 0\) (min). Also, notice that \(f\) is even, so the picture is symmetric about the \(y\)-axis, as our answers are.

Example 8.2 Second Derivative Test with a trigonometric function

Let \(f(x) = x - 2\sin x\) for \(0 \lt x \lt 2\pi\). Use the Second Derivative Test to classify the critical numbers, and find the inflection point.

(Similar to Stewart §3.3, Example 4)
Show solution (try it first)
Given
  • \(f(x) = x - 2\sin x\) on \((0, 2\pi)\).
  • Find: the critical numbers, their type (by the Second Derivative Test), and the inflection point.
Step 1: Find the critical numbers

We differentiate and set \(f'(x) = 0\). In \((0, 2\pi)\), cosine equals \(\tfrac12\) twice.

\[f'(x) = 1 - 2\cos x\]

\[1 - 2\cos x = 0 \quad\Rightarrow\quad \cos x = \tfrac12\]

\[x = \tfrac{\pi}{3} \text{ or } x = \tfrac{5\pi}{3}\]

Step 2: Find the second derivative

The Second Derivative Test needs \(f''\).

\[f''(x) = \frac{d}{dx}(1 - 2\cos x) = 2\sin x\]

Step 3: Test x = π/3

We check the sign of \(f''\), then compute the function value.

\[f''\left(\tfrac{\pi}{3}\right) = 2\cdot\tfrac{\sqrt3}{2} = \sqrt3 \gt 0 \;\Rightarrow\; \text{local minimum}\]

\[f\left(\tfrac{\pi}{3}\right) = \tfrac{\pi}{3} - 2\cdot\tfrac{\sqrt3}{2} = \tfrac{\pi}{3} - \sqrt3 \approx -0.685\]

Step 4: Test x = 5π/3

Take note that \(\sin\tfrac{5\pi}{3} = -\tfrac{\sqrt3}{2}\), since \(\tfrac{5\pi}{3}\) is in the fourth quadrant.

\[f''\left(\tfrac{5\pi}{3}\right) = 2\left(-\tfrac{\sqrt3}{2}\right) = -\sqrt3 \lt 0 \;\Rightarrow\; \text{local maximum}\]

\[f\left(\tfrac{5\pi}{3}\right) = \tfrac{5\pi}{3} - 2\left(-\tfrac{\sqrt3}{2}\right) = \tfrac{5\pi}{3} + \sqrt3 \approx 6.968\]

Step 5: Find the inflection point

\(f''(x) = 2\sin x\) is positive on \((0, \pi)\) and negative on \((\pi, 2\pi)\), so the concavity changes at \(x = \pi\).

\[f(\pi) = \pi - 2\sin\pi = \pi - 0 = \pi\]

Answer

Local minimum \(f(\pi/3) = \tfrac{\pi}{3} - \sqrt3 \approx -0.685\); local maximum \(f(5\pi/3) = \tfrac{5\pi}{3} + \sqrt3 \approx 6.968\). The inflection point is \((\pi, \pi)\).

Check

Does it make sense that the local minimum sits in the concave-up part \((0, \pi)\) and the local maximum in the concave-down part \((\pi, 2\pi)\)? Yes: a cup holds a minimum, a cap holds a maximum.

Example 8.3 Limits at infinity: a rational function and a square root

Evaluate (a) \(\displaystyle\lim_{x\to\infty}\frac{2x^3 - 5x + 1}{4x^3 + x^2}\) and (b) \(\displaystyle\lim_{x\to-\infty}\frac{\sqrt{9x^2 + x}}{2x - 1}\).

(Similar to Stewart §3.4, Examples 3 and 4)
Show solution (try it first)
Given
  • (a) A rational function, with \(x \to \infty\). The highest power in the denominator is \(x^3\).
  • (b) A square root over a linear function, with \(x \to -\infty\), so \(x \lt 0\).
  • Find: both limits.
Step 1: Divide (a) by x³

We divide every term of the numerator and denominator by \(x^3\), the highest power in the denominator.

\[\frac{2x^3 - 5x + 1}{4x^3 + x^2} = \frac{\frac{2x^3}{x^3} - \frac{5x}{x^3} + \frac{1}{x^3}}{\frac{4x^3}{x^3} + \frac{x^2}{x^3}}\]

\[= \frac{2 - \frac{5}{x^2} + \frac{1}{x^3}}{4 + \frac{1}{x}}\]

Step 2: Let x go to infinity in (a)

Each term of the form \(\frac{k}{x^r}\) goes to 0.

\[\lim_{x\to\infty}\frac{2 - \frac{5}{x^2} + \frac{1}{x^3}}{4 + \frac{1}{x}} = \frac{2 - 0 + 0}{4 + 0} = \frac24 = \frac12\]

Step 3: Take x out of the square root in (b)

Let's factor \(x^2\) out of the root. Since \(x \lt 0\), \(\sqrt{x^2} = |x| = -x\).

\[\sqrt{9x^2 + x} = \sqrt{x^2\left(9 + \tfrac1x\right)}\]

\[= \sqrt{x^2}\,\sqrt{9 + \tfrac1x}\]

\[= -x\sqrt{9 + \tfrac1x}\]

Step 4: Factor x out of the denominator and cancel

We write \(2x - 1 = x\left(2 - \frac1x\right)\), then cancel the common factor \(x\).

\[\frac{\sqrt{9x^2 + x}}{2x - 1} = \frac{-x\sqrt{9 + \frac1x}}{x\left(2 - \frac1x\right)}\]

\[= \frac{-\sqrt{9 + \frac1x}}{2 - \frac1x}\]

Step 5: Let x go to negative infinity in (b)

Again \(\frac1x \to 0\).

\[\lim_{x\to-\infty}\frac{-\sqrt{9 + \frac1x}}{2 - \frac1x} = \frac{-\sqrt{9 + 0}}{2 - 0} = -\frac32\]

Answer

(a) The limit is \(\tfrac12\). (b) The limit is \(-\tfrac32\).

Check

(a) The degrees are equal, so the limit should be the ratio of leading coefficients, \(\tfrac24\). It is. (b) A quick sign check: when \(x\) is a large negative number, the numerator is positive and the denominator negative, so the limit must be negative. Students who write \(\sqrt{x^2} = x\) get \(+\tfrac32\), which fails this check.

Example 8.4 A limit of the form ∞ − ∞

Evaluate \(\displaystyle\lim_{x\to\infty}\left(\sqrt{x^2 + 6x} - x\right)\).

(Similar to Stewart §3.4, Example 5)
Show solution (try it first)
Given
  • \(\sqrt{x^2 + 6x} - x\) with \(x \to \infty\), so \(x \gt 0\).
  • Both terms grow without bound, so this is of the form \(\infty - \infty\).
  • Find: the limit.
Step 1: Multiply by the conjugate

If we substitute right away we get \(\infty - \infty\), which tells us nothing. So let's multiply top and bottom by the conjugate \(\sqrt{x^2 + 6x} + x\).

\[\sqrt{x^2 + 6x} - x = \left(\sqrt{x^2 + 6x} - x\right)\cdot\frac{\sqrt{x^2 + 6x} + x}{\sqrt{x^2 + 6x} + x}\]

Step 2: Simplify the numerator

The numerator is a difference of squares, \((a - b)(a + b) = a^2 - b^2\).

\[= \frac{(x^2 + 6x) - x^2}{\sqrt{x^2 + 6x} + x}\]

\[= \frac{6x}{\sqrt{x^2 + 6x} + x}\]

Step 3: Divide top and bottom by x

Since \(x \gt 0\), we can write \(x = \sqrt{x^2}\) inside the root.

\[\frac{\sqrt{x^2 + 6x}}{x} = \sqrt{\frac{x^2 + 6x}{x^2}} = \sqrt{1 + \frac{6}{x}}\]

\[\frac{6x}{\sqrt{x^2 + 6x} + x} = \frac{6}{\sqrt{1 + \frac{6}{x}} + 1}\]

Step 4: Let x go to infinity

Now \(\frac{6}{x} \to 0\).

\[\lim_{x\to\infty}\frac{6}{\sqrt{1 + \frac{6}{x}} + 1} = \frac{6}{\sqrt{1} + 1} = \frac{6}{2} = 3\]

Answer

\(\displaystyle\lim_{x\to\infty}\left(\sqrt{x^2 + 6x} - x\right) = 3\).

Check

Let's try \(x = 1000\): \(\sqrt{1006000} - 1000 \approx 2.996\), close to 3. Notice that the answer is not 0, which is what we would get if we wrongly wrote \(\infty - \infty = 0\).
