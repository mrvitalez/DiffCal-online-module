3.5Summary of Curve Sketching

Let's take stock of what we already have. Limits give us asymptotes (Stewart §1.5 and §3.4), the first derivative tells us where the graph rises and falls, and the second derivative tells us how it bends (§3.3). So, why do we still sketch by hand when a graphing app can draw the curve for us? Because an app can easily hide a vertical asymptote or a tiny bump. Stewart §3.5 collects all our tools into one checklist, and the checklist tells us what must be there.

Checklist A–H
  1. A. Domain: the \(x\)-values where \(f(x)\) is defined.
  2. B. Intercepts: \(y\)-intercept \(f(0)\); \(x\)-intercepts from \(f(x) = 0\) (skip if hard to solve).
  3. C. Symmetry: even if \(f(-x) = f(x)\) (mirror in the \(y\)-axis), odd if \(f(-x) = -f(x)\) (rotate \(180^\circ\) about the origin), or periodic.
  4. D. Asymptotes: horizontal (\(\lim_{x\to\pm\infty} f(x) = L\)), vertical (\(f \to \pm\infty\) as \(x \to a\)), and slant (\(f(x) - (mx + b) \to 0\)).
  5. E. Intervals of increase or decrease: sign of \(f'\).
  6. F. Local maximum and minimum values: critical numbers and the First Derivative Test.
  7. G. Concavity and points of inflection: sign of \(f''\).
  8. H. Sketch: plot the special points, draw the asymptotes as dashed lines, and join everything following E and G.

Let's go through the checklist with two functions.

Example 1: \(f(x) = \dfrac{x}{x^2 - 4}\). A: \(x \ne \pm 2\). B: the only intercept is \((0,0)\). C: \(f(-x) = -f(x)\), so \(f\) is odd. D: \(f(x) \to 0\) as \(x \to \pm\infty\) (the bottom has the higher degree), so \(y = 0\) is a horizontal asymptote; the denominator is 0 at \(x = \pm 2\) while the top is not, so \(x = \pm 2\) are vertical asymptotes. Just right of 2, \(f > 0\), so \(f \to \infty\); just left of 2, \(f \to -\infty\). E: the Quotient Rule gives \[f'(x) = \frac{(x^2 - 4) - x(2x)}{(x^2-4)^2} = -\frac{x^2 + 4}{(x^2-4)^2} < 0,\] so \(f\) decreases on each of its three intervals. F: since \(f'\) never changes sign, there are no local extrema. G: \(f''(x) = \dfrac{2x(x^2+12)}{(x^2-4)^3}\). Its sign changes at \(x = -2, 0, 2\): concave down on \((-\infty,-2)\) and \((0,2)\), concave up on \((-2,0)\) and \((2,\infty)\). Since \(0\) is in the domain, \((0,0)\) is an inflection point. What about \(x = \pm 2\)? They are not inflection points, because there is no point on the graph there. See Figure 9.1.

Example 2: \(f(x) = x^4 - 4x^3\). A: all reals. B: \(f(0) = 0\); \(x^3(x - 4) = 0\) gives \(x = 0, 4\). C: none. D: polynomials have no asymptotes. E: \(f'(x) = 4x^3 - 12x^2 = 4x^2(x - 3)\): negative for \(x < 3\) (also on both sides of 0), positive for \(x > 3\). F: take note that \(x = 0\) is a critical number, but \(f'\) does not change sign there, so it is not an extremum. The only local extremum is the local minimum \(f(3) = -27\). G: \(f''(x) = 12x^2 - 24x = 12x(x - 2)\): concave up on \((-\infty,0)\) and \((2,\infty)\), down on \((0,2)\). Inflection points \((0,0)\) and \((2,-16)\). See Figure 9.2.

Common mistake Take note that a critical number is not automatically a maximum or minimum, and a zero of \(f''\) is not automatically an inflection point. So we always check that the sign actually changes, and that the point is in the domain.
Key equations
\[ f(-x) = f(x)\ \text{(even)}, \qquad f(-x) = -f(x)\ \text{(odd)} \]
\[ \lim_{x\to\infty}\big[f(x) - (mx + b)\big] = 0 \ \Rightarrow\ y = mx + b \text{ is a slant asymptote} \]
\[ f' \gt 0 \Rightarrow \text{increasing}, \qquad f'' \gt 0 \Rightarrow \text{concave up} \]

3.7Optimization Problems

What is the largest box we can fold from one sheet of cardboard? What is the cheapest can that still holds the same amount? Questions like these ask for the best value: the largest volume, the least cost, the shortest distance. Stewart §3.7 shows that each one is really the absolute maximum or minimum of a function of one variable, which we already know how to find (Stewart §3.1). So most of the work is setting up that function.

Strategy
  1. Understand the problem: what is unknown, what is given, what must be optimized?
  2. Draw a diagram and label it.
  3. Name the quantity to be optimized, say \(Q\), as a formula in the labelled variables.
  4. Use the given conditions (a fixed area, perimeter or volume) to write \(Q\) as a function of one variable. Write its domain.
  5. Find the absolute extreme value: Closed Interval Method if the domain is closed, otherwise the test below.
First Derivative Test for Absolute Extreme Values Suppose \(c\) is a critical number of a continuous \(f\) on an interval. If \(f'(x) > 0\) for all \(x < c\) and \(f'(x) < 0\) for all \(x > c\), then \(f(c)\) is the absolute maximum. If the signs are reversed (\(-\) then \(+\)), \(f(c)\) is the absolute minimum.

Why do we need this test? Recall that the Closed Interval Method needs a closed interval \([a, b]\). On an open interval like \((0,\infty)\) there are no endpoints to compare, so we use the sign of \(f'\) instead.

A box. Let's start with a box. From an 18 cm by 18 cm square of cardboard, cut a square of side \(x\) from each corner and fold up the sides to make an open box. Its volume is \(V(x) = x(18 - 2x)^2\) with \(0 \le x \le 9\). Then \(V'(x) = (18-2x)^2 - 4x(18-2x) = (18-2x)(18-6x)\), which is 0 at \(x = 3\) and \(x = 9\). Now let's compare the values at the critical number and the endpoints: \(V(0) = 0\), \(V(9) = 0\), \(V(3) = 3\cdot 12^2 = 432\). So the largest box has volume \(432\text{ cm}^3\) (Figure 9.3).

A fence. A farmer has 600 m of fencing to enclose a rectangle along a straight river, with no fence on the river side. With \(x\) the length of each side perpendicular to the river, the side parallel to the river is \(600 - 2x\), so \(A(x) = x(600 - 2x)\), \(0 \le x \le 300\). \(A'(x) = 600 - 4x = 0\) gives \(x = 150\), and \(A(150) = 45\,000\text{ m}^2\), while \(A = 0\) at both ends. That is our maximum area.

A can of fixed volume \(V\) with least surface area, and the point on a curve closest to a given point, follow the same plan; they are Examples 2 and 3 below. For a distance, let's minimize \(d^2\) instead of \(d\). Why is that allowed? Because \(d \ge 0\), so \(d\) and \(d^2\) are smallest at the same place, and the square root disappears.

Common mistake Take note that finding the critical number is not the end. We still state why it gives the absolute (not just local) extreme value, and we answer the question that was asked: often the problem wants the dimensions or the maximum value, not just \(x\).
Key equations
\[ Q = Q(x) \text{ on its domain; solve } Q'(x) = 0 \]
\[ f' \gt 0 \text{ for } x \lt c,\ f' \lt 0 \text{ for } x \gt c \ \Rightarrow\ f(c) \text{ is the absolute maximum} \]
\[ \text{minimize } d^2 = (x - a)^2 + (y - b)^2 \text{ instead of } d \]

★Key takeaways

  • When we sketch a curve, we go through eight checks: domain, intercepts, symmetry, asymptotes, increase/decrease, extrema, concavity and the final sketch.
  • When the top of a rational function has degree one more than the bottom, long division gives us a slant asymptote y = mx + b.
  • Take note that extrema and inflection points need a sign change (of f′ or f″) at a point in the domain.
  • In optimization, most of our work is writing the quantity as a function of one variable using the given constraint.
  • On an open interval, one critical number where f′ changes sign gives us the absolute maximum or minimum.
  • To minimize a distance, we minimize its square; then we answer the question that was actually asked.

Example 9.1 A graph with a slant asymptote

Use the checklist to sketch \(f(x) = \dfrac{x^2}{x - 2}\).

(Similar to Stewart §3.5, Example 7)
Show solution (try it first)
Given
  • \(f(x) = \dfrac{x^2}{x - 2}\)
  • Asked: a sketch of the graph, using checklist A–H.
Step 1: Find the domain and the intercepts (A, B)

The denominator is 0 at \(x = 2\), so we remove that value from the domain.

\[x - 2 = 0 \quad\Longrightarrow\quad x = 2\]

So the domain is \(x \ne 2\). Next, let's find the intercepts.

\[f(0) = \frac{0^2}{0 - 2} = 0\]

\[f(x) = 0 \quad\Longrightarrow\quad x^2 = 0 \quad\Longrightarrow\quad x = 0\]

The only intercept is \((0, 0)\).

Step 2: Check for symmetry (C)

We replace \(x\) by \(-x\) and compare with \(f(x)\).

\[f(-x) = \frac{(-x)^2}{-x - 2} = \frac{x^2}{-x - 2}\]

This is neither \(f(x)\) nor \(-f(x)\), so the graph has no symmetry.

Step 3: Divide to find the slant asymptote (D)

The top has degree one more than the bottom, so we expect a slant asymptote. Let's do the long division first.

\[x^2 = (x - 2)(x + 2) + 4\]

\[f(x) = \frac{(x - 2)(x + 2) + 4}{x - 2} = x + 2 + \frac{4}{x - 2}\]

Now we check that the difference from the line goes to 0.

\[\lim_{x\to\pm\infty}\big[f(x) - (x + 2)\big] = \lim_{x\to\pm\infty}\frac{4}{x - 2} = 0\]

So \(y = x + 2\) is a slant asymptote, and there is no horizontal asymptote.

Step 4: Find the vertical asymptote (D)

At \(x = 2\) the bottom is 0 but the top is \(2^2 = 4\), not 0. So the function blows up there. The sign of the bottom decides the direction.

\[\lim_{x\to 2^+}\frac{x^2}{x - 2} = \infty \quad(\text{top} \approx 4,\ \text{bottom small and positive})\]

\[\lim_{x\to 2^-}\frac{x^2}{x - 2} = -\infty \quad(\text{top} \approx 4,\ \text{bottom small and negative})\]

So \(x = 2\) is a vertical asymptote.

Step 5: Find f′ and where f increases or decreases (E)

We use the Quotient Rule, then simplify the top.

\[f'(x) = \frac{(x - 2)(2x) - x^2(1)}{(x - 2)^2}\]

\[= \frac{2x^2 - 4x - x^2}{(x - 2)^2}\]

\[= \frac{x^2 - 4x}{(x - 2)^2}\]

\[= \frac{x(x - 4)}{(x - 2)^2}\]

The bottom is always positive, so the sign comes from \(x(x - 4)\).

Interval\(x\)\(x - 4\)\(f'(x)\)\(f\)
\((-\infty, 0)\)\(-\)\(-\)\(+\)increasing
\((0, 2)\)\(+\)\(-\)\(-\)decreasing
\((2, 4)\)\(+\)\(-\)\(-\)decreasing
\((4, \infty)\)\(+\)\(+\)\(+\)increasing
Step 6: Find the local maximum and minimum (F)

From the table, \(f'\) changes from \(+\) to \(-\) at \(x = 0\) and from \(-\) to \(+\) at \(x = 4\). Let's compute the values there.

\[f(0) = \frac{0^2}{0 - 2} = 0 \quad(\text{local maximum})\]

\[f(4) = \frac{4^2}{4 - 2} = \frac{16}{2} = 8 \quad(\text{local minimum})\]

Step 7: Find the concavity (G)

The divided form \(f(x) = x + 2 + 4(x - 2)^{-1}\) is easier to differentiate twice.

\[f'(x) = 1 - 4(x - 2)^{-2}\]

\[f''(x) = 8(x - 2)^{-3} = \frac{8}{(x - 2)^3}\]

For \(x < 2\), \((x - 2)^3 < 0\), so \(f'' < 0\): concave down. For \(x > 2\), \(f'' > 0\): concave up. The concavity changes at \(x = 2\), but \(x = 2\) is not in the domain, so there is no inflection point.

Step 8: Sketch the graph (H)

We draw the dashed lines \(x = 2\) and \(y = x + 2\), plot \((0, 0)\) and \((4, 8)\), and join them following Steps 5 and 7. On the left, the curve rises to the peak at the origin and then dives to \(-\infty\) at \(x = 2\). On the right, it falls from \(+\infty\) to the valley at \((4, 8)\) and then hugs the slant asymptote from above.

Answer

So the graph of \(f(x) = \dfrac{x^2}{x - 2}\) has the vertical asymptote \(x = 2\), the slant asymptote \(y = x + 2\), a local maximum at \((0, 0)\), a local minimum at \((4, 8)\), and no inflection point. It is concave down for \(x < 2\) and concave up for \(x > 2\).

Check

For large \(x\), \(\dfrac{4}{x - 2} > 0\), so the curve sits above \(y = x + 2\) on the right. That agrees with \(f(4) = 8 > 6\), the height of the line at \(x = 4\). Notice that the local maximum value 0 is smaller than the local minimum value 8. Is that a mistake? No. The two pieces are separated by the asymptote, so this can happen.

Example 9.2 The largest open box

An open box is made from a 30 cm by 16 cm sheet of cardboard by cutting a square of side \(x\) cm from each corner and folding up the sides. What value of \(x\) gives the largest volume, and what is that volume?

(Similar to Stewart §3.7, Example 1)
Show solution (try it first)
Given
  • Sheet: 30 cm by 16 cm.
  • A square of side \(x\) is cut from each corner.
  • Asked: the \(x\) that makes the volume largest, and the largest volume.
Step 1: Write the volume as a function of x

Cutting \(x\) from both ends of each side leaves a base of \((30 - 2x)\) by \((16 - 2x)\), and the height is \(x\).

\[V(x) = x(30 - 2x)(16 - 2x)\]

The width cannot be negative, so \(16 - 2x \ge 0\), that is \(x \le 8\). So the domain is \(0 \le x \le 8\), a closed interval.

Step 2: Expand so that V is easy to differentiate

Let's multiply the two binomials first.

\[(30 - 2x)(16 - 2x) = 480 - 60x - 32x + 4x^2\]

\[= 4x^2 - 92x + 480\]

\[V(x) = 4x^3 - 92x^2 + 480x\]

Step 3: Find the critical numbers

We differentiate and set \(V'(x) = 0\).

\[V'(x) = 12x^2 - 184x + 480\]

\[= 4(3x^2 - 46x + 120)\]

\[= 4(3x - 10)(x - 12)\]

\[V'(x) = 0 \quad\Longrightarrow\quad x = \tfrac{10}{3} \ \text{ or } \ x = 12\]

Only \(x = \tfrac{10}{3}\) is in \([0, 8]\).

Step 4: Compare values (Closed Interval Method)

The domain is closed, so we compare \(V\) at the endpoints and at the critical number.

\[V(0) = 0 \qquad V(8) = 8(14)(0) = 0\]

\[V\!\left(\tfrac{10}{3}\right) = \tfrac{10}{3}\left(30 - \tfrac{20}{3}\right)\left(16 - \tfrac{20}{3}\right)\]

\[= \tfrac{10}{3}\cdot\tfrac{70}{3}\cdot\tfrac{28}{3}\]

\[= \tfrac{19600}{27} \approx 725.9\]

Answer

So we cut squares of side \(x = \tfrac{10}{3} \approx 3.33\) cm. The box measures \(\tfrac{70}{3}\) cm by \(\tfrac{28}{3}\) cm by \(\tfrac{10}{3}\) cm, and its largest volume is \(\tfrac{19600}{27} \approx 725.9\text{ cm}^3\).

Check

Try nearby whole numbers: \(V(3) = 3(24)(10) = 720\) and \(V(4) = 4(22)(8) = 704\). Both are a little smaller than 725.9. ✓

Example 9.3 Closest point on a curve

Find the point on the curve \(y = \sqrt{x}\) that is closest to the point \((4, 0)\), and find that shortest distance.

(Similar to Stewart §3.7, Example 3)
Show solution (try it first)
Given
  • Curve: \(y = \sqrt{x}\), \(x \ge 0\).
  • Fixed point: \((4, 0)\).
  • Asked: the closest point on the curve and the shortest distance.
Step 1: Write the distance from a general point of the curve

A point on the curve is \((x, \sqrt{x})\). We use the distance formula.

\[d = \sqrt{(x - 4)^2 + (\sqrt{x} - 0)^2}\]

Step 2: Minimize the square of the distance instead

\(d\) and \(d^2\) are smallest at the same place, and \(d^2\) has no square root. So let's call \(D(x) = d^2\).

\[D(x) = (x - 4)^2 + (\sqrt{x})^2\]

\[= (x - 4)^2 + x, \qquad x \ge 0\]

Step 3: Find the critical number

We differentiate and set the derivative equal to 0.

\[D'(x) = 2(x - 4) + 1\]

\[= 2x - 7\]

\[2x - 7 = 0 \quad\Longrightarrow\quad x = \tfrac72\]

Step 4: Show that it is the absolute minimum

The domain \([0, \infty)\) has no right endpoint, so we use the First Derivative Test for Absolute Extreme Values. \(D'(x) = 2x - 7 < 0\) for \(x < \tfrac72\) and \(D'(x) > 0\) for \(x > \tfrac72\). So \(x = \tfrac72\) gives the absolute minimum.

Step 5: Find the point and the distance

We substitute \(x = \tfrac72\) into the curve and into \(D\).

\[y = \sqrt{\tfrac72} \approx 1.871\]

\[D\!\left(\tfrac72\right) = \left(\tfrac72 - 4\right)^2 + \tfrac72\]

\[= \left(-\tfrac12\right)^2 + \tfrac72\]

\[= \tfrac14 + \tfrac{14}{4} = \tfrac{15}{4}\]

\[d = \sqrt{\tfrac{15}{4}} = \frac{\sqrt{15}}{2} \approx 1.936\]

Answer

So the closest point is \(\left(\tfrac72, \sqrt{\tfrac72}\right) \approx (3.5, 1.871)\), and the shortest distance is \(\dfrac{\sqrt{15}}{2} \approx 1.936\) units.

Check

Compare with nearby points: at \(x = 4\), \(d = \sqrt{0 + 4} = 2\); at \(x = 3\), \(d = \sqrt{1 + 3} = 2\). Both are larger than 1.936. ✓ Also (Figure 9.4), the segment from \((3.5, 1.871)\) to \((4, 0)\) has slope \(-1.871/0.5 \approx -3.74\), and the tangent slope there is \(\frac{1}{2\sqrt{3.5}} \approx 0.267\). Their product is \(-1\), so they are perpendicular, as a shortest segment should be.

Example 9.4 The cheapest can

A closed cylindrical can must hold \(500\pi\text{ cm}^3\). The material for the top and bottom costs twice as much per square centimetre as the material for the side. What radius and height make the can cheapest?

(Similar to Stewart §3.7, Example 2)
Show solution (try it first)
Given
  • Volume: \(\pi r^2 h = 500\pi\text{ cm}^3\).
  • Side material costs \(k\) per cm²; top and bottom cost \(2k\) per cm² (the value of \(k\) will not matter).
  • Asked: the radius \(r\) and height \(h\) of the cheapest can.
Step 1: Write the cost in terms of r and h

The can has two disks (top and bottom) and one curved side. We multiply each area by its cost.

\[\text{top and bottom: } 2\cdot\pi r^2\cdot 2k = 4k\pi r^2\]

\[\text{side: } 2\pi r h\cdot k = 2k\pi r h\]

\[C = 4k\pi r^2 + 2k\pi r h\]

Step 2: Use the volume to remove h

The cost has two variables, so we use the fixed volume to write \(h\) in terms of \(r\).

\[\pi r^2 h = 500\pi\]

\[h = \frac{500}{r^2}\]

Step 3: Write C as a function of r alone

We substitute \(h = \dfrac{500}{r^2}\) into the cost.

\[C(r) = 4k\pi r^2 + 2k\pi r\cdot\frac{500}{r^2}\]

\[= 4k\pi r^2 + \frac{1000k\pi}{r}, \qquad r > 0\]

Step 4: Find the critical number

We differentiate, combine into one fraction and set the top equal to 0.

\[C'(r) = 8k\pi r - \frac{1000k\pi}{r^2}\]

\[= \frac{8k\pi r^3 - 1000k\pi}{r^2}\]

\[= \frac{8k\pi\,(r^3 - 125)}{r^2}\]

\[r^3 - 125 = 0 \quad\Longrightarrow\quad r^3 = 125 \quad\Longrightarrow\quad r = 5\]

Step 5: Show that it is the absolute minimum

The domain \((0, \infty)\) is open, so we check the sign of \(C'\). For \(0 < r < 5\), \(r^3 - 125 < 0\), so \(C' < 0\). For \(r > 5\), \(C' > 0\). By the First Derivative Test for Absolute Extreme Values, \(r = 5\) gives the absolute minimum cost.

Step 6: Find the height

We substitute \(r = 5\) into the formula from Step 2.

\[h = \frac{500}{5^2} = \frac{500}{25} = 20\]

Answer

So the cheapest can has radius 5 cm and height 20 cm.

Check

Volume: \(\pi(5^2)(20) = 500\pi\). ✓ Notice that \(h = 4r\): because the ends are expensive, the best can is tall and thin. If all material cost the same, the same method gives \(h = 2r\). Take note of a common slip: there are two ends, not one.
