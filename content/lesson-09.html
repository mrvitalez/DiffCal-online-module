3.5Summary of Curve Sketching

By now you own every tool needed to draw an honest graph: limits give asymptotes (Stewart §1.5 and §3.4), the first derivative gives rise and fall, and the second derivative gives bending (§3.3). Stewart §3.5 collects them into one checklist. A graphing app can draw a curve for you, but it can easily hide a vertical asymptote or a tiny bump; the checklist tells you what must be there.

Checklist A–H
  1. A. Domain: the \(x\)-values where \(f(x)\) is defined.
  2. B. Intercepts: \(y\)-intercept \(f(0)\); \(x\)-intercepts from \(f(x) = 0\) (skip if hard to solve).
  3. C. Symmetry: even if \(f(-x) = f(x)\) (mirror in the \(y\)-axis), odd if \(f(-x) = -f(x)\) (rotate \(180^\circ\) about the origin), or periodic.
  4. D. Asymptotes: horizontal (\(\lim_{x\to\pm\infty} f(x) = L\)), vertical (\(f \to \pm\infty\) as \(x \to a\)), and slant (\(f(x) - (mx + b) \to 0\)).
  5. E. Intervals of increase or decrease: sign of \(f'\).
  6. F. Local maximum and minimum values: critical numbers and the First Derivative Test.
  7. G. Concavity and points of inflection: sign of \(f''\).
  8. H. Sketch: plot the special points, draw the asymptotes as dashed lines, and join everything following E and G.

Example 1: \(f(x) = \dfrac{x}{x^2 - 4}\). A: \(x \ne \pm 2\). B: the only intercept is \((0,0)\). C: \(f(-x) = -f(x)\), so \(f\) is odd. D: \(f(x) \to 0\) as \(x \to \pm\infty\) (the bottom has the higher degree), so \(y = 0\) is a horizontal asymptote; the denominator is 0 at \(x = \pm 2\) while the top is not, so \(x = \pm 2\) are vertical asymptotes. Just right of 2, \(f > 0\), so \(f \to \infty\); just left of 2, \(f \to -\infty\). E: the Quotient Rule gives \[f'(x) = \frac{(x^2 - 4) - x(2x)}{(x^2-4)^2} = -\frac{x^2 + 4}{(x^2-4)^2} < 0,\] so \(f\) decreases on each of its three intervals. F: no local extrema. G: \(f''(x) = \dfrac{2x(x^2+12)}{(x^2-4)^3}\). Its sign changes at \(x = -2, 0, 2\): concave down on \((-\infty,-2)\) and \((0,2)\), concave up on \((-2,0)\) and \((2,\infty)\). Since \(0\) is in the domain, \((0,0)\) is an inflection point; \(x = \pm 2\) are not (no point there). See Figure 9.1.

Example 2: \(f(x) = x^4 - 4x^3\). A: all reals. B: \(f(0) = 0\); \(x^3(x - 4) = 0\) gives \(x = 0, 4\). C: none. D: polynomials have no asymptotes. E: \(f'(x) = 4x^3 - 12x^2 = 4x^2(x - 3)\): negative for \(x < 3\) (also on both sides of 0), positive for \(x > 3\). F: \(x = 0\) is a critical number but \(f'\) does not change sign, so it is not an extremum; local minimum \(f(3) = -27\). G: \(f''(x) = 12x^2 - 24x = 12x(x - 2)\): concave up on \((-\infty,0)\) and \((2,\infty)\), down on \((0,2)\). Inflection points \((0,0)\) and \((2,-16)\). See Figure 9.2.

Common mistake A critical number is not automatically a maximum or minimum, and a zero of \(f''\) is not automatically an inflection point. Always check that the sign actually changes, and that the point is in the domain.
Key equations
\[ f(-x) = f(x)\ \text{(even)}, \qquad f(-x) = -f(x)\ \text{(odd)} \]
\[ \lim_{x\to\infty}\big[f(x) - (mx + b)\big] = 0 \ \Rightarrow\ y = mx + b \text{ is a slant asymptote} \]
\[ f' \gt 0 \Rightarrow \text{increasing}, \qquad f'' \gt 0 \Rightarrow \text{concave up} \]

3.7Optimization Problems

Optimization problems ask for the best value: the largest volume, the least cost, the shortest distance. Stewart §3.7 turns them into the absolute maximum or minimum of a function of one variable, which you learned to find in Stewart §3.1. Most of the work is setting up that function.

Strategy
  1. Understand the problem: what is unknown, what is given, what must be optimized?
  2. Draw a diagram and label it.
  3. Name the quantity to be optimized, say \(Q\), as a formula in the labelled variables.
  4. Use the given conditions (a fixed area, perimeter or volume) to write \(Q\) as a function of one variable. Write its domain.
  5. Find the absolute extreme value: Closed Interval Method if the domain is closed, otherwise the test below.
First Derivative Test for Absolute Extreme Values Suppose \(c\) is a critical number of a continuous \(f\) on an interval. If \(f'(x) > 0\) for all \(x < c\) and \(f'(x) < 0\) for all \(x > c\), then \(f(c)\) is the absolute maximum. If the signs are reversed (\(-\) then \(+\)), \(f(c)\) is the absolute minimum.

This test is handy on open intervals like \((0,\infty)\), where the Closed Interval Method cannot be used.

A box. From an 18 cm by 18 cm square of cardboard, cut a square of side \(x\) from each corner and fold up the sides to make an open box. Its volume is \(V(x) = x(18 - 2x)^2\) with \(0 \le x \le 9\). Then \(V'(x) = (18-2x)^2 - 4x(18-2x) = (18-2x)(18-6x)\), which is 0 at \(x = 3\) and \(x = 9\). Compare: \(V(0) = 0\), \(V(9) = 0\), \(V(3) = 3\cdot 12^2 = 432\). The largest box has volume \(432\text{ cm}^3\) (Figure 9.3).

A fence. A farmer has 600 m of fencing to enclose a rectangle along a straight river, with no fence on the river side. With \(x\) the length of each side perpendicular to the river, the side parallel to the river is \(600 - 2x\), so \(A(x) = x(600 - 2x)\), \(0 \le x \le 300\). \(A'(x) = 600 - 4x = 0\) gives \(x = 150\), and \(A(150) = 45\,000\text{ m}^2\), while \(A = 0\) at both ends.

A can of fixed volume \(V\) with least surface area, and the point on a curve closest to a given point, follow the same plan; they are Examples 2 and 3 below. For a distance, minimize \(d^2\) instead of \(d\): the square root disappears and both are smallest at the same place.

Common mistake Finding the critical number is not the end. State why it gives the absolute (not just local) extreme value, and answer the question that was asked: often the problem wants the dimensions or the maximum value, not just \(x\).
Key equations
\[ Q = Q(x) \text{ on its domain; solve } Q'(x) = 0 \]
\[ f' \gt 0 \text{ for } x \lt c,\ f' \lt 0 \text{ for } x \gt c \ \Rightarrow\ f(c) \text{ is the absolute maximum} \]
\[ \text{minimize } d^2 = (x - a)^2 + (y - b)^2 \text{ instead of } d \]

★Key takeaways

  • Curve sketching combines eight checks: domain, intercepts, symmetry, asymptotes, increase/decrease, extrema, concavity and the final sketch.
  • When the top of a rational function has degree one more than the bottom, long division reveals a slant asymptote y = mx + b.
  • Extrema and inflection points require a sign change (of f′ or f″) at a point in the domain.
  • In optimization, most of the work is writing the quantity as a function of one variable using the given constraint.
  • On an open interval, a single critical number where f′ changes sign gives the absolute maximum or minimum.
  • To minimize a distance, minimize its square; then answer the question that was actually asked.

Example 9.1 A graph with a slant asymptote

Use the checklist to sketch \(f(x) = \dfrac{x^2}{x - 2}\).

(Similar to Stewart §3.5, Example 7)
Show solution (try it first)

Strategy:

The top has degree one more than the bottom, so expect a slant asymptote. Do long division first; it also helps with the limits.

Solution:

A. Domain: \(x \ne 2\). B. \(f(0) = 0\), and \(f(x) = 0\) only at \(x = 0\). C. \(f(-x) = \dfrac{x^2}{-x-2}\) is neither \(f(x)\) nor \(-f(x)\): no symmetry.

D. Dividing, \(x^2 = (x - 2)(x + 2) + 4\), so \(f(x) = x + 2 + \dfrac{4}{x - 2}\). As \(x \to \pm\infty\), \(\dfrac{4}{x-2} \to 0\), so \(y = x + 2\) is a slant asymptote (no horizontal asymptote). At \(x = 2\) the bottom is 0 and the top is 4, so \(x = 2\) is a vertical asymptote: \(f \to \infty\) as \(x \to 2^+\), \(f \to -\infty\) as \(x \to 2^-\).

E. \(f'(x) = \dfrac{2x(x-2) - x^2(1)}{(x-2)^2} = \dfrac{x^2 - 4x}{(x-2)^2} = \dfrac{x(x-4)}{(x-2)^2}\). The bottom is positive, so the sign comes from \(x(x - 4)\): increasing on \((-\infty, 0)\) and \((4, \infty)\), decreasing on \((0, 2)\) and \((2, 4)\).

F. Local maximum \(f(0) = 0\); local minimum \(f(4) = \dfrac{16}{2} = 8\).

G. From \(f(x) = x + 2 + 4(x-2)^{-1}\): \(f'(x) = 1 - 4(x-2)^{-2}\) and \(f''(x) = \dfrac{8}{(x-2)^3}\). Concave down for \(x < 2\), concave up for \(x > 2\). No inflection point, since \(x = 2\) is not in the domain.

H. Draw the dashed lines \(x = 2\) and \(y = x + 2\), plot \((0,0)\) and \((4,8)\), and join: on the left, the curve rises to the peak at the origin and dives to \(-\infty\) at \(x = 2\); on the right, it falls from \(+\infty\) to the valley at \((4, 8)\) and then hugs the slant asymptote from above.

Check:

For large \(x\), \(\dfrac{4}{x-2} > 0\), so the curve sits above \(y = x + 2\) on the right and below it on the left. That agrees with \(f(4) = 8 > 6\) on the line. Also, the local maximum value 0 is smaller than the local minimum value 8: this is possible because the two pieces are separated by the asymptote.

Example 9.2 The cheapest can

A closed cylindrical can must hold \(500\pi\text{ cm}^3\). The material for the top and bottom costs twice as much per square centimetre as the material for the side. What radius and height make the can cheapest?

(Similar to Stewart §3.7, Example 2)
Show solution (try it first)

Strategy:

Let the side material cost \(k\) per cm² (the value of \(k\) will not matter). Write the cost in terms of \(r\) and \(h\), use the volume to remove \(h\), then minimize on \((0, \infty)\).

Solution:

Top and bottom: two disks of area \(\pi r^2\) at cost \(2k\) each, total \(4k\pi r^2\). Side: area \(2\pi r h\) at cost \(k\). So \(C = k(4\pi r^2 + 2\pi r h)\).

Volume: \(\pi r^2 h = 500\pi\), so \(h = \dfrac{500}{r^2}\). Then \[C(r) = k\left(4\pi r^2 + 2\pi r\cdot\frac{500}{r^2}\right) = k\left(4\pi r^2 + \frac{1000\pi}{r}\right), \quad r > 0.\]

\(C'(r) = k\left(8\pi r - \dfrac{1000\pi}{r^2}\right) = \dfrac{8k\pi\,(r^3 - 125)}{r^2}\). This is 0 when \(r^3 = 125\), so \(r = 5\).

For \(0 < r < 5\), \(r^3 - 125 < 0\) so \(C' < 0\); for \(r > 5\), \(C' > 0\). By the First Derivative Test for Absolute Extreme Values, \(r = 5\) gives the absolute minimum cost. Then \(h = \dfrac{500}{25} = 20\).

The cheapest can has radius 5 cm and height 20 cm.

Check:

Volume: \(\pi(25)(20) = 500\pi\). ✓ Notice \(h = 4r\): because the ends are expensive, the best can is tall and thin. If all material cost the same, the same method gives \(h = 2r\) (height equals diameter). A common slip is to forget there are two ends.

Example 9.3 Closest point on a curve

Find the point on the curve \(y = \sqrt{x}\) that is closest to the point \((4, 0)\), and find that shortest distance.

(Similar to Stewart §3.7, Example 3)
Show solution (try it first)

Strategy:

A point on the curve is \((x, \sqrt{x})\) with \(x \ge 0\). Minimize the square of the distance to avoid the square root.

Solution:

\(d^2 = (x - 4)^2 + (\sqrt{x} - 0)^2 = (x-4)^2 + x\). Call this \(D(x)\), for \(x \ge 0\).

\(D'(x) = 2(x - 4) + 1 = 2x - 7\). So \(D'(x) = 0\) at \(x = \tfrac72\).

\(D' < 0\) for \(x < \tfrac72\) and \(D' > 0\) for \(x > \tfrac72\), so this is the absolute minimum on \([0, \infty)\).

The point is \(\left(\tfrac72, \sqrt{\tfrac72}\right) \approx (3.5, 1.871)\). The squared distance is \(D(\tfrac72) = \tfrac14 + \tfrac72 = \tfrac{15}{4}\), so the shortest distance is \(d = \dfrac{\sqrt{15}}{2} \approx 1.936\).

Check:

Compare with nearby points: at \(x = 4\), \(d = 2\); at \(x = 3\), \(d = \sqrt{1 + 3} = 2\). Both are larger than 1.936. ✓ Geometrically (Figure 9.4), the slope of the segment from \((3.5, 1.871)\) to \((4,0)\) is \(-1.871/0.5 \approx -3.74\), and the tangent slope there is \(\frac{1}{2\sqrt{3.5}} \approx 0.267\); their product is \(-1\), so they are perpendicular, as a shortest segment should be.
