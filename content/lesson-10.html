3.8Newton's Method

We can solve \(x^2 - 5x + 6 = 0\) with the quadratic formula. But what about \(x^3 - x - 3 = 0\), or \(\cos x = x\)? There is no simple formula for these. In astronomy, this is not a small problem: finding the position of a planet in its orbit means solving Kepler's equation \(M = E - e\sin E\), which also has no formula for \(E\). So, how do we find a root that we cannot solve for exactly? We approximate it, and the derivative gives us a very fast way to do it.

The idea. Recall that near a point, the tangent line is a good approximation of the curve (this was linearization in Module 6). So let's start with a first guess \(x_1\) near the root \(r\). Instead of finding where the curve crosses the \(x\)-axis, which is hard, we find where its tangent line crosses the \(x\)-axis, which is easy. The tangent line at \((x_1, f(x_1))\) is

\[ y - f(x_1) = f'(x_1)(x - x_1). \]

Setting \(y = 0\) and solving for \(x\) gives our next guess \(x_2\). Then we repeat with \(x_2\), and so on.

Newton's method If \(x_n\) is an approximation of a root of \(f(x) = 0\) and \(f'(x_n) \ne 0\), then the next approximation is \[ x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}. \] We stop when two successive approximations agree to the number of decimal places we need.

Let's check Figure 10.1. For \(f(x) = x^3 - x - 3\), we have \(f'(x) = 3x^2 - 1\). Starting with \(x_1 = 1.5\): \(f(1.5) = 3.375 - 1.5 - 3 = -1.125\) and \(f'(1.5) = 5.75\), so

\[ x_2 = 1.5 - \frac{-1.125}{5.75} \approx 1.6957. \]

One step already moved us from 1.5 to 1.696, very close to the root \(r \approx 1.672\). Two or three more steps give the root to six decimal places. This speed is why calculators and computers use Newton's method (or a version of it) to compute square roots.

When it fails. Newton's method is fast, but it is not magic. Take note of these situations:

  • If \(f'(x_n) = 0\), the tangent line is horizontal and never meets the \(x\)-axis, so \(x_{n+1}\) cannot be computed.
  • If the first guess is far from the root, the tangent can send us to a different root, or far away.
  • For some functions the method never settles. For \(f(x) = \sqrt[3]{x}\), each step lands twice as far from the root 0, on the other side: \(1 \to -2 \to 4 \to -8\) (Figure 10.2).
Common mistake Mixing degrees and radians. For equations like \(\cos x = x\), set your calculator to radian mode; the derivative formula \(\frac{d}{dx}\cos x = -\sin x\) is only true in radians. Also, keep enough digits in each step and round only at the end.
Key equations
\[ x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)} \]

3.9Antiderivatives

Since Module 3, we have been asking: "Given \(f\), what is \(f'\)?" Now let's ask it backwards: "Given the derivative, what was the original function?" This is exactly the situation in physics. A physicist who knows the velocity of a particle wants its position; an astronomer who knows the acceleration due to gravity wants the path. In both cases we know the rate of change, and we want the function.

Definition A function \(F\) is called an antiderivative of \(f\) on an interval \(I\) if \(F'(x) = f(x)\) for all \(x\) in \(I\).

For example, \(F(x) = x^3 - 3x\) is an antiderivative of \(f(x) = 3x^2 - 3\), because \(F'(x) = 3x^2 - 3\). But so is \(x^3 - 3x + 5\), and \(x^3 - 3x - 2\). Adding a constant does not change the derivative. Is that the only freedom we have? Recall the corollary of the Mean Value Theorem from Module 7: two functions with the same derivative differ by a constant. So we get the following.

Theorem If \(F\) is an antiderivative of \(f\) on an interval \(I\), then the most general antiderivative of \(f\) on \(I\) is \(F(x) + C\), where \(C\) is an arbitrary constant.

Geometrically, the antiderivatives form a family of curves that are vertical shifts of each other, all with the same slope at every \(x\) (Figure 10.3).

Table of antidifferentiation formulas. Each formula is a derivative formula read backwards. You can always check an antiderivative by differentiating it.

FunctionParticular antiderivativeFunctionParticular antiderivative
\(c\,f(x)\)\(c\,F(x)\)\(\cos x\)\(\sin x\)
\(f(x) + g(x)\)\(F(x) + G(x)\)\(\sin x\)\(-\cos x\)
\(x^n\;(n \ne -1)\)\(\dfrac{x^{n+1}}{n + 1}\)\(\sec^2 x\)\(\tan x\)
\(1\)\(x\)\(\sec x\tan x\)\(\sec x\)

So to antidifferentiate a power, we add 1 to the exponent, then divide by the new exponent. For instance, an antiderivative of \(x^{1/2}\) is \(\frac{x^{3/2}}{3/2} = \frac23 x^{3/2}\).

Initial-value problems. An equation like \(f'(x) = 2x\) is a simple differential equation. Its general solution \(f(x) = x^2 + C\) has one unknown constant, and one extra fact, an initial condition such as \(f(1) = 5\), fixes it: \(1 + C = 5\), so \(C = 4\). If we start from \(f''\), we antidifferentiate twice and get two constants, so we need two conditions.

Rectilinear motion. Since \(v = s'\) and \(a = v'\), we go backwards: velocity is an antiderivative of acceleration, and position is an antiderivative of velocity. For a ball thrown upward near the Earth's surface, \(a(t) = -9.8\text{ m/s}^2\), so \(v(t) = -9.8t + v_0\) and \(s(t) = -4.9t^2 + v_0 t + s_0\). This is exactly the kinematic equation we used when we studied the velocity problem in Module 2, now derived instead of memorized (Figure 10.4).

Common mistake Forgetting the \(+\,C\). Without it you have found only one antiderivative, not the most general one, and an initial-value problem cannot be solved. Also, the power formula does not work for \(n = -1\): \(\frac{x^0}{0}\) is undefined.
Key equations
\[ F'(x) = f(x) \;\Rightarrow\; \text{most general antiderivative } F(x) + C \]
\[ x^n \;\longrightarrow\; \frac{x^{n+1}}{n + 1} + C \quad (n \ne -1) \]
\[ s'(t) = v(t), \quad v'(t) = a(t) \;\Rightarrow\; s(t) = -\tfrac12 g t^2 + v_0 t + s_0 \text{ when } a = -g \]

★Key takeaways

  • Newton's method replaces the curve by its tangent line: x₍ₙ₊₁₎ = xₙ − f(xₙ)/f′(xₙ).
  • Stop when two successive approximations agree to the required decimal places; use radians for trigonometric equations.
  • The method fails if f′(xₙ) = 0 or the first guess is poor; then pick a starting value closer to the root (use a graph or the IVT).
  • An antiderivative F of f satisfies F′ = f; the most general antiderivative is F(x) + C.
  • Read the derivative formulas backwards; for powers, add 1 to the exponent and divide by the new exponent (n ≠ −1).
  • Initial conditions fix the constants: one condition per antidifferentiation. Velocity comes from acceleration, position from velocity.

Example 10.1 A cube root by Newton's method

Use Newton's method to find \(\sqrt[3]{10}\) correct to six decimal places, starting with \(x_1 = 2\).

(Similar to Stewart §3.8, Example 2)
Show solution (try it first)

Given: \(\sqrt[3]{10}\), \(x_1 = 2\). Find: the root to six decimal places.

Plan: \(\sqrt[3]{10}\) is the root of \(f(x) = x^3 - 10\). Apply Newton's formula until two iterates agree to six decimals.

Step 1. Set up the function and its derivative.

\[f(x) = x^3 - 10, \qquad f'(x) = 3x^2\]

Step 2. Write Newton's formula for this \(f\).

\[x_{n+1} = x_n - \frac{x_n^3 - 10}{3x_n^2}\]

Step 3. First step from \(x_1 = 2\): \(f(2) = -2\), \(f'(2) = 12\).

\[x_2 = 2 - \frac{-2}{12} = 2.166667\]

Step 4. Second step.

\[x_3 = 2.166667 - \frac{(2.166667)^3 - 10}{3(2.166667)^2} \approx 2.154504\]

Step 5. Third and fourth steps.

\[x_4 \approx 2.154435, \qquad x_5 \approx 2.154435\]

Step 6. \(x_4\) and \(x_5\) agree to six decimal places, so we stop.

Answer: \(\boxed{\sqrt[3]{10} \approx 2.154435}\). That is our answer.

Check: \((2.154435)^3 \approx 10.0000\). ✓

Example 10.2 Solving cos x = x

Find the root of \(\cos x = x\) correct to six decimal places.

(Similar to Stewart §3.8, Example 3)
Show solution (try it first)

Given: \(\cos x = x\) (radians). Find: the root to six decimal places.

Plan: Move everything to one side: \(f(x) = \cos x - x = 0\). Use a graph to choose \(x_1\), then iterate.

Step 1. Choose a starting value. The graphs of \(y = \cos x\) and \(y = x\) cross a little below 1 (at \(x = 1\), \(\cos 1 \approx 0.54 \lt 1\); at \(x = 0\), \(\cos 0 = 1 \gt 0\)). Take \(x_1 = 1\).

Step 2. Set up Newton's formula.

\[f(x) = \cos x - x, \quad f'(x) = -\sin x - 1, \quad x_{n+1} = x_n - \frac{\cos x_n - x_n}{-\sin x_n - 1}\]

Step 3. Iterate (calculator in radian mode).

\[x_2 \approx 0.750364, \quad x_3 \approx 0.739113, \quad x_4 \approx 0.739085, \quad x_5 \approx 0.739085\]

Step 4. \(x_4\) and \(x_5\) agree to six decimal places.

Answer: \(\boxed{x \approx 0.739085}\)

Check: \(\cos(0.739085) \approx 0.739085\). ✓

Example 10.3 A ball thrown upward

A ball is thrown upward with a speed of 15 m/s from the edge of a platform 20 m above the ground. Use \(a(t) = -9.8\text{ m/s}^2\). Find its height \(s(t)\), its maximum height, and when it hits the ground.

(Similar to Stewart §3.9, Example 7)
Show solution (try it first)

Given: \(a(t) = -9.8\), \(v(0) = 15\), \(s(0) = 20\). Find: \(s(t)\), the maximum height, and the landing time.

Plan: Antidifferentiate twice, using one initial condition each time. Then use \(v = 0\) for the top and \(s = 0\) for the landing.

Step 1. Velocity is an antiderivative of acceleration.

\[v(t) = -9.8t + C_1, \qquad v(0) = 15 \Rightarrow C_1 = 15\]

Step 2. Position is an antiderivative of velocity.

\[s(t) = -4.9t^2 + 15t + C_2, \qquad s(0) = 20 \Rightarrow C_2 = 20\]

Step 3. Maximum height: the ball stops rising when \(v(t) = 0\).

\[-9.8t + 15 = 0 \;\Rightarrow\; t = \frac{15}{9.8} \approx 1.53\text{ s}, \qquad s(1.53) \approx 31.5\text{ m}\]

Step 4. Landing: solve \(s(t) = 0\) with the quadratic formula and keep the positive root.

\[t = \frac{15 + \sqrt{15^2 + 4(4.9)(20)}}{9.8} = \frac{15 + \sqrt{617}}{9.8} \approx 4.07\text{ s}\]

Answer: \(\boxed{s(t) = -4.9t^2 + 15t + 20}\); maximum height \(\approx \boxed{31.5\text{ m}}\) at \(t \approx 1.53\) s; it lands at \(\boxed{t \approx 4.07\text{ s}}\).

Check: Energy check: rising \(\frac{v_0^2}{2g} = \frac{225}{19.6} \approx 11.5\) m above the 20 m platform gives 31.5 m. ✓ (Figure 10.4.)

Example 10.4 The most general antiderivative

Find the most general antiderivative of \(g(x) = 4\sin x + \dfrac{2x^5 - \sqrt x}{x}\) for \(x \gt 0\).

(Similar to Stewart §3.9, Example 2)
Show solution (try it first)

Given: \(g(x)\). Find: \(G(x) + C\) with \(G' = g\).

Plan: Simplify the fraction into powers of \(x\) first, then use the table term by term.

Step 1. Divide each term of the fraction by \(x\).

\[\frac{2x^5 - \sqrt x}{x} = 2x^4 - x^{-1/2}\]

Step 2. Antidifferentiate each term. Recall that an antiderivative of \(\sin x\) is \(-\cos x\).

\[4(-\cos x) + 2\cdot\frac{x^5}{5} - \frac{x^{1/2}}{1/2}\]

Step 3. Simplify and add the constant.

\[G(x) = -4\cos x + \tfrac25 x^5 - 2\sqrt x + C\]

Answer: \(\boxed{G(x) = -4\cos x + \tfrac25 x^5 - 2\sqrt x + C}\)

Check: Differentiate: \(4\sin x + 2x^4 - x^{-1/2}\), which is \(g(x)\). ✓

Example 10.5 Finding f from f''

Find \(f\) if \(f''(x) = 12x^2 + 6x - 4\), \(f(0) = 4\), and \(f(1) = 1\).

(Similar to Stewart §3.9, Example 5)
Show solution (try it first)

Given: \(f''\) and two values of \(f\). Find: \(f(x)\).

Plan: Antidifferentiate twice; this gives two constants, and the two conditions determine them.

Step 1. First antiderivative.

\[f'(x) = 4x^3 + 3x^2 - 4x + C\]

Step 2. Second antiderivative.

\[f(x) = x^4 + x^3 - 2x^2 + Cx + D\]

Step 3. Use \(f(0) = 4\).

\[0 + 0 - 0 + 0 + D = 4 \;\Rightarrow\; D = 4\]

Step 4. Use \(f(1) = 1\).

\[1 + 1 - 2 + C + 4 = 1 \;\Rightarrow\; C = -3\]

Answer: \(\boxed{f(x) = x^4 + x^3 - 2x^2 - 3x + 4}\)

Check: \(f''(x) = 12x^2 + 6x - 4\) ✓, \(f(0) = 4\) ✓, \(f(1) = 1 + 1 - 2 - 3 + 4 = 1\) ✓.
