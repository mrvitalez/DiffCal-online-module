3.8Newton's Method

Many equations cannot be solved with algebra: try \(x^3 - x - 3 = 0\) or \(\cos x = x\). Stewart §3.8 describes Newton's method, which uses tangent lines to get very accurate approximations of a root in a few steps.

Where the formula comes from. Suppose \(r\) is a root of \(f(x) = 0\) and \(x_1\) is a first guess near \(r\). Near \(x_1\) the curve looks like its tangent line \[y = f(x_1) + f'(x_1)(x - x_1).\] A line is easy to solve: set \(y = 0\) and call the \(x\)-intercept \(x_2\). Then \(0 = f(x_1) + f'(x_1)(x_2 - x_1)\), so \[x_2 = x_1 - \frac{f(x_1)}{f'(x_1)}, \quad \text{provided } f'(x_1) \ne 0.\] Why should this help? Close to \(x_1\), the tangent line and the curve almost agree, so the place where the line crosses the axis should be near the place where the curve does. Usually \(x_2\) is closer to \(r\) than \(x_1\) was (Figure 10.1). Now repeat with \(x_2\) in place of \(x_1\), and so on.

Newton's method \[x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}, \qquad n = 1, 2, 3, \dots\] If the numbers \(x_n\) approach a limit, that limit is a root of \(f(x) = 0\).

An iteration table. For \(f(x) = x^3 - x - 3\) we have \(f'(x) = 3x^2 - 1\). Since \(f(1) = -3 < 0\) and \(f(2) = 3 > 0\), a root lies between 1 and 2; start at \(x_1 = 1.5\).

So \(x_2 = 1.5 - \frac{-1.125}{5.75} \approx 1.695652\), and so on. Once two successive values agree to the number of decimals you want, stop: here the root is \(r \approx 1.6717\) (to 4 decimal places). Notice how the number of correct digits roughly doubles at each step. Keep all digits on your calculator between steps; round only at the end.

When Newton's method fails.

  • If \(f'(x_n) = 0\), the tangent is horizontal and never meets the \(x\)-axis: the formula divides by zero.
  • If \(f'(x_n)\) is close to 0, \(x_{n+1}\) is thrown far away, possibly toward a different root than the one you wanted.
  • For some functions the guesses get worse each time. For \(f(x) = \sqrt[3]{x}\) the formula simplifies to \(x_{n+1} = -2x_n\), so \(1, -2, 4, -8, \dots\) runs away from the root 0 (Figure 10.2).
Common mistake Set your calculator to radians whenever trigonometric functions appear, and always start with a sensible \(x_1\): use a sign change of \(f\) or a quick sketch to locate the root first.
Key equations
\[ x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)} \]
\[ y = f(x_n) + f'(x_n)(x - x_n) \ \text{(tangent line used at each step)} \]

3.9Antiderivatives

So far you have started with a function and found its derivative. Stewart §3.9 asks the reverse question: if you know the derivative, what was the function?

Definition A function \(F\) is an antiderivative of \(f\) on an interval \(I\) if \(F'(x) = f(x)\) for all \(x\) in \(I\).

For \(f(x) = 3x^2\), one antiderivative is \(x^3\). But \(x^3 + 5\) and \(x^3 - 2\) also work, because the derivative of a constant is 0. Are there any others? No: a consequence of the Mean Value Theorem is that two functions with the same derivative on an interval differ by a constant. So:

Theorem If \(F\) is an antiderivative of \(f\) on an interval \(I\), then the most general antiderivative of \(f\) on \(I\) is \(F(x) + C\), where \(C\) is an arbitrary constant.

Graphically, the antiderivatives form a family of vertical shifts of one curve (Figure 10.3). All of them have the same slope at each \(x\).

A table of antiderivatives. Read each derivative rule backwards:

FunctionParticular antiderivative
\(c\,f(x)\)\(c\,F(x)\)
\(f(x) + g(x)\)\(F(x) + G(x)\)
\(x^n\ (n \ne -1)\)\(\dfrac{x^{n+1}}{n+1}\)
\(\cos x\)\(\sin x\)
\(\sin x\)\(-\cos x\)
\(\sec^2 x\)\(\tan x\)
\(\sec x \tan x\)\(\sec x\)

Add \(+\,C\) once at the end for the general antiderivative. Rewrite roots and fractions as powers first: \(\sqrt{x} = x^{1/2}\) has antiderivative \(\tfrac23 x^{3/2}\), and \(\dfrac{2}{x^3} = 2x^{-3}\) has antiderivative \(\dfrac{2x^{-2}}{-2} = -\dfrac{1}{x^2}\). (The case \(n = -1\) needs a new function, which you will meet in Chapter 6.) Always check by differentiating your answer.

Initial conditions. An extra fact such as \(F(1) = 4\) picks out one member of the family. Example: if \(f'(x) = 4x - \cos x\) and \(f(0) = 3\), then \(f(x) = 2x^2 - \sin x + C\), and \(f(0) = C = 3\). So \(f(x) = 2x^2 - \sin x + 3\). If you are given \(f''\), antidifferentiate twice; you will need two conditions for the two constants.

Rectilinear motion. For an object moving on a line, \(v = s'\) and \(a = v'\). So velocity is an antiderivative of acceleration and position is an antiderivative of velocity. Near Earth's surface, a falling object has \(a = -9.8\text{ m/s}^2\) (up positive), which gives \(v(t) = -9.8t + v_0\) and \(s(t) = -4.9t^2 + v_0 t + s_0\), where \(v_0\) and \(s_0\) are the initial velocity and position.

Common mistake Forgetting \(+\,C\), or adding the second constant only at the very end when working from \(f''\). Each antidifferentiation brings its own constant, and you should find it before going on.
Key equations
\[ F'(x) = f(x) \ \Rightarrow\ \text{general antiderivative } F(x) + C \]
\[ x^n \ \to\ \frac{x^{n+1}}{n+1} + C \quad (n \ne -1) \]
\[ a(t) = v'(t), \quad v(t) = s'(t) \]

★Key takeaways

  • Newton's method replaces the curve by its tangent line: x_{n+1} = x_n − f(x_n)/f′(x_n).
  • Stop when successive approximations agree to the required number of decimals; keep all digits in between.
  • Newton's method can fail when f′(x_n) = 0 or is very small, or when the iterates run away from the root.
  • If F′ = f on an interval, every antiderivative of f there has the form F(x) + C.
  • Initial conditions fix the constants: one condition per antidifferentiation.
  • Velocity is an antiderivative of acceleration, and position is an antiderivative of velocity.

Example 10.1 A cube root by Newton's method

Use Newton's method to find \(\sqrt[3]{20}\) correct to six decimal places.

(Similar to Stewart §3.8, Example 2)
Show solution (try it first)

Strategy:

\(\sqrt[3]{20}\) is the positive root of \(f(x) = x^3 - 20 = 0\). Since \(2^3 = 8\) and \(3^3 = 27\), the root is between 2 and 3, nearer 3; take \(x_1 = 3\). Iterate until two successive values agree to six decimals.

Solution:

\(f'(x) = 3x^2\), so \[x_{n+1} = x_n - \frac{x_n^3 - 20}{3x_n^2}.\]

\(x_2 = 3 - \dfrac{27 - 20}{27} = 3 - 0.259259 = 2.740741\).

\(x_3 = 2.740741 - \dfrac{2.740741^3 - 20}{3(2.740741)^2} = 2.740741 - \dfrac{0.587512}{22.534979} \approx 2.714670\).

\(x_4 \approx 2.714670 - \dfrac{0.005571}{22.108294}\approx 2.714418\) (more exactly 2.7144176).

\(x_5 \approx 2.7144176\) again (the change is about \(2\times 10^{-8}\)).

Since \(x_4\) and \(x_5\) agree to six decimal places, \(\sqrt[3]{20} \approx 2.714418\).

Check:

\(2.714418^3 \approx 20.000008\) and \(2.714417^3 \approx 19.999986\), so the root lies between them and is closer to 2.714418. ✓ Keep every digit between steps; rounding \(x_2\) to 2.74 would slow things down.

Example 10.2 Finding f from f''

Find \(f\) if \(f''(x) = 6x + 4\sin x\), \(f'(0) = 1\) and \(f(0) = 3\).

(Similar to Stewart §3.9, Example 5)
Show solution (try it first)

Strategy:

Antidifferentiate once to get \(f'\) with a constant \(C\); use \(f'(0) = 1\) to find \(C\). Then antidifferentiate again with a new constant \(D\) and use \(f(0) = 3\).

Solution:

An antiderivative of \(6x\) is \(3x^2\); of \(4\sin x\) it is \(-4\cos x\). So \[f'(x) = 3x^2 - 4\cos x + C.\]

\(f'(0) = 0 - 4\cos 0 + C = -4 + C = 1\), so \(C = 5\) and \(f'(x) = 3x^2 - 4\cos x + 5\).

Again: an antiderivative of \(3x^2\) is \(x^3\), of \(-4\cos x\) is \(-4\sin x\), of 5 is \(5x\). So \[f(x) = x^3 - 4\sin x + 5x + D.\]

\(f(0) = 0 - 0 + 0 + D = 3\), so \(D = 3\).

\[f(x) = x^3 - 4\sin x + 5x + 3.\]

Check:

\(f'(x) = 3x^2 - 4\cos x + 5\), \(f'(0) = -4 + 5 = 1\) ✓; \(f''(x) = 6x + 4\sin x\) ✓; \(f(0) = 3\) ✓. A common error is \(\int \sin x = \cos x\): remember the derivative of \(\cos x\) is \(-\sin x\), so the antiderivative of \(\sin x\) is \(-\cos x\).

Example 10.3 A ball thrown upward

A ball is thrown straight up at 15 m/s from the edge of a platform 20 m above the ground. Use \(a = -9.8\text{ m/s}^2\). (a) When does the ball reach its maximum height, and what is that height? (b) When does it hit the ground?

(Similar to Stewart §3.9, Example 7)
Show solution (try it first)

Strategy:

Take up as positive and \(s\) = height above the ground. Antidifferentiate \(a(t) = -9.8\) to get \(v\), then \(s\), using \(v(0) = 15\) and \(s(0) = 20\). The top is where \(v = 0\); the ground is where \(s = 0\).

Solution:

\(v(t) = -9.8t + C\), and \(v(0) = 15\) gives \(C = 15\): \(v(t) = -9.8t + 15\).

\(s(t) = -4.9t^2 + 15t + D\), and \(s(0) = 20\) gives \(D = 20\): \(s(t) = -4.9t^2 + 15t + 20\).

(a) \(v(t) = 0\) when \(t = \dfrac{15}{9.8} \approx 1.53\) s. The height then is \[s\!\left(\tfrac{15}{9.8}\right) = 20 + \frac{15^2}{4(4.9)} = 20 + \frac{225}{19.6} \approx 31.48\text{ m}.\]

(b) Solve \(-4.9t^2 + 15t + 20 = 0\), i.e. \(4.9t^2 - 15t - 20 = 0\): \[t = \frac{15 \pm \sqrt{225 + 392}}{9.8} = \frac{15 \pm \sqrt{617}}{9.8}.\] The negative root makes no sense here, so \(t = \dfrac{15 + 24.839}{9.8} \approx 4.07\) s.

Check:

\(s(4.07) \approx -4.9(16.56) + 61.05 + 20 \approx 0\) ✓. The ball rises for 1.53 s and falls from 31.48 m for about \(\sqrt{31.48/4.9} \approx 2.53\) s, total about 4.07 s ✓ (Figure 10.4).
