3.8Newton's Method

Let's try to solve \(x^3 - x - 3 = 0\) or \(\cos x = x\) with algebra. Can we do it? Not with any formula we know. So, how do we find the root? Stewart §3.8 describes Newton's method, which uses tangent lines to get very accurate approximations of a root in a few steps.

Where the formula comes from. Let's suppose \(r\) is a root of \(f(x) = 0\) and \(x_1\) is a first guess near \(r\). Near \(x_1\) the curve looks like its tangent line \[y = f(x_1) + f'(x_1)(x - x_1).\] A line is easy to solve, so we set \(y = 0\) and call the \(x\)-intercept \(x_2\). Then \(0 = f(x_1) + f'(x_1)(x_2 - x_1)\), so \[x_2 = x_1 - \frac{f(x_1)}{f'(x_1)}, \quad \text{provided } f'(x_1) \ne 0.\] Why should this help? Close to \(x_1\), the tangent line and the curve almost agree, so the place where the line crosses the axis should be near the place where the curve does. Usually \(x_2\) is closer to \(r\) than \(x_1\) was (Figure 10.1). Now we repeat with \(x_2\) in place of \(x_1\), and so on.

Newton's method \[x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}, \qquad n = 1, 2, 3, \dots\] If the numbers \(x_n\) approach a limit, that limit is a root of \(f(x) = 0\).

An iteration table. For \(f(x) = x^3 - x - 3\) we have \(f'(x) = 3x^2 - 1\). Since \(f(1) = -3 < 0\) and \(f(2) = 3 > 0\), a root lies between 1 and 2, so let's start at \(x_1 = 1.5\).

\(n\)\(x_n\)\(f(x_n)\)\(f'(x_n)\)
11.5\(-1.125\)5.75
21.6956520.1797497.625709

So \(x_2 = 1.5 - \frac{-1.125}{5.75} \approx 1.695652\), and so on. Once two successive values agree to the number of decimals we want, we stop. Here the root is \(r \approx 1.6717\) (to 4 decimal places). Notice how the number of correct digits roughly doubles at each step. Take note that we keep all digits on the calculator between steps and round only at the end.

When Newton's method fails. Does Newton's method always work? No. Here are the usual problems.

  • If \(f'(x_n) = 0\), the tangent is horizontal and never meets the \(x\)-axis: the formula divides by zero.
  • If \(f'(x_n)\) is close to 0, \(x_{n+1}\) is thrown far away, possibly toward a different root than the one we wanted.
  • For some functions the guesses get worse each time. For \(f(x) = \sqrt[3]{x}\) the formula simplifies to \(x_{n+1} = -2x_n\), so \(1, -2, 4, -8, \dots\) runs away from the root 0 (Figure 10.2).
Common mistake Take note: set your calculator to radians whenever trigonometric functions appear, and always start with a sensible \(x_1\). We use a sign change of \(f\) or a quick sketch to locate the root first.
Key equations
\[ x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)} \]
\[ y = f(x_n) + f'(x_n)(x - x_n) \ \text{(tangent line used at each step)} \]

3.9Antiderivatives

So far we have started with a function and found its derivative. But what if we already know the derivative? For example, if we know the velocity of a car at every instant, can we recover where the car is? Stewart §3.9 asks this reverse question: if we know the derivative, what was the function?

Definition A function \(F\) is an antiderivative of \(f\) on an interval \(I\) if \(F'(x) = f(x)\) for all \(x\) in \(I\).

For \(f(x) = 3x^2\), one antiderivative is \(x^3\). But \(x^3 + 5\) and \(x^3 - 2\) also work, because the derivative of a constant is 0. Are there any others? No. Do you know why? A consequence of the Mean Value Theorem is that two functions with the same derivative on an interval differ by a constant. So:

Theorem If \(F\) is an antiderivative of \(f\) on an interval \(I\), then the most general antiderivative of \(f\) on \(I\) is \(F(x) + C\), where \(C\) is an arbitrary constant.

Graphically, we can see that the antiderivatives form a family of vertical shifts of one curve (Figure 10.3). All of them have the same slope at each \(x\).

A table of antiderivatives. Let's read each derivative rule backwards:

FunctionParticular antiderivative
\(c\,f(x)\)\(c\,F(x)\)
\(f(x) + g(x)\)\(F(x) + G(x)\)
\(x^n\ (n \ne -1)\)\(\dfrac{x^{n+1}}{n+1}\)
\(\cos x\)\(\sin x\)
\(\sin x\)\(-\cos x\)
\(\sec^2 x\)\(\tan x\)
\(\sec x \tan x\)\(\sec x\)

We add \(+\,C\) once at the end for the general antiderivative. Take note that we rewrite roots and fractions as powers first: \(\sqrt{x} = x^{1/2}\) has antiderivative \(\tfrac23 x^{3/2}\), and \(\dfrac{2}{x^3} = 2x^{-3}\) has antiderivative \(\dfrac{2x^{-2}}{-2} = -\dfrac{1}{x^2}\). (The case \(n = -1\) needs a new function, which we will meet in Chapter 6.) Always check by differentiating the answer.

Initial conditions. Which member of the family do we want? An extra fact such as \(F(1) = 4\) picks out one member. Example: if \(f'(x) = 4x - \cos x\) and \(f(0) = 3\), then \(f(x) = 2x^2 - \sin x + C\), and \(f(0) = C = 3\). So \(f(x) = 2x^2 - \sin x + 3\). If we are given \(f''\), we antidifferentiate twice, and we need two conditions for the two constants.

Rectilinear motion. For an object moving on a line, \(v = s'\) and \(a = v'\). So we can see that velocity is an antiderivative of acceleration and position is an antiderivative of velocity. Near Earth's surface, a falling object has \(a = -9.8\text{ m/s}^2\) (up positive), which gives \(v(t) = -9.8t + v_0\) and \(s(t) = -4.9t^2 + v_0 t + s_0\), where \(v_0\) and \(s_0\) are the initial velocity and position.

Common mistake Forgetting \(+\,C\), or adding the second constant only at the very end when working from \(f''\). Each antidifferentiation brings its own constant, and we should find it before going on.
Key equations
\[ F'(x) = f(x) \ \Rightarrow\ \text{general antiderivative } F(x) + C \]
\[ x^n \ \to\ \frac{x^{n+1}}{n+1} + C \quad (n \ne -1) \]
\[ a(t) = v'(t), \quad v(t) = s'(t) \]

★Key takeaways

  • Newton's method replaces the curve by its tangent line: x_{n+1} = x_n − f(x_n)/f′(x_n).
  • We stop when successive approximations agree to the required number of decimals, and we keep all digits in between.
  • Take note that Newton's method can fail when f′(x_n) = 0 or is very small, or when the iterates run away from the root.
  • If F′ = f on an interval, every antiderivative of f there has the form F(x) + C.
  • Initial conditions fix the constants: we need one condition per antidifferentiation.
  • Velocity is an antiderivative of acceleration, and position is an antiderivative of velocity.

Example 10.1 A cube root by Newton's method

Use Newton's method to find \(\sqrt[3]{20}\) correct to six decimal places.

(Similar to Stewart §3.8, Example 2)
Show solution (try it first)
Given
  • We want \(\sqrt[3]{20}\), the positive root of \(f(x) = x^3 - 20 = 0\).
  • Asked: the root correct to six decimal places.
Step 1: Choose a starting value

We look for two cubes on either side of 20.

\[2^3 = 8 \lt 20 \lt 27 = 3^3\]

So the root is between 2 and 3, and nearer 3. Let's take \(x_1 = 3\).

Step 2: Write the Newton formula for this f

We need \(f'(x)\) to fill in \(x_{n+1} = x_n - \dfrac{f(x_n)}{f'(x_n)}\).

\[f'(x) = 3x^2\]

\[x_{n+1} = x_n - \frac{x_n^3 - 20}{3x_n^2}\]

Step 3: Compute x₂

We substitute \(x_1 = 3\).

\[x_2 = 3 - \frac{3^3 - 20}{3(3)^2}\]

\[= 3 - \frac{27 - 20}{27}\]

\[= 3 - \frac{7}{27}\]

\[= 3 - 0.259259 = 2.740741\]

Step 4: Compute x₃

We substitute \(x_2 = 2.740741\), keeping all the calculator digits.

\[f(x_2) = 2.740741^3 - 20 = 0.587512\]

\[f'(x_2) = 3(2.740741)^2 = 22.534979\]

\[x_3 = 2.740741 - \frac{0.587512}{22.534979}\]

\[= 2.740741 - 0.026071 = 2.714670\]

Step 5: Compute x₄ and x₅

We repeat until two values agree to six decimals.

\[f(x_3) = 0.005571, \qquad f'(x_3) = 22.108294\]

\[x_4 = 2.714670 - \frac{0.005571}{22.108294}\]

\[= 2.714670 - 0.000252 = 2.714418\]

One more step changes \(x_4\) by only about \(2\times 10^{-8}\), so \(x_5 \approx 2.714418\) as well.

Answer

Since \(x_4\) and \(x_5\) agree to six decimal places, \(\sqrt[3]{20} \approx 2.714418\).

Check

\(2.714418^3 \approx 20.000008\) and \(2.714417^3 \approx 19.999986\). So the root lies between them and is closer to 2.714418. ✓ Take note: if we had rounded \(x_2\) to 2.74, the steps after it would be less accurate.

Example 10.2 A general antiderivative from the table

Find the most general antiderivative of \(f(x) = 6\sqrt{x} - \dfrac{4}{x^3} + 3\cos x\) for \(x > 0\).

(Similar to Stewart §3.9, Example 2)
Show solution (try it first)
Given
  • \(f(x) = 6\sqrt{x} - \dfrac{4}{x^3} + 3\cos x\), \(x > 0\).
  • Asked: the most general antiderivative \(F(x)\).
Step 1: Rewrite the root and the fraction as powers

The power rule \(x^n \to \dfrac{x^{n+1}}{n+1}\) only works on powers, so let's rewrite first.

\[\sqrt{x} = x^{1/2}, \qquad \frac{4}{x^3} = 4x^{-3}\]

\[f(x) = 6x^{1/2} - 4x^{-3} + 3\cos x\]

Step 2: Antidifferentiate 6x^(1/2)

We add 1 to the exponent and divide by the new exponent.

\[6\cdot\frac{x^{1/2 + 1}}{1/2 + 1} = 6\cdot\frac{x^{3/2}}{3/2}\]

\[= 6\cdot\frac23\,x^{3/2} = 4x^{3/2}\]

Step 3: Antidifferentiate −4x^(−3)

Same rule, with \(n = -3\). Take note that the new exponent is \(-2\), not \(-4\).

\[-4\cdot\frac{x^{-3 + 1}}{-3 + 1} = -4\cdot\frac{x^{-2}}{-2}\]

\[= 2x^{-2} = \frac{2}{x^2}\]

Step 4: Antidifferentiate 3 cos x

From the table, an antiderivative of \(\cos x\) is \(\sin x\).

\[3\cos x \ \to\ 3\sin x\]

Step 5: Add the pieces and the constant

We add the three antiderivatives and put one \(+\,C\) at the end.

\[F(x) = 4x^{3/2} + \frac{2}{x^2} + 3\sin x + C\]

Answer

So the most general antiderivative is \(F(x) = 4x^{3/2} + \dfrac{2}{x^2} + 3\sin x + C\).

Check

Let's differentiate our answer.

\[F'(x) = 4\cdot\tfrac32 x^{1/2} + 2(-2)x^{-3} + 3\cos x\]

\[= 6\sqrt{x} - \frac{4}{x^3} + 3\cos x = f(x) \ ✓\]

Example 10.3 Finding f from f''

Find \(f\) if \(f''(x) = 6x + 4\sin x\), \(f'(0) = 1\) and \(f(0) = 3\).

(Similar to Stewart §3.9, Example 5)
Show solution (try it first)
Given
  • \(f''(x) = 6x + 4\sin x\)
  • \(f'(0) = 1\) and \(f(0) = 3\)
  • Asked: the function \(f(x)\).
Step 1: Antidifferentiate once to get f′

An antiderivative of \(6x\) is \(3x^2\), and of \(4\sin x\) it is \(-4\cos x\). We add a constant \(C\).

\[f'(x) = 3x^2 - 4\cos x + C\]

Step 2: Use f′(0) = 1 to find C

We find the first constant right away, before going on.

\[f'(0) = 3(0)^2 - 4\cos 0 + C\]

\[= 0 - 4(1) + C = -4 + C\]

\[-4 + C = 1 \quad\Longrightarrow\quad C = 5\]

\[f'(x) = 3x^2 - 4\cos x + 5\]

Step 3: Antidifferentiate again to get f

An antiderivative of \(3x^2\) is \(x^3\), of \(-4\cos x\) is \(-4\sin x\), and of 5 is \(5x\). This step brings a new constant \(D\).

\[f(x) = x^3 - 4\sin x + 5x + D\]

Step 4: Use f(0) = 3 to find D

We substitute \(x = 0\).

\[f(0) = 0^3 - 4\sin 0 + 5(0) + D\]

\[= 0 - 0 + 0 + D = D\]

\[D = 3\]

Answer

So \(f(x) = x^3 - 4\sin x + 5x + 3\).

Check

\(f'(x) = 3x^2 - 4\cos x + 5\), so \(f'(0) = -4 + 5 = 1\) ✓. \(f''(x) = 6x + 4\sin x\) ✓. \(f(0) = 3\) ✓. Take note of a common error: the antiderivative of \(\sin x\) is \(-\cos x\), not \(\cos x\), because the derivative of \(\cos x\) is \(-\sin x\).

Example 10.4 A ball thrown upward

A ball is thrown straight up at 15 m/s from the edge of a platform 20 m above the ground. Use \(a = -9.8\text{ m/s}^2\). (a) When does the ball reach its maximum height, and what is that height? (b) When does it hit the ground?

(Similar to Stewart §3.9, Example 7)
Show solution (try it first)
Given
  • \(a(t) = -9.8\text{ m/s}^2\) (up is positive).
  • \(v(0) = 15\) m/s and \(s(0) = 20\) m, where \(s\) is the height above the ground.
  • Asked: (a) the time and value of the maximum height; (b) the time the ball hits the ground.
Step 1: Find the velocity

Velocity is an antiderivative of acceleration. We then use \(v(0) = 15\).

\[v(t) = -9.8t + C\]

\[v(0) = -9.8(0) + C = C = 15\]

\[v(t) = -9.8t + 15\]

Step 2: Find the position

Position is an antiderivative of velocity. We then use \(s(0) = 20\).

\[s(t) = -4.9t^2 + 15t + D\]

\[s(0) = 0 + 0 + D = D = 20\]

\[s(t) = -4.9t^2 + 15t + 20\]

Step 3: Find when the ball is highest

At the top the ball stops for an instant, so \(v(t) = 0\).

\[-9.8t + 15 = 0\]

\[t = \frac{15}{9.8} \approx 1.53\text{ s}\]

Step 4: Find the maximum height

We substitute \(t = \dfrac{15}{9.8}\) into \(s(t)\).

\[s\!\left(\tfrac{15}{9.8}\right) = -4.9\left(\frac{15}{9.8}\right)^2 + 15\left(\frac{15}{9.8}\right) + 20\]

\[= -\frac{225}{19.6} + \frac{450}{19.6} + 20\]

\[= \frac{225}{19.6} + 20\]

\[\approx 11.48 + 20 = 31.48\text{ m}\]

Step 5: Find when the ball hits the ground

On the ground the height is 0, so we solve \(s(t) = 0\). Multiply by \(-1\) and use the quadratic formula.

\[-4.9t^2 + 15t + 20 = 0\]

\[4.9t^2 - 15t - 20 = 0\]

\[t = \frac{15 \pm \sqrt{(-15)^2 - 4(4.9)(-20)}}{2(4.9)}\]

\[= \frac{15 \pm \sqrt{225 + 392}}{9.8} = \frac{15 \pm \sqrt{617}}{9.8}\]

The negative root makes no sense here (it is before the throw), so

\[t = \frac{15 + 24.839}{9.8} \approx 4.07\text{ s}\]

Answer

(a) The ball reaches its maximum height of about 31.48 m at \(t \approx 1.53\) s. (b) It hits the ground at \(t \approx 4.07\) s.

Check

\(s(4.065) \approx -4.9(16.524) + 60.975 + 20 \approx 0\) ✓. Also, falling from rest through 31.48 m takes \(\sqrt{31.48/4.9} \approx 2.53\) s, and \(1.531 + 2.535 = 4.066 \approx 4.07\) s ✓ (Figure 10.4).
