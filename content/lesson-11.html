6.1Inverse Functions

The inverse of a function is a rule that acts on the output of the function and gives back the corresponding input. The inverse "undoes", or reverses, what the function has done. If \(f\) takes 2 to 8, then its inverse takes 8 back to 2. This is Stewart §6.1, and it is the key that unlocks exponentials and logarithms in this chapter.

So, can we reverse every function? No. Suppose two different inputs give the same output. If someone tells us only the output, we cannot say which input it came from. That is why we need one-to-one functions.

One-to-one function A function \(f\) is one-to-one if it never takes the same value twice: \[f(x_1) \ne f(x_2) \quad\text{whenever}\quad x_1 \ne x_2.\]

Let's look at two examples. Is \(f(x) = x^3\) one-to-one? Yes. Two different numbers can't have the same cube, so \(x_1 \ne x_2\) gives \(x_1^3 \ne x_2^3\). How about \(f(x) = x^4\)? This is not one-to-one, because a positive input and its negative give the same result: \(f(1) = 1 = f(-1)\).

Any function, when graphed, can be checked with the Horizontal Line Test: a function is one-to-one if and only if no horizontal line meets its graph more than once (Figure 11.1). Take note that a function that is always increasing (or always decreasing) passes the test automatically. So if \(f'(x) > 0\) everywhere, \(f\) is one-to-one.

It is important to discuss one-to-one functions in this topic because they are exactly the functions that possess an inverse, according to the following definition.

Definition Let \(f\) be one-to-one with domain \(A\) and range \(B\). Its inverse \(f^{-1}\) has domain \(B\) and range \(A\), and \[f^{-1}(y) = x \iff f(x) = y.\]

Because the inverse undoes \(f\), we get the cancellation equations: \(f^{-1}(f(x)) = x\) for \(x\) in \(A\), and \(f(f^{-1}(x)) = x\) for \(x\) in \(B\).

Common mistake The \(-1\) in \(f^{-1}\) is not an exponent: \(f^{-1}(x)\) does not mean \(\dfrac{1}{f(x)}\).

How to find the inverse of a one-to-one function \(f\).

  1. Step 1: Write \(y = f(x)\).
  2. Step 2: Solve this equation for \(x\) in terms of \(y\).
  3. Step 3: To express \(f^{-1}\) as a function of \(x\), interchange \(x\) and \(y\). The resulting equation is \(y = f^{-1}(x)\).

Interchanging \(x\) and \(y\) turns the point \((a, b)\) into \((b, a)\). So the graph of \(f^{-1}\) is the graph of \(f\) reflected in the line \(y = x\) (Figure 11.2).

The calculus of inverse functions. If \(f\) is one-to-one and differentiable, and \(f'(f^{-1}(a)) \ne 0\), then \[(f^{-1})'(a) = \frac{1}{f'\big(f^{-1}(a)\big)}.\] Why is this true? Recall the cancellation equation \(f\big(f^{-1}(a)\big) = a\). Let's take the derivative of both sides with respect to \(a\). On the left we use the Chain Rule: the derivative of the outside, evaluated at the inside, times the derivative of the inside: \[f'\big(f^{-1}(a)\big)\cdot(f^{-1})'(a) = 1.\] Divide by \(f'\big(f^{-1}(a)\big)\) and we just proved the formula.

To compute the derivative of an inverse easily, follow these steps.

  1. Step 1: Find the inverse value \(f^{-1}(a)\): solve \(f(x) = a\) for \(x\).
  2. Step 2: Compute the derivative \(f'(x)\) of the given function.
  3. Step 3: Substitute the inverse value into \(f'\).
  4. Step 4: Apply the formula: take the reciprocal.

For example, let \(f(x) = x^3\) and \(a = 8\). Step 1: \(x^3 = 8\) gives \(x = 2\), so \(f^{-1}(8) = 2\). Step 2: \(f'(x) = 3x^2\). Step 3: \(f'(2) = 3(2)^2 = 12\). Step 4: \((f^{-1})'(8) = \frac{1}{12}\).

Notice that we never needed a formula for \(f^{-1}\), only one value of it. Take \(f(x) = 3x^3 + 4x^2 + 6x + 5\) and \(a = 5\). Setting \(f(x) = 5\) gives \(3x^3 + 4x^2 + 6x = 0\), that is \(x(3x^2 + 4x + 6) = 0\). The quadratic factor has no real roots (its discriminant is \(16 - 72 < 0\)), so \(x = 0\) and \(f^{-1}(5) = 0\). Then \(f'(x) = 9x^2 + 8x + 6\), \(f'(0) = 6\), and \((f^{-1})'(5) = \frac16\).

Try these Find \((f^{-1})'(a)\). (1) \(f(x) = x^5\), \(a = 32\). (2) \(f(x) = x^3 - 2\), \(a = 25\). (3) \(f(x) = \sqrt{x + 1}\), \(a = 3\). (4) \(f(x) = \sqrt{2x - 4}\), \(a = 2\). (5) \(f(x) = x^3 + 3x\), \(a = 4\). (6) \(f(x) = 2x^3 + x\), \(a = 3\). (7) \(f(x) = x + \sin x\), \(a = 0\). (8) \(f(x) = x + \tan x\), \(a = 0\).
Answers: (1) \(\frac{1}{80}\) (2) \(\frac{1}{27}\) (3) 6 (4) 2 (5) \(\frac16\) (6) \(\frac17\) (7) \(\frac12\) (8) \(\frac12\).
Key equations
\[ f^{-1}(y) = x \iff f(x) = y \]
\[ f^{-1}(f(x)) = x, \qquad f(f^{-1}(x)) = x \]
\[ (f^{-1})'(a) = \frac{1}{f'\big(f^{-1}(a)\big)} \]

6.2Exponential Functions and Their Derivatives

Recall that an exponential function has the form \(f(x) = b^x\), with a fixed positive base \(b\). Notice the difference from a power function: in \(x^2\) the base varies, while in \(2^x\) the exponent varies. This is Stewart §6.2.

What does \(b^x\) mean? For whole numbers, \(2^3 = 2\cdot 2\cdot 2\). Then \(b^0 = 1\), \(b^{-n} = 1/b^n\), and \(b^{p/q} = \sqrt[q]{b^p}\), so \(8^{2/3} = 4\). For an irrational exponent such as \(2^{\sqrt 3}\), we use rational exponents closer and closer to \(\sqrt 3\) and take the limit. The result is a smooth curve with no gaps, always passing through \((0, 1)\), with range \((0, \infty)\) (Figure 11.3).

Laws of Exponents For \(a, b > 0\) and all real \(x, y\): \(b^{x+y} = b^x b^y\), \(b^{x-y} = \dfrac{b^x}{b^y}\), \((b^x)^y = b^{xy}\), \((ab)^x = a^x b^x\).

Limits. Take note of how \(b^x\) behaves at the ends:

  • If \(b > 1\), then \(\displaystyle\lim_{x\to\infty} b^x = \infty\) and \(\displaystyle\lim_{x\to-\infty} b^x = 0\).
  • If \(0 < b < 1\), then \(\displaystyle\lim_{x\to\infty} b^x = 0\) and \(\displaystyle\lim_{x\to-\infty} b^x = \infty\).

For example, let's find \(\displaystyle\lim_{x\to\infty}\left(2^{-x} - 1\right)\). We rewrite \(2^{-x} = \left(\tfrac12\right)^x\). Since the base \(\tfrac12\) is between 0 and 1, \(\left(\tfrac12\right)^x \to 0\), so the limit is \(0 - 1 = -1\).

The derivative, and the special number \(e\). Let's start from the definition of the derivative: \[\frac{d}{dx}b^x = \lim_{h\to0}\frac{b^{x+h} - b^x}{h} = b^x \lim_{h\to0}\frac{b^h - 1}{h}.\] So the derivative of \(b^x\) is \(b^x\) times a constant: the slope of the curve at \((0, 1)\). That slope is about 0.69 for \(b = 2\) and about 1.10 for \(b = 3\). Somewhere between 2 and 3 there is a base whose slope at 0 is exactly 1 (Figure 11.4). That base is the number \(e \approx 2.71828\), and \(e^x\) is the natural exponential function. Its derivative is the simplest rule in calculus: \[\frac{d}{dx}\,e^x = e^x.\] (In §6.4 we will see that the constant for a general base is \(\ln b\), so \(\frac{d}{dx}b^x = b^x\ln b\).)

With the Chain Rule, \(\frac{d}{dx}\,e^{u} = e^{u}\,\frac{du}{dx}\). For \(y = e^{3x}\), let \(u = 3x\); then \(y' = e^{u}\cdot 3 = 3e^{3x}\). For \(y = e^{x^2}\), let \(u = x^2\); then \(y' = 2x\,e^{x^2}\). For \(y = e^{\sqrt x}\), \(y' = \dfrac{e^{\sqrt x}}{2\sqrt x}\).

Common mistake The Power Rule does not apply to \(e^x\): its derivative is not \(x e^{x-1}\). And don't forget the Chain Rule factor: \(\frac{d}{dx}e^{3x} = 3e^{3x}\), not \(e^{3x}\).

We can now mix \(e^x\) with all the rules from Chapter 2. Quotient Rule: \[\frac{d}{dx}\frac{e^{3x}}{x^2 + 1} = \frac{(x^2 + 1)\,3e^{3x} - e^{3x}\,(2x)}{(x^2 + 1)^2} = \frac{e^{3x}(3x^2 - 2x + 3)}{(x^2 + 1)^2}.\] Sometimes rewriting is easier. For \(y = \dfrac{x^3}{e^x}\), write \(y = x^3e^{-x}\) and use the Product Rule: \(y' = 3x^2e^{-x} - x^3e^{-x} = \dfrac{3x^2 - x^3}{e^x}\).

Notice that we factored out the exponential. That makes it easy to find where a derivative is zero, because \(e^x\) is never zero. Also, since \(e^x > 0\), the slope of \(y = e^x\) is always positive, so \(e^x\) is always increasing and therefore one-to-one. That matters in the next module.

Limits with \(e^x\). For a quotient of exponentials as \(x \to \infty\), divide top and bottom by the fastest-growing exponential: \[\lim_{x\to\infty}\frac{e^{2x} - e^{-2x}}{e^{2x} + e^{-2x}} = \lim_{x\to\infty}\frac{1 - e^{-4x}}{1 + e^{-4x}} = \frac{1 - 0}{1 + 0} = 1.\]

Key equations
\[ b \gt 1:\ \lim_{x\to\infty} b^x = \infty,\ \lim_{x\to-\infty} b^x = 0; \qquad 0 \lt b \lt 1:\ \lim_{x\to\infty} b^x = 0,\ \lim_{x\to-\infty} b^x = \infty \]
\[ \frac{d}{dx}\,e^x = e^x, \qquad \frac{d}{dx}\,e^{u} = e^{u}\,\frac{du}{dx} \]

★Key takeaways

  • A function has an inverse only if it is one-to-one: different inputs always give different outputs, and no horizontal line hits the graph twice.
  • To find f⁻¹: write y = f(x), solve for x in terms of y, then interchange x and y; the graph of f⁻¹ is the reflection of f in y = x.
  • (f⁻¹)′(a) = 1/f′(f⁻¹(a)): find the input that gives a, put it into f′, and take the reciprocal.
  • If b > 1, bˣ → ∞ as x → ∞ and bˣ → 0 as x → −∞; if 0 < b < 1, the two limits swap.
  • The number e ≈ 2.71828 is the base for which d/dx eˣ = eˣ; with the Chain Rule, d/dx eᵘ = eᵘ · du/dx.

Example 11.1 One-to-one, then the inverse

Show that \(f(x) = x^3 + 2\) is one-to-one, then find its inverse function \(f^{-1}(x)\).

(Similar to Stewart §6.1, Examples 1 and 4)
Show solution (try it first)
Given
  • \(f(x) = x^3 + 2\), defined for all real \(x\).
  • Asked: is \(f\) one-to-one, and what is \(f^{-1}(x)\)?
Step 1: Check that f is one-to-one

Two different numbers can't have the same cube. So if \(x_1 \ne x_2\), then \(x_1^3 \ne x_2^3\), and adding 2 to both keeps them different.

\[x_1 \ne x_2 \;\Longrightarrow\; x_1^3 + 2 \ne x_2^3 + 2\]

So \(f\) is one-to-one and has an inverse.

Step 2: Write y = f(x)

\[y = x^3 + 2\]

Step 3: Solve for x in terms of y

Subtract 2 from both sides, then take the cube root.

\[y - 2 = x^3\]

\[x = \sqrt[3]{y - 2}\]

Step 4: Interchange x and y

The resulting equation is \(y = f^{-1}(x)\).

\[y = \sqrt[3]{x - 2}\]

Answer

So \(f^{-1}(x) = \sqrt[3]{x - 2}\).

Check

Try \(x = 2\): \(f(2) = 8 + 2 = 10\), and \(f^{-1}(10) = \sqrt[3]{10 - 2} = \sqrt[3]{8} = 2\). The inverse brings us back to 2. ✓

Example 11.2 Inverse of a fraction

Let \(f(x) = \dfrac{2x + 3}{x - 1}\) for \(x \ne 1\). Find \(f^{-1}(x)\) and state its domain.

(Similar to Stewart §6.1, Example 4)
Show solution (try it first)
Given
  • \(f(x) = \dfrac{2x + 3}{x - 1}\), \(x \ne 1\).
  • Asked: a formula for \(f^{-1}(x)\) and its domain.
Step 1: Write y = f(x)

\[y = \frac{2x + 3}{x - 1}\]

Step 2: Clear the fraction

Multiply both sides by \(x - 1\) so that \(x\) is no longer in a denominator.

\[y(x - 1) = 2x + 3\]

\[yx - y = 2x + 3\]

Step 3: Collect the x terms on one side

Move \(2x\) to the left and \(-y\) to the right.

\[yx - 2x = y + 3\]

\[x(y - 2) = y + 3\]

Step 4: Solve for x

Divide by \(y - 2\).

\[x = \frac{y + 3}{y - 2}\]

Step 5: Interchange x and y

\[y = f^{-1}(x) = \frac{x + 3}{x - 2}\]

The formula breaks down at \(x = 2\). That means 2 is not in the range of \(f\), so the domain of \(f^{-1}\) is all real numbers except 2.

Answer

So \(f^{-1}(x) = \dfrac{x + 3}{x - 2}\), with domain \(x \ne 2\).

Check

\(f(2) = \frac{4 + 3}{1} = 7\) and \(f^{-1}(7) = \frac{7 + 3}{7 - 2} = \frac{10}{5} = 2\). ✓

Example 11.3 Derivative of an inverse: a square root

If \(f(x) = \sqrt{x - 2}\), find \((f^{-1})'(2)\).

(Similar to Stewart §6.1, Example 7)
Show solution (try it first)
Given
  • \(f(x) = \sqrt{x - 2}\), \(x \ge 2\) (one-to-one, since it is always increasing).
  • \(a = 2\).
  • Asked: \((f^{-1})'(2) = \dfrac{1}{f'\big(f^{-1}(2)\big)}\).
Step 1: Find the inverse value f⁻¹(2)

Set \(f(x) = 2\) and solve. Square both sides first.

\[\sqrt{x - 2} = 2\]

\[x - 2 = 4\]

\[x = 6\]

Since \(f(6) = 2\), the definition gives \(f^{-1}(2) = 6\).

Step 2: Compute the derivative of f

Write \(f(x) = (x - 2)^{1/2}\) and use the Chain Rule.

\[f'(x) = \tfrac12 (x - 2)^{-1/2}\cdot 1 = \frac{1}{2\sqrt{x - 2}}\]

Step 3: Substitute the inverse value

\[f'(6) = \frac{1}{2\sqrt{6 - 2}} = \frac{1}{2\sqrt 4} = \frac{1}{2\cdot 2} = \frac14\]

Step 4: Apply the formula

\[(f^{-1})'(2) = \frac{1}{f'(6)} = \frac{1}{1/4} = 4\]

Answer

So \((f^{-1})'(2) = 4\).

Check

Here we can find the inverse directly: \(f^{-1}(x) = x^2 + 2\) for \(x \ge 0\), so \((f^{-1})'(x) = 2x\) and \((f^{-1})'(2) = 4\). ✓

Example 11.4 Derivative of an inverse we cannot solve for

Let \(f(x) = 2x + \cos x\). Find \((f^{-1})'(1)\).

(Similar to Stewart §6.1, Example 7)
Show solution (try it first)
Given
  • \(f(x) = 2x + \cos x\).
  • \(a = 1\).
  • Asked: \((f^{-1})'(1)\).
Step 1: Check that f has an inverse

\(f'(x) = 2 - \sin x\). Since \(\sin x \le 1\), we get \(f'(x) \ge 1 > 0\). So \(f\) is always increasing and one-to-one.

Step 2: Find the inverse value f⁻¹(1)

The equation \(2x + \cos x = 1\) cannot be solved algebraically. But let's try \(x = 0\):

\[f(0) = 2(0) + \cos 0 = 0 + 1 = 1\]

And so \(f^{-1}(1) = 0\).

Step 3: Compute the derivative of f

\[f'(x) = 2 - \sin x\]

Step 4: Substitute the inverse value

\[f'(0) = 2 - \sin 0 = 2 - 0 = 2\]

Step 5: Apply the formula

\[(f^{-1})'(1) = \frac{1}{f'(0)} = \frac12\]

Answer

So \((f^{-1})'(1) = \dfrac12\), even though we have no formula for \(f^{-1}\).

Example 11.5 Chain Rule and Product Rule with e

Differentiate (a) \(y = e^{\sec x}\) and (b) \(y = e^{-4x}\sin 5x\).

(Similar to Stewart §6.2, Example 8)
Show solution (try it first)
Given
  • (a) \(y = e^{\sec x}\), a composition: \(e^u\) with \(u = \sec x\).
  • (b) \(y = e^{-4x}\sin 5x\), a product of two functions.
  • Asked: \(\dfrac{dy}{dx}\) for each.
Step 1: (a) Set up the Chain Rule

Let \(u = \sec x\), then \(y = e^u\).

\[\frac{dy}{dx} = \frac{dy}{du}\cdot\frac{du}{dx} = \frac{d}{du}\big(e^u\big)\cdot\frac{d}{dx}(\sec x)\]

Step 2: (a) Differentiate and substitute back u

\[\frac{dy}{dx} = e^u\cdot\sec x\tan x\]

\[\frac{dy}{dx} = e^{\sec x}\sec x\tan x\]

Step 3: (b) Set up the Product Rule

\[\frac{dy}{dx} = \sin 5x\cdot\frac{d}{dx}\big(e^{-4x}\big) + e^{-4x}\cdot\frac{d}{dx}\big(\sin 5x\big)\]

Step 4: (b) Use the Chain Rule on each factor

For the first factor, let \(u = -4x\): \(\frac{d}{dx}e^{-4x} = e^{u}\cdot(-4) = -4e^{-4x}\).

For the second, let \(u = 5x\): \(\frac{d}{dx}\sin 5x = \cos u\cdot 5 = 5\cos 5x\).

Step 5: (b) Substitute back and factor

\[\frac{dy}{dx} = -4e^{-4x}\sin 5x + 5e^{-4x}\cos 5x\]

\[\frac{dy}{dx} = e^{-4x}(5\cos 5x - 4\sin 5x)\]

Answer

(a) \(y' = e^{\sec x}\sec x\tan x\). (b) \(y' = e^{-4x}(5\cos 5x - 4\sin 5x)\).

Example 11.6 Simplify first, then differentiate

Find the derivative of \(y = \dfrac{e^{-2x}\csc x}{\cot x}\).

(Similar to Stewart §6.2, Example 9)
Show solution (try it first)
Given
  • \(y = \dfrac{e^{-2x}\csc x}{\cot x}\).
  • Asked: \(y'\).
Step 1: Simplify the trig part

As we can observe, \(\dfrac{\csc x}{\cot x}\) simplifies. Write both in sines and cosines.

\[\frac{\csc x}{\cot x} = \frac{1/\sin x}{\cos x/\sin x} = \frac{1}{\sin x}\cdot\frac{\sin x}{\cos x} = \frac{1}{\cos x} = \sec x\]

So we can rewrite the function as \(y = e^{-2x}\sec x\). No Quotient Rule needed.

Step 2: Apply the Product Rule

Use \(\frac{d}{dx}e^{-2x} = -2e^{-2x}\) and \(\frac{d}{dx}\sec x = \sec x\tan x\).

\[y' = \big(-2e^{-2x}\big)\sec x + e^{-2x}\big(\sec x\tan x\big)\]

Step 3: Factor out the common terms

Both terms contain \(e^{-2x}\sec x\).

\[y' = e^{-2x}\sec x\,(\tan x - 2)\]

Answer

So \(y' = e^{-2x}\sec x\,(\tan x - 2)\).

Check

Take note that the original function is undefined where \(\sin x = 0\) or \(\cos x = 0\), so \(y = e^{-2x}\sec x\) and this derivative are used only at those other \(x\). Without simplifying first we would need the Quotient Rule and much more algebra, and we would arrive at the same answer.
