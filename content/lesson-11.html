6.1Inverse Functions

Let's start with a question. If we know what a function does to an input, can we go backwards? Given the output, can we recover the input? This is exactly what an inverse function does. The inverse of a function is a rule that acts on the output of the function and produces the corresponding input. The inverse "undoes" or reverses what the function has done. In astronomy we do this all the time: we measure the brightness of a star (the output) and work backwards to its distance (the input).

One-to-one functions. Before we can go backwards, we need to make sure that every output came from exactly one input. Think of a function that sends two different students to the same seat number: if I only tell you the seat number, you cannot say which student it was. So we need the following idea.

Definition 1 A function \(f\) is called one-to-one if it never takes on the same value twice; that is, \[f(x_1) \ne f(x_2) \quad\text{whenever}\quad x_1 \ne x_2.\]

Any function, when graphed, can be checked whether it is a one-to-one function. That is through the Horizontal Line Test.

Horizontal Line Test A function is one-to-one if and only if no horizontal line intersects its graph more than once.

Let's check two quick cases. The function \(f(x) = x^3\) is one-to-one, because two different numbers can't have the same cube: if \(x_1 \ne x_2\), then \(x_1^3 \ne x_2^3\). On the other hand, \(f(x) = x^4\) is not one-to-one, because a positive input and its negative give the same result: \(f(1) = 1 = f(-1)\). In the graph, the horizontal line \(y = 1\) hits \(y = x^4\) twice.

There is also a calculus shortcut. If \(f'(x) > 0\) everywhere (always increasing) or \(f'(x) < 0\) everywhere (always decreasing), then the graph can never come back to the same height, so \(f\) is one-to-one. For example, \(f(x) = x^3 + 4x - 2\) has \(f'(x) = 3x^2 + 4 > 0\).

It is important to discuss one-to-one functions in this topic because they are exactly the functions that possess an inverse, according to the following definition.

Definition 2 Let \(f\) be a one-to-one function with domain \(A\) and range \(B\). Then its inverse function \(f^{-1}\) has domain \(B\) and range \(A\) and is defined by \[f^{-1}(y) = x \iff f(x) = y\] for any \(y\) in \(B\).

Notice what this says: \(f\) takes \(x\) to \(y\), and \(f^{-1}\) takes \(y\) back to \(x\). If we apply one after the other, we get back where we started. These are the cancellation equations: \[f^{-1}\big(f(x)\big) = x \;\text{ for every } x \text{ in } A, \qquad f\big(f^{-1}(x)\big) = x \;\text{ for every } x \text{ in } B.\]

Common mistake Take note that the \(-1\) in \(f^{-1}\) is not an exponent. \(f^{-1}(x)\) does not mean \(\dfrac{1}{f(x)}\). The reciprocal is written \([f(x)]^{-1}\).

How to find the inverse function of a one-to-one function \(f\).

  1. STEP 1: Write \(y = f(x)\).
  2. STEP 2: Solve this equation for \(x\) in terms of \(y\) (if possible).
  3. STEP 3: To express \(f^{-1}\) as a function of \(x\), interchange \(x\) and \(y\). The resulting equation is \(y = f^{-1}(x)\).

For instance, for \(f(x) = x^3 + 2\): Step 1, \(y = x^3 + 2\). Step 2, \(y - 2 = x^3\), so \(x = \sqrt[3]{y - 2}\). Step 3, interchange: \(f^{-1}(x) = \sqrt[3]{x - 2}\).

Graphs. Interchanging \(x\) and \(y\) sends the point \((a, b)\) to \((b, a)\). So the graph of \(f^{-1}\) is obtained by reflecting the graph of \(f\) about the line \(y = x\) (Figure 11.2).

The calculus of inverse functions. Now, how do we get the derivative of an inverse? Here is the theorem.

Theorem If \(f\) is a one-to-one differentiable function with inverse function \(f^{-1}\) and \(f'\big(f^{-1}(a)\big) \ne 0\), then the inverse function is differentiable at \(a\) and \[(f^{-1})'(a) = \frac{1}{f'\big(f^{-1}(a)\big)}.\]

Proof. Recall the cancellation equation \(f\big(f^{-1}(a)\big) = a\). Now, if we take the derivative of both sides with respect to \(a\), where we use the Chain Rule on the left-hand side (meaning, the derivative of the outside evaluated at the inside, multiplied by the derivative of the inside), then we get \[f'\big(f^{-1}(a)\big)\cdot(f^{-1})'(a) = 1.\] Dividing both sides by \(f'\big(f^{-1}(a)\big)\), we just proved that \((f^{-1})'(a) = \dfrac{1}{f'\big(f^{-1}(a)\big)}\). In a picture: reflecting a tangent line about \(y = x\) swaps its rise and its run, so the slope becomes its reciprocal.

In order to easily compute the derivative of an inverse, I have devised these steps:

  1. STEP 1: Find the inverse value: solve \(f(x) = a\) for \(x\). That \(x\) is \(f^{-1}(a)\).
  2. STEP 2: Compute the derivative \(f'(x)\) of the given function.
  3. STEP 3: Substitute the value of the inverse into the derivative: find \(f'\big(f^{-1}(a)\big)\).
  4. STEP 4: Apply the formula \((f^{-1})'(a) = 1/f'\big(f^{-1}(a)\big)\).

Let's try it. If \(f(x) = x^3\), find \((f^{-1})'(8)\). Step 1: \(x^3 = 8\), so \(x = 2\) and \(f^{-1}(8) = 2\). Step 2: \(f'(x) = 3x^2\). Step 3: \(f'(2) = 3(2)^2 = 12\). Step 4: \((f^{-1})'(8) = \dfrac{1}{12}\). Notice that we never needed the formula of \(f^{-1}\) itself, only one of its values. This is very useful for functions like \(f(x) = 3x^3 + 4x^2 + 6x + 5\), whose inverse we cannot write down: to find \((f^{-1})'(5)\), we solve \(3x^3 + 4x^2 + 6x = 0\), that is \(x(3x^2 + 4x + 6) = 0\). The quadratic factor has a negative discriminant (\(16 - 72 < 0\)), so its roots are imaginary, hence \(x = 0\). Then \(f'(x) = 9x^2 + 8x + 6\) gives \(f'(0) = 6\), and \((f^{-1})'(5) = \dfrac16\).

Common mistake The derivative of \(f\) must be evaluated at the input \(f^{-1}(a)\), not at \(a\). For \(f(x) = x^3\) and \(a = 8\), the answer is \(1/f'(2) = 1/12\), not \(1/f'(8) = 1/192\).
Key equations
\[ f^{-1}(y) = x \iff f(x) = y \]
\[ f^{-1}(f(x)) = x, \qquad f(f^{-1}(x)) = x \]
\[ (f^{-1})'(a) = \frac{1}{f'\big(f^{-1}(a)\big)} \]

6.2Exponential Functions and Their Derivatives

Recall that an exponential function is given by the form \[f(x) = b^x, \qquad b > 0,\] and its special case \[f(x) = e^x, \qquad e \approx 2.71828.\] Take note of the difference from a power function: in \(x^2\) the base changes and the exponent is fixed, while in \(2^x\) the exponent changes and the base is fixed. Exponential functions describe things that grow or shrink by the same factor in equal time steps, like a population of bacteria, the charge on a discharging capacitor, or the light from a supernova fading over the weeks.

What does \(b^x\) mean? For whole numbers it is repeated multiplication, \(2^3 = 2\cdot2\cdot2 = 8\). Then \(b^0 = 1\), \(b^{-n} = 1/b^n\), and \(b^{p/q} = \sqrt[q]{b^p}\), so \(8^{2/3} = 4\). For an irrational exponent like \(2^{\sqrt3}\), we use exponents closer and closer to \(\sqrt3\) (\(2^{1.7}, 2^{1.73}, 2^{1.732}, \ldots\)) and take the limit, so the graph is a smooth curve with no holes.

Laws of Exponents For \(a, b > 0\) and all real \(x, y\): \(b^{x+y} = b^x b^y\), \(\;b^{x-y} = \dfrac{b^x}{b^y}\), \(\;(b^x)^y = b^{xy}\), \(\;(ab)^x = a^x b^x\).

Shape and limits. Every graph \(y = b^x\) passes through \((0, 1)\), its domain is all real numbers and its range is \((0, \infty)\). Now take note that \[\text{If } b > 1:\quad \lim_{x\to\infty} b^x = \infty \;\text{ and }\; \lim_{x\to-\infty} b^x = 0.\] \[\text{If } 0 < b < 1:\quad \lim_{x\to\infty} b^x = 0 \;\text{ and }\; \lim_{x\to-\infty} b^x = \infty.\] For example, \(\displaystyle\lim_{x\to\infty}\left(2^{-x} - 1\right)\): we rewrite \(2^{-x} = \left(\tfrac12\right)^x\). Since \(0 < \tfrac12 < 1\), \(\left(\tfrac12\right)^x \to 0\), so the limit is \(0 - 1 = -1\).

The derivative of an exponential function Using the definition of the derivative, \[\frac{d}{dx}b^x = \lim_{h\to0}\frac{b^{x+h} - b^x}{h} = b^x\lim_{h\to0}\frac{b^h - 1}{h}.\] The last limit is a constant (it is the slope of \(y = b^x\) at \(x = 0\)): about 0.69 for \(b = 2\) and about 1.10 for \(b = 3\). The number \(e\) is defined as the base for which this slope is exactly 1. That gives the two derivative formulas \[\frac{d}{dx}e^x = e^x \qquad\text{and}\qquad \frac{d}{dx}b^x = b^x\ln b.\]

So \(e^x\) is the function that is its own derivative: at every point of its graph, the slope is equal to the height. Since \(e^x > 0\), the slope is always positive, so \(e^x\) is always increasing (and, by the Horizontal Line Test, one-to-one: this is why it has an inverse, the natural logarithm, in the next module).

Using the Chain Rule. Most of the time, the exponent is not just \(x\). Recall the Chain Rule: if \(y = e^u\) and \(u = g(x)\), then \(\dfrac{dy}{dx} = \dfrac{dy}{du}\cdot\dfrac{du}{dx}\). So \[\frac{d}{dx}e^{g(x)} = e^{g(x)}\,g'(x).\] Let's check a few. For \(y = e^{3x}\): let \(u = 3x\), then \(y' = e^u\cdot 3 = 3e^{3x}\). For \(y = e^{x^2}\): let \(u = x^2\), then \(y' = e^u\cdot 2x = 2xe^{x^2}\). For \(y = e^{\sqrt x}\): \(y' = e^{\sqrt x}\cdot\dfrac{1}{2\sqrt x} = \dfrac{e^{\sqrt x}}{2\sqrt x}\). For \(y = e^{\sec x}\): \(y' = e^{\sec x}\sec x\tan x\). The rule is always the same: copy the exponential, then multiply by the derivative of the exponent.

We can also combine with the Product and Quotient Rules. For \(y = \dfrac{x^3}{e^x}\), it is easier to rewrite it as \(y = x^3e^{-x}\) and use the Product Rule: \(y' = 3x^2e^{-x} - x^3e^{-x} = \dfrac{3x^2 - x^3}{e^x}\). And sometimes we should simplify first: \(y = e^{-2x}\dfrac{\csc x}{\cot x}\) looks scary, but \(\dfrac{\csc x}{\cot x} = \dfrac{1/\sin x}{\cos x/\sin x} = \dfrac{1}{\cos x} = \sec x\), so \(y = e^{-2x}\sec x\) and \(y' = -2e^{-2x}\sec x + e^{-2x}\sec x\tan x = e^{-2x}\sec x(\tan x - 2)\).

Common mistake The Power Rule does not apply to \(e^x\): its derivative is not \(xe^{x-1}\), because here the exponent changes, not the base. Also, do not forget the Chain Rule factor: \(\dfrac{d}{dx}e^{3x} = 3e^{3x}\), not \(e^{3x}\).

Limits with \(e^x\). For a quotient of exponentials as \(x \to \infty\), we divide the numerator and denominator by the fastest-growing exponential. For example, \[\lim_{x\to\infty}\frac{e^{2x} - e^{-2x}}{e^{2x} + e^{-2x}} = \lim_{x\to\infty}\frac{1 - e^{-4x}}{1 + e^{-4x}} = \frac{1 - 0}{1 + 0} = 1.\]

Key equations
\[ \lim_{x\to\infty} e^x = \infty, \qquad \lim_{x\to-\infty} e^x = 0 \]
\[ \frac{d}{dx}\,e^x = e^x, \qquad \frac{d}{dx}\,b^x = b^x\ln b \]
\[ \frac{d}{dx}\,e^{g(x)} = e^{g(x)}\,g'(x) \]

★Key takeaways

  • A function has an inverse only if it is one-to-one; we check this with the Horizontal Line Test or a derivative that never changes sign.
  • To find f⁻¹: write y = f(x), solve for x, then interchange x and y. The graph of f⁻¹ is the reflection of f about y = x.
  • (f⁻¹)′(a) = 1/f′(f⁻¹(a)): first find the input b with f(b) = a, then take the reciprocal of f′(b). We do not need the formula of f⁻¹.
  • If b > 1, bˣ → ∞ as x → ∞ and bˣ → 0 as x → −∞; if 0 < b < 1 the two limits swap.
  • e ≈ 2.71828 is the base with d/dx eˣ = eˣ; with the Chain Rule, d/dx e^g(x) = e^g(x)·g′(x), and d/dx bˣ = bˣ ln b.

Example 11.1 Is it one-to-one?

Decide whether each function is one-to-one: (a) \(f(x) = x^3\); (b) \(g(x) = x^4\).

(From the instructor's module)
Show solution (try it first)

Given: \(f(x) = x^3\) and \(g(x) = x^4\), both on all real numbers.   Find: whether each passes the one-to-one test.

Plan: Use Definition 1: a function is one-to-one if different inputs always give different outputs. To show a function is not one-to-one, one pair of inputs with the same output is enough.

Step 1. For \(f(x) = x^3\), suppose \(f(x_1) = f(x_2)\), that is \(x_1^3 = x_2^3\). Taking the cube root of both sides (the cube root is defined for every real number and gives exactly one value):

\[x_1^3 = x_2^3 \;\Longrightarrow\; x_1 = x_2\]

Step 2. So two different numbers can never have the same cube. We can also see it with calculus: \(f'(x) = 3x^2 \ge 0\), and it is zero only at \(x = 0\), so \(f\) is always increasing.

Step 3. For \(g(x) = x^4\), try a number and its negative:

\[g(1) = 1^4 = 1, \qquad g(-1) = (-1)^4 = 1\]

Step 4. Two different inputs (\(1 \ne -1\)) gave the same output, so \(g\) fails the definition. In the graph, the horizontal line \(y = 1\) meets \(y = x^4\) twice.

Answer: (a) \(f(x) = x^3\) is one-to-one; (b) \(g(x) = x^4\) is not one-to-one. That is our answer.

Check: Horizontal Line Test: every horizontal line meets the S-shaped cubic once, while \(y = c\) with \(c > 0\) meets the U-shaped \(x^4\) twice. Consistent.

Example 11.2 Finding an inverse in three steps

Find the inverse function of \(f(x) = x^3 + 2\).

(From the instructor's module)
Show solution (try it first)

Given: \(f(x) = x^3 + 2\), which is one-to-one (Example 11.1, shifted up 2).   Find: \(f^{-1}(x)\).

Plan: Follow the three steps: write y = f(x), solve for x, interchange x and y.

Step 1. Write \(y = f(x)\):

\[y = x^3 + 2\]

Step 2. Solve for \(x\) in terms of \(y\). Subtract 2 from both sides, then take the cube root:

\[y - 2 = x^3 \;\Longrightarrow\; x = \sqrt[3]{y - 2}\]

Step 3. Interchange \(x\) and \(y\). The resulting equation is \(y = f^{-1}(x)\):

\[y = \sqrt[3]{x - 2}\]

Answer: \(\boxed{f^{-1}(x) = \sqrt[3]{x - 2}}\). That is our answer.

Check: Use a cancellation equation: \(f\big(f^{-1}(x)\big) = \big(\sqrt[3]{x - 2}\big)^3 + 2 = x - 2 + 2 = x\). Numerically, \(f(1) = 3\) and \(f^{-1}(3) = \sqrt[3]{1} = 1\).

Example 11.3 The inverse of a rational function

Let \(f(x) = \dfrac{2x + 3}{x - 1}\), \(x \ne 1\). Find \(f^{-1}(x)\) and its domain.

(Similar to Stewart §6.1, Example 4)
Show solution (try it first)

Given: \(f(x) = \dfrac{2x + 3}{x - 1}\).   Find: \(f^{-1}(x)\) and the domain of \(f^{-1}\).

Plan: Same three steps. The new part is the algebra: clear the fraction, then gather every term with \(x\) on one side and factor \(x\) out.

Step 1. Write \(y = f(x)\):

\[y = \frac{2x + 3}{x - 1}\]

Step 2. Multiply both sides by \(x - 1\) to clear the fraction, and expand:

\[y(x - 1) = 2x + 3 \;\Longrightarrow\; xy - y = 2x + 3\]

Step 3. Move the \(x\)-terms to the left and the rest to the right, then factor out \(x\):

\[xy - 2x = y + 3 \;\Longrightarrow\; x(y - 2) = y + 3\]

Step 4. Divide by \(y - 2\):

\[x = \frac{y + 3}{y - 2}\]

Step 5. Interchange \(x\) and \(y\). The formula is undefined at \(x = 2\), so the domain of \(f^{-1}\) (which is the range of \(f\)) is all real numbers except 2.

\[f^{-1}(x) = \frac{x + 3}{x - 2}, \quad x \ne 2\]

Answer: \(\boxed{f^{-1}(x) = \dfrac{x + 3}{x - 2}}\), with domain \(x \ne 2\). That is our answer.

Check: \(f(2) = \dfrac{7}{1} = 7\) and \(f^{-1}(7) = \dfrac{10}{5} = 2\). Also, \(y = 2\) is the horizontal asymptote of \(f\), so 2 is the one value \(f\) never reaches, matching the domain of \(f^{-1}\).

Example 11.4 The derivative of an inverse in four steps

If \(f(x) = \sqrt{x - 2}\), find \((f^{-1})'(2)\).

(From the instructor's module)
Show solution (try it first)

Given: \(f(x) = \sqrt{x - 2}\), \(x \ge 2\) (one-to-one, since it is increasing), and \(a = 2\).   Find: \((f^{-1})'(2)\).

Plan: Use the four steps: find the inverse value, differentiate f, substitute, then apply the reciprocal formula.

Step 1. Find the inverse value: solve \(f(x) = 2\). Square both sides, then add 2:

\[\sqrt{x - 2} = 2 \;\Longrightarrow\; x - 2 = 4 \;\Longrightarrow\; x = 6\]

Step 2. From Definition 2, \(f^{-1}(2) = 6\). Now compute the derivative of \(f\) (Chain Rule on \((x - 2)^{1/2}\)):

\[f'(x) = \tfrac12(x - 2)^{-1/2}\cdot 1 = \frac{1}{2\sqrt{x - 2}}\]

Step 3. Substitute the value of the inverse, \(x = 6\):

\[f'(6) = \frac{1}{2\sqrt{6 - 2}} = \frac{1}{2\cdot 2} = \frac14\]

Step 4. Apply the formula:

\[(f^{-1})'(2) = \frac{1}{f'\big(f^{-1}(2)\big)} = \frac{1}{f'(6)} = \frac{1}{1/4} = 4\]

Answer: \(\boxed{(f^{-1})'(2) = 4}\). That is our answer.

Check: Here we can find the inverse directly: \(y = \sqrt{x - 2}\) gives \(x = y^2 + 2\), so \(f^{-1}(x) = x^2 + 2\) (\(x \ge 0\)) and \((f^{-1})'(x) = 2x\). At \(x = 2\): \(2(2) = 4\). ✓

Example 11.5 When the inverse cannot be found by algebra

If \(f(x) = 2x + \cos x\), find \((f^{-1})'(1)\).

(From the instructor's module)
Show solution (try it first)

Given: \(f(x) = 2x + \cos x\) and \(a = 1\).   Find: \((f^{-1})'(1)\).

Plan: We cannot solve \(2x + \cos x = 1\) with algebra, but we can try a convenient value of \(x\). Then use the formula.

Step 1. Check that \(f\) is one-to-one: \(f'(x) = 2 - \sin x\). Since \(\sin x \le 1\), \(f'(x) \ge 1 > 0\), so \(f\) is always increasing.

\[f'(x) = 2 - \sin x \ge 1\]

Step 2. Find the inverse value. Try \(x = 0\):

\[f(0) = 2(0) + \cos 0 = 0 + 1 = 1 \;\Longrightarrow\; f^{-1}(1) = 0\]

Step 3. Substitute the inverse value into the derivative:

\[f'(0) = 2 - \sin 0 = 2\]

Step 4. Apply the formula:

\[(f^{-1})'(1) = \frac{1}{f'(0)} = \frac12\]

Answer: \(\boxed{(f^{-1})'(1) = \tfrac12}\). That is our answer.

Check: The tangent to \(f\) at \((0, 1)\) has slope 2; reflecting about \(y = x\) gives the point \((1, 0)\) on \(f^{-1}\) with slope \(\tfrac12\). A slip to avoid: \(1/f'(1) = 1/(2 - \sin 1) \approx 0.86\) is wrong, because the derivative must be evaluated at \(f^{-1}(1) = 0\).

Example 11.6 Product Rule and Chain Rule together

Find the derivative of \(y = e^{-4x}\sin 5x\).

(From the instructor's module)
Show solution (try it first)

Given: \(y = e^{-4x}\sin 5x\), a product of two functions.   Find: \(\dfrac{dy}{dx}\).

Plan: Use the Product Rule, d(fg) = g·f′ + f·g′. Each factor needs the Chain Rule.

Step 1. Write the Product Rule:

\[\frac{dy}{dx} = \sin 5x\,\frac{d}{dx}\big(e^{-4x}\big) + e^{-4x}\,\frac{d}{dx}\big(\sin 5x\big)\]

Step 2. First factor, Chain Rule: let \(u = -4x\), so \(e^{-4x} = e^u\) and \(\dfrac{du}{dx} = -4\):

\[\frac{d}{dx}e^{-4x} = e^u\cdot(-4) = -4e^{-4x}\]

Step 3. Second factor, Chain Rule: let \(u = 5x\), so \(\dfrac{d}{du}\sin u = \cos u\) and \(\dfrac{du}{dx} = 5\):

\[\frac{d}{dx}\sin 5x = 5\cos 5x\]

Step 4. Substitute back into the Product Rule and factor out \(e^{-4x}\):

\[y' = -4e^{-4x}\sin 5x + 5e^{-4x}\cos 5x = e^{-4x}\big(5\cos 5x - 4\sin 5x\big)\]

Answer: \(\boxed{y' = e^{-4x}(5\cos 5x - 4\sin 5x)}\). That is our answer.

Check: At \(x = 0\): \(y' = e^0(5 - 0) = 5\). Near 0, \(y \approx (1)(5x) = 5x\), whose slope is 5. ✓
