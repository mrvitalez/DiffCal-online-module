6.1Inverse Functions

Many questions in science run "backwards". If you know the temperature as a function of time, you may want the time at which a given temperature is reached. Undoing a function like this is the job of an inverse function, the subject of Stewart §6.1. Inverse functions are also the key that unlocks exponentials and logarithms in this chapter.

One-to-one functions. You can only run a function backwards if every output comes from exactly one input. A function \(f\) is one-to-one if it never takes the same value twice: \[f(x_1) \ne f(x_2) \quad\text{whenever}\quad x_1 \ne x_2.\] For example, \(f(x) = x^2\) on all real numbers is not one-to-one, because \(f(-3) = f(3) = 9\). If someone tells you the output is 9, you cannot say whether the input was 3 or \(-3\).

Horizontal Line Test A function is one-to-one if and only if no horizontal line meets its graph more than once.

A function that is always increasing (or always decreasing) passes the test automatically. So a quick way to prove one-to-one is to show \(f'(x) > 0\) everywhere. For example, \(f(x) = x^3 + 4x - 2\) has \(f'(x) = 3x^2 + 4 > 0\), so it is one-to-one.

Definition Let \(f\) be one-to-one with domain \(A\) and range \(B\). Its inverse \(f^{-1}\) has domain \(B\) and range \(A\), and \[f^{-1}(y) = x \iff f(x) = y.\]

The inverse undoes \(f\), and \(f\) undoes the inverse. These are the cancellation equations: \(f^{-1}(f(x)) = x\) for \(x\) in \(A\), and \(f(f^{-1}(x)) = x\) for \(x\) in \(B\).

Common mistake The \(-1\) in \(f^{-1}\) is not an exponent: \(f^{-1}(x)\) does not mean \(\dfrac{1}{f(x)}\). The reciprocal is written \([f(x)]^{-1}\).

Finding a formula for \(f^{-1}\). (1) Write \(y = f(x)\). (2) Solve this equation for \(x\) in terms of \(y\), if you can. (3) Swap the letters \(x\) and \(y\) to get \(y = f^{-1}(x)\). For \(f(x) = 5x - 2\): \(y = 5x - 2\) gives \(x = \frac{y + 2}{5}\), so \(f^{-1}(x) = \frac{x + 2}{5}\). Check: \(f(f^{-1}(x)) = 5\cdot\frac{x+2}{5} - 2 = x\).

Graphs. Swapping \(x\) and \(y\) turns the point \((a, b)\) into \((b, a)\). So the graph of \(f^{-1}\) is the graph of \(f\) reflected in the line \(y = x\).

Calculus of inverses. If \(f\) is continuous and one-to-one on an interval, so is \(f^{-1}\). If \(f\) is also differentiable and \(f'(f^{-1}(a)) \ne 0\), then \(f^{-1}\) is differentiable at \(a\), with \[(f^{-1})'(a) = \frac{1}{f'\big(f^{-1}(a)\big)}.\] Why? Write \(y = f^{-1}(x)\), so \(f(y) = x\). Differentiate implicitly: \(f'(y)\,\frac{dy}{dx} = 1\), so \(\frac{dy}{dx} = \frac{1}{f'(y)}\). In pictures: reflecting a tangent line in \(y = x\) swaps rise and run, so the slope turns into its reciprocal.

The great thing is that you often do not need a formula for \(f^{-1}\). Take \(f(x) = x^3 + 4x - 2\) again and find \((f^{-1})'(3)\). Solving \(x^3 + 4x - 2 = 3\) by algebra is hard, but you can spot \(f(1) = 3\), so \(f^{-1}(3) = 1\). Then \((f^{-1})'(3) = \frac{1}{f'(1)} = \frac{1}{7}\).

Key equations
\[ f^{-1}(y) = x \iff f(x) = y \]
\[ f^{-1}(f(x)) = x, \qquad f(f^{-1}(x)) = x \]
\[ (f^{-1})'(a) = \frac{1}{f'\big(f^{-1}(a)\big)} \]

6.2Exponential Functions and Their Derivatives

Stewart §6.2 studies functions of the form \(f(x) = a^x\) with a fixed base \(a > 0\). Notice the difference from a power function: in \(x^2\) the base varies, while in \(2^x\) the exponent varies.

What does \(a^x\) mean? For whole numbers, \(2^3 = 2\cdot 2\cdot 2\). Then \(a^0 = 1\), \(a^{-n} = 1/a^n\), and for fractions \(a^{p/q} = \sqrt[q]{a^p}\), so \(8^{2/3} = 4\). For an irrational exponent such as \(2^{\sqrt 3}\), use rational exponents closer and closer to \(\sqrt 3\) (\(2^{1.7}, 2^{1.73}, 2^{1.732}, \ldots\)) and take the limit. The result is a smooth curve with no gaps.

Shape and limits. If \(a > 1\), \(a^x\) increases; if \(0 < a < 1\), it decreases; if \(a = 1\) it is the constant 1. The domain is all real numbers, the range is \((0, \infty)\), and the graph always passes through \((0, 1)\). For \(a > 1\), \[\lim_{x\to\infty} a^x = \infty, \qquad \lim_{x\to-\infty} a^x = 0,\] so the \(x\)-axis is a horizontal asymptote. For \(0 < a < 1\) the two limits swap.

Laws of Exponents For \(a, b > 0\) and all real \(x, y\): \(a^{x+y} = a^x a^y\), \(a^{x-y} = \dfrac{a^x}{a^y}\), \((a^x)^y = a^{xy}\), \((ab)^x = a^x b^x\).

The derivative. Start from the definition: \[f'(x) = \lim_{h\to0}\frac{a^{x+h} - a^x}{h} = a^x \lim_{h\to0}\frac{a^h - 1}{h} = f'(0)\,a^x.\] So an exponential function's rate of change is proportional to its own size. The constant \(f'(0)\) is the slope at \((0,1)\). Numerically it is about 0.69 for \(a = 2\) and about 1.10 for \(a = 3\). Somewhere between 2 and 3 there is a base whose slope at 0 is exactly 1. That base is the number \[e \approx 2.71828.\] The function \(e^x\) is called the natural exponential function, and with \(f'(0) = 1\) the formula becomes the simplest rule in calculus: \[\frac{d}{dx}\,e^x = e^x.\] Combine it with the Chain Rule: \(\frac{d}{dx}\,e^{g(x)} = e^{g(x)}\,g'(x)\). For example, \(\frac{d}{dx}\,e^{x^2+1} = 2x\,e^{x^2+1}\) and \(\frac{d}{dx}\,e^{-4x} = -4e^{-4x}\).

Common mistake The Power Rule does not apply to \(e^x\): its derivative is not \(x e^{x-1}\). The exponent changes, not the base. Also remember the Chain Rule factor: \(\frac{d}{dx}e^{3x} = 3e^{3x}\), not \(e^{3x}\).

What \(\frac{d}{dx}e^x = e^x\) says about the graph. At every point of \(y = e^x\), the slope equals the height. At \(x = 0\) the curve has height 1 and slope 1; at \(x = 3\) it has height and slope about 20. Since \(e^x > 0\), the derivative is always positive, so \(e^x\) is always increasing (and therefore one-to-one, which matters in the next module). The second derivative is also \(e^x > 0\), so the graph is always concave upward. You can now mix \(e^x\) with all the rules from Chapter 2. For example, by the Product Rule, \[\frac{d}{dx}\big(e^x\sin x\big) = e^x\sin x + e^x\cos x = e^x(\sin x + \cos x).\] Factoring out the exponential, as here, makes it easy to find where the derivative is zero, because \(e^x\) itself is never zero.

Limits with \(e^x\). Because \(e > 1\), \(e^x \to \infty\) as \(x \to \infty\) and \(e^x \to 0\) as \(x \to -\infty\). For a quotient, divide top and bottom by the fastest-growing exponential. For instance, \[\lim_{x\to\infty}\frac{e^{2x} - e^{-2x}}{e^{2x} + e^{-2x}} = \lim_{x\to\infty}\frac{1 - e^{-4x}}{1 + e^{-4x}} = \frac{1 - 0}{1 + 0} = 1.\]

Key equations
\[ a^{x+y} = a^x a^y, \quad (a^x)^y = a^{xy} \]
\[ \lim_{x\to\infty} e^x = \infty, \qquad \lim_{x\to-\infty} e^x = 0 \]
\[ \frac{d}{dx}\,e^x = e^x, \qquad \frac{d}{dx}\,e^{g(x)} = e^{g(x)}\,g'(x) \]

★Key takeaways

  • A function has an inverse only if it is one-to-one; the Horizontal Line Test, or a derivative that never changes sign, shows this.
  • To find f⁻¹, solve y = f(x) for x and then swap x and y; the graph of f⁻¹ is the reflection of the graph of f in the line y = x.
  • The derivative of an inverse is a reciprocal: (f⁻¹)′(a) = 1/f′(b) where f(b) = a, so you only need to find b.
  • For a > 1, aˣ grows without bound as x → ∞ and approaches 0 as x → −∞; the x-axis is a horizontal asymptote.
  • The number e ≈ 2.71828 is the base for which d/dx eˣ = eˣ; with the Chain Rule, d/dx e^g(x) = e^g(x) g′(x).

Example 11.1 Finding and checking an inverse

Let \(f(x) = \dfrac{2x + 3}{x - 1}\) for \(x \ne 1\). Find a formula for \(f^{-1}(x)\), state its domain, and check your answer.

(Similar to Stewart §6.1, Example 4)
Show solution (try it first)

Strategy:

Write \(y = f(x)\), solve for \(x\), then swap \(x\) and \(y\). The domain of \(f^{-1}\) is the range of \(f\), which will show up as the values where the new formula is undefined.

Solution:

Start with \(y = \dfrac{2x + 3}{x - 1}\). Multiply both sides by \(x - 1\): \[y(x - 1) = 2x + 3 \quad\Longrightarrow\quad xy - y = 2x + 3.\] Collect the terms with \(x\) on the left and the rest on the right: \[xy - 2x = y + 3 \quad\Longrightarrow\quad x(y - 2) = y + 3 \quad\Longrightarrow\quad x = \frac{y + 3}{y - 2}.\] Swap \(x\) and \(y\): \[f^{-1}(x) = \frac{x + 3}{x - 2}, \qquad x \ne 2.\] So the range of \(f\) is every real number except 2. (That makes sense: as \(x \to \pm\infty\), \(f(x) \to 2\), a horizontal asymptote that the graph never reaches.)

Check:

Use a cancellation equation: \[f\big(f^{-1}(x)\big) = \frac{2\cdot\frac{x+3}{x-2} + 3}{\frac{x+3}{x-2} - 1} = \frac{\frac{2x + 6 + 3x - 6}{x - 2}}{\frac{x + 3 - x + 2}{x - 2}} = \frac{5x}{5} = x.\] A quick numerical check also works: \(f(2) = 7\) and \(f^{-1}(7) = \frac{10}{5} = 2\). Do not confuse the answer with the reciprocal \(\frac{x - 1}{2x + 3}\); that is \(1/f(x)\), a different function.

Example 11.2 The derivative of an inverse without its formula

Let \(f(x) = x^5 + 2x^3 + 4\). Explain why \(f\) is one-to-one, find \((f^{-1})'(7)\), and write the equation of the tangent line to \(y = f^{-1}(x)\) at the point where \(x = 7\).

(Similar to Stewart §6.1, Example 7)
Show solution (try it first)

Strategy:

Solving \(x^5 + 2x^3 + 4 = y\) for \(x\) is hopeless, so do not try. Instead use \((f^{-1})'(a) = 1/f'(b)\), where \(b = f^{-1}(a)\) is found by spotting an input that gives 7.

Solution:

One-to-one: \(f'(x) = 5x^4 + 6x^2 \ge 0\), and it equals 0 only at the single point \(x = 0\). So \(f\) is increasing on the whole real line and passes the Horizontal Line Test.

Find \(b\): try small integers. \(f(1) = 1 + 2 + 4 = 7\). So \(f^{-1}(7) = 1\).

Derivative: \(f'(1) = 5 + 6 = 11\), so \[(f^{-1})'(7) = \frac{1}{f'(1)} = \frac{1}{11}.\] Tangent line: the point on the graph of \(f^{-1}\) is \((7, 1)\) and the slope is \(\frac{1}{11}\): \[y - 1 = \tfrac{1}{11}(x - 7) \quad\Longrightarrow\quad y = \tfrac{1}{11}x + \tfrac{4}{11}.\]

Check:

The tangent to \(f\) at \((1, 7)\) has slope 11. Reflecting in \(y = x\) gives the point \((7, 1)\) and slope \(\frac{1}{11}\), matching our answer. A common slip is to compute \(1/f'(7)\) instead of \(1/f'(1)\): the derivative of \(f\) must be taken at the output of \(f^{-1}\), not at 7.

Example 11.3 Analysing an exponential curve

Let \(f(x) = \dfrac{e^x}{1 + e^x}\). (a) Find \(f'(x)\). (b) Show that \(f\) is increasing everywhere. (c) Find \(\displaystyle\lim_{x\to\infty} f(x)\) and \(\displaystyle\lim_{x\to-\infty} f(x)\), and describe the horizontal asymptotes.

(Similar to Stewart §6.2, Examples 6 and 8)
Show solution (try it first)

Strategy:

Use the Quotient Rule with \(\frac{d}{dx}e^x = e^x\). For the limit at \(\infty\), divide top and bottom by \(e^x\); at \(-\infty\), use \(e^x \to 0\).

Solution:

(a) With top \(e^x\) and bottom \(1 + e^x\) (both have derivative \(e^x\)): \[f'(x) = \frac{e^x(1 + e^x) - e^x\cdot e^x}{(1 + e^x)^2} = \frac{e^x + e^{2x} - e^{2x}}{(1 + e^x)^2} = \frac{e^x}{(1 + e^x)^2}.\] (b) Both \(e^x\) and \((1 + e^x)^2\) are always positive, so \(f'(x) > 0\) for every \(x\). Hence \(f\) is increasing on \((-\infty, \infty)\) (and so it is one-to-one).

(c) As \(x \to \infty\): \[\lim_{x\to\infty}\frac{e^x}{1 + e^x} = \lim_{x\to\infty}\frac{1}{e^{-x} + 1} = \frac{1}{0 + 1} = 1.\] As \(x \to -\infty\), \(e^x \to 0\), so \(f(x) \to \frac{0}{1 + 0} = 0\). The lines \(y = 1\) and \(y = 0\) are horizontal asymptotes; the graph is an S-shaped curve rising from 0 to 1.

Check:

At \(x = 0\): \(f(0) = \frac12\), halfway between the asymptotes, and \(f'(0) = \frac{1}{4}\). Also \(0 < f(x) < 1\) for all \(x\) because the top is positive and smaller than the bottom, consistent with the limits. A frequent error in (a) is to "cancel" \(e^x\) before differentiating; the Quotient Rule must be applied to the whole fraction.
