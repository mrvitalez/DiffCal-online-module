6.3Logarithmic Functions

In the last module we saw that \(f(x) = b^x\) (with \(b > 0\), \(b \ne 1\)) is always increasing or always decreasing, so it is one-to-one. And what do we know about one-to-one functions? They have inverses. So the question for this section is: what is the inverse of an exponential function? The answer is the logarithm.

Definition The logarithmic function with base \(b\), written \(\log_b\), is the inverse of \(b^x\): \[\log_b x = y \iff b^y = x, \qquad x > 0.\]

In words: \(\log_b x\) is the exponent we must put on \(b\) to get \(x\). For example, \(\log_2 8 = 3\) because \(2^3 = 8\), and \(\log_{10} 0.001 = -3\) because \(10^{-3} = 0.001\). Notice that the input of a logarithm must be positive, since \(b^y\) is always positive. Recall the cancellation equations from inverse functions; for logarithms they become \[\log_b(b^x) = x \;\text{ for every real } x, \qquad b^{\log_b x} = x \;\text{ for } x > 0.\]

The natural logarithm. The most important base in calculus is \(e\). The logarithm with base \(e\) is called the natural logarithm and we write \(\ln x = \log_e x\). So \[\ln x = y \iff e^y = x, \qquad \ln(e^x) = x, \qquad e^{\ln x} = x.\] In particular \(\ln 1 = 0\) (since \(e^0 = 1\)) and \(\ln e = 1\).

Laws of Logarithms For \(x, y > 0\) and any real \(r\): \[\ln(xy) = \ln x + \ln y, \qquad \ln\frac{x}{y} = \ln x - \ln y, \qquad \ln(x^r) = r\ln x.\] These come directly from the laws of exponents: multiplying powers adds exponents, so the log of a product is a sum.

Let's use these. To expand \(\ln\dfrac{x^2\sqrt{x + 1}}{x - 3}\), we write it as \(2\ln x + \tfrac12\ln(x + 1) - \ln(x - 3)\). And to combine \(\ln 5 + 2\ln 3 - \ln 15\), we go the other way: \(\ln\dfrac{5\cdot 3^2}{15} = \ln 3\).

Solving equations. Logarithms are the tool for getting a variable down from an exponent. To solve \(e^{5 - 3x} = 10\), take \(\ln\) of both sides: \(5 - 3x = \ln 10\), so \(x = \dfrac{5 - \ln 10}{3} \approx 0.899\). Going the other way, to solve \(\ln x = 4\), we exponentiate both sides: \(x = e^4\).

Change of base. A calculator usually has only \(\ln\) and \(\log_{10}\). For any other base we use \[\log_b x = \frac{\ln x}{\ln b}.\] For example, \(\log_5 20 = \dfrac{\ln 20}{\ln 5} \approx \dfrac{2.996}{1.609} \approx 1.861\).

The graph and limits of \(\ln x\). Since \(\ln x\) is the inverse of \(e^x\), its graph is the reflection of \(y = e^x\) about the line \(y = x\) (Figure 12.1). The domain is \((0, \infty)\), the range is all real numbers, and it increases slowly. Reflecting the limits of \(e^x\), we get \[\lim_{x\to\infty}\ln x = \infty, \qquad \lim_{x\to0^+}\ln x = -\infty,\] so the \(y\)-axis is a vertical asymptote. Take note that \(\ln x\) grows to infinity, but very slowly: \(\ln(1\,000\,000) \approx 13.8\). That is why astronomers use logarithmic scales like magnitudes, which squeeze huge ranges of brightness into small numbers.

Common mistake There is no law for the log of a sum: \(\ln(x + y) \ne \ln x + \ln y\). Also, \(\dfrac{\ln x}{\ln y}\) is not \(\ln\dfrac{x}{y}\). Only products, quotients and powers inside the logarithm can be split.
Key equations
\[ \log_b x = y \iff b^y = x \]
\[ \ln(xy) = \ln x + \ln y, \quad \ln\frac{x}{y} = \ln x - \ln y, \quad \ln(x^r) = r\ln x \]
\[ \log_b x = \frac{\ln x}{\ln b} \]

6.4Derivatives of Logarithmic Functions

Now that we have logarithms, how do we differentiate them? Recall our formula for the derivative of an inverse function. Since \(y = \ln x\) means \(e^y = x\), we differentiate \(e^y = x\) implicitly with respect to \(x\): \[e^y\frac{dy}{dx} = 1 \;\Longrightarrow\; \frac{dy}{dx} = \frac{1}{e^y} = \frac{1}{x}.\] That is our first and most important formula.

Derivatives of logarithmic functions \[\frac{d}{dx}\ln x = \frac1x, \qquad \frac{d}{dx}\ln|x| = \frac1x, \qquad \frac{d}{dx}\log_b x = \frac{1}{x\ln b}.\] With the Chain Rule: \[\frac{d}{dx}\ln g(x) = \frac{g'(x)}{g(x)}.\]

The Chain Rule version is the one we will use most. In words: the derivative of the inside, divided by the inside. For example, \(\dfrac{d}{dx}\ln(x^3 + 1) = \dfrac{3x^2}{x^3 + 1}\), and \(\dfrac{d}{dx}\ln(\sin x) = \dfrac{\cos x}{\sin x} = \cot x\).

Why \(\ln|x|\)? The function \(\ln x\) only lives on \(x > 0\). But \(\ln|x|\) is defined for every \(x \ne 0\). For \(x < 0\), \(|x| = -x\), and the Chain Rule gives \(\dfrac{d}{dx}\ln(-x) = \dfrac{-1}{-x} = \dfrac1x\). So the same formula \(1/x\) works on both sides (Figure 12.3). This will matter a lot when we integrate \(1/x\) in Integral Calculus.

Simplify first! Before differentiating a complicated logarithm, use the laws of logarithms to break it apart. For \(y = \ln\dfrac{x^2}{\sqrt{x + 1}}\), we write \(y = 2\ln x - \tfrac12\ln(x + 1)\), so \(y' = \dfrac{2}{x} - \dfrac{1}{2(x + 1)}\). Much easier than the Quotient Rule inside the Chain Rule.

Exponentials with other bases. Since \(b^x = e^{x\ln b}\), the Chain Rule gives \(\dfrac{d}{dx}b^x = e^{x\ln b}\ln b = b^x\ln b\). For example \(\dfrac{d}{dx}10^x = 10^x\ln 10\), and \(\dfrac{d}{dx}3^{\sin x} = 3^{\sin x}\ln 3\cos x\).

Logarithmic differentiation. Some functions are a nightmare with the Product and Quotient Rules, like \(y = \dfrac{x^{3/4}\sqrt{x^2 + 1}}{(3x + 2)^5}\). Here is the trick, in steps:

  1. STEP 1: Take the natural logarithm of both sides and use the Laws of Logarithms to expand.
  2. STEP 2: Differentiate both sides implicitly with respect to \(x\) (the left side becomes \(y'/y\)).
  3. STEP 3: Solve for \(y'\) by multiplying by \(y\), then substitute the original \(y\) back.

For the example above: \(\ln y = \tfrac34\ln x + \tfrac12\ln(x^2 + 1) - 5\ln(3x + 2)\), so \(\dfrac{y'}{y} = \dfrac{3}{4x} + \dfrac{x}{x^2 + 1} - \dfrac{15}{3x + 2}\), and \(y' = \dfrac{x^{3/4}\sqrt{x^2 + 1}}{(3x + 2)^5}\left(\dfrac{3}{4x} + \dfrac{x}{x^2 + 1} - \dfrac{15}{3x + 2}\right)\).

Logarithmic differentiation is also the only way to handle a variable in both the base and the exponent, like \(y = x^{\sqrt x}\). Neither the Power Rule (fixed exponent) nor the exponential rule (fixed base) applies.

Common mistake Know which rule applies: \(\dfrac{d}{dx}x^n = nx^{n-1}\) needs a constant exponent; \(\dfrac{d}{dx}b^x = b^x\ln b\) needs a constant base. For \(x^x\) or \(x^{\cos x}\), use logarithmic differentiation. And \(\dfrac{d}{dx}e^e = 0\): it is just a constant.

The number \(e\) as a limit. Since the derivative of \(\ln x\) at \(x = 1\) is \(1\), the definition of the derivative says \(\displaystyle\lim_{h\to0}\frac{\ln(1 + h) - \ln 1}{h} = \lim_{h\to0}\ln(1 + h)^{1/h} = 1\). Exponentiating both sides, \[e = \lim_{h\to0}(1 + h)^{1/h} = \lim_{n\to\infty}\left(1 + \frac1n\right)^n.\] This is where \(e\) shows up in compound interest (Figure 12.4).

Key equations
\[ \frac{d}{dx}\ln x = \frac1x, \qquad \frac{d}{dx}\ln g(x) = \frac{g'(x)}{g(x)} \]
\[ \frac{d}{dx}b^x = b^x\ln b, \qquad \frac{d}{dx}\log_b x = \frac{1}{x\ln b} \]
\[ e = \lim_{h\to0}(1 + h)^{1/h} \]

★Key takeaways

  • log_b x is the exponent on b that gives x: log_b x = y ⇔ bʸ = x. ln x is the logarithm with base e.
  • The log of a product is a sum, of a quotient is a difference, and of a power is a multiple; there is no rule for ln(x + y).
  • ln x is the reflection of eˣ about y = x: domain (0, ∞), ln x → −∞ as x → 0⁺ and ln x → ∞ (slowly) as x → ∞.
  • d/dx ln g(x) = g′(x)/g(x): the derivative of the inside divided by the inside. Also d/dx ln|x| = 1/x for every x ≠ 0.
  • d/dx bˣ = bˣ ln b and d/dx log_b x = 1/(x ln b).
  • Logarithmic differentiation: take ln, expand, differentiate implicitly, multiply by y. It is required when the variable is in both the base and the exponent.

Example 12.1 Solving exponential and logarithmic equations

Solve each equation exactly. (a) \(3e^{2x - 1} = 12\)   (b) \(\ln(x + 2) + \ln(x - 1) = \ln 10\)

(Similar to Stewart §6.3, Examples 3 and 4)
Show solution (try it first)

Given: (a) an exponential equation; (b) a logarithmic equation.   Find: the exact value(s) of \(x\).

Plan: For (a), isolate the exponential, then take ln of both sides. For (b), combine the logs into one log, then drop the ln (it is one-to-one), and check the domain at the end.

Step 1. (a) Divide both sides by 3 to isolate the exponential:

\[e^{2x - 1} = 4\]

Step 2. Take \(\ln\) of both sides and use \(\ln(e^u) = u\):

\[2x - 1 = \ln 4\]

Step 3. Solve the linear equation:

\[x = \frac{1 + \ln 4}{2} \approx 1.193\]

Step 4. (b) Use \(\ln A + \ln B = \ln(AB)\) on the left side:

\[\ln\big[(x + 2)(x - 1)\big] = \ln 10\]

Step 5. Since \(\ln\) is one-to-one, the insides are equal. Expand and solve the quadratic:

\[(x + 2)(x - 1) = 10 \;\Longrightarrow\; x^2 + x - 12 = 0 \;\Longrightarrow\; (x + 4)(x - 3) = 0\]

Step 6. Check the domain: we need \(x + 2 > 0\) and \(x - 1 > 0\), so \(x > 1\). The root \(x = -4\) would put negative numbers inside the logarithms, so we reject it.

Answer: (a) \(\boxed{x = \tfrac{1 + \ln 4}{2} \approx 1.193}\); (b) \(\boxed{x = 3}\). That is our answer.

Check: (a) \(3e^{2(1.193) - 1} = 3e^{1.386} \approx 3(4.00) = 12\). ✓ (b) \(\ln 5 + \ln 2 = \ln 10\). ✓

Example 12.2 Simplify first, then differentiate

Differentiate \(y = \ln\dfrac{(x + 1)^3}{\sqrt{2x - 1}}\).

(Similar to Stewart §6.4, Example 2)
Show solution (try it first)

Given: \(y = \ln\dfrac{(x + 1)^3}{\sqrt{2x - 1}}\), \(x > \tfrac12\).   Find: \(\dfrac{dy}{dx}\).

Plan: Use the laws of logarithms to break the expression into simple pieces before differentiating. Then each piece is \(\ln g(x)\), whose derivative is \(g'/g\).

Step 1. Quotient becomes a difference, powers come down (\(\sqrt{2x - 1} = (2x - 1)^{1/2}\)):

\[y = 3\ln(x + 1) - \tfrac12\ln(2x - 1)\]

Step 2. Differentiate each term with \(\dfrac{d}{dx}\ln g = \dfrac{g'}{g}\):

\[y' = 3\cdot\frac{1}{x + 1} - \frac12\cdot\frac{2}{2x - 1}\]

Step 3. Simplify:

\[y' = \frac{3}{x + 1} - \frac{1}{2x - 1}\]

Answer: \(\boxed{y' = \dfrac{3}{x + 1} - \dfrac{1}{2x - 1}}\). That is our answer.

Check: Numerically at \(x = 1\): the formula gives \(\tfrac32 - 1 = 0.5\). A difference quotient, \([y(1.001) - y(0.999)]/0.002 \approx 0.500\). ✓

Example 12.3 Other bases

Differentiate (a) \(y = x\cdot 2^x\) and (b) \(y = \log_{10}(x^2 + 5)\).

(Similar to Stewart §6.4, Examples 5 and 6)
Show solution (try it first)

Given: (a) a product with an exponential of base 2; (b) a logarithm of base 10.   Find: \(y'\) for each.

Plan: Use \(\dfrac{d}{dx}b^x = b^x\ln b\) with the Product Rule in (a), and \(\dfrac{d}{dx}\log_b u = \dfrac{u'}{u\ln b}\) in (b).

Step 1. (a) Product Rule, with \(\dfrac{d}{dx}x = 1\) and \(\dfrac{d}{dx}2^x = 2^x\ln 2\):

\[y' = 1\cdot 2^x + x\cdot 2^x\ln 2\]

Step 2. Factor out \(2^x\):

\[y' = 2^x(1 + x\ln 2)\]

Step 3. (b) Let \(u = x^2 + 5\), so \(u' = 2x\). Apply the log rule for base 10:

\[y' = \frac{u'}{u\ln 10} = \frac{2x}{(x^2 + 5)\ln 10}\]

Answer: (a) \(\boxed{y' = 2^x(1 + x\ln 2)}\); (b) \(\boxed{y' = \dfrac{2x}{(x^2 + 5)\ln 10}}\). That is our answer.

Check: (b) can be checked by change of base: \(y = \dfrac{\ln(x^2 + 5)}{\ln 10}\), and \(\ln 10\) is just a constant, so \(y' = \dfrac{1}{\ln 10}\cdot\dfrac{2x}{x^2 + 5}\). Same result. ✓

Example 12.4 Logarithmic differentiation of a quotient

Use logarithmic differentiation to find \(y'\) for \(y = \dfrac{x^2\sqrt{4x + 1}}{(x^2 + 2)^3}\), \(x > 0\).

(Similar to Stewart §6.4, Example 7)
Show solution (try it first)

Given: a product and quotient of powers.   Find: \(y'\).

Plan: Follow the three steps of logarithmic differentiation: take ln and expand, differentiate implicitly, multiply by \(y\).

Step 1. Take \(\ln\) of both sides and expand with the Laws of Logarithms:

\[\ln y = 2\ln x + \tfrac12\ln(4x + 1) - 3\ln(x^2 + 2)\]

Step 2. Differentiate both sides with respect to \(x\). The left side gives \(y'/y\) by the Chain Rule:

\[\frac{y'}{y} = \frac{2}{x} + \frac12\cdot\frac{4}{4x + 1} - 3\cdot\frac{2x}{x^2 + 2} = \frac2x + \frac{2}{4x + 1} - \frac{6x}{x^2 + 2}\]

Step 3. Multiply by \(y\) and substitute the original function back:

\[y' = \frac{x^2\sqrt{4x + 1}}{(x^2 + 2)^3}\left(\frac2x + \frac{2}{4x + 1} - \frac{6x}{x^2 + 2}\right)\]

Answer: \(\boxed{y' = \dfrac{x^2\sqrt{4x + 1}}{(x^2 + 2)^3}\left(\dfrac2x + \dfrac{2}{4x + 1} - \dfrac{6x}{x^2 + 2}\right)}\). That is our answer.

Check: At \(x = 2\): \(y = \dfrac{4\cdot 3}{216} = \dfrac{1}{18}\) and the bracket is \(1 + \tfrac29 - 2 = -\tfrac79\), so \(y'(2) = -\tfrac{7}{162} \approx -0.0432\). A difference quotient on a calculator gives the same value.

Example 12.5 A variable in the base and the exponent

Find \(y'\) for \(y = (x^2 + 1)^x\), and evaluate \(y'(1)\).

(Similar to Stewart §6.4, Example 9)
Show solution (try it first)

Given: \(y = (x^2 + 1)^x\): both the base and the exponent change with \(x\).   Find: \(y'\) and \(y'(1)\).

Plan: Neither the Power Rule nor the exponential rule applies, so we use logarithmic differentiation.

Step 1. Take \(\ln\) of both sides; the exponent comes down:

\[\ln y = x\ln(x^2 + 1)\]

Step 2. Differentiate implicitly. The right side needs the Product Rule:

\[\frac{y'}{y} = 1\cdot\ln(x^2 + 1) + x\cdot\frac{2x}{x^2 + 1}\]

Step 3. Multiply by \(y = (x^2 + 1)^x\):

\[y' = (x^2 + 1)^x\left[\ln(x^2 + 1) + \frac{2x^2}{x^2 + 1}\right]\]

Step 4. Evaluate at \(x = 1\): \((1 + 1)^1 = 2\) and the bracket is \(\ln 2 + \tfrac22\):

\[y'(1) = 2(\ln 2 + 1) \approx 3.386\]

Answer: \(\boxed{y' = (x^2 + 1)^x\left[\ln(x^2 + 1) + \dfrac{2x^2}{x^2 + 1}\right]}\) and \(y'(1) = 2 + 2\ln 2 \approx 3.386\). That is our answer.

Check: \(y(1.001) = 2.002001^{1.001} \approx 2.003389\) and \(y(0.999) \approx 1.996618\); their difference divided by 0.002 is about 3.386. ✓
