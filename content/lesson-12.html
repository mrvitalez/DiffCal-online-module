6.3Logarithmic Functions

Recall from Module 11 that \(b^x\) (with \(b > 0\), \(b \ne 1\)) is either always increasing or always decreasing. So it passes the Horizontal Line Test, it is one-to-one, and it has an inverse. So, what do we call that inverse? Stewart §6.3 gives it a name: the logarithmic function with base \(b\), written \(\log_b\).

Definition For \(x > 0\): \(\quad\log_b x = y \iff b^y = x.\)

In words, \(\log_b x\) is the exponent we must put on \(b\) to get \(x\). Let's try two: \(\log_2 32 = 5\) because \(2^5 = 32\), and \(\log_{10} 0.01 = -2\) because \(10^{-2} = 0.01\). The cancellation equations from §6.1 now become \[\log_b(b^x) = x \ \text{ for every real } x, \qquad b^{\log_b x} = x \ \text{ for } x > 0.\] Take note that the domain of \(\log_b\) is \((0, \infty)\). Why? No power of a positive base is ever zero or negative, so we cannot take the logarithm of zero or of a negative number.

Laws of Logarithms For \(x, y > 0\) and any real \(r\): \[\log_b(xy) = \log_b x + \log_b y, \quad \log_b\frac{x}{y} = \log_b x - \log_b y, \quad \log_b(x^r) = r\log_b x.\]

These come straight from the laws of exponents. The first one is just \(b^{u+v} = b^u b^v\) read backwards. We use them in both directions: to expand a messy logarithm into simple pieces, like \(\ln\frac{x^3}{y^2} = 3\ln x - 2\ln y\), and to combine several logarithms into one. When combining, first move every coefficient up into an exponent, then use the product and quotient laws: \[2\ln x - \ln(x + 1) + 3\ln 2 = \ln x^2 - \ln(x + 1) + \ln 8 = \ln\frac{8x^2}{x + 1}.\]

Common mistake There is no law for the log of a sum: \(\ln(x + y) \ne \ln x + \ln y\). Also \(\dfrac{\ln x}{\ln y} \ne \ln x - \ln y\). The quotient law is about the log of a quotient, not a quotient of logs.

The natural logarithm. The most important base is the number \(e\) from Module 11. We write \(\ln x = \log_e x\), so \[\ln x = y \iff e^y = x, \qquad \ln(e^x) = x, \qquad e^{\ln x} = x \ (x > 0).\] In particular \(\ln 1 = 0\) and \(\ln e = 1\).

How do we solve an equation when the unknown sits in an exponent? Let's isolate the exponential first, then take \(\ln\) of both sides to bring the exponent down. For example, \(e^{4 - 2x} = 9\) gives \(4 - 2x = \ln 9\), so \(x = \frac{4 - \ln 9}{2} = 2 - \ln 3 \approx 0.901\).

Change of base. Calculators usually have only \(\ln\) and \(\log_{10}\). Any other base is reached by \[\log_b x = \frac{\ln x}{\ln b}.\] So \(\log_3 20 = \frac{\ln 20}{\ln 3} \approx 2.727\). Notice that this formula shows every log function is just a constant multiple of \(\ln x\) (Figure 12.2).

Graphs and limits. The graph of \(y = \ln x\) is the reflection of \(y = e^x\) in the line \(y = x\) (Figure 12.1). It passes through \((1, 0)\), it is increasing and concave downward, and \[\lim_{x\to\infty}\ln x = \infty, \qquad \lim_{x\to0^+}\ln x = -\infty,\] so the \(y\)-axis is a vertical asymptote. Does \(\ln x\) really go to infinity? Yes, but very slowly: \(\ln x\) only reaches 10 when \(x\) is about 22,000.

Key equations
\[ \log_b x = y \iff b^y = x \]
\[ \ln(xy) = \ln x + \ln y, \quad \ln\frac{x}{y} = \ln x - \ln y, \quad \ln(x^r) = r\ln x \]
\[ \ln(e^x) = x, \quad e^{\ln x} = x, \quad \log_b x = \frac{\ln x}{\ln b} \]

6.4Derivatives of Logarithmic Functions

Now that we have \(\ln x\), the natural question is: what is its derivative? Stewart §6.4 answers it with implicit differentiation from Chapter 2. Let \(y = \ln x\). Then \(e^y = x\). Let's differentiate both sides with respect to \(x\), using the Chain Rule on the left: \[e^y\,\frac{dy}{dx} = 1 \quad\Longrightarrow\quad \frac{dy}{dx} = \frac{1}{e^y} = \frac{1}{x}.\] Recall the inverse-function rule from Module 11: this is exactly the reciprocal of the derivative of \(e^y\).

Derivatives of logarithms \[\frac{d}{dx}\ln x = \frac1x, \qquad \frac{d}{dx}\ln u = \frac{1}{u}\,\frac{du}{dx}, \qquad \frac{d}{dx}\ln|x| = \frac1x \ (x \ne 0).\]

For example, for \(y = \ln(x^2 + 7)\), let \(u = x^2 + 7\); then \(y' = \frac{1}{u}\cdot 2x = \frac{2x}{x^2 + 7}\). For \(y = \ln(\sin x)\), \(y' = \frac{\cos x}{\sin x} = \cot x\). Why does \(\ln|x|\) also have derivative \(\frac1x\)? For \(x < 0\), \(\ln|x| = \ln(-x)\), whose derivative is \(\frac{-1}{-x} = \frac1x\) (Figure 12.3).

What \(\frac1x\) tells us about the graph. For \(x > 0\) the slope \(\frac1x\) is always positive, so \(\ln x\) is always increasing. But the slope shrinks toward 0 as \(x\) grows; that is why the curve rises so slowly. The second derivative \(-\frac{1}{x^2}\) is negative, so the graph is concave downward. For instance, the tangent line to \(y = \ln x\) at \((e, 1)\) has slope \(\frac1e\), so its equation is \(y - 1 = \frac1e(x - e)\), that is \(y = \frac{x}{e}\).

Simplify before differentiating. The laws of logarithms turn products, quotients and roots inside a log into sums. So \(\ln\frac{x^4}{\sqrt{x+1}} = 4\ln x - \frac12\ln(x + 1)\), and its derivative \(\frac4x - \frac{1}{2(x+1)}\) needs no Quotient Rule at all.

Other bases. Since \(b = e^{\ln b}\), we can write \(b^x = e^{x\ln b}\). The Chain Rule then gives the formula we promised in Module 11, and change of base handles \(\log_b\): \[\frac{d}{dx}b^x = b^x\ln b, \qquad \frac{d}{dx}\log_b x = \frac{1}{x\ln b}.\] For \(b = e\), \(\ln e = 1\) and these reduce to the natural formulas. For instance \(\frac{d}{dx}10^x = 10^x\ln 10\).

Logarithmic differentiation. How do we differentiate \(x^x\), where the variable is in both the base and the exponent? Or a long product of powers? Let's follow these steps.

  1. Step 1: Take \(\ln\) of both sides.
  2. Step 2: Expand with the laws of logarithms.
  3. Step 3: Differentiate implicitly; the left side gives \(\frac{y'}{y}\).
  4. Step 4: Multiply by \(y\) to solve for \(y'\).

For \(y = x^{x}\) (\(x > 0\)): \(\ln y = x\ln x\), so \(\frac{y'}{y} = \ln x + 1\) and \(y' = x^x(\ln x + 1)\).

Common mistake Tell the four cases apart: \(\frac{d}{dx}(\text{const})^{\text{const}} = 0\); \(\frac{d}{dx}x^n = nx^{n-1}\) (Power Rule); \(\frac{d}{dx}b^{x} = b^x\ln b\); and \(x^x\) needs logarithmic differentiation. Using the Power Rule on \(x^x\) or \(2^x\) is wrong.

The number \(e\) as a limit. Let \(f(x) = \ln x\). Then \(f'(1) = 1\), and by the definition of the derivative \[1 = \lim_{h\to0}\frac{\ln(1 + h) - \ln 1}{h} = \lim_{h\to0}\ln\big[(1 + h)^{1/h}\big].\] Because \(e^x\) is continuous, we can exponentiate both sides: \(\displaystyle e = \lim_{h\to0}(1 + h)^{1/h}\). With \(n = 1/h\), \(e = \lim_{n\to\infty}\left(1 + \tfrac1n\right)^n\) (Figure 12.4). Try it: \(n = 1000\) gives about 2.7169.

Key equations
\[ \frac{d}{dx}\ln x = \frac{1}{x}, \qquad \frac{d}{dx}\ln|x| = \frac{1}{x} \]
\[ \frac{d}{dx}\ln u = \frac{1}{u}\,\frac{du}{dx} \]
\[ \frac{d}{dx}b^x = b^x\ln b, \qquad \frac{d}{dx}\log_b x = \frac{1}{x\ln b} \]
\[ e = \lim_{h\to0}(1 + h)^{1/h} = \lim_{n\to\infty}\left(1 + \frac1n\right)^n \]

★Key takeaways

  • log_b x is the exponent that turns b into x; ln x = log_e x, so ln(eˣ) = x and e^(ln x) = x.
  • The laws of logarithms turn products, quotients and powers into sums, differences and multiples, but there is no law for ln(x + y).
  • To solve for an unknown in an exponent, isolate the exponential and take ln of both sides; use log_b x = ln x / ln b for other bases.
  • d/dx ln x = 1/x, d/dx ln u = u′/u, d/dx bˣ = bˣ ln b and d/dx log_b x = 1/(x ln b).
  • Logarithmic differentiation (take ln, expand, differentiate implicitly, multiply by y) handles messy products and variable exponents like x^x.
  • The number e is the limit of (1 + h)^(1/h) as h → 0, because the slope of ln x at x = 1 is 1.

Example 12.1 Unknown in the exponent

Solve \(3e^{2x - 1} = 12\) exactly, then give a decimal value.

(Similar to Stewart §6.3, Example 4)
Show solution (try it first)
Given
  • \(3e^{2x - 1} = 12\).
  • Asked: the exact value of \(x\) and a decimal.
Step 1: Isolate the exponential

Divide both sides by 3.

\[e^{2x - 1} = 4\]

Step 2: Take ln of both sides

Since \(\ln(e^u) = u\), the exponent comes down.

\[2x - 1 = \ln 4\]

Step 3: Solve for x

\[2x = 1 + \ln 4\]

\[x = \frac{1 + \ln 4}{2}\]

Step 4: Simplify with a law of logarithms

\(\ln 4 = \ln 2^2 = 2\ln 2\).

\[x = \frac{1 + 2\ln 2}{2} = \frac12 + \ln 2 \approx 0.5 + 0.6931 = 1.1931\]

Answer

So \(x = \frac12 + \ln 2 \approx 1.193\).

Check

\(2x - 1 = 1 + 2\ln 2 - 1 = \ln 4\), so \(3e^{\ln 4} = 3\cdot 4 = 12\). ✓

Example 12.2 A logarithmic equation (watch the domain)

Solve \(\ln(x + 2) + \ln(x - 1) = \ln 10\).

(Similar to Stewart §6.3, Example 3)
Show solution (try it first)
Given
  • \(\ln(x + 2) + \ln(x - 1) = \ln 10\).
  • Both logs need positive inputs: \(x + 2 > 0\) and \(x - 1 > 0\), so \(x > 1\).
  • Asked: all solutions \(x\).
Step 1: Combine the logs with the product law

\[\ln\big[(x + 2)(x - 1)\big] = \ln 10\]

Step 2: Drop the ln on both sides

\(\ln\) is one-to-one, so equal logs mean equal inputs.

\[(x + 2)(x - 1) = 10\]

Step 3: Expand and solve the quadratic

\[x^2 + x - 2 = 10\]

\[x^2 + x - 12 = 0\]

\[(x + 4)(x - 3) = 0\]

\[x = -4 \quad\text{or}\quad x = 3\]

Step 4: Check the domain

\(x = -4\) gives \(\ln(-2)\), which is undefined, so we reject it. \(x = 3\) satisfies \(x > 1\).

Answer

So the only solution is \(x = 3\).

Check

\(\ln(3 + 2) + \ln(3 - 1) = \ln 5 + \ln 2 = \ln 10\). ✓ Does that mean \(-4\) was a wrong calculation? No. It solves the quadratic, but not the original log equation.

Example 12.3 Expand first, then differentiate

Differentiate \(y = \ln\dfrac{(x + 1)^3}{\sqrt{2x - 1}}\) (for \(x > \tfrac12\)).

(Similar to Stewart §6.4, Example 4)
Show solution (try it first)
Given
  • \(y = \ln\dfrac{(x + 1)^3}{\sqrt{2x - 1}}\), \(x > \tfrac12\).
  • Asked: \(y'\).
Step 1: Expand with the laws of logarithms

Quotient law, then power law (\(\sqrt{2x-1} = (2x - 1)^{1/2}\)).

\[y = \ln(x + 1)^3 - \ln(2x - 1)^{1/2}\]

\[y = 3\ln(x + 1) - \tfrac12\ln(2x - 1)\]

Step 2: Differentiate each piece with d/dx ln u = u′/u

\[y' = 3\cdot\frac{1}{x + 1} - \frac12\cdot\frac{2}{2x - 1}\]

Step 3: Simplify

\[y' = \frac{3}{x + 1} - \frac{1}{2x - 1}\]

Answer

So \(y' = \dfrac{3}{x + 1} - \dfrac{1}{2x - 1}\).

Check

At \(x = 1\): \(y' = \frac32 - 1 = \frac12\). The Quotient Rule inside the log gives the same value after much more algebra.

Example 12.4 Bases other than e

Differentiate (a) \(y = x\cdot 2^{x}\) and (b) \(y = \log_{10}(x^2 + 5)\).

(Similar to Stewart §6.4, Examples 5 and 6)
Show solution (try it first)
Given
  • (a) \(y = x\cdot 2^x\), a product.
  • (b) \(y = \log_{10}(x^2 + 5)\), a composition with \(u = x^2 + 5\).
  • Rules: \(\frac{d}{dx}b^x = b^x\ln b\), \(\frac{d}{dx}\log_b u = \frac{1}{u\ln b}\,\frac{du}{dx}\).
Step 1: (a) Apply the Product Rule

\[y' = \frac{d}{dx}(x)\cdot 2^x + x\cdot\frac{d}{dx}\big(2^x\big)\]

\[y' = 1\cdot 2^x + x\cdot 2^x\ln 2\]

Step 2: (a) Factor out 2^x

\[y' = 2^x(1 + x\ln 2)\]

Step 3: (b) Find du/dx

\[u = x^2 + 5, \qquad \frac{du}{dx} = 2x\]

Step 4: (b) Apply the log rule with base 10

\[y' = \frac{1}{(x^2 + 5)\ln 10}\cdot 2x = \frac{2x}{(x^2 + 5)\ln 10}\]

Answer

(a) \(y' = 2^x(1 + x\ln 2)\). (b) \(y' = \dfrac{2x}{(x^2 + 5)\ln 10}\).

Check

Take note of two common slips: in (a), using the Power Rule on \(2^x\) (writing \(x2^{x-1}\)) is wrong; in (b), the factor \(\frac{1}{\ln 10}\) is needed, since only the natural log has the plain derivative \(\frac{u'}{u}\).

Example 12.5 Logarithmic differentiation of a product and quotient

Use logarithmic differentiation to find \(y'\) for \(y = \dfrac{x^2\sqrt{4x + 1}}{(x^2 + 2)^3}\), \(x > 0\).

(Similar to Stewart §6.4, Example 7)
Show solution (try it first)
Given
  • \(y = \dfrac{x^2\sqrt{4x + 1}}{(x^2 + 2)^3}\), \(x > 0\), so \(y > 0\).
  • Asked: \(y'\).
Step 1: Take ln of both sides

\[\ln y = \ln\frac{x^2(4x + 1)^{1/2}}{(x^2 + 2)^3}\]

Step 2: Expand with the laws of logarithms

\[\ln y = 2\ln x + \tfrac12\ln(4x + 1) - 3\ln(x^2 + 2)\]

Step 3: Differentiate implicitly

The left side gives \(\frac{y'}{y}\) by the Chain Rule.

\[\frac{y'}{y} = \frac{2}{x} + \frac12\cdot\frac{4}{4x + 1} - 3\cdot\frac{2x}{x^2 + 2}\]

\[\frac{y'}{y} = \frac{2}{x} + \frac{2}{4x + 1} - \frac{6x}{x^2 + 2}\]

Step 4: Multiply by y

\[y' = \frac{x^2\sqrt{4x + 1}}{(x^2 + 2)^3}\left(\frac{2}{x} + \frac{2}{4x + 1} - \frac{6x}{x^2 + 2}\right)\]

Answer

So \(y' = \dfrac{x^2\sqrt{4x + 1}}{(x^2 + 2)^3}\left(\dfrac{2}{x} + \dfrac{2}{4x + 1} - \dfrac{6x}{x^2 + 2}\right)\).

Check

At \(x = 2\): \(y = \frac{4\cdot 3}{216} = \frac{1}{18}\) and the bracket is \(1 + \frac29 - 2 = -\frac79\), so \(y' = -\frac{7}{162} \approx -0.0432\). A direct Quotient Rule computation gives the same value. Students often forget Step 4 and stop at \(\frac{y'}{y}\).

Example 12.6 Variable in the base and the exponent

Find \(y'\) for \(y = (x^2 + 1)^{x}\) and evaluate it at \(x = 1\).

(Similar to Stewart §6.4, Example 9)
Show solution (try it first)
Given
  • \(y = (x^2 + 1)^x\): the variable is in both the base and the exponent.
  • Asked: \(y'\) and \(y'(1)\).
Step 1: Take ln of both sides

Neither the Power Rule nor the \(b^x\) rule works alone, so let's take logarithms.

\[\ln y = \ln(x^2 + 1)^x = x\ln(x^2 + 1)\]

Step 2: Differentiate implicitly (Product Rule on the right)

\[\frac{y'}{y} = 1\cdot\ln(x^2 + 1) + x\cdot\frac{2x}{x^2 + 1}\]

\[\frac{y'}{y} = \ln(x^2 + 1) + \frac{2x^2}{x^2 + 1}\]

Step 3: Multiply by y

\[y' = (x^2 + 1)^x\left(\ln(x^2 + 1) + \frac{2x^2}{x^2 + 1}\right)\]

Step 4: Substitute x = 1

\[y'(1) = (1 + 1)^1\left(\ln 2 + \frac{2}{2}\right) = 2(\ln 2 + 1) = 2 + 2\ln 2 \approx 3.386\]

Answer

So \(y' = (x^2 + 1)^x\left(\ln(x^2 + 1) + \dfrac{2x^2}{x^2 + 1}\right)\) and \(y'(1) = 2 + 2\ln 2 \approx 3.386\).

Check

Numerically, \(y(1.001) \approx 2.003391\) and \(y(1) = 2\), so the slope is about \(\frac{0.003391}{0.001} \approx 3.39\). ✓
