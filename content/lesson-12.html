6.3Logarithmic Functions

In Module 11 you saw that \(a^x\) (with \(a > 0\), \(a \ne 1\)) is either always increasing or always decreasing, so it is one-to-one and has an inverse. Stewart §6.3 gives this inverse a name: the logarithmic function with base \(a\), written \(\log_a\).

Definition For \(x > 0\): \(\quad\log_a x = y \iff a^y = x.\)

In words, \(\log_a x\) is the exponent you must put on \(a\) to get \(x\). So \(\log_2 32 = 5\) because \(2^5 = 32\), and \(\log_{10} 0.01 = -2\) because \(10^{-2} = 0.01\). The cancellation equations from §6.1 become \[\log_a(a^x) = x \ \text{ for every real } x, \qquad a^{\log_a x} = x \ \text{ for } x > 0.\] The domain of \(\log_a\) is \((0, \infty)\): you cannot take the logarithm of zero or of a negative number, because no power of a positive base is zero or negative.

Laws of Logarithms For \(x, y > 0\) and any real \(r\): \[\log_a(xy) = \log_a x + \log_a y, \quad \log_a\frac{x}{y} = \log_a x - \log_a y, \quad \log_a(x^r) = r\log_a x.\]

These come straight from the laws of exponents; for example, the first one is \(a^{u+v} = a^u a^v\) read backwards. You will use them in both directions: to expand a messy logarithm into simple pieces, and to combine several logarithms into one. For example, expanding gives \(\ln\frac{x^3}{y^2} = 3\ln x - 2\ln y\), while combining gives \[2\ln x - \ln(x + 1) + 3\ln 2 = \ln x^2 - \ln(x + 1) + \ln 8 = \ln\frac{8x^2}{x + 1}.\] When combining, first move every coefficient up into an exponent, then use the product and quotient laws.

Common mistake There is no law for the log of a sum: \(\ln(x + y) \ne \ln x + \ln y\). Also \(\dfrac{\ln x}{\ln y} \ne \ln x - \ln y\); the quotient law is about the log of a quotient, not a quotient of logs.

The natural logarithm. The most important base is \(e\). We write \(\ln x = \log_e x\), so \[\ln x = y \iff e^y = x, \qquad \ln(e^x) = x, \qquad e^{\ln x} = x \ (x > 0).\] In particular \(\ln 1 = 0\) and \(\ln e = 1\). To solve an equation with the unknown in an exponent, isolate the exponential and take \(\ln\) of both sides. For example, \(e^{4 - 2x} = 9\) gives \(4 - 2x = \ln 9\), so \(x = \frac{4 - \ln 9}{2} = 2 - \ln 3 \approx 0.901\).

Change of base. Calculators usually have only \(\ln\) and \(\log_{10}\). Any other base is reached by \[\log_a x = \frac{\ln x}{\ln a}.\] So \(\log_3 20 = \frac{\ln 20}{\ln 3} \approx 2.727\). This formula also shows that every log function is just a constant multiple of \(\ln x\).

Graphs and limits. The graph of \(y = \ln x\) is the reflection of \(y = e^x\) in the line \(y = x\). It passes through \((1, 0)\), is increasing and concave downward, and \[\lim_{x\to\infty}\ln x = \infty, \qquad \lim_{x\to0^+}\ln x = -\infty,\] so the \(y\)-axis is a vertical asymptote. Although \(\ln x\) does go to infinity, it grows very slowly: \(\ln x\) only reaches 10 when \(x\) is about 22,000.

Key equations
\[ \log_a x = y \iff a^y = x \]
\[ \ln(xy) = \ln x + \ln y, \quad \ln\frac{x}{y} = \ln x - \ln y, \quad \ln(x^r) = r\ln x \]
\[ \ln(e^x) = x, \quad e^{\ln x} = x, \quad \log_a x = \frac{\ln x}{\ln a} \]

6.4Derivatives of Logarithmic Functions

Stewart §6.4 finds the derivative of the logarithm using implicit differentiation, which you learned in Chapter 2. Let \(y = \ln x\). Then \(e^y = x\). Differentiate both sides with respect to \(x\): \[e^y\,\frac{dy}{dx} = 1 \quad\Longrightarrow\quad \frac{dy}{dx} = \frac{1}{e^y} = \frac{1}{x}.\] (This is also the inverse-function rule of §6.1: the reciprocal of the derivative of \(e^y\).)

Derivatives of logarithms \[\frac{d}{dx}\ln x = \frac1x, \qquad \frac{d}{dx}\ln g(x) = \frac{g'(x)}{g(x)}, \qquad \frac{d}{dx}\ln|x| = \frac1x \ (x \ne 0).\]

For example, \(\frac{d}{dx}\ln(x^2 + 7) = \frac{2x}{x^2 + 7}\) and \(\frac{d}{dx}\ln(\sin x) = \frac{\cos x}{\sin x} = \cot x\). The \(\ln|x|\) formula follows because for \(x < 0\), \(\ln|x| = \ln(-x)\), whose derivative is \(\frac{-1}{-x} = \frac1x\).

What \(\frac{d}{dx}\ln x = \frac1x\) tells you about the graph. For \(x > 0\) the slope \(\frac1x\) is always positive, so \(\ln x\) is always increasing. But the slope shrinks toward 0 as \(x\) grows, which is why the curve rises so slowly; and the second derivative \(-\frac{1}{x^2}\) is negative, so the graph is concave downward. For example, the tangent line to \(y = \ln x\) at the point \((e, 1)\) has slope \(\frac1e\), so its equation is \(y - 1 = \frac1e(x - e)\), which simplifies to \(y = \frac{x}{e}\). Surprisingly, this tangent line passes through the origin. The absolute-value version is useful when the inside can be negative: \(\frac{d}{dx}\ln|2x - 5| = \frac{2}{2x - 5}\) for every \(x \ne \frac52\).

Simplify before differentiating. The laws of logarithms turn products, quotients and roots inside a log into sums. So \(\ln\frac{x^4}{\sqrt{x+1}} = 4\ln x - \frac12\ln(x + 1)\), whose derivative \(\frac4x - \frac{1}{2(x+1)}\) needs no Quotient Rule at all.

Other bases. Since \(a = e^{\ln a}\), we can write \(a^x = e^{x\ln a}\). The Chain Rule then gives the general formulas, and change of base handles \(\log_a\): \[\frac{d}{dx}a^x = a^x\ln a, \qquad \frac{d}{dx}\log_a x = \frac{1}{x\ln a}.\] For \(a = e\), \(\ln e = 1\) and these reduce to the natural formulas. For instance \(\frac{d}{dx}10^x = 10^x\ln 10\).

Logarithmic differentiation. For a complicated product or quotient of powers, or a function like \(x^x\) with the variable in both base and exponent: (1) take \(\ln\) of both sides; (2) expand with the laws of logarithms; (3) differentiate implicitly; (4) solve for \(y'\). For \(y = x^{x}\) (\(x > 0\)): \(\ln y = x\ln x\), so \(\frac{y'}{y} = \ln x + 1\) and \(y' = x^x(\ln x + 1)\).

Common mistake Tell the four cases apart: \(\frac{d}{dx}(\text{const})^{\text{const}} = 0\); \(\frac{d}{dx}x^b = bx^{b-1}\) (Power Rule); \(\frac{d}{dx}b^{x} = b^x\ln b\); and \(x^x\) needs logarithmic differentiation. Using the Power Rule on \(x^x\) or \(2^x\) is wrong.

The number e as a limit. Let \(f(x) = \ln x\). Then \(f'(1) = 1\), and by the definition of the derivative \[1 = \lim_{h\to0}\frac{\ln(1 + h) - \ln 1}{h} = \lim_{h\to0}\ln\big[(1 + h)^{1/h}\big].\] Because \(e^x\) is continuous, exponentiating gives \(\displaystyle e = \lim_{h\to0}(1 + h)^{1/h}\), or with \(n = 1/h\), \(e = \lim_{n\to\infty}\left(1 + \tfrac1n\right)^n\). Try it: \(n = 1000\) gives about 2.7169.

Key equations
\[ \frac{d}{dx}\ln x = \frac{1}{x}, \qquad \frac{d}{dx}\ln|x| = \frac{1}{x} \]
\[ \frac{d}{dx}\ln g(x) = \frac{g'(x)}{g(x)} \]
\[ \frac{d}{dx}a^x = a^x\ln a, \qquad \frac{d}{dx}\log_a x = \frac{1}{x\ln a} \]
\[ e = \lim_{h\to0}(1 + h)^{1/h} = \lim_{n\to\infty}\left(1 + \frac1n\right)^n \]

★Key takeaways

  • logₐ x is the exponent that turns a into x; ln x = logₑ x, so ln(eˣ) = x and e^(ln x) = x.
  • The laws of logarithms turn products, quotients and powers into sums, differences and multiples, but there is no law for ln(x + y).
  • To solve an equation with the unknown in an exponent, isolate the exponential and take ln of both sides; use logₐ x = ln x / ln a for other bases.
  • d/dx ln x = 1/x, d/dx ln|g(x)| = g′(x)/g(x), d/dx aˣ = aˣ ln a and d/dx logₐ x = 1/(x ln a).
  • Logarithmic differentiation (take ln, expand, differentiate implicitly) handles messy products and variable exponents like x^x.
  • The number e is the limit of (1 + h)^(1/h) as h → 0, which follows from the slope of ln x at x = 1 being 1.

Example 12.1 Solving exponential and logarithmic equations

Solve each equation exactly. (a) \(3e^{2x - 1} = 12\)   (b) \(\ln(x + 2) + \ln(x - 1) = \ln 10\)

(Similar to Stewart §6.3, Examples 3 and 4)
Show solution (try it first)

Strategy:

In (a), isolate the exponential, then take \(\ln\) of both sides to bring the exponent down. In (b), combine the logs into one with the product law, then use the fact that \(\ln\) is one-to-one. Check the domain at the end: logs need positive inputs.

Solution:

(a) Divide by 3: \(e^{2x - 1} = 4\). Take \(\ln\): \(2x - 1 = \ln 4\). So \[x = \frac{1 + \ln 4}{2} = \frac12 + \ln 2 \approx 1.193.\] (We used \(\ln 4 = \ln 2^2 = 2\ln 2\).)

(b) Product law: \(\ln\big[(x + 2)(x - 1)\big] = \ln 10\). Since \(\ln\) is one-to-one, the inputs are equal: \[(x + 2)(x - 1) = 10 \;\Longrightarrow\; x^2 + x - 2 = 10 \;\Longrightarrow\; x^2 + x - 12 = 0 \;\Longrightarrow\; (x + 4)(x - 3) = 0.\] So \(x = 3\) or \(x = -4\). But \(x = -4\) makes \(\ln(x + 2) = \ln(-2)\) undefined, so the only solution is \(x = 3\).

Check:

(a) \(2x - 1 = 2\ln 2 = \ln 4\), so \(3e^{\ln 4} = 3\cdot 4 = 12\). ✓ (b) \(\ln 5 + \ln 2 = \ln 10\). ✓ Forgetting to reject \(x = -4\) is the most common error in problems like (b).

Example 12.2 Derivatives with logarithms and other bases

Differentiate: (a) \(y = \ln\dfrac{(x + 1)^3}{\sqrt{2x - 1}}\)   (b) \(y = x\cdot 2^{x}\)   (c) \(y = \log_{10}(x^2 + 5)\)

(Similar to Stewart §6.4, Examples 2, 5 and 6)
Show solution (try it first)

Strategy:

(a) Expand with the laws of logarithms first so each piece is easy. (b) Product Rule with \(\frac{d}{dx}2^x = 2^x\ln 2\). (c) Chain Rule with \(\frac{d}{dx}\log_{10}u = \frac{1}{u\ln 10}\).

Solution:

(a) \(y = 3\ln(x + 1) - \tfrac12\ln(2x - 1)\). Then \[y' = \frac{3}{x + 1} - \frac12\cdot\frac{2}{2x - 1} = \frac{3}{x + 1} - \frac{1}{2x - 1}.\] (b) \(y' = 1\cdot 2^x + x\cdot 2^x\ln 2 = 2^x(1 + x\ln 2)\).

(c) With \(u = x^2 + 5\), \(u' = 2x\): \[y' = \frac{1}{(x^2 + 5)\ln 10}\cdot 2x = \frac{2x}{(x^2 + 5)\ln 10}.\]

Check:

In (a), doing the Quotient Rule inside the log gives the same result after a lot more algebra; at \(x = 1\) both give \(\frac32 - 1 = \frac12\). In (b), a common mistake is \(x\cdot x2^{x-1}\), using the Power Rule on \(2^x\). In (c), do not forget the factor \(\frac{1}{\ln 10}\): only the natural log has the plain derivative \(\frac{u'}{u}\).

Example 12.3 Logarithmic differentiation

(a) Use logarithmic differentiation to find \(y'\) for \(y = \dfrac{x^2\sqrt{4x + 1}}{(x^2 + 2)^3}\), \(x > 0\). (b) Find \(y'\) for \(y = (x^2 + 1)^{x}\) and evaluate it at \(x = 1\).

(Similar to Stewart §6.4, Examples 7 and 9)
Show solution (try it first)

Strategy:

Take \(\ln\) of both sides, expand into simple pieces, differentiate implicitly (the left side gives \(\frac{y'}{y}\)), then multiply by \(y\). In (b) the variable is in both base and exponent, so neither the Power Rule nor the \(a^x\) rule applies on its own.

Solution:

(a) \(\ln y = 2\ln x + \tfrac12\ln(4x + 1) - 3\ln(x^2 + 2)\). Differentiate: \[\frac{y'}{y} = \frac2x + \frac12\cdot\frac{4}{4x + 1} - 3\cdot\frac{2x}{x^2 + 2} = \frac2x + \frac{2}{4x + 1} - \frac{6x}{x^2 + 2}.\] So \(y' = \dfrac{x^2\sqrt{4x + 1}}{(x^2 + 2)^3}\left(\dfrac2x + \dfrac{2}{4x + 1} - \dfrac{6x}{x^2 + 2}\right)\).

(b) \(\ln y = x\ln(x^2 + 1)\). Product Rule on the right: \[\frac{y'}{y} = \ln(x^2 + 1) + x\cdot\frac{2x}{x^2 + 1}, \qquad y' = (x^2 + 1)^x\left(\ln(x^2 + 1) + \frac{2x^2}{x^2 + 1}\right).\] At \(x = 1\): \(y' = 2^1(\ln 2 + 1) = 2 + 2\ln 2 \approx 3.386\).

Check:

For (b), estimate numerically: \(y(1.001) = (2.002001)^{1.001} \approx 2.003391\) and \(y(1) = 2\), so the slope is about \(3.39\). ✓ Students often forget the final step of multiplying by \(y\), leaving only \(\frac{y'}{y}\).
