6.7Hyperbolic Functions

Certain combinations of \(e^x\) and \(e^{-x}\) appear so often in mathematics and engineering that they have their own names. Stewart §6.7 calls them the hyperbolic functions: \[\sinh x = \frac{e^x - e^{-x}}{2}, \qquad \cosh x = \frac{e^x + e^{-x}}{2}, \qquad \tanh x = \frac{\sinh x}{\cosh x},\] together with \(\operatorname{csch} x = 1/\sinh x\), \(\operatorname{sech} x = 1/\cosh x\) and \(\coth x = \cosh x/\sinh x\). Notice that \(\sinh 0 = 0\), \(\cosh 0 = 1\), \(\cosh x \ge 1\) for every \(x\), \(\sinh\) is odd and \(\cosh\) is even, and \(\tanh x\) always lies between \(-1\) and \(1\), approaching \(\pm 1\) as \(x \to \pm\infty\).

Identities. The most important one is \[\cosh^2 x - \sinh^2 x = 1.\] To see why, square: \(\cosh^2 x = \tfrac14\left(e^{2x} + 2 + e^{-2x}\right)\) and \(\sinh^2 x = \tfrac14\left(e^{2x} - 2 + e^{-2x}\right)\); subtracting leaves \(\tfrac44 = 1\). This explains the name: the point \((\cosh t, \sinh t)\) lies on the hyperbola \(x^2 - y^2 = 1\), just as \((\cos t, \sin t)\) lies on the circle \(x^2 + y^2 = 1\). Dividing the identity by \(\cosh^2 x\) gives \(1 - \tanh^2 x = \operatorname{sech}^2 x\). There are also addition formulas, such as \(\sinh(x+y) = \sinh x\cosh y + \cosh x\sinh y\).

Derivatives. Using \((e^{-x})' = -e^{-x}\) you get \[\frac{d}{dx}\sinh x = \cosh x, \qquad \frac{d}{dx}\cosh x = \sinh x, \qquad \frac{d}{dx}\tanh x = \operatorname{sech}^2 x,\] and \((\operatorname{csch} x)' = -\operatorname{csch}x\coth x\), \((\operatorname{sech} x)' = -\operatorname{sech}x\tanh x\), \((\coth x)' = -\operatorname{csch}^2 x\). The Chain Rule works as usual: \(\frac{d}{dx}\cosh(4x) = 4\sinh(4x)\).

Common mistake Trigonometry habits creep in. The derivative of \(\cosh x\) is \(+\sinh x\) (no minus sign), and the basic identity is \(\cosh^2 x - \sinh^2 x = 1\) (a minus sign, not a plus).

Inverse hyperbolic functions. \(\sinh\) and \(\tanh\) are one-to-one; \(\cosh\) is restricted to \([0,\infty)\). Because these functions are built from \(e^x\), their inverses can be written with logarithms. For \(y = \sinh^{-1}x\), write \(x = \frac{e^y - e^{-y}}{2}\) and multiply by \(2e^y\): \((e^y)^2 - 2x\,e^y - 1 = 0\). This is a quadratic in \(e^y\); since \(e^y \gt 0\), keep the root \(e^y = x + \sqrt{x^2+1}\). In this way: \[\sinh^{-1}x = \ln\big(x + \sqrt{x^2+1}\big), \qquad \cosh^{-1}x = \ln\big(x + \sqrt{x^2-1}\big)\ (x \ge 1), \qquad \tanh^{-1}x = \tfrac12\ln\frac{1+x}{1-x}\ (|x| \lt 1).\] Their derivatives are \(\dfrac{1}{\sqrt{1+x^2}}\), \(\dfrac{1}{\sqrt{x^2-1}}\) and \(\dfrac{1}{1-x^2}\). Compare \(\dfrac{d}{dx}\sin^{-1}x = \dfrac{1}{\sqrt{1-x^2}}\) and \(\dfrac{d}{dx}\tan^{-1}x = \dfrac{1}{1+x^2}\): only signs change.

The catenary. A flexible cable or chain hanging under its own weight between two supports takes the shape \(y = c + a\cosh(x/a)\), called a catenary (from the Latin word for chain). Power lines between poles are a familiar example. Near its lowest point a catenary looks like a parabola, but farther out it rises faster, because \(\cosh\) grows exponentially.

Key equations
\[ \sinh x = \frac{e^x - e^{-x}}{2}, \qquad \cosh x = \frac{e^x + e^{-x}}{2} \]
\[ \cosh^2 x - \sinh^2 x = 1 \]
\[ \frac{d}{dx}\sinh x = \cosh x, \quad \frac{d}{dx}\cosh x = \sinh x, \quad \frac{d}{dx}\tanh x = \operatorname{sech}^2 x \]
\[ \sinh^{-1}x = \ln\big(x + \sqrt{x^2+1}\big), \qquad \frac{d}{dx}\sinh^{-1}x = \frac{1}{\sqrt{1+x^2}} \]
\[ \frac{d}{dx}\cosh^{-1}x = \frac{1}{\sqrt{x^2-1}}, \qquad \frac{d}{dx}\tanh^{-1}x = \frac{1}{1-x^2} \]

6.8Indeterminate Forms and l'Hospital's Rule

How would you find \(\displaystyle\lim_{x\to 1}\frac{\ln x}{x - 1}\)? Top and bottom both approach 0, so the limit laws only give the meaningless \(0/0\). Such a limit is an indeterminate form of type \(\tfrac00\): it could turn out to be any number, or fail to exist. Similarly, \(\lim_{x\to\infty} \frac{\ln x}{x}\) is of type \(\tfrac{\infty}{\infty}\). Stewart §6.8 gives one powerful tool for both.

l'Hospital's Rule Suppose \(f\) and \(g\) are differentiable and \(g'(x) \ne 0\) near \(a\) (except possibly at \(a\)). If \(\lim_{x\to a} f(x) = 0\) and \(\lim_{x\to a} g(x) = 0\), or if both limits are \(\pm\infty\), then \[\lim_{x\to a}\frac{f(x)}{g(x)} = \lim_{x\to a}\frac{f'(x)}{g'(x)},\] provided the limit on the right exists (or is \(\pm\infty\)). The same is true for one-sided limits and for \(x \to \pm\infty\).

So \(\displaystyle\lim_{x\to 1}\frac{\ln x}{x-1} = \lim_{x\to 1}\frac{1/x}{1} = 1\). If the new quotient is still indeterminate, use the rule again: \(\displaystyle\lim_{x\to\infty}\frac{e^x}{x^2} = \lim_{x\to\infty}\frac{e^x}{2x} = \lim_{x\to\infty}\frac{e^x}{2} = \infty\). In the same way \(e^x\) beats every power of \(x\), and every power \(x^p\) with \(p \gt 0\) beats \(\ln x\): \(\lim_{x\to\infty}\frac{\ln x}{x^p} = 0\).

Cautions (1) Differentiate the top and the bottom separately; this is not the Quotient Rule. (2) Check the form first. \(\lim_{x\to 0}\frac{\cos x}{x + 1} = \frac11 = 1\) directly, but blindly "applying" the rule gives \(\lim_{x\to 0}\frac{-\sin x}{1} = 0\), which is wrong. (3) Sometimes the rule goes round in circles, and simple algebra works better.

Indeterminate products (\(0\cdot\infty\)). Rewrite \(fg\) as a quotient, \(\frac{f}{1/g}\) or \(\frac{g}{1/f}\). For example, \[\lim_{x\to 0^+} x\ln x = \lim_{x\to 0^+}\frac{\ln x}{1/x} = \lim_{x\to 0^+}\frac{1/x}{-1/x^2} = \lim_{x\to 0^+}(-x) = 0.\]

Indeterminate differences (\(\infty - \infty\)). Combine into a single fraction (common denominator, rationalising or factoring) to reach \(\tfrac00\) or \(\tfrac{\infty}{\infty}\). For \(\lim_{x\to 0^+}\left(\frac{1}{x} - \frac{1}{\sin x}\right)\), write the difference as \(\frac{\sin x - x}{x\sin x}\), which is of type \(\tfrac00\).

Indeterminate powers (\(0^0\), \(\infty^0\), \(1^\infty\)). For \(y = f(x)^{g(x)}\), take logarithms: \(\ln y = g(x)\ln f(x)\) is a product of type \(0\cdot\infty\). Find \(L = \lim \ln y\); then the original limit is \(e^{L}\). For \(\lim_{x\to 0^+}(1 + x)^{1/x}\) (type \(1^\infty\)): \(\ln y = \frac{\ln(1+x)}{x}\), and by the rule \(\lim_{x\to 0^+}\frac{1/(1+x)}{1} = 1\), so the limit is \(e^1 = e\).

Note Do not stop at \(\lim \ln y = L\). The last step, \(\lim y = e^{L}\), is easy to forget. Also, \(1^\infty\) is not automatically 1: the base approaches 1 while the exponent grows, and the two effects compete.
Key equations
\[ \lim_{x\to a}\frac{f(x)}{g(x)} = \lim_{x\to a}\frac{f'(x)}{g'(x)} \quad \text{(type } \tfrac00 \text{ or } \tfrac{\infty}{\infty}\text{)} \]
\[ fg = \frac{f}{1/g} \quad \text{(type } 0\cdot\infty\text{)} \]
\[ y = f(x)^{g(x)}:\quad \ln y = g(x)\ln f(x), \qquad \lim y = e^{\lim \ln y} \]

★Key takeaways

  • sinh x = (eˣ − e⁻ˣ)/2 and cosh x = (eˣ + e⁻ˣ)/2 satisfy cosh²x − sinh²x = 1.
  • (sinh x)′ = cosh x and (cosh x)′ = sinh x, with no minus sign; (tanh x)′ = sech²x.
  • Inverse hyperbolic functions are logarithms, e.g. sinh⁻¹x = ln(x + √(x² + 1)), with derivatives 1/√(1 + x²), 1/√(x² − 1), 1/(1 − x²).
  • l'Hospital's Rule replaces f/g by f′/g′, but only for the forms 0/0 and ∞/∞: always check the form first.
  • Turn 0·∞ into a quotient, combine ∞ − ∞ into one fraction, and handle 1^∞, 0^0, ∞^0 by taking logarithms and finishing with e^L.

Example 14.1 From one hyperbolic value to the others

Suppose \(\sinh x = \tfrac34\). Find (a) \(\cosh x\), (b) \(\tanh x\), and (c) the number \(x\) itself, in exact form.

(Compare Stewart §6.7, identities and inverse functions)
Show solution (try it first)

Strategy:

Use \(\cosh^2 x - \sinh^2 x = 1\) and the fact that \(\cosh x \gt 0\). For (c) use the logarithm form of \(\sinh^{-1}\).

Solution:

(a) \(\cosh^2 x = 1 + \sinh^2 x = 1 + \tfrac{9}{16} = \tfrac{25}{16}\). Since \(\cosh x \ge 1 \gt 0\), \(\cosh x = \tfrac54\).

(b) \(\tanh x = \dfrac{\sinh x}{\cosh x} = \dfrac{3/4}{5/4} = \dfrac35\).

(c) \(x = \sinh^{-1}\tfrac34 = \ln\left(\tfrac34 + \sqrt{\tfrac{9}{16} + 1}\right) = \ln\left(\tfrac34 + \tfrac54\right) = \ln 2\).

Check:

From the definitions: \(e^{\ln 2} = 2\) and \(e^{-\ln 2} = \tfrac12\), so \(\sinh(\ln 2) = \frac{2 - 1/2}{2} = \frac34\) and \(\cosh(\ln 2) = \frac{2 + 1/2}{2} = \frac54\). Both agree. Note that \(\cosh x\) cannot be \(-\tfrac54\), unlike \(\cos x\), which can be negative.

Example 14.2 Differentiating an inverse hyperbolic function

Find the derivative of \(y = \sinh^{-1}(\tan x)\) for \(-\tfrac{\pi}{2} \lt x \lt \tfrac{\pi}{2}\), and simplify.

(Compare Stewart §6.7, derivatives of inverse hyperbolic functions)
Show solution (try it first)

Strategy:

Use \(\frac{d}{du}\sinh^{-1}u = \frac{1}{\sqrt{1+u^2}}\) with \(u = \tan x\) and the Chain Rule, then simplify with the trigonometric identity \(1 + \tan^2 x = \sec^2 x\).

Solution:

\[\frac{dy}{dx} = \frac{1}{\sqrt{1 + \tan^2 x}}\cdot\frac{d}{dx}(\tan x) = \frac{\sec^2 x}{\sqrt{\sec^2 x}} = \frac{\sec^2 x}{|\sec x|}.\]

On \((-\pi/2, \pi/2)\), \(\cos x \gt 0\), so \(\sec x \gt 0\) and \(|\sec x| = \sec x\). Therefore \(\dfrac{dy}{dx} = \sec x\).

Check:

At \(x = 0\): \(y' = \sec 0 = 1\). Directly, near 0 we have \(\tan x \approx x\) and \(\sinh^{-1}u \approx u\), so \(y \approx x\) and the slope 1 makes sense. A common slip is to forget the inner derivative \(\sec^2 x\), giving \(1/\sqrt{1+\tan^2 x} = \cos x\) instead.

Example 14.3 Using l'Hospital's Rule several times, and an indeterminate power

Evaluate (a) \(\displaystyle\lim_{x\to 0}\frac{x - \sin x}{x^3}\) and (b) \(\displaystyle\lim_{x\to 0^+}(\cos x)^{1/x^2}\).

(Similar to Stewart §6.8, quotient and power examples)
Show solution (try it first)

Strategy:

(a) is of type \(\tfrac00\); apply the rule and check the form again after each step. (b) has base \(\to 1\) and exponent \(\to \infty\), type \(1^\infty\); take \(\ln\) first.

Solution:

(a) Each line below is still \(\tfrac00\) until the last: \[\lim_{x\to 0}\frac{x - \sin x}{x^3} = \lim_{x\to 0}\frac{1 - \cos x}{3x^2} = \lim_{x\to 0}\frac{\sin x}{6x} = \lim_{x\to 0}\frac{\cos x}{6} = \frac16.\]

(b) Let \(y = (\cos x)^{1/x^2}\). Then \(\ln y = \dfrac{\ln(\cos x)}{x^2}\), type \(\tfrac00\). By the rule (with the Chain Rule on top), \[\lim_{x\to 0^+}\frac{\ln(\cos x)}{x^2} = \lim_{x\to 0^+}\frac{-\sin x/\cos x}{2x} = \lim_{x\to 0^+}\left(-\frac{\sin x}{x}\cdot\frac{1}{2\cos x}\right) = -1\cdot\frac12 = -\frac12.\] So \(\displaystyle\lim_{x\to 0^+}(\cos x)^{1/x^2} = e^{-1/2} = \frac{1}{\sqrt e} \approx 0.607\).

Check:

Numerically, at \(x = 0.01\): \((x - \sin x)/x^3 \approx 0.16666\) and \((\cos 0.01)^{10000} \approx 0.6065\). Both match. In (b) the tempting answer \(1^\infty = 1\) is wrong; in (a), stopping at \(\frac{1 - \cos x}{3x^2}\) and plugging in gives \(0/0\), a sign that you must keep going.
